210. Course Schedule II Medium Graph Topological Sort
Key idea: This is Course Schedule, but return the order. In Kahn's algorithm a course is queued only after all its prerequisites are taken, so the order courses leave the queue is a valid schedule. If fewer than numCourses come out, there's a cycle: return [].

Problem View on LeetCode (opens in a new tab) ↗

Same input as Course Schedule: [a, b] means take b before a. Return an order that takes every course, or [] if there isn't one. Any valid order is accepted.

  • 1 <= numCourses <= 2000, 0 <= prerequisites.length <= numCourses × (numCourses − 1)
  • All pairs are different; a != b

Example: 2, [[1,0]] → [0,1]. 4, [[1,0],[2,0],[3,1],[3,2]] → [0,1,2,3] or [0,2,1,3]. 1, [] → [0].

Edge cases

Try these against your solution before reading the approaches.

Input Expected Why it's tricky
3, [[1,2],[2,1]] [] Kahn's algorithm that returns order without checking its length said [0]: course 0 is free, but 1 and 2 form a cycle. Wrong on 397 of 3049 tests.
2, [[1,0]] [0,1] The DFS finish order is backwards: returning it without reversing said [1,0]. Wrong on 1707 tests.
3, [] any order, like [0,1,2] No prerequisites: every course still has to be in the answer.
2000 courses in one chain [0,1,…,1999] The round-by-round approach takes 2000 rounds: 249 ms in Python.

Approach 1: Take Courses in Rounds

Each round, count the unfinished prerequisites of every course by scanning all pairs, and take (append) every course whose count is 0. If courses are left but none is ready, return [].

  • Easy to follow: each round is a "layer" of courses you could take together.
  • Recounts every pair each round; a chain needs one round per course.
Time O(n·(n + p)) Space O(n)

A 2000-course chain: Python 249 ms, Java 8.9 ms, C++ 6.1 ms.

Approach 2: DFS Finish Order, Reversed

Run the three-state DFS from Course Schedule. When a course finishes, everything that needs it has already finished, so add it to post. Reversed, post puts every course before the courses that need it.

  • A course still "on the path" means a cycle: return [].
  • The Java version fills the answer from the back instead of reversing.
Time O(n + p) Space O(n + p)

A 2000-course chain: Python 0.80 ms. Slowest over 3049 tests: Python 8.0 ms, Java 0.33 ms, C++ 0.33 ms.

Approach 3: Kahn's Algorithm (BFS) Optimal

Count each course's prerequisites (need) and queue the courses with none. Pop a course, append it to the order, and lower need for the courses after it; queue those that reach 0. Return the order if it has every course, else [].

  • The final length check is what catches cycles.
  • In Java the answer array doubles as the queue: no extra structure.
Time O(n + p) Space O(n + p)

A 2000-course chain: Python 0.74 ms. Slowest over 3049 tests: Python 4.1 ms, Java 0.27 ms, C++ 0.29 ms.

In practice No shortcut

Outside LeetCode, Python's graphlib.TopologicalSorter(graph).static_order() returns a valid order (map each course to its prerequisites), and raises CycleError on a cycle. C++ and Java have nothing built in.

On LeetCode, Approach 3 is what you'd write.
