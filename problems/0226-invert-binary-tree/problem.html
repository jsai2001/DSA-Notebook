226. Invert Binary Tree Easy Tree Depth-First Search Breadth-First Search
Key idea: Mirroring a tree means swapping the left and right child of every node. Visit each node once (by recursion or a queue) and swap its two children. O(n) time. With recursion, read both subtrees before changing either one.

Problem View on LeetCode (opens in a new tab) ↗

Invert a binary tree (mirror it left to right) and return its root.

  • The number of nodes is in [0, 100]
  • -100 <= Node.val <= 100

Example: [4,2,7,1,3,6,9] → [4,7,2,9,6,3,1]. [2,1,3] → [2,3,1]. [] → [].

Edge cases

Try these against your solution before reading the approaches.

Input Expected Why it's tricky
[1,2] [1,null,2] root.left = invert(root.right) then root.right = invert(root.left) reads the left side after it was overwritten: it said [1]. Wrong on 2846 of 3205 tests.
[4,2,7,1,3,6,9] [4,7,2,9,6,3,1] The same bug gives [4,7,7,9,9,9,9]: both children end up as the same node.
[73,22,null,2] [73,null,22,null,2] Swapping only the root's children isn't enough: 22's children must swap too.
[] [] An empty tree: return None, don't touch root.left.

Approach 1: Build a Mirrored Copy

mirror(node) makes a new node with the same value. Its left child is mirror(node.right) and its right child is mirror(node.left). The input tree stays as it was.

  • Useful when the caller still needs the original.
  • Uses a second tree's worth of memory.
Time O(n) Space O(n) for the new tree

Average over 3206 trees: Python 2.6 µs, C++ 0.30 µs, Java 0.18 µs. The slowest in Python and C++, because of the new nodes.

Approach 2: BFS With a Queue

Put the root in a queue. Pop a node, swap its children, and queue them. When the queue is empty, every node has been swapped.

  • No recursion, so a very deep tree can't overflow the stack.
  • The order doesn't matter: any visit order that reaches every node works.
Time O(n) Space O(width) for the queue

Average: Python 1.9 µs, C++ 0.23 µs, Java 0.43 µs.

Approach 3: Recursive Swap Optimal

Invert both subtrees and put each on the other side, in place. In Python, one tuple assignment reads both calls before assigning either side; Java keeps them in variables; C++ swaps the children first and then inverts each one.

  • The shortest code. With at most 100 nodes, the recursion depth is never a problem here.
Time O(n) Space O(height) call stack

Average: Python 1.6 µs, C++ 0.12 µs, Java 0.14 µs, the fastest in every language.

In practice No shortcut

No standard library has a binary tree to mirror. Approach 3 is what you'd write.

Comparison

Approach Technique Time Space Notes
Build a Mirrored Copy New tree, sides crossed O(n) O(n) Leaves the input unchanged
BFS With a Queue Pop, swap, queue the children O(n) O(width) No recursion
Recursive Swap Invert both sides, then cross them O(n) O(height) Expected answer
