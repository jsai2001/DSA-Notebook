312. Burst Balloons Hard Dynamic Programming Array
Key idea: Think about which balloon is burst last, not first. Pad the array with a 1 at each end. If k is the last balloon burst between lo and hi, its neighbours at that moment are exactly lo and hi, and the two sides are independent: dp[lo][hi] = max over k of dp[lo][k] + a[lo]·a[k]·a[hi] + dp[k][hi]. O(n³).

Problem View on LeetCode (opens in a new tab) ↗

Bursting balloon i earns nums[left] × nums[i] × nums[right], where left and right are its current neighbours (use 1 past either end). Burst them all, in the best order, and return the most coins.

  • 1 <= n <= 300, 0 <= nums[i] <= 100

Example: [3,1,5,8] → 167 (3·1·5 + 3·5·8 + 1·3·8 + 1·8·1). [1,5] → 10.

Edge cases

Try these against your solution before reading the approaches.

Input Expected Why it's tricky
[1,2,22] 88 Greedy "burst the smallest balloon first" said 68. Wrong on 805 of 1505 tests: there's no greedy rule here.
[7] 7 One balloon: 1 × 7 × 1.
[9,0,9] 90 Burst the 0 first (it earns nothing), so the two 9s become neighbours: 0 + 9·9·1 + 1·9·1.

Approach 1: Try Every Next Balloon (Bitmask Memo)

The state is "which balloons are still there". For each state, try each remaining balloon as the next one, using its current neighbours, and remember the best total for that state.

  • Thinking "first" forces you to remember the whole set: 2ⁿ states.
  • Works for about n ≤ 15, not for 300.
Time O(2ⁿ · n) Space O(2ⁿ)

Just 15 balloons: Python 104 ms, Java 5.4 ms, C++ 6.9 ms. Each extra balloon roughly doubles that.

Approach 2: Interval Recursion, Last Balloon

best(lo, hi) = the most coins from the balloons strictly between lo and hi. Pick k to be burst last: everything else in there is gone by then, so it earns a[lo]·a[k]·a[hi], and the two sides best(lo, k) and best(k, hi) don't affect each other.

  • Only about n²/2 intervals instead of 2ⁿ sets.
Time O(n³) Space O(n²)

300 balloons: Python 2.5 s, Java 18 ms, C++ 16 ms. The function calls make it slow in Python.

Approach 3: Interval DP, Bottom-Up Optimal

Fill dp[lo][hi] by increasing gap hi − lo. When you reach an interval, every shorter one inside it is already done.

  • The same formula as Approach 2, with loops instead of calls.
  • The same pattern solves matrix-chain multiplication and similar "split an interval" problems.
Time O(n³) Space O(n²)

300 balloons: Python 0.62 s, Java 4.5 ms, C++ 4.9 ms, the fastest in every language, and 4 times faster than Approach 2 in Python.

In practice No shortcut

Nothing built in. Approach 3 is what you'd write.
