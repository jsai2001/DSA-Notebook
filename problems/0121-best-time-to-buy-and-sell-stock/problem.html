121. Best Time to Buy and Sell Stock Easy Array Sliding Window
Key idea: For each day, the best sale on that day is its price minus the cheapest price before it. So walk once, keeping the lowest price seen so far and the best profit. Start the profit at 0: not trading is allowed. O(n) time, O(1) space.

Problem View on LeetCode (opens in a new tab) ↗

prices[i] is a stock's price on day i. Buy on one day and sell on a later day. Return the most profit you can make, or 0 if no trade makes money.

  • 1 <= prices.length <= 10⁵ and 0 <= prices[i] <= 10⁴.
  • Only one buy and one sell.

Examples: [7,1,5,3,6,4] → 5 (buy at 1, sell at 6); [7,6,4,3,1] → 0.

Edge cases

Try these against your solution before reading the approaches.

Input Expected Why it's tricky
[5] 0 One day: there's no later day to sell on.
[7,6,4,3,1] 0 Prices only fall. Taking highest minus lowest says 6 (it sells before buying); starting best below 0 says −1.
[2,4,1] 2 The lowest price (1) comes after the highest (4). Highest minus lowest says 3.
[3,8,1,5] 5 A new low (1) shows up later, but the best trade (3 → 8) was before it. Keep the best profit seen, not just the latest.
[3,3,3] 0 Flat prices: a trade makes 0, which is also the answer for not trading.
10⁵ days — Trying every pair is about 5 × 10⁹ pairs: around 5 minutes in Python (0.28 s at 3000 days, and it grows with n²).

Approach 1: Every Buy Day, Every Sell Day

Try buying on each day i and selling on each later day j, and keep the biggest prices[j] − prices[i]. Start at 0 for "don't trade".

  • j starts at i + 1: the sale must come after the buy.
Time O(n²) Space O(1)

Correct, and a good check for the faster ones, but far too slow at 10⁵ days.

Approach 2: Two Pointers, Buy and Sell

Keep a buy day and move the sell day right, one day at a time. If the sell day's price is lower than the buy day's, move the buy day there: a cheaper buy is better for every sale after it. Otherwise, check the profit.

  • The window buy..sell grows on the right, and jumps on the left to every new low.
Time O(n) Space O(1)

One pass: 7.9 ms for 10⁵ days in Python. The usual way to see it as a sliding window.

Approach 3: Lowest Price So Far Optimal

The same idea with only values, no days: for each price, first see what selling today would make (p − lowest), then let today lower lowest for the days after.

  • Profit first, then the low, so every sale uses an earlier buy day. (The other order also works here: it only adds a same-day trade worth 0.)
  • On day 0, lowest is infinity, so the profit is negative and best stays 0.
Time O(n) Space O(1)

Two lines in the loop (7.3 ms). The same shape is Maximum Subarray (53) on the daily changes, and the start of the other stock problems (122, 309, 714).

In practice Built-ins

In Python, itertools.accumulate(prices, min) gives the lowest price up to each day; subtract it from each price and take the max. C++ and Java have no direct equivalent worth using here: write the loop.

Time O(n) Space O(1) (both are lazy)

Here the low includes today, so a day can pair with itself and give 0; that's fine because 0 is always allowed. 7.8 ms for 10⁵ days.

Comparison

Approach Technique Time Space Notes
Every Pair All buy and sell days O(n²) O(1) About 5 minutes at 10⁵
Two Pointers Buy jumps to each new low O(n) O(1) The sliding-window view
Lowest So Far Profit, then update the low O(n) O(1) The usual answer
