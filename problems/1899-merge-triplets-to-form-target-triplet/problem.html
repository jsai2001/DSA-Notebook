1899. Merge Triplets to Form Target Triplet Medium Greedy Array
Key idea: Merging takes the max per position, so a value can only go up. Any triplet with a value above the target's can never be used. Every other triplet is safe to merge, so the answer is yes exactly when, for each of the 3 positions, some safe triplet hits the target value there. One pass, O(n).

Problem View on LeetCode (opens in a new tab) ↗

You may pick two triplets i and j and set triplets[j] to [max(ai, aj), max(bi, bj), max(ci, cj)], as often as you like. Can some triplet become exactly target?

  • 1 <= triplets.length <= 10⁵, every value between 1 and 1000

Example: triplets = [[2,5,3],[1,8,4],[1,7,5]], target = [2,7,5] → true (merge the first and last). [[3,4,5],[4,5,6]] with target [3,2,5] → false.

Edge cases

Try these against your solution before reading the approaches.

Input Expected Why it's tricky
[[1,3,1],[1,2,1]], target [1,2,1] true Merging everything, including [1,3,1], gives [1,3,1]. Skip triplets that go over the target. Without that filter it was wrong on 441 of 3,005 tests.
[[1,2,2],[1,1,1]], target [1,1,2] false [1,2,2] hits the 2 in the last spot, but its middle 2 is too big. Counting hits without the safe check said true: wrong on 457 of 3,005 tests.
[[1,1,1]], target [1,1,1] true No merge needed.

Approach 1: Every Reachable Triplet

Keep a set of every triplet some merges can make. Each new triplet adds itself and its merge with everything already in the set.

  • Each position of a merge is one of the n values, so the set can hold up to n³ triplets.
Time O(n⁴) at worst Space O(n³)

Random triplets in Python: 100 of them made 34,022 triplets (0.33 s), 200 made 300,076 (9.6 s).

Approach 2: Merge Every Safe Triplet

A triplet is safe when none of its values is above the target's. Merging safe triplets never overshoots, and more merging only gets closer. So merge all of them and compare with the target.

  • Skipping an unsafe triplet costs nothing: it could never be part of the answer.
Time O(n) Space O(1)

10⁵ triplets: Python 25 ms, Java 0.15 ms (1.4 ms on the first, cold run), C++ 0.14 ms.

Approach 3: Three Flags, Stop Early Optimal

Same idea without building the merge: for each safe triplet, set a flag for every position where it equals the target. Once all three flags are on, stop and return true.

  • The merged value of a safe position can only reach the target if some safe triplet has it exactly.
Time O(n) Space O(1)

10⁵ triplets with no answer: Python 16 ms, Java 0.68 ms (cold run), C++ 0.14 ms. When the target is easy to hit it stops early: Python 0.18 ms, C++ 0.002 ms.

In practice No shortcut

Nothing built in. Approach 3 is what you'd write.
