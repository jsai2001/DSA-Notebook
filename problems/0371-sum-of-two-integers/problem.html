371. Sum of Two Integers Medium Bit Manipulation Math
Key idea: a ^ b is the sum without carries, and (a & b) << 1 is the carries. Add those two the same way, until the carries are 0. In Python, mask to 32 bits every round, or a negative sum never stops.

Problem View on LeetCode (opens in a new tab) ↗

Return a + b without using the operators + and -.

  • -1000 <= a, b <= 1000

Example: a = 1, b = 2 → 3. a = 2, b = 3 → 5.

Edge cases

Try these against your solution before reading the approaches.

Input Expected Why it's tricky
a = -1, b = 1 0 The carry runs through all 32 bits: 32 rounds of the carry loop. Python ints have no bit 31 to fall off, so without a mask the carry moves up forever. That never stopped on 1,142 of 4,694 tests.
a = -1000, b = -1000 -2000 A negative answer. In Python, turn a 32-bit pattern with bit 31 set back into a negative number: ~(x ^ 0xFFFFFFFF).
a = 5, b = 0 5 No carries at all: the loop doesn't run.

Approach 1: Bit-by-Bit Full Adder

Add like on paper, in binary. For each of the 32 bits, from the lowest: the sum bit is x ^ y ^ carry (1 when an odd number of them are 1), and the new carry is 1 when at least two of them are 1.

  • This is how a ripple-carry adder circuit works.
  • Always 32 rounds.
Time O(1): 32 rounds Space O(1)

Average over 4,694 pairs: Python 4.9 µs, 3.5 times Approach 3. In Java and C++ every approach averaged under 0.1 µs, too fast to rank.

Approach 2: Carry Recursion

a + b = (a ^ b) + ((a & b) << 1): the bits without carries, plus the carries one place up. Call yourself on those two until the carry part is 0.

  • Each round, the lowest carry moves up at least one bit, so it ends within 32 rounds.
  • In C++ use unsigned: shifting a negative number left is undefined before C++20.
Time O(1): at most 32 rounds Space O(1): at most 32 calls deep

Python 1.9 µs on average. For random pairs in range it took 8.5 rounds on average, not 32.

Approach 3: Carry Loop Optimal

The same as Approach 2 as a loop: a, b = a ^ b, (a & b) << 1 until b is 0. In Python, mask both to 32 bits each round and fix the sign at the end.

  • In Java, int already wraps at 32 bits, so no mask is needed.
Time O(1): at most 32 rounds Space O(1)

Python 1.4 µs on average, the fastest of the three.

In practice Built-ins

You'd write a + b. If the rule is only "no + in your code", sum((a, b)), std::plus<int>()(a, b) and Integer.sum(a, b) follow the letter of it, not the point.

Time O(1) Space O(1)

Python 0.26 µs on average, 5 times faster than Approach 3.
