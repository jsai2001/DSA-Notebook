213. House Robber II Medium Array Dynamic Programming
Key idea: The houses form a circle, so the first and last houses are neighbours and can't both be robbed. Break the circle: solve House Robber once without the last house and once without the first, and take the bigger answer. One house alone is a special case.

Problem View on LeetCode (opens in a new tab) ↗

Same as House Robber, but the houses stand in a circle: house 0 and the last house are next to each other. You can't rob two neighbours. Return the most money you can rob.

  • 1 <= nums.length <= 100
  • 0 <= nums[i] <= 1000

Example: [2,3,2] → 3. [1,2,3,1] → 4. [1,2,3] → 3.

Edge cases

Try these against your solution before reading the approaches.

Input Expected Why it's tricky
[2,3,2] 3 Plain House Robber takes both 2s, which are neighbours on the circle: it said 4. Wrong on 1469 of 4509 tests.
[5] 5 Without the special case, both passes get an empty street: it said 0.
[3,10] 10 Leaving out both ends at once is too strict: it said 0. Wrong on 3564 tests. Leave out one end per pass.
[2,7,9,3,1] 11 On a straight street the answer is 2 + 9 + 1 = 12, but houses 0 and 4 touch here.

Approach 1: Recursion with Memo, Twice

best(i) = the most from house i to the end of the range: max(best(i + 1), nums[i] + best(i + 2)). Run it on houses 0..n − 2 and on 1..n − 1, each with a fresh memo.

  • Any valid choice skips house 0 or skips the last house, so one of the two passes covers it.
Time O(n) Space O(n)

At 100 houses: Python 56 µs. Average over 4509 tests: Java 0.32 µs, C++ 0.30 µs.

Approach 2: DP Table, Twice

Build House Robber's table for each range: dp[i] = max(dp[i − 1], dp[i − 2] + house), where dp[i] covers the first i houses of the range. Return the larger last entry.

  • Pass the range bounds instead of copying the array.
Time O(n) Space O(n)

At 100 houses: Python 19 µs. Average: Java 0.32 µs, C++ 0.30 µs.

Approach 3: Two Variables, Twice Optimal

House Robber needs only the last two answers, prev and cur. Run that loop on houses 0..n − 2 and on 1..n − 1, and return the bigger result.

  • The Python version slices (nums[:-1], nums[1:]) for clarity; C++ and Java pass bounds, so they use O(1) space.
Time O(n) Space O(1) (O(n) for Python's slices)

At 100 houses: Python 10 µs. Average: Java 0.23 µs, C++ 0.04 µs, the fastest in every language.

In practice No shortcut

Nothing built in. Reuse your House Robber function and call it twice: that's Approach 3.
