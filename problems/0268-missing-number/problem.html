268. Missing Number Easy Bit Manipulation Math Array
Key idea: XOR all the indexes 0..n and all the values together. Every number that's present shows up twice (once as an index, once as a value) and cancels, since x ^ x = 0. The missing number is what's left. O(n) time, O(1) space. The sum 0 + 1 + … + n minus the actual sum works the same way.

Problem View on LeetCode (opens in a new tab) ↗

nums holds n different numbers from the range 0..n. Exactly one is missing. Return it.

  • 1 <= n <= 10⁴, all values different

Example: [3,0,1] → 2. [0,1] → 2. [9,6,4,2,3,5,7,0,1] → 8.

Edge cases

Try these against your solution before reading the approaches.

Input Expected Why it's tricky
[0] 1 The missing number is n itself. The sorted scan without a final return n found no gap; wrong on 503 of 3007 tests.
[1] 0 0 is missing: check from 0, not 1.
[0,1] 2 The range is 0..n, so n = 2 counts.

Approach 1: Sort

After sorting, index i should hold i. The first index that doesn't is the answer; if every one does, the answer is n.

Time O(n log n) Space O(1) in place (O(n) for Python's sorted)

10⁴ values: Python 1.1 ms, Java 0.69 ms, C++ 0.17 ms, the slowest in every language.

Approach 2: Mark What's There

Mark every value as seen, then check 0, 1, …, n for the first one that isn't. The values are at most n, so C++ and Java use an array of n + 1 flags instead of a hash set.

Time O(n) Space O(n)

10⁴ values: Python 0.43 ms, Java 47 µs, C++ 8.7 µs.

Approach 3: XOR Optimal

Start with res = n (the one index with no slot). For each i, do res ^= i ^ nums[i]. Pairs cancel, and the missing number remains.

  • XOR can't overflow; a sum can in languages with fixed-size ints (here n ≤ 10⁴ keeps the sum small, so both work).
Time O(n) Space O(1)

10⁴ values: Python 0.40 ms, Java 27 µs, C++ 4.0 µs, the fastest in C++ and Java.

In practice Built-ins

In Python, Gauss's formula with sum: n(n + 1)/2 − sum(nums). Python ints don't overflow.

Time O(n) Space O(1)

Should pass on LeetCode: 34 µs for 10⁴ values, 12 times faster than the XOR loop in Python, because sum runs in C.
