48. Rotate Image Medium Array Matrix Math
Key idea: A clockwise turn is two flips you can do in place: transpose (swap m[i][j] with m[j][i], only for j > i), then reverse every row. O(n²) time, O(1) extra space. The cell at [i][j] ends up at [j][n − 1 − i].

Problem View on LeetCode (opens in a new tab) ↗

You're given an n × n matrix (an image). Rotate it by 90 degrees clockwise, in place: change the given matrix directly, without allocating another 2D matrix.

  • 1 <= n <= 20 and -1000 <= matrix[i][j] <= 1000.

Examples: [[1,2,3],[4,5,6],[7,8,9]] → [[7,4,1],[8,5,2],[9,6,3]]; [[5,1,9,11],[2,4,8,10],[13,3,6,7],[15,14,12,16]] → [[15,13,2,5],[14,3,4,1],[12,6,8,9],[16,7,10,11]].

Edge cases

Try these against your solution before reading the approaches.

Input Expected Why it's tricky
[[1]] [[1]] n = 1: no rings to turn and nothing to swap. The loops must simply not run.
[[1,2],[3,4]] [[3,1],[4,2]] The smallest real rotation: one ring, one cycle of four.
[[1,2,3],[4,5,6],[7,8,9]] [[7,4,1],[8,5,2],[9,6,3]] Odd n: the centre (5) stays. Transposing with j from 0 instead of i + 1 swaps every pair twice, leaving only the row reversal: [[3,2,1],[6,5,4],[9,8,7]], a mirror image.
The 4 × 4 example See above Even n with two rings: the inner ring's corners are a different cycle from the outer ring's.
[[7,7],[7,7]] [[7,7],[7,7]] All equal: looks unchanged even if the code is wrong. Test with distinct values.
Python: matrix = … Caller sees the change Assigning a new list to matrix only changes the local name; the caller's matrix stays as it was. Write into it: matrix[:] = ….
Counter-clockwise by mistake Clockwise Transpose then reverse each column, or reverse each row before transposing, turns it counter-clockwise: [[3,6,9],[2,5,8],[1,4,7]]. Check a corner: top-left must go to top-right.

Approach 1: Copy into a New Matrix

Work out where each cell goes and write it into a second grid. Turning clockwise, row i becomes column n − 1 − i, so matrix[i][j] lands at rotated[j][n − 1 − i].

  • Then copy the result back into matrix: the caller only sees that one.
Time O(n²) Space O(n²)

The easiest way to get the mapping right, and useful for checking the other two. But it allocates a second matrix, which the problem rules out.

Approach 2: Transpose, Then Reverse Each Row Optimal

A rotation is two reflections. Transposing flips the matrix over its main diagonal ([i][j] → [j][i]); reversing each row flips it left to right ([j][i] → [j][n − 1 − i]). Together: [i][j] → [j][n − 1 − i], exactly the clockwise turn.

  • Transpose only above the diagonal (j from i + 1): each pair is swapped once.
  • Both steps are plain swaps, so nothing extra is allocated.
Time O(n²) Space O(1)

The answer to remember: two easy loops instead of index arithmetic. For a counter-clockwise turn, transpose and then reverse each column (or reverse each row first, then transpose).

Approach 3: Rotate Four Cells at a Time

Under a 90° turn, cells move in cycles of four: top → right → bottom → left → top. Go ring by ring from the outside in; on each ring, every cell of the top side (except the last corner) starts one such cycle.

  • Save the top cell, then move left → top, bottom → left, right → bottom, and the saved top → right.
  • There are n / 2 rings; an odd n's centre cell never moves.
Time O(n²) Space O(1)

Every cell is moved exactly once (Approach 2 moves most cells twice), but the four index expressions are easy to get wrong. Good to know; Approach 2 is safer in an interview.

In practice Built-ins

In Python, zip(*matrix[::-1]) reads the rows bottom to top and column by column, which is the rotated matrix. In C++, std::reverse on the rows flips the matrix upside down (just swapping row pointers), and a transpose finishes the turn. Java has nothing built in for this.

Time O(n²) Space O(n²) in Python, O(1) in C++

Both pass. The Python line builds new lists, so it isn't really in place, and it must assign with matrix[:] =; plain matrix = leaves the caller's matrix untouched.
