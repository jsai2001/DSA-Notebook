238. Product of Array Except Self Medium Array Prefix Sum
Key idea: Everything except nums[i] is (the product of everything before i) × (the product of everything after i). One pass from the left fills the "before" products into the answer; one pass from the right multiplies in the "after" products with a single running number. No division, so zeros are no problem.

Problem View on LeetCode (opens in a new tab) ↗

Return answer where answer[i] is the product of every value in nums except nums[i]. Don't use division, and run in O(n).

  • 2 <= nums.length <= 10⁵, -30 <= nums[i] <= 30
  • Every product fits in a 32-bit integer

Example: [1,2,3,4] → [24,12,8,6]. [-1,1,0,-3,3] → [0,0,9,0,0].

Edge cases

Try these against your solution before reading the approaches.

Input Expected Why it's tricky
[-1,0] [0,-1] "Multiply everything, then divide by nums[i]" can't divide by the 0: it said [0,0]. Wrong on 950 of 3005 tests (and division isn't allowed anyway).
[0,0] [0,0] Two zeros: every product includes a zero.
[2,3] [3,2] The shortest input: each answer is just the other value.
10⁴ values - Multiplying the others for each i is 10⁸ steps: 3.3 s in Python.

Approach 1: Multiply the Others for Each i

For each position, multiply every value except the one at that position.

  • Correct with zeros, but O(n²) work.
Time O(n²) Space O(1) besides the answer

10⁴ values: Python 3.3 s, Java 94 ms, C++ 101 ms. At 10⁵ it's 100 times more: too slow.

Approach 2: Prefix and Suffix Arrays

Build left[i] (product of everything before i) from the left and right[i] (product of everything after i) from the right. Then answer[i] = left[i] × right[i].

  • left[0] and right[n − 1] are 1: nothing is before the first or after the last.
  • Two extra arrays of size n.
Time O(n) Space O(n)

10⁵ values: Python 13 ms, Java 0.37 ms, C++ 0.22 ms.

Approach 3: Answer Array + One Running Product Optimal

Fill the left products straight into the answer. Then walk from the back with right = 1: multiply answer[i] by right, then multiply right by nums[i] for the next position.

  • Update answer[i] before right. The other order includes nums[i]: [1,2,3,4] gave [24,24,24,24].
  • The answer array doesn't count as extra space, so this is O(1) extra.
Time O(n) Space O(1) besides the answer

10⁵ values: Python 11 ms, Java 0.25 ms, C++ 0.20 ms, the fastest in every language.

In practice No shortcut

itertools.accumulate(nums, operator.mul) builds the prefix products in Python, but you still need the suffix side. C++'s std::partial_sum with std::multiplies is the same idea.

Approach 3 is what you'd write.
