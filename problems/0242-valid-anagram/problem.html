242. Valid Anagram Easy String Hash Table Sorting
Key idea: Two strings are anagrams when every letter appears the same number of times in both. Check the lengths, count the letters of s in an array of 26, and count t back down. If a count ever goes below 0, they're not anagrams. O(n) time, O(1) space.

Problem View on LeetCode (opens in a new tab) ↗

Return true if t uses exactly the same letters as s, the same number of times, in any order.

  • 1 <= s.length, t.length <= 5 × 10⁴
  • Lowercase English letters only

Example: "anagram", "nagaram" → true. "rat", "car" → false.

Edge cases

Try these against your solution before reading the approaches.

Input Expected Why it's tricky
"ab", "a" false Counting t down without checking the lengths never goes below 0: it said true.
"aacc", "ccac" false Same letters, different counts. Comparing set(s) == set(t) says true.
"a", "a" true One letter.

Approach 1: Sort Both

Anagrams contain the same letters, so their sorted letters are equal. Sort both and compare.

  • One line in Python; works for any characters, not just a–z.
Time O(n log n) Space O(n)

5 × 10⁴ letters: Python 8.5 ms, Java 1.9 ms, C++ 0.81 ms, the slowest in every language.

Approach 2: Hash Map of Counts

Walk both strings together: +1 for the letter from s, −1 for the one from t. Anagrams end with every count at 0.

  • Handles any characters, including Unicode (LeetCode's follow-up).
Time O(n) Space O(k) for k different characters

5 × 10⁴ letters: Python 5.9 ms, Java 4.4 ms, C++ 0.31 ms. In Java the HashMap was slower than sorting.

Approach 3: Array of 26 Counts Optimal

After checking the lengths, count each letter of s into count[ch − 'a']. Then count t down. The moment a count drops below 0, return false.

  • The same lengths plus no negative count means every count ended at 0.
  • An index instead of a hash: no hashing, no objects.
Time O(n) Space O(1) (26 counters)

5 × 10⁴ letters: Python 5.9 ms, Java 1.0 ms, C++ 0.07 ms, the fastest in C++ and Java.

In practice Built-ins

Counter(s) == Counter(t) counts the letters of each and compares the two counts.

Time O(n) Space O(k)

Should pass on LeetCode: 2.8 ms for 5 × 10⁴ letters, the fastest in Python because the counting runs in C. C++ and Java have no equivalent; use Approach 3.
