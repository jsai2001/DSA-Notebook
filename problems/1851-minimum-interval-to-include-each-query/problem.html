1851. Minimum Interval to Include Each Query Hard Intervals Heap Sweep Line
Key idea: Answer the queries in sorted order, not the given order. Sweep left to right: push every interval that has started into a min-heap by size, pop tops that have already ended (later queries are bigger, so they're gone for good), and the top is the answer. O(n log n + q log q).

Problem View on LeetCode (opens in a new tab) ↗

The size of [l, r] is r − l + 1. For each query q, return the size of the smallest interval with l <= q <= r, or -1 if there is none.

  • 1 <= intervals.length, queries.length <= 10⁵, 1 <= l <= r <= 10⁷, 1 <= q <= 10⁷

Example: intervals = [[1,4],[2,4],[3,6],[4,4]], queries = [2,3,4,5] → [3,3,1,4]. intervals = [[2,3],[2,5],[1,8],[20,25]], queries = [2,19,5,22] → [2,-1,4,6].

Edge cases

Try these against your solution before reading the approaches.

Input Expected Why it's tricky
intervals = [[100,145]], queries = [151] [-1] The interval started but ended before the query. Reading the heap top without popping ended intervals gave 46, and was wrong on 2,383 of 3,004 tests.
intervals = [[1,1]], queries = [1,2] [1,-1] An interval of one point has size 1, not 0.
Repeated queries, like [5,5,5] the same answer three times Return answers in the queries' original order: sort a copy, then map back.

Approach 1: Check Every Interval per Query

For each query, look at every interval and keep the smallest that contains it.

  • Simple, but 10⁵ × 10⁵ checks at LeetCode's size.
Time O(n · q) Space O(1) besides the answer

3,000 intervals and 3,000 queries: Python 0.29 s, Java 26 ms, C++ 17 ms.

Approach 2: Smallest Interval First, Skip Answered Points

Sort the different query points, and the intervals by size. The smallest interval left is the answer for every unanswered point it covers. Find them with binary search, and skip answered points with a "next unanswered" pointer per point (union-find with path compression).

  • Each point is answered exactly once.
Time O(n log n + q log q) Space O(q)

10⁵ intervals and 10⁵ queries, average of 8 runs: Python 157 ms, Java 46 ms, C++ 21 ms. A little faster than Approach 3 in Python and C++, a little slower in Java.

Approach 3: Sweep With a Min-Heap Optimal

Sort intervals by left end and go through the queries in increasing order. Push each interval whose left end is at most q as (size, right). Pop the top while its right end is less than q. The top is then the smallest interval containing q.

  • An interval popped for one query has ended for every later query too, so each is pushed and popped once.
  • Intervals that ended but aren't on top can stay in the heap: they only matter once they reach the top.
Time O(n log n + q log q) Space O(n + q)

Same input: Python 165 ms, Java 38 ms, C++ 24 ms. About the same as Approach 2; the sweep is the answer most people expect.

In practice No shortcut

Nothing built in. Approach 3 is what you'd write.
