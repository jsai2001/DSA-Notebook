191. Number of 1 Bits Easy Bit Manipulation
Key idea: n & (n − 1) is n with its lowest 1 bit cleared. Repeat until n is 0 and count the rounds: the loop runs once per 1 bit, not once per bit position.

Problem View on LeetCode (opens in a new tab) ↗

Return how many 1 bits the binary form of the positive integer n has (its Hamming weight).

  • 1 <= n <= 2³¹ − 1

Example: 11 (1011) → 3. 128 → 1. 2147483645 → 30.

Edge cases

Try these against your solution before reading the approaches.

Input Expected Why it's tricky
2147483647 31 The most 1 bits possible: the worst case for Approach 3 (31 rounds).
1073741824 (2³⁰) 1 One high bit: Approach 2 still shifts 31 times (1.5 µs in Python), Approach 3 needs 1 round (0.16 µs).
11 3 In Java, if (n & 1 == 1) doesn't compile: == runs before &. Write (n & 1) == 1.

Approach 1: Test All 32 Bits

For i from 0 to 31, (n >> i) & 1 is bit i. Add them up.

  • Always 32 rounds, whatever n is.
Time O(1) (32 rounds) Space O(1)

Average per call over 20,006 inputs: Python 1.6 µs, Java 0.05 µs, C++ 0.02 µs.

Approach 2: Shift Until Zero

Add n & 1, shift n right, and stop when n is 0. The loop ends right after the highest 1 bit.

  • Fast for small numbers, still up to 31 rounds for big ones.
  • In Java use >>>: with >>, a negative number would never reach 0.
Time O(log n) Space O(1)

Average per call: Python 1.6 µs, Java 0.06 µs, C++ 0.04 µs. Random inputs are mostly large, so it saves little over Approach 1.

Approach 3: Clear the Lowest 1 (Brian Kernighan) Optimal

Subtracting 1 flips the lowest 1 bit to 0 and every 0 below it to 1. So n & (n − 1) keeps everything above that bit and clears the bit itself. Count how many times you can do this before n is 0.

  • Rounds = number of 1 bits, so sparse numbers finish almost at once.
  • The same trick checks for a power of two: n & (n − 1) == 0.
Time O(number of 1 bits) Space O(1)

Average per call: Python 0.98 µs, Java 0.06 µs, C++ 0.03 µs. On 2147483647 it's no faster (31 rounds, 1.9 µs in Python).

In practice Built-ins

Every language has a popcount: bin(n).count("1") or n.bit_count() (Python 3.10+), __builtin_popcount or C++20's std::popcount, and Java's Integer.bitCount. Many CPUs count bits in a single instruction.

Time O(1) Space O(1)

Should pass on LeetCode. Python's version averaged 0.24 µs, 4 times faster than Approach 3, because the counting happens in C.
