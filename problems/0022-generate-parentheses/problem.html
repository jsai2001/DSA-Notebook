22. Generate Parentheses Medium String Backtracking Dynamic Programming
Key idea: Build the string one bracket at a time and only make moves that can still lead to a valid answer: add '(' while opened < n, and add ')' only while closed < opened. Every string that reaches length 2n is valid, so nothing is ever thrown away.

Problem View on LeetCode (opens in a new tab) ↗

Given n pairs of parentheses, return every combination of well-formed (balanced) parentheses.

  • 1 <= n <= 8.
  • The answer can be in any order.

Examples: n = 3 → ["((()))","(()())","(())()","()(())","()()()"]; n = 1 → ["()"].

Edge cases

Try these against your solution before reading the approaches.

Input Expected Why it's tricky
n = 1 ["()"] The smallest input: a list with one string, not the string itself.
n = 2 ["(())","()()"] The two basic shapes: nested and side by side. Code that only nests, or only repeats "()", misses one.
n = 3 5 strings "(()())" is the one most often missed: a pair inside, next to another pair inside.
"())(()" (n = 3) Not in the answer Three of each bracket but invalid: the balance goes below 0 at the second ')'. Counting totals isn't enough.
"((())(" (n = 3) Not in the answer The balance never goes below 0, but it ends at 2: it must also end at exactly 0.
n = 2 by inserting "()" into "()" "()()" only once Inserting at the front or the back both give "()()". Build methods like this need a set to remove duplicates.
n = 8 1,430 strings The largest input. Brute force checks 2¹⁶ = 65,536 strings, which still passes; backtracking only builds the 1,430 valid ones.

Approach 1: Brute Force (Every String, Then Check)

Each of the 2n positions is '(' or ')', so there are 2²ⁿ strings. Make every one of them and keep the balanced ones.

  • A counter mask from 0 to 2²ⁿ - 1 covers every string: bit k decides position k.
  • A string is valid when its running balance (+1 for '(', -1 for ')') never goes below 0 and ends at 0. That's the check from Valid Parentheses with only one bracket type.
Time O(4ⁿ · n) Space O(n) besides the answer

Passes for n ≤ 8, but nearly all the work is wasted: for n = 8, only 1,430 of the 65,536 strings are valid (about 2%).

Approach 2: Backtracking with Counts Optimal

Instead of checking a finished string, never build an invalid one. A prefix can still become valid exactly when it hasn't used more than n opens and has never closed more than it opened.

  • Add '(' if opened < n.
  • Add ')' if closed < opened: there's an unmatched '(' for it to close.
  • When the path has 2n characters, it's valid by construction: add it.
  • After each choice, undo it (pop) so the other choice can be tried from the same prefix.
Time O(4ⁿ / √n) Space O(n) besides the answer

Every branch ends in a valid answer, so the work is proportional to the output: the number of answers is the n-th Catalan number, about 4ⁿ / (n√n), and each one takes O(n) to copy. This is the answer interviewers expect.

Approach 3: Build from Smaller Answers (by the First Pair)

Every valid string starts with '('. Its matching ')' splits the rest into two smaller valid strings: "(" + inside + ")" + after, where inside has c pairs and after has n - 1 - c.

  • dp[k] holds every answer for k pairs, with dp[0] = [""]. Build dp[1], then dp[2], up to dp[n].
  • For each c from 0 to k - 1, combine every string in dp[c] with every string in dp[k - 1 - c].
  • No duplicates: the first pair is fixed for any given string, so it's made by exactly one (c, inside, after).
Time O(4ⁿ / √n) Space O(4ⁿ / √n) for all the smaller tables

Same time as backtracking, but it keeps every smaller answer in memory. Worth knowing because the same split gives the Catalan recurrence C(k) = Σ C(c) · C(k - 1 - c), which also counts binary trees (Unique Binary Search Trees).

In practice No shortcut

No standard library generates balanced strings. Python's itertools.product("()", repeat=2 * n) lists every string, but that's just Approach 1 with a filter on top.

Write Approach 2. The pattern, "only make a choice if the partial answer can still be completed", is what makes backtracking fast in N-Queens, Sudoku and Combination Sum too.
