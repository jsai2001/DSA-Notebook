125. Valid Palindrome Easy String Two Pointers
Key idea: Put one pointer at each end and walk them inward. Skip anything that isn't a letter or digit, compare the rest lowercased, and stop at the first mismatch. One pass, O(n) time, O(1) extra space.

Problem View on LeetCode (opens in a new tab) ↗

Lowercase every letter and remove everything that isn't a letter or a digit. Return true if what's left reads the same forwards and backwards.

  • 1 <= s.length <= 2 × 10⁵
  • s is printable ASCII.

Example: "A man, a plan, a canal: Panama" → true ("amanaplanacanalpanama"). "race a car" → false ("raceacar").

Edge cases

Try these against your solution before reading the approaches.

Input Expected Why it's tricky
" " true Nothing is left after cleaning, and an empty string is a palindrome.
".," true All punctuation. Skipping without the i < j check runs off the end: Python raised IndexError here.
"0P" false Digits count. Keeping only letters (isalpha) leaves "p" and says true.
"A man, a plan, a canal: Panama" true Case doesn't matter. Comparing without lowercasing says false ('A' ≠ 'a').
"race a car" false Looks close, but "raceacar" breaks at 'e' vs 'a'.
"ab_a" true _ is not a letter or digit. A regex like \W keeps it (it counts _ as a word character) and says false.
"a." true One real character: the pointers meet on it, and it equals itself.
2 × 10⁵ characters, broken only in the middle false Worst case for the two-pointer exit: it has to walk all the way in.

Approach 1: Clean, Then Reverse and Compare

Do exactly what the problem says: build a copy with only the letters and digits, lowercased, then check that it equals its reverse.

  • One pass to build the copy, one to reverse it, one to compare.
  • In C++, pass unsigned char to isalnum and tolower: a negative char is undefined behavior there. The input is ASCII, so it's a habit, not a bug fix.
Time O(n) Space O(n) for the copy and its reverse

Easy to get right and fast enough: about 11 ms in Python, 1.3 ms in C++ and 9 ms in Java for 2 × 10⁵ characters here. The interviewer will usually ask next: can you do it without the copy?

Approach 2: Clean, Then Two Pointers

Build the same clean copy, but skip the reverse. Compare the first and last characters, then move both inward, and stop at the first mismatch.

  • No reversed copy, and a mismatch ends the check early.
  • The copy itself is still O(n).
Time O(n) Space O(n) for the copy

A step between the two ideas: same speed as Approach 1 here (about 13 ms in Python, 1.3 ms in C++ for 2 × 10⁵ characters). The cleaning pass always reads the whole string, even when the first pair already differs.

Approach 3: Two Pointers in Place Optimal

Work on s directly. Move i forward past anything that isn't a letter or digit, move j back the same way, then compare the two characters lowercased.

  • Keep i < j in the skip loops. Without it, a string of only punctuation runs past the end.
  • If the pointers meet on one character, it equals itself, so the answer is still right.
  • Returns at the first mismatch, without reading the rest.
Time O(n) Space O(1)

The answer interviewers expect. Fastest in C++ here (0.8 ms vs 1.3 ms for 2 × 10⁵ characters). In Python it's about the same as the others (14 ms), because every step runs as Python code; it wins on memory, not speed.

In practice Built-ins

Clean and compare in two lines: "".join(filter(str.isalnum, s)).lower() and [::-1] in Python, remove_if + std::equal with a reverse iterator in C++, replaceAll("[^A-Za-z0-9]", "") in Java.

Time O(n) Space O(n)

The Python one is the fastest Python version here (4.4 ms for 2 × 10⁵ characters), since the loops run inside C. Java's regex is the slowest Java one (20 ms). Fine for everyday code; in an interview, expect to be asked for Approach 3.

Comparison

Approach Technique Time Space Notes
Clean, Then Reverse and Compare Copy letters/digits, compare with reverse O(n) O(n) Simplest; two extra strings
Clean, Then Two Pointers Copy, then compare ends inward O(n) O(n) No reverse; still a copy
Two Pointers in Place Skip non-alphanumerics from both ends O(n) O(1) Expected answer; mind i < j while skipping
