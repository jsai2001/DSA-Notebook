746. Min Cost Climbing Stairs Easy Array Dynamic Programming
Key idea: To stand on step i, you came from step i − 1 or i − 2 and paid that step's cost. So dp[i] = min(dp[i−1] + cost[i−1], dp[i−2] + cost[i−2]), with dp[0] = dp[1] = 0. The top is step n, one past the last stair. Two variables are enough.

Problem View on LeetCode (opens in a new tab) ↗

cost[i] is what you pay to step off stair i; from there you climb one or two stairs. You can start on stair 0 or stair 1. Return the cheapest way to get past the last stair (the top).

  • 2 <= cost.length <= 1000
  • 0 <= cost[i] <= 999

Example: [10,15,20] → 15 (start on 15, jump to the top). [1,100,1,1,1,100,1,1,100,1] → 6.

Edge cases

Try these against your solution before reading the approaches.

Input Expected Why it's tricky
[5,3] 3 The top is past the last stair. Returning dp[n − 1] (standing on the last stair) said 0; wrong on 1618 of 3005 tests.
[5,3] 3 You may start on stair 1. Starting only on stair 0 said 5; wrong on 1773 tests.
[0,0] 0 Free stairs.
1000 stairs - The recursion goes about 1000 calls deep: without raising Python's limit it raised RecursionError.

Approach 1: Recursion with Memo

reach(i) = the cheapest way to stand on step i. Steps 0 and 1 are free. Otherwise it's the cheaper of coming from i − 1 (paying cost[i − 1]) or from i − 2. Start with reach(n).

  • Without the memo, the calls double like Fibonacci.
Time O(n) Space O(n)

1000 stairs: Python 0.33 ms, Java 7.5 µs, C++ 8.1 µs.

Approach 2: DP Table

Fill dp[0..n] from the bottom with the same rule, and return dp[n].

  • The table has n + 1 slots: the extra one is the top.
Time O(n) Space O(n)

1000 stairs: Python 0.14 ms, Java 3.2 µs, C++ 2.2 µs.

Approach 3: Two Variables Optimal

Each dp[i] uses only the two before it. Keep them as two and one, and shift them along.

  • The same pattern as Climbing Stairs and House Robber.
Time O(n) Space O(1)

1000 stairs: Python 98 µs, Java 1.0 µs, C++ 0.9 µs, the fastest in every language.

In practice No shortcut

Nothing built in. Approach 3 is four lines.
