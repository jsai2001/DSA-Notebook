Streaming responses FastAPI

FastAPI › 5. Sending Data › Streaming responses

For large or incremental data use StreamingResponse. JSON itself does not stream, but JSON Lines (NDJSON), one JSON object per line, does. The handler passes a generator; items are sent as produced, without buffering everything. Under the hood HTTP uses chunked transfer encoding (chunk size in hex, then data).
