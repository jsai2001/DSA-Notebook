Why JWT RESTful API

RESTful API › 7. Security: Registration, JWT, Login, Email › Why JWT

  • JSON Web Tokens handle authentication and authorization and keep the API stateless. APIs avoid server-side session plugins such as Flask-Login or Flask-User.
  • JWT is an open standard supported across languages, and works for web apps (React, Angular), mobile and desktop clients.
  • Planetary API rule: login is required to add, edit or delete planets. Login is not required to list planets, view details, or register.
  • Library: Flask-JWT-extended. It can be used as a black box; see jwt.io for internals.
