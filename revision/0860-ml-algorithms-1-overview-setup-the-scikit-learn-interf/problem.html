scikit-learn conventions (asked often):

  • X (capital) is a 2D matrix (rows = samples, columns = features). y is the label vector (Series, 1D). Use df[['col']] for X, df['col'] for y.
  • Attributes ending in _ (cluster_centers_, coef_, intercept_, components_, explained_variance_ratio_) exist only after .fit().
  • Same interface for every estimator, so you can swap the class and keep the rest of the code.
MethodUsed for
.fit(X)Unsupervised learning (clustering, PCA)
.fit(X, y)Supervised learning (regression, classification)
.predict(X)Predictions (labels or values)

.score(X, y)R² (regression) or accuracy (classification)
