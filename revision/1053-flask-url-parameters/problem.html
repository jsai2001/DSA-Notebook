Flask › 3. Routes, Views and URL Parameters › URL parameters

A static route per item does not scale:

A URL parameter captures a path variable, so one route handles many URLs:

  • <int:post_id> captures an integer, validates the type, and passes it as post_id.
  • posts.get() returns None instead of raising KeyError; always handle missing data with a 404.
