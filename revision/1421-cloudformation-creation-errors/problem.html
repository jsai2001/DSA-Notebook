Creation errors AWS CloudFormation

AWS CloudFormation › 10. Errors, Rollback and Troubleshooting › Creation errors

A stack built from a bad template goes from CREATE_IN_PROGRESS to CREATE_FAILED. CloudFormation shows the reason, for example: Properties validation failed for resource MyInstance, extraneous key AssociatePublicIpAddress is not permitted.

By default, everything created before the failure is rolled back automatically. The UI shows a Likely root cause section, which helps on complex templates, and a red error banner at the top. To fix it, delete the failed stack, correct the template and try again.
