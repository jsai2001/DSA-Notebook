Geographies, regions, region pairs AZ-900

AZ-900 › 5. Core architecture: regions, zones, resources › Geographies, regions, region pairs

  • Geography: boundary defined by country, continent or regulation, so data stays compliant with local rules.
  • Region: a physical location within a geography containing data centers and the facilities Azure needs.
  • Region pair: each region is paired with another, at least ~300 miles apart, for disaster recovery.
    • Automatic failover to the pair if you replicated resources.
    • Rolling updates: Microsoft updates one region of a pair, verifies it, then the other, so Azure updates cause no downtime.
