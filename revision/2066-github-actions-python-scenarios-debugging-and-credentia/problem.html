Q. Scenario: a workflow fails because of a dependency issue in a Python script. How do you debug it? Check the logs, reproduce locally with the same environment, pin versions in requirements.txt, add debug output, and install dependencies in a separate step to isolate issues.

Q. Scenario: a workflow exposes AWS credentials in logs. How do you secure it? Store credentials in secrets, make sure sensitive data is not printed, and check Python scripts for accidental logging.
