Ansible vs Terraform on AWS AWS

AWS › 21. Automating AWS: Credentials, Tools and Idempotency › Ansible vs Terraform on AWS

Q. What are the key differences between Ansible and Terraform when managing AWS resources?

  • Approach: Terraform is declarative (defines desired state). Ansible is procedural (defines steps to reach a state).
  • Focus: Terraform provisions infrastructure (for example EC2 instances). Ansible configures it (for example installing software on instances).
  • State: Terraform keeps a state file. Ansible is stateless.
  • Python integration: Terraform through python-terraform or subprocess. Ansible through the ansible Python API or custom modules.
