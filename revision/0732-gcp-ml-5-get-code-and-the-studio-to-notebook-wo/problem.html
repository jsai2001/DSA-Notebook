GCP for Machine Learning › 5. Get Code and the Studio-to-Notebook Workflow

Every prompt designed in Vertex AI Studio can be exported via Get Code as Python, Node.js, Java, curl, or Open in Colab Enterprise.

Challenge (select and test a GenAI model), solution flow:

  1. Model Garden → filter Generation → Language → pick Gemini Pro (newest, integrated in Studio; skip PaLM 2/text-bison as older, Codey as code-specific).
  2. View Details → Open Language Studio → paste the email prompt, iterate, save it.
  3. Get Code → Python with the model settings → Open Notebook (Colab Enterprise) → authenticate, pip install, run.

The generated code is the same pattern as the GenerationConfig snippet in Section 3, with settings max_output_tokens=1024, temperature=0.9, top_p=1.0 and an email-writing prompt.

ToolRole
Model GardenDiscover and select models
Vertex AI StudioDesign, test, save prompts
Get CodeExport prompt as code
Colab EnterpriseNotebook to build applications on the API

These three work together for rapid prototyping.
