Common error: spawn uv ENOENT Model Context Protocol

Model Context Protocol › 6. Testing with MCP Inspector and Troubleshooting › Common error: spawn uv ENOENT

Meaning: the app cannot find uv because the config uses the bare command uv, which is not on its PATH. Fix: get the absolute path (which uv or where uv, for example /Users/your-username/.local/bin/uv or C:\Users\your-username\.local\bin\uv.exe), put it in command, and restart Claude fully.
