Hierarchical structure via transitions:

Why policies: structured communication, logical information flow, mirrors org hierarchies, fewer wasted turns (lower token cost), forces review checkpoints.

Gotchas: loops → set max_round, check circular transitions, add termination. Wrong agent speaking → check the policy dictionary, give the manager an LLM config, make sure agent names/objects match the policy keys. Poor collaboration → sharpen system messages, adjust transitions, add intermediate agents, raise max_round. Give each agent one focused role with no overlapping responsibilities, and test agents individually first.
