Ansible › 9. Advanced Features and Scaling › Tower/AWX, SSH keys, check mode, limit

Q. What is Ansible Tower/AWX? A GUI, API and workflow layer over Ansible. Core Ansible is CLI only; Tower (commercial) and AWX (open source) add scheduling and RBAC. AWX can be installed with Docker or Kubernetes, then used to create projects, inventories and job templates (for example schedule a playbook daily).

Q. Configure Ansible with SSH keys? Generate a key (ssh-keygen), copy it to hosts (ssh-copy-id), and set it in the inventory or ansible.cfg.

Q. Purpose of the --check flag? A dry run: it simulates the playbook without making changes.
