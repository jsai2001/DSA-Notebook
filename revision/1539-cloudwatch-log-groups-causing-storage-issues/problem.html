Log groups causing storage issues AWS CloudWatch

AWS CloudWatch › 18. Troubleshooting Logs › Log groups causing storage issues

Q. Log groups are growing and costing storage. What do you do? Set a retention policy and export old data to S3.

Console: Logs > my-app-logs > Actions > Edit retention (7 days), and Actions > Export data to S3 with a time range and bucket.
