Q. How do you handle failures (for example continue on error)? Use continue-on-error: true on a step, or if: failure() to run a step after a failure. Combine them to handle errors gracefully, and avoid overusing continue-on-error because it can mask real issues.

Typical uses of continue-on-error: notifications to services that may be down, optional linting, and metrics collection that is not critical to deployment.
