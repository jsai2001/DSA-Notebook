Setup: enable the Cloud Tasks API, then create two queues.

Problem: sending emails in a loop is fine for few recipients, but with thousands or hundreds of thousands the loop times out.

PatternDescriptionScalability
DirectLoop and send synchronouslyDoes not scale, risks timeout
Task per emailOne Cloud Task per emailBetter, but the task-creation loop can still time out
Fan-outGenerator tasks each create the send tasks for a batchBest; parallel, App Engine auto-scales instances

Fan-out: create tasks that create tasks. Example: 100,000 emails with batch size 100 gives 1,000 generator tasks. Each receives startCount and batchSize, queries that slice from the DB, and creates the individual send-email tasks.
