High latency, concurrency limits and cold starts AWS Lambda

AWS Lambda › 13. On-call troubleshooting › High latency, concurrency limits and cold starts

Symptom: high Lambda latency. Enable X-Ray, optimize code and increase memory. Console: Configuration > Monitoring and operations tools > Enable X-Ray, then General configuration > memory (for example 512 MB), then analyze traces.

Symptom: hitting the concurrency limit. Check metrics, set reserved concurrency and optimize execution time.

Symptom: high cold start times. Enable Provisioned Concurrency, use a lightweight runtime and optimize initialization.
