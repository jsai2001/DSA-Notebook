Q. What is Python, and what are its key features? A high-level, interpreted language known for simplicity. Features: readable syntax, dynamic typing, extensive libraries, cross-platform, multi-paradigm (procedural, OOP, functional), garbage-collected.

Q. Python 2 vs Python 3? Python 2 reached end of life in 2020. In Python 3, print is a function, 5/2 gives 2.5 (float division), Unicode is native, range() replaces xrange(), and modern features such as f-strings exist.

Q. What are PEP 8 guidelines and why do they matter? Python's style guide: 4-space indentation, 79-character lines, snake_case for functions. It keeps code readable and consistent for collaboration.

Q. How is Python an interpreted language? The interpreter runs code line by line, converting it to bytecode that the Python Virtual Machine (PVM) executes. It is not compiled to machine code.

Q. How does Python handle memory management? Reference counting (memory is freed when the count hits 0) plus a garbage collector for cyclic references, available through the gc module.
