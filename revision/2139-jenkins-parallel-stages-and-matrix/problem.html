Parallel stages and matrix Jenkins

Jenkins › 3. Declarative Pipeline Basics › Parallel stages and matrix

Q. How do you run stages in parallel? Wrap stages in a parallel block so they run concurrently on available executors or agents, which cuts wall-clock time for independent work.

Q. What is the matrix directive? It runs a stage's steps across combinations of axes (for example OS by JDK version) in parallel without repeating stage code, ideal for cross-platform or multi-version testing. excludes skips invalid combinations.
