Quick recall AWS Lambda

AWS Lambda › 14. Key numbers to memorize › Quick recall

  • Serverless, event-driven, stateless, per-ms billing, Firecracker microVMs.
  • Init once (cache clients), Invoke per event, Shutdown cleanup.
  • Cold start fixes: Provisioned Concurrency, SnapStart, smaller package, lazy load.
  • Memory is the CPU dial; tune with Power Tuning.
  • Sync (API Gateway, ALB) waits. Async (S3, SNS, EventBridge) retries twice, then DLQ or destination. ESM (SQS, Kinesis, DynamoDB) polls batches.
  • DLQ holds the failed payload. Destinations route success and failure with full context.
  • Execution role is outbound. Resource policy is inbound.
  • Secrets go in Secrets Manager or SSM, fetched at Init.
  • A VPC needs ENIs (Hyperplane), NAT for internet and endpoints for private AWS access.
  • Concurrency = requests per second x duration. Reserved caps and guarantees. Provisioned pre-warms.
  • Observability: CloudWatch metrics and logs, X-Ray, Logs Insights, structured JSON.
  • Deploy with layers, versions and aliases, CodeDeploy canary or linear, and SAM.
  • Patterns: fan-out, queue buffer, idempotency, async offload.
