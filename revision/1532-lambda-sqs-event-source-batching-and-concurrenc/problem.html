Q34. How does Lambda poll SQS, and what are batch size vs batch window? Lambda runs pollers that call ReceiveMessage and invoke your function with a batch. Batch size is the maximum records per invocation (up to 10,000 for standard SQS, within a 6 MB payload). Batch window (MaximumBatchingWindowInSeconds, 0 to 300) is how long Lambda waits to gather a fuller batch before invoking. Successful batches are deleted from the queue automatically. Failures return to the queue after the visibility timeout.

Q40. How does Maximum Concurrency work with SQS as an event source? MaximumConcurrency (2 to 1000) on the SQS ESM caps how many concurrent invocations the poller drives. It protects downstream systems and stops a busy queue from consuming all account concurrency, without reserved concurrency (which throttled the pollers awkwardly).
