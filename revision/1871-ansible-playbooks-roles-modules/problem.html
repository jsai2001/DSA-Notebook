Playbooks, roles, modules Ansible

Ansible › 1. Ansible Fundamentals › Playbooks, roles, modules

Q. What is an Ansible Playbook? A YAML file defining tasks and workflows for automation (for example install Nginx, then start it). It is the blueprint for what happens on which hosts.

Q. Difference between Playbooks and Roles? A playbook is a full automation script. A role is a modular, reusable chunk (tasks, vars, templates) that playbooks call for structure.

Q. What are Ansible Modules? How do they work? Modules are scripts that perform tasks (file operations, package installs). Ansible ships them to the hosts over SSH, executes them, and cleans up. They are idempotent by design.

Q. What is an Inventory file and what is its purpose? It lists the hosts (IPs, names, groups) Ansible targets, static or dynamic, for example [webservers] web1.
