CrewAI › 6. Tools

Agents without tools are essentially smart chatbots. Tools (skills/functions for external actions) are what make an agent agentic.

SourceExamplesNotes
CrewAI built-inFileReadTool, GitHubSearchTool, SerperDevToolBundled in crewai[tools]
LangChain toolsTavilySearchTool, TwilioToolWeb browsing, SMS
Bridge toolsComposioTool250+ tools from Composio
CustomExtend BaseToolTurn Python classes into tools

Some tools are paid (DALL-E, Composio, Serper beyond its free tier). Import tools from crewai_tools, not crewai.

SerperDevTool is a Google Search API (free tier, key from serper.dev) and needs SERPER_API_KEY. It returns JSON (credits_used, results with title/link/snippet), which agents process automatically. A tool can be tested directly with .run() before assigning it.
