Prepare the repository and the job Jenkins

Jenkins › 6. Connecting Jenkins to GitHub › Prepare the repository and the job

Prerequisites: a publicly reachable Jenkins server and a GitHub account.

  1. In GitHub create or reuse a repository, add a Jenkinsfile (Add file, Create new file) and commit to main. Copy the HTTPS URL from the Code button.
  2. In Jenkins click New Item, name the job after the repo (for example connect-jenkins-to-github) and choose Pipeline.
  3. General: optionally add the repo URL under GitHub project for a clickable link.
  4. Build Triggers: enable GitHub hook trigger for GITScm polling.
  5. Pipeline: select Pipeline script from SCM, SCM Git, paste the URL, set Branch Specifier to main and keep Script Path Jenkinsfile.
  6. Save and click Build Now. A first successful build is required so Jenkins reads the repo configuration.
