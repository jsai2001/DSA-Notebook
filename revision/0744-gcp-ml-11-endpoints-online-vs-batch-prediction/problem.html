GCP for Machine Learning › 11. Endpoints: Online vs Batch Prediction

TypeMethodEndpoint neededUse case
OnlineSynchronous requests✅ deploy model to an EndpointReal-time apps (web, mobile)
BatchAsynchronous job❌ requested directly from the modelOne-off or scheduled bulk predictions

An Endpoint wraps compute (containers/VMs) around a model, so you do not set up Kubernetes or Cloud Run yourself.

Deployment flow: train → save artifacts → upload to Model Registry → manage versions → either online (create Endpoint → deploy → predict) or batch (submit job from the model → results).
