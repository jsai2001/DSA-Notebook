Deploy to GitHub Pages GitHub Actions

GitHub Actions › 8. Integrations: Packages, Pages, Terraform, CodeQL, Dependabot › Deploy to GitHub Pages

Pages hosts static sites from a repo. The workflow checks out the code, builds, uploads the output with actions/upload-pages-artifact and deploys with actions/deploy-pages. It needs pages: write and id-token: write. The repo must have Pages enabled (Settings > Pages > Source), the artifact path must match the build output directory, and single-page apps need a 404.html or routing rules.
