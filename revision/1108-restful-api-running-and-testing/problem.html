Running and testing RESTful API

RESTful API › 2. Project Setup, First Endpoint, Dev Server › Running and testing

  • Flask has a built-in dev server (Werkzeug). It is fragile and not for production.
  • Alternative: a PyCharm Flask-server Run Configuration pointing at app.py.
  • Why Postman: a browser only sends GET. APIs use GET/POST/PUT/DELETE for CRUD. Check body, status (200 OK) and the server log (verb, route, status).
  • Auto-reload: without it, every code change needs a manual restart. Set the Run Configuration environment variables FLASK_ENV=development and FLASK_DEBUG=True. Environment variables are also where config such as DB strings and API keys belongs.
