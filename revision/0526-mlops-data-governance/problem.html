Data governance MLOps

MLOps › 4. Data Processing & Management › Data governance

Ensures integrity, security and usability of data via people, policies and processes. It applies to all data (raw, intermediate, temporary, features, metadata), at rest or in motion.

ElementDetail
ConsistencyEveryone sees a consistent snapshot once data is committed
IntegrityComplete, accurate, conforming, error-free
SecurityOnly authorized users can view/create/modify/delete; protection from adversarial attacks
PrivacyProtect sensitive personal info; comply with laws/standards; redaction and obfuscation in the pipeline
ResiliencyBackups, standbys, redundancy; recovery to last known good state
Life cycle managementPolicies and automation from creation to cleanup

Implementing it:

  1. Identify a governance team (data owners and custodians).
  2. Reuse existing production-data policies.
  3. Identify all data elements in the ML pipeline.
  4. Classify data by security and privacy needs.
  5. Enforce through automation (scale, fewer human errors).
