LangChain Level Up › 4. RAG: Architecture & the Red30 Shoes Q&A Chatbot › 4.1 Why RAG / architecture

LLM limits: training-data cut-off, no specialized domain knowledge, no access to your private data. RAG combines retrieval with generation to fix this.

BenefitDescription
Up-to-date informationRetrieves context from external sources
Improved accuracyAnswers aligned with the actual data
Domain-specific knowledgeLLM knows your products, services, policies

Two components: information retrieval from an external source, and augmented generation (retrieved context added to the prompt).

StageWhat happens
1. Document indexingSplit documents into smaller chunks
2. Create embeddingsChunks → numeric vectors
3. Store in vector storeSave embeddings for efficient similarity search
4. User queryTriggers search
5. RetrievalSearch the store, retrieve relevant documents
6. Context integrationCombine retrieved docs with the original query
7. Augmented generationLLM answers using query + retrieved docs

Project: Q&A chatbot for fictitious Red30 Shoes, data source is a .txt FAQ (opening hours 24/7, return policy, shipping costs, product info). Layout: .env, requirements.txt, main.py, docs/ FAQ file, README. Extra install: pip install chromadb.
