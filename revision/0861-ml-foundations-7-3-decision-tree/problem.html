7.3 Decision tree ML Foundations

ML Foundations › 7. Model Creation › 7.3 Decision tree

Splits each feature at the best value to minimize error.

PropertyLinear regressionDecision tree
Needs standardized dataYesNo (value-based splits)
Categorical featuresNeeds encodingSome implementations handle them
Missing dataNoSome implementations handle it
Non-linear relationshipsNoYes (can re-split the same column)

R² ≈ 0.73, worse than linear regression. Cause: sklearn trees are unbounded by default, splitting until each leaf holds one row, so they memorize noise (overfitting). Pruning with max_depth fixes it:

max_depthR²State
None≈ 0.73Overfit
1 (decision stump)≈ 0.3Underfit
9> 0.73Good balance

Simplifying the tree improves test performance. This is counterintuitive and fundamental.
