Creating a metric filter AWS CloudWatch

AWS CloudWatch › 7. Metric Filters (Logs to Metrics) › Creating a metric filter

  1. CloudWatch > Logs > Log groups > select the group > Metric filters > Create metric filter.
  2. Confirm the log streams have recent events (use "Fail all requests" in the demo app to produce errors).
  3. Define the filter pattern. Options: match terms (error, warning), JSON properties (errorType = ValidationException), or status codes (statusCode = 500).

This matches JSON events whose errorType equals ValidationException.

  1. Test the pattern by pasting a real log entry into Test Pattern and confirming at least one row matches.
