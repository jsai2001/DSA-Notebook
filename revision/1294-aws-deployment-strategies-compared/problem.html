Q. What deployment strategies exist and how do they compare?

  1. Blue-Green (used): two environments (Blue is current, Green is new). Zero downtime, low MTTR, high availability. Tools: AWS ELB, Kubernetes, Terraform, CloudWatch.
  2. Canary: gradual rollout to a small user subset. Reduces change failure rate through early issue detection.
  3. Rolling: incremental pod updates in Kubernetes. Resource-efficient but risks compatibility issues.
  4. Feature flag: hide features behind toggles. Flexible, reduces change failure rate through selective rollout.
  5. A/B testing: compare versions for user feedback. Improves CSAT and NPS.
  6. Shadow: test the new version with duplicated traffic. Safe, with no user impact.
  7. Recreate: terminate the old version, deploy the new one. High risk and not used because of downtime.
