MLOps › 3. Requirements & Design › Designing the ML workflow

An ML workflow is a sequence of processes and iterations that develop, manage and improve ML products.

PracticeDetail
TraceabilityTrack data, models, processing steps; lineage helps measure progress and troubleshoot
Repeatability"Data as code" and "model as code" pipelines; rebuild from scratch with the same results
AutomationWherever possible
Access controlsWho can create, promote, use, discard artifacts
FlexibilityPlug-and-play; replace one part without affecting the rest
OwnershipDefined owner for each pipeline part
AutoscalingScale with data, models, teams

Decoupled sub-pipelines: data engineering, model development, product development, deployment & operations. Decoupling lets each evolve independently, progress in parallel, and be owned by its own sub-team. Tight coupling blocks everyone when one part has a problem.
