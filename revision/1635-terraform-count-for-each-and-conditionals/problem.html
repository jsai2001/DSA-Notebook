Terraform › 3. Variables and Outputs › count, for_each and conditionals

Q. How do you use count with resources? It multiplies the resource.

Q. What is for_each, and how does it differ from count? for_each iterates over a map or set with keys. count gives only a numeric index.

Q. How do you conditionally create resources? Use count with a condition.
