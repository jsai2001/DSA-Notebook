Q. How do timeout, retry and catchError work?

  • timeout: abort a block that exceeds a duration.
  • retry(n): re-run a block up to n times on failure.
  • catchError: continue the pipeline but set the build result (for example UNSTABLE) instead of failing hard.

Q. What is the difference between sh, bat and powershell steps? sh runs shell commands on Unix, Linux and macOS agents; bat runs Windows batch and powershell runs PowerShell on Windows agents. Pick by agent OS (target it with labels): sh will not work on a Windows agent and vice versa.
