4. PCA and Other Dimensionality Reduction ML Algorithms

ML Algorithms › 4. PCA and Other Dimensionality Reduction

PCA is an unsupervised dimensionality reduction technique. It finds linear combinations of the original features that capture the most variance; each is a principal component (PC). Use cases: visualizing high-dimensional data in 2D/3D, cutting columns to speed up other algorithms, finding which features carry the information. PCA assumes linear relationships, and PC1 will not always hold 90%+ of the variance.
