Docker agents Jenkins

Jenkins › 8. Agents and Distributed Builds › Docker agents

Prerequisites: enough storage and RAM on the Jenkins server for Docker images, Docker installed as a service (check docker --version and docker ps), and the Docker Pipeline plugin installed (Manage Plugins, Installed) to enable the docker agent keyword.

Pin a version (for example maven:3.8.4) instead of latest for consistency. Console Output shows Docker pulling and running the image, the commands inside the container, then the container being stopped and removed. Every run starts a fresh container, though the image may be reused.
