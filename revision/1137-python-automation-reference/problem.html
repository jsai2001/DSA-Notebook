Python Automation › 10. Selenium Browser Automation › Reference

MethodPurpose
driver.get(url)Load a page
driver.maximize_window()Maximize the browser so elements are visible
driver.execute_script(js)Run JavaScript (scrolling)
driver.quit()Close the browser
find_element(By.X, value)Find one element
element.send_keys("text")Type into a field
element.click()Click

Locator strategies: By.XPATH, By.ID, By.CLASS_NAME, By.CSS_SELECTOR. XPath copied from the browser breaks when the page changes, so prefer IDs when available.

IssueCauseFix
Element not foundWrong XPathRe-inspect and copy again
Element not clickableNot loaded yetUse an explicit wait
Stale elementPage refreshedFind the element again
Driver not foundMissing driverUse webdriver_manager
