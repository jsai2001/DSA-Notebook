Alarm on RUM JavaScript errors AWS CloudWatch

AWS CloudWatch › 11. Alarms › Alarm on RUM JavaScript errors

In the app monitor, Configuration > Alarms > Create a new alarm (same flow as the alarms page). Metric namespace AWS/RUM, filter by Application Name (demoapp), metric JsErrorCount, statistic Sum, period 1 minute, condition greater than 5 (the demo produces about 9 errors a minute), notify an existing SNS topic, name it (rumdemo). Start 100 requests and wait 1-2 minutes for In alarm.

If it stays at Insufficient Data, RUM may be ignoring repeated localhost sessions. Open the app in an incognito window, open DevTools > Network, restart the requests, and confirm calls reach the app monitor:
