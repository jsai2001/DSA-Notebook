Lambda use cases and when not to use it AWS Lambda

AWS Lambda › 1. What Lambda is › Lambda use cases and when not to use it

Use cases:

  • Data processing: enrich data streams or run real-time analytics (for example Kinesis records).
  • Web and mobile backends: replace EC2 for HTTP requests (API Gateway + Lambda for REST APIs).
  • Infrastructure management: trigger code that manages cloud resources, such as stopping unused EC2 instances.
  • Event-driven architectures: run business logic in response to events.

Poor fits:

  • Extreme real-time needs: Lambda typically answers in double-digit milliseconds, not single-digit.
  • Specialized hardware: generic hardware does not suit tasks such as video rendering.
  • 100% reliability: not for critical systems (for example life support) because of third-party dependencies.
