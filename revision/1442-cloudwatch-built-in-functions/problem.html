Built-in functions AWS CloudWatch

AWS CloudWatch › 9. Metric Math › Built-in functions

  • RATE returns the rate of change (difference between the latest and previous data point). Switch aggregation from average to sum for totals over a period such as 5 minutes.
  • DAY returns the day of week, 1 (Monday) to 7 (Sunday). Combine with IF to filter days.
  • FILL replaces missing data points so intermittent line graphs read as continuous.

The second expression keeps only weekend values (6 Saturday, 7 Sunday). The third fills gaps in the error series with 0.
