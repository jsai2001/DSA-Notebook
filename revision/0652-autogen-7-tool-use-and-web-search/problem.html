7. Tool Use and Web Search AutoGen

AutoGen › 7. Tool Use and Web Search

Tools are Python functions the LLM can invoke; they extend an LLM beyond text (calculations, web search, databases).

Two-agent pattern: the assistant (LLM) suggests which tool to call; the user proxy (no LLM) executes it. This separation is why registration happens twice (register_for_llm and register_for_execution).
