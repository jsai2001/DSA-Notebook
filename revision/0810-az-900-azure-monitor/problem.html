AZ-900 › 12. Monitoring tools › Azure Monitor

  • Metrics: real-time performance data (CPU, disk, network). Choose a scope, combine metrics that share a unit, pick a chart type (line, area, bar), pin to a dashboard.
  • Application Insights: automatic instrumentation for web apps, Functions and VMs. Tracks failed requests, response times, availability and page views. Available as soon as you create a web app, and supports on-prem VMs through the Application Insights Agent.
  • Log Analytics: historical analysis with Kusto Query Language (KQL).
