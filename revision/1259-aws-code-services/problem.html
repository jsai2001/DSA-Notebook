AWS › 9. DevOps and CI/CD › Code services

Q. What is AWS CodePipeline? A CI/CD service that integrates CodeCommit, CodeBuild and CodeDeploy.

Q. How do you build CI/CD with CodeBuild and CodeDeploy? Pipeline stages: Source (CodeCommit), Build (CodeBuild), Deploy (CodeDeploy).

Q. What is AWS CodeStar? It unifies pipeline setup: CodeCommit, CodeBuild and hosting.
