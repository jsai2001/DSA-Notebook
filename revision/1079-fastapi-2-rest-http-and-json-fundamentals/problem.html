FastAPI › 2. REST, HTTP and JSON Fundamentals

  • REST (Representational State Transfer) is a form of RPC: client sends a request, server replies. It works on collections of things and supports CRUD over HTTP, with JSON as the encoding.
  • Frameworks hide the HTTP/JSON layers most of the time, but they leak through.
