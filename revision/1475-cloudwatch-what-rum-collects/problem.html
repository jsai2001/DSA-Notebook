What RUM collects AWS CloudWatch

AWS CloudWatch › 14. CloudWatch RUM › What RUM collects

Real User Monitoring gathers performance data from the end-user perspective, which is more accurate than internal network testing. A small RUM SDK injected into the web app sends data to CloudWatch RUM, which stores it and provides visualization.

  • Page load times: how long users wait.
  • JavaScript errors during interactions.
  • HTTP requests: failed requests only.
  • Browsers and devices: which are most used and which have issues.
  • User behavior: time on pages, navigation, exit points.
