Q. What does pass do? It is a no-op placeholder for an empty code block.

Q. How do you swap two variables without a temp variable? Tuple unpacking.

Q. What is a module and how do you import one? A file of reusable code.

Q. What does if __name__ == "__main__": do? It runs the code only when the script is executed directly, not when imported.

Q. What are *args and **kwargs? *args collects variable positional arguments (a tuple). **kwargs collects variable keyword arguments (a dict).
