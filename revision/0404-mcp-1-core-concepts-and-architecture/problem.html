Model Context Protocol › 1. Core Concepts and Architecture

MCP (Model Context Protocol) is a simple protocol that gives any data source or software a natural-language interface for AI models. Anthropic open sourced it in November 2024. It lets a model retrieve data, run tools, use resources beyond its training data, and execute actions from natural-language commands.

Three defining traits:

  • Open source: anyone can build a server; community driven; free to use and modify.
  • Client agnostic: any LLM-powered app can hook in (Claude, ChatGPT, Cursor); no vendor lock-in.
  • Protocol based: standardized communication that supplies context and enables interaction with external resources.

USB-C analogy: before USB-C every device had its own connector and standard. MCP is USB-C for AI: one universal protocol between AI apps and data, working with any MCP-compatible app.
