Model Context Protocol › 9. Security › As a user, before installing an MCP

  • Trust the developers: who built it, is the source reputable, is the code open source and reviewed?
  • Understand capabilities: read-only retrieval is safest; write, modify/delete, and execute need much more trust.
  • Review permissions, read the docs, test in a safe environment, and monitor actions during use.
