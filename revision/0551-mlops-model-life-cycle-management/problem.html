MLOps › 6. Model Management › Model life cycle management

A model moves through states and transitions. Sample flow (customize per organization): Training → Created → Benchmarking (pass: Passed, fail: Discarded) → Integration testing (pass: Approved, fail: Archived) → Deployment (Deployed) → replaced by a new version (Retired).

StateHow the model gets there
CreatedTraining produces it
PassedPasses benchmarking
DiscardedFails benchmarking
ApprovedPasses integration testing
ArchivedFails integration testing
DeployedApproved model goes to production
RetiredA new version replaces it

Promotion best practices:

  • Define the life cycle and promotion criteria during requirements.
  • Base promotions on the performance and operational metrics from requirements.
  • Integration-test pass criteria include ML metrics and non-ML criteria (e.g. total issues found).
  • Automate promotions on metric thresholds. Add human oversight at first and reduce it as the pipeline matures.
  • Record decisions and promotion history in the registry.
