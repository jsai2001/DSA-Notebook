Vector Databases › 3. Vector databases: concepts › Key features

  • Data types: float vectors (dense embeddings), binary vectors (compressed), plus scalars (int, float, string).
  • CRUD on vectors. Consistency: transaction isolation exists but not RDBMS-level; tuned for read-heavy loads.
  • Distinguishing feature: built-in similarity search (L2, Cosine, IP) with no custom code.
