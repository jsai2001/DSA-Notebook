6. Prompt Engineering Case Studies (1/4) Fine-Tuning LLMs

Fine-Tuning LLMs › 6. Prompt Engineering Case Studies

Common thread: replace a generic prompt with a specific, contextual, structured one that guides the user or model.

Domain (company)ProblemPrompt fixResult
Customer service (Zendesk, Salesforce)Generic greeting led to meandering conversationsCategorised options that route users to the right channelFaster routing, better satisfaction
Healthcare (IBM Watson)Vague prompts gave ambiguous diagnostic helpStructured request for symptoms, tests, history, duration/severityMore accurate, actionable insights
Media (Google News)Summaries misleading, missed critical pointsAsk for key points, controversies, implicationsBalanced, more accurate digests
Education (Duolingo)Plain translation prompts were mechanical, low engagementScenario/context in the prompt ("as if explaining to a friend in a Paris cafe")Higher engagement, more relatable
