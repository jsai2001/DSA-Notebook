Failing to access RDS AWS Lambda

AWS Lambda › 13. On-call troubleshooting › Failing to access RDS

Symptom: Lambda failing to access RDS. Verify the VPC config (correct VPC, subnets and security groups), that the RDS security group allows the DB port (for example 3306), and IAM permissions. The role also needs the ENI actions for VPC access.
