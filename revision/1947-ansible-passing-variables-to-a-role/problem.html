Ansible › 8. Roles and Galaxy › Passing variables to a role

Q. Pass variables to a role? Variables passed in the playbook override the role defaults, so the same role serves different environments (for example port 8080 for dev and 443 for prod).

If port is not passed, the role falls back to the default port: 80.
