PropertyNotes
pathURL segment, relative to the parent route or to base href. '' is the root, ** is a wildcard, :id is a dynamic parameter
redirectTo/players is absolute (from base href), players is relative to the parent
pathMatch'prefix' (default) matches partially, 'full' requires an exact match. Needed on path: '' because the empty path prefixes every URL
loadChildrenlazy-load a module
loadComponentlazy-load a standalone component
titlestatic string, or a function receiving ActivatedRouteSnapshot (can use route params and DI). Sets the tab and bookmark name
datacustom key-value metadata: preload flags, roles, animation state
