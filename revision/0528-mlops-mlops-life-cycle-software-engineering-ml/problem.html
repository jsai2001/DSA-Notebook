Requirements & Design splits into two parallel tracks: non-ML development (APIs, services, DBs, UIs) and data engineering.

ActivityDescription
Requirements & DesignML project needs; design of ML and non-ML parts
Data EngineeringRaw data to usable features
Continuous TrainingBuild and refine the model until it meets requirements
Model GovernanceTrack, evaluate, manage models under a governance framework
Continuous IntegrationIntegrate model with non-ML code at regular intervals (sprint/week)
Package & DeliverBundle model plus non-ML code
Continuous DeploymentDeploy approved packages
Serving / MonitoringServe users; keep the model within performance thresholds
Feedback loopPerformance, drift and bias info goes to model governance and requirements
Data captureProduction feature/label data goes to data engineering for new datasets

If governance decides retraining is needed, it kicks off a new training cycle with new data.
