Install and create a MySQL database Database with Python

Database with Python › 4. MySQL with Python › Install and create a MySQL database

Install the Community Edition and set a root password. Add the MySQL bin folder to PATH (Mac: edit .zshrc, then restart the terminal). Log in with mysql -u root -p, which asks for the machine (sudo) password and then the MySQL root password. Keep the root password safe.
