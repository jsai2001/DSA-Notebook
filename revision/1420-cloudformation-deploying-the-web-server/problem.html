Deploying the web server AWS CloudFormation

AWS CloudFormation › 9. Web Server Template with Mappings (JSON) › Deploying the web server

Create an SSH key pair in the EC2 console first. Then CloudFormation, Create Stack, upload webserver.template, and name the stack (for example demo). Fill in the parameters: InstanceType from the dropdown (for example m3.medium), KeyName from your key pairs, and SSHLocation left at 0.0.0.0/0 or restricted to your IP. Leave defaults, then Next, Review, Create Stack.

The security group is created first and the instance after it, and the stack reaches CREATE_COMPLETE. Check both resources on the Resources tab, then open WebsiteURL from Outputs in a new tab. The server may need a few seconds to boot, so retry if needed.
