Logical IDs (labels) AWS CloudFormation

AWS CloudFormation › 3. Template Anatomy › Logical IDs (labels)

  • The label can be anything. It is used only inside the template and does not appear as the resource's name in the console.
  • Its purpose is readability and referencing between resources in the same template.
  • Prefix with My to tell your names from CloudFormation keywords, and use intercaps (MyInstance).
  • Every resource has a type string such as AWS::EC2::Instance or AWS::S3::Bucket.
