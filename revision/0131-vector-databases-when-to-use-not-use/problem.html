When to use / not use Vector Databases

Vector Databases › 3. Vector databases: concepts › When to use / not use

  • Use: semantic search, RAG, recommendations, image/video search, anomaly detection, deduplication.
  • Avoid: complex transactions, heavy aggregations/reporting/warehousing, purely relational data (users, orders, catalogs).
  • Hybrid approach: metadata in RDBMS, embeddings in the vector DB, join in the app.
  • Future: better transactions, more built-in functions, faster ingestion, lower memory, richer integrations, hybrid DBs.
