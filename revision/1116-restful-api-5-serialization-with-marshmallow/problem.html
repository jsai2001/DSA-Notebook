A list endpoint that returns ORM objects directly fails:

  • Result: TypeError: Object of type Planet is not JSON serializable. A 500 also appears if the DB was dropped and not recreated (flask db_create, flask db_seed).
  • Marshmallow converts SQLAlchemy objects into JSON-compatible dicts, with no manual loops. Flask-Marshmallow integrates it (installs marshmallow too). Initialize it after SQLAlchemy.
