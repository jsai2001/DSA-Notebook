AZ-900 › 8. Identity, access and security › Directory services

Authentication = who or what is accessing. Authorization = what that identity can do.

Azure AD (Entra ID) is a cloud identity service that authenticates and authorizes access to Azure, third-party and on-prem resources. It comes with your Azure subscription.

Identity typeMeaning
UsersPeople in your org or invited external users
Service principals (enterprise applications)Apps registered in Azure AD, so users sign in to external services with their Azure AD account. Revoking the user revokes access to all linked apps at once (for example AWS as an enterprise app)
Managed identitiesLet Azure resources authenticate to other Azure services without stored credentials

Azure AD vs Azure AD Domain Services (AD DS):

Azure ADAzure AD Domain Services
TypeCloud-native identityManaged Windows AD Domain Services in the cloud
ProtocolsOAuth, SAML, OpenID ConnectLDAP, Kerberos, NTLM
UseCloud apps, third-party apps, Azure resourcesLegacy apps that lack modern auth, integration with on-prem AD, lift-and-shift
ComponentsUsers, groups, service principals, managed identitiesManaged domains, replica sets
