AWS Lambda › 8. Storage, state and integrations › EFS vs /tmp vs S3

Q72. How do you attach an EFS volume to a function? Put the function in the same VPC as the EFS mount target, create an EFS Access Point, and set the function's FileSystemConfig to mount it at a local path (for example /mnt/data). The execution role needs EFS permissions. The function then reads and writes EFS like a shared, durable local file system.

Q73. When use /tmp, EFS or S3?

  • /tmp (512 MB to 10 GB): fast, local, ephemeral scratch space for one invocation or warm environment.
  • EFS: a shared, durable, low-latency POSIX file system across many concurrent functions. Use for large models, shared state, or when you need a file system. Requires VPC.
  • S3: durable, massively scalable object storage for inputs, outputs, artifacts and large blobs accessed over the API (no VPC needed).
