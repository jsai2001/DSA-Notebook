Microservices, serverless, migration and DR AWS

AWS › 8. Architecture and Design › Microservices, serverless, migration and DR

Q. How do you run microservices on AWS? ECS or EKS, Lambda, API Gateway and SQS. Scalable and independent.

Q. What is a serverless architecture on AWS? Lambda, API Gateway, DynamoDB, S3 and Step Functions.

Q. How do you migrate a monolith to AWS? Lift-and-shift to EC2, then refactor into microservices (ECS, Lambda).

Q. What is the disaster recovery approach in AWS? Multi-region deployment, S3 replication, RDS replicas and Route 53 failover.
