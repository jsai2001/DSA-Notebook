6. Autograd PyTorch Hands-On

PyTorch Hands-On › 6. Autograd

Tracks tensor operations and builds a dynamic computation graph; used to compute gradients of the loss w.r.t. parameters for backpropagation. Dynamic graph means flexible architectures (RNNs, transformers, conditional logic).

Training loop in 3 steps

StepActionPhase
1Compute loss between prediction and labelForward pass
2Compute gradients of loss w.r.t. parametersBackward pass (chain rule)
3Update weights with optimizer (SGD, Adam)Optimization

Forward: each layer's output feeds the next. Backward: traverse from the output, collecting gradients with the chain rule. A tensor with requires_grad=True is a tracked leaf; grad_fn records the op that created a tensor.
