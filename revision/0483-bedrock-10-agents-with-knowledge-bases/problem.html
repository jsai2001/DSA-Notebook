Amazon Bedrock › 10. Agents with Knowledge Bases

Two core components of modern Bedrock apps: agent (task execution) + knowledge base (grounded data).

Steps:

  1. Create an agent with a basic prompt, then Prepare and test. "What is Rust?" gives a generic answer from training data with no citations (the citation problem).
  1. In Agent Builder, scroll to Knowledge Bases, select your knowledge base, add knowledge base instructions (You are an expert programming assistant.), Add, Save and Exit, Prepare.
  2. Test again. The answer is grounded in your data and shows a clickable citation to the S3 source file.
AspectAgent onlyAgent + Knowledge Base

Agent design principles: keep agents small and specific, return structured output (JSON), ground with knowledge bases, test in the console first, orchestrate with code (Bash to prototype, Rust for production).
