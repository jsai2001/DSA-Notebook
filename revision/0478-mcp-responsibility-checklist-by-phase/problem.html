Model Context Protocol › 11. Conclusion: Mindset and Responsibility › Responsibility checklist by phase

  • Before building: define purpose and scope, identify risks, plan security, consider privacy, document intended behavior.
  • During development: least privilege, validate inputs, handle errors, add logging, test adversarial prompts, review security implications.
  • Before deployment: test thoroughly, document capabilities and limits, give usage instructions, set up monitoring, plan incident response.
  • After deployment: monitor usage and errors, respond to security issues quickly, update from feedback, maintain docs, communicate changes.
