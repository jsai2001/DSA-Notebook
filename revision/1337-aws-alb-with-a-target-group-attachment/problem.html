Q. How does an ALB with a target group work? Attachments link instances to the target group.

  • The ALB is created in the given subnets and is internet-facing.
  • The target group routes traffic to EC2 instances.
  • Request flow: a user request hits the ALB, the ALB evaluates rules and selects a target group, the target group routes to a healthy instance, and the instance returns the response through the ALB.
  • Benefits: scalability (traffic spread across instances), high availability (routes only to healthy instances) and flexibility (supports various targets).
