Hugging Face Transformers › 4. Natural Language Generation › Content generation (GPT-2)

GPT-2 uses only the decoder stack and can produce several different continuations from the same seed sentence. Model: gpt2.

  • num_return_sequences: number of separate outputs from the same input.
  • max_new_tokens: max tokens generated beyond the input.
  • set_seed(): reproducible output.
