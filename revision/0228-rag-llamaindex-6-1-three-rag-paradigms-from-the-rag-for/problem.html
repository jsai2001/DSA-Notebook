RAG with LlamaIndex › 6. Advanced RAG: Pre-Retrieval & Indexing › 6.1 Three RAG paradigms (from the "RAG for LLMs: A Survey" paper)

ParadigmWhat it does
Naive RAGIndex (clean, extract, chunk, vectorize) → retrieve (similarity between query and chunks) → generate (query + docs into a prompt)
Advanced RAGPre-retrieval: better indexing (granularity, structure, metadata, alignment, mixed retrieval), fine-tuned or dynamic embeddings. Post-retrieval: re-ranking (diversity, best-document placement, recomputed similarity), prompt compression (importance estimation, summarization)
Modular RAGAdds modules (search module, memory module), allows serialized pipelines or end-to-end training across modules, builds on Advanced RAG
Optimization areaTechniques
Pre-retrievalData granularity (standardize text, remove ambiguity, domain annotations); index structure (varied chunk sizes, multiple index paths, graphs); metadata (dates, chapters) for filtering; alignment (hypothetical questions matched to document content); mixed retrieval (keyword + semantic + vector)
EmbeddingsFine-tune embedding models for the domain (not covered in the course); dynamic embeddings that adapt to context
Post-retrievalRe-ranking; prompt compression to cut noise
PipelineHybrid search; recursive retrieval and query engines (start small, expand); step-back prompting (broader reasoning); sub-queries and HyDE

Course map: pre-retrieval (chunk size, small-to-big, semantic chunking, metadata, document summary index, query transformations) → post-retrieval (node post-processing, reranking, FLARE, prompt compression, self-correcting) → modular (hybrid retrievers, agentic RAG, ensemble retrieval, ensemble query engine).
