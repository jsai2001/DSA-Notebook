AWS › 7. Monitoring, Logging and Management › Management tools

Q. How does AWS Systems Manager help with EC2? The SSM Agent runs commands, applies patches and opens sessions remotely.

Q. What is AWS Trusted Advisor? It recommends cost, performance and security fixes.

Q. What is AWS Config? It tracks resource configurations and flags compliance drift.

Q. How do you automate with the AWS CLI and SDKs? Script the tasks, for example aws ec2 start-instances, or Boto3 code.

Q. How do you troubleshoot a failed deployment? Check CloudWatch logs and CloudTrail, then roll back with the deployment tool.
