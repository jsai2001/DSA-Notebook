AutoGen › 5. Sequential Chats: Research Assistant

Project: marketing-video research assistant. Roles: Manager (UserProxyAgent, supplies topic, selects ideas, decides), Idea Generator (several campaign concepts), Script Writer (full script: dialog, scenes, camera directions), Script Reviewer (coherence, engagement, alignment with the topic).

Flow: Manager → Idea Generator → Manager picks/refines an idea → Script Writer → Script Reviewer → Manager final decision.

Three phases: create agents (roles) → define tasks (list of chat dicts) → initiate chats (initiate_chats).
