Python Automation › 5. Parsing Data Files (txt, CSV, JSON, XML)

All four use the same pattern: open the file, read, convert into Python structures.

  • next(csv_reader) consumes the header row. CSV values are strings, so cast numbers.
  • json.loads takes a string. json.load takes a file object.
  • XML values from .text are strings, so cast (float(price)) before comparing.
