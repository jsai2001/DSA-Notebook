Alarm actions with Auto Scaling: policies and alarm AWS CloudWatch

AWS CloudWatch › 11. Alarms › Alarm actions with Auto Scaling: policies and alarm

In the group, Automatic scaling > Create dynamic scaling policy, type Simple scaling:

  • ScaleUp: add 1 capacity unit, cooldown 300 seconds.
  • ScaleDown: remove 1 capacity unit, cooldown 300 seconds.

Cooldown prevents rapid repeated scaling. Then CloudWatch > Alarms > Create alarm on EC2 > By Auto Scaling Group > scalingdemo > CPUUtilization, Average, 1 minute, static threshold greater than 70. Actions: Alarm state runs ScaleUp on scalingdemo; OK state runs ScaleDown. A notification is optional (for example the apiadmins topic). Name it ScaleUpDown.
