LangChain Level Up › 5. Interactive Web App with Streamlit › Deploying to Streamlit Community Cloud

  1. Put the app in a new public GitHub repo (separate from the course clone) with app.py, query.py, docs/, requirements.txt. Never push .env (API keys).
  1. share.streamlit.io → sign in → Create app → "Yes, I have an app" → paste the GitHub URL to app.py or pick repo/branch (main)/file → Advanced settings → Secrets → Deploy. The app is served at https://<your-app-name>.streamlit.app.
  2. Since .env isn't pushed, secrets go in Streamlit's TOML secrets and the code reads st.secrets:

Post-deploy dashboard: edit with Codespaces, change subdomain/visibility, invite collaborators, view visitor analytics, update secrets.
