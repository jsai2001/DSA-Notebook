FastAPI › 5. Sending Data › Example: query logs with content negotiation

Return JSON by default, CSV if Accept: text/csv, 404 if nothing matches, 400 on bad input.

  • Content negotiation: the Accept header picks the format; */* means "anything", so default to JSON; reject unsupported types with 400.
  • CSV: StringIO + csv.DictWriter, datetime.isoformat(), media_type='text/csv'.
