PyTorch Hands-On › 9. TorchAudio › Lab: speech-to-text

Flow: load audio, extract acoustic features frame by frame (one tensor per transformer layer, 12 for the base model), classify each frame, greedy-decode to a transcript; optionally use Whisper instead.

Greedy CTC decoding: argmax class per frame, collapse consecutive repeats, drop the blank token. Simplest decoder; no external dictionary.
