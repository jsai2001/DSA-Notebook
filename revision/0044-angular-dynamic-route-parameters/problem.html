Dynamic route parameters Angular

Angular › 13. Routing and Navigation › Dynamic route parameters

path: 'profile/:id' matches /profile/123, /profile/abc and so on. Multiple parameters are allowed:

  • ActivatedRouteSnapshot: a synchronous snapshot of the route at one moment. Used in route config such as the title function (route.paramMap.get('id')).
  • ActivatedRoute: injected into components; exposes observables because values can change over time.

switchMap swaps to the new inner request whenever the parameter changes.
