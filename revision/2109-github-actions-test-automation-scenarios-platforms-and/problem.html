GitHub Actions › 12. Test automation with GitHub Actions › Test automation scenarios: platforms and monorepos

Q. A Bash script fails on Windows runners. How do you fix it? Use portable commands, check the OS or use Unix runners.

Q. Monorepo: run tests only for specific directories. Use paths filters.

Q. A workflow does not trigger on PRs. How do you troubleshoot? Check on: pull_request, branch rules, file paths and permissions.

Q. How do you get a custom test environment? Use a Docker container or a self-hosted runner.

Q. A test fails because of a dependency version mismatch. How do you ensure consistency? Pin versions in requirements.txt, cache, and use a fixed Python version.
