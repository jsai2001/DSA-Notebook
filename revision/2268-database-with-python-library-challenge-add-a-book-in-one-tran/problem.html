Database with Python › 5. PostgreSQL with Python › Library challenge: add a book in one transaction

Steps: collect the title, pages and author name. Skip if the book exists. Look up the author and add one if new. Flush so ids exist, create the BookAuthor pairing, then commit. Example run: "The Huntress" (560 pages, Kate Quinn), "The Institute" (576 pages, Steven King), and "The Diamond Eye" by Kate Quinn reuses her existing author_id.

Validate input (for example page counts), add error handling, and extend the model to several authors per book or queries such as all books by an author.
