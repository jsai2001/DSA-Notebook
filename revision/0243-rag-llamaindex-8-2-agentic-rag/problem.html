8.2 Agentic RAG (1/2) RAG with LlamaIndex

RAG with LlamaIndex › 8. Modular RAG › 8.2 Agentic RAG

Data agents are LLM-powered workers that go beyond query engines: they read from static data and can also call external APIs and modify state. A data agent needs a reasoning loop and tool abstractions; given a task it decides which tools to call, in what order, with which parameters.

Here the agent turns the user's question into metadata filters + a query against the vector DB (auto-retrieval). Pieces: metadata on nodes (manual known_for plus extractors) → a VectorStoreInfo describing the schema → a Pydantic schema for the tool arguments → a function tool → an agent.
