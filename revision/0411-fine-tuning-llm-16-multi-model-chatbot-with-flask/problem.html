Notebook Chapter5_Demo-Chatbot_Flask_App_with_Sentiment_Summarization_QA. A Flask app that combines four models behind one API and routes each message:

MessageModel used
Contains "summarize"FLAN-T5-large summarisation (summarize_text)
Contains "?"FLAN-T5-large Q&A (answer_question)
Anything elseFallback decoder-only model (gpt2-large text-generation pipeline)
Every messageDistilBERT SST-2 sentiment; if negative, the decoder prompt is prefixed with "The user is angry. Their message: ..."

Design points: models load once at startup; conversation_history/conversation_summaries are module-level globals (single-user and not thread-safe: demo only); /reset summarises, stores the summary and clears history; /greet greets.
