AWS CloudWatch › 7. Metric Filters (Logs to Metrics) › Metric details

  • Filter name and metric name, for example ValidationExceptions.
  • Namespace: create or choose one, for example MetricFilters.
  • Metric value: value added on each match; use 1 to count occurrences, or another value (such as a duration) for other cases.
  • Default value: optional (for example 0). If unset, nothing is pushed when no event matches, which is cheaper.
  • Unit and dimensions: optional.

Review, create, then generate requests (for example 100) and look under Metrics > namespace to see the new metric.
