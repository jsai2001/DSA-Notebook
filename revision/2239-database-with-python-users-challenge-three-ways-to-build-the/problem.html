Database with Python › 2. SQLite with Python › Users challenge: three ways to build the same table

The task is a Users table (User_Id, First_Name, Last_Name, Email_Address), five rows with at least two gmail.com addresses, and a query for all email addresses. User_Id is an auto-incrementing primary key. It uniquely identifies records and supports foreign keys. Auto-increment is convenient but adds overhead, so it is not ideal in production.

Version 1: sqlite3 module

Version 2: SQLAlchemy, insert row by row

Version 3: SQLAlchemy expression language (readable bulk insert)

Each version creates the table, inserts the rows and reads them back, and SQLAlchemy handles the primary-key increment. The sqlite3 module suits direct SQL on lightweight apps. SQLAlchemy abstracts the SQL, and the engine makes it easy to switch backends later (for example SQLite to PostgreSQL).
