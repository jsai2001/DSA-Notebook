Search always returns results: use a threshold Vector Databases

Vector Databases › 8. Query vs Search › Search always returns results: use a threshold

Even an unrelated query returns Top-K. Demo: "machine learning" gave distances 0.33-0.50; "best movies of the year" gave 0.62-0.65. So pick a similarity threshold from observed distances, or push it into the search with radius.

Ideas for choosing it dynamically (source): percentile of distances, mean minus std, or fixed per metric (L2 ~0.5, COSINE ~0.8). A "fallback" pattern: if nothing passes the threshold, show the top 3 anyway.
