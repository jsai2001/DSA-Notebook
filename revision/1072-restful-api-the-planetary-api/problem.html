The Planetary API RESTful API

RESTful API › 1. Course Overview and the Planetary API › The Planetary API

  • Backend-only REST API, no UI, so any client (web, mobile, desktop) can use it. All testing is done in Postman.
  • Features: list planets, register users, authenticate users, add / update / delete planets (for example, deleting Pluto after reclassification).
  • Stores planets (name, type, home star, mass, radius, distance) and users (name, email, password).
