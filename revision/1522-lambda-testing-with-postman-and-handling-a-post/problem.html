AWS Lambda › 2. Console, programming model and triggers › Testing with Postman and handling a POST body

Browsers only send simple GET requests. Postman supports all HTTP methods plus headers, query parameters, bodies and authorization. A trigger configured with ANY accepts any method, but the function must parse event.body itself, because API Gateway delivers the body as a string.
