Terraform › 6. Providers › Versions and authentication

Q. How do you specify a provider version?

Q. What happens if you do not specify a provider version? Terraform grabs the latest, which risks inconsistency and breakage.

Q. How do you authenticate with AWS, Azure and GCP?

  • AWS: environment variables (AWS_ACCESS_KEY_ID).
  • Azure: CLI login (az login).
  • GCP: key file (GOOGLE_CREDENTIALS).

Q. What is the difference between an official and a community provider? Official providers are HashiCorp-backed and stable. Community providers are third-party with variable quality.

Q. How do you troubleshoot provider errors? Check logs (TF_LOG), credentials, configuration and versions.
