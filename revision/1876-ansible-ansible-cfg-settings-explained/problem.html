Ansible › 2. Installation and ansible.cfg › ansible.cfg settings explained

  • inventory: path to the inventory file.
  • remote_user: default SSH user for remote hosts.
  • private_key_file: path to the SSH private key.
  • host_key_checking: disabled here for simplicity (not recommended for production).
  • retry_files_enabled: disables .retry files on task failure.
  • log_path: where Ansible logs are saved.
  • become, become_method, become_user: enable privilege escalation via sudo to root.
  • become_ask_pass: do not prompt for a sudo password.

Place the file next to the playbooks, or in ~/.ansible.cfg for global use.
