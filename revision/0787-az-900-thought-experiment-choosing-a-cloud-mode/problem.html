Thought experiment: choosing a cloud model AZ-900

AZ-900 › 4. Service types: IaaS, PaaS, SaaS › Thought experiment: choosing a cloud model

Cora advises on a cloud type. Requirements from her boss Samuel: VMs plus a database, no complex networking (too few network technicians), fault tolerance and reliability, always available including end-of-month demand spikes, privacy first (data must never sit on a network shared with an unknown company, and any shared party must be vetted for compliance), and a generous budget.

ModelVerdictWhy
PublicNoShared infrastructure breaks the privacy requirement
HybridNoNeeds complex on-prem-to-cloud networking, and public VMs may fail compliance
Private (third-party provider)YesSingle-tenant, provider handles networking, provider can be vetted, scaling and fault tolerance available, higher cost is acceptable

Lesson: list requirements first, then test each model against them. Privacy and compliance push toward private cloud even at higher cost.
