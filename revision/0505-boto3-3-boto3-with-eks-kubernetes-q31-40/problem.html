Boto3 › 3. boto3 with EKS / Kubernetes (Q31-40)

Use the eks client for cluster details, node groups and add-ons.

Q31. Get EKS cluster details. describe_cluster returns status, endpoint, version.

Q32. List EKS clusters in a region. list_clusters with a paginator.

Q33. Update cluster config (scale a node group). update_nodegroup_config with scalingConfig; needs the cluster and node group names.

Q34. IAM roles for EKS service accounts (IRSA). Create a role whose trust policy lets the cluster's OIDC provider assume it via sts:AssumeRoleWithWebIdentity, scoped to one service account, then attach policies. Annotate the Kubernetes service account with the role ARN.
