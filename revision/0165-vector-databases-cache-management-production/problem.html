Vector Databases › 9. Use case 1: LLM semantic cache › Cache management (production)

  • Timestamp (last_used) field: update on every hit (upsert) so you can prune LRU / by age.
  • Pruning strategies: age-based (simple, may delete popular old entries), LRU (keeps popular, needs timestamp updates), size-based (predictable, may delete recent), hybrid (best, more complex).
  • User feedback field (+1 thumbs up / -1 thumbs down) and delete negative entries.
  • TTL, cache warming (pre-populate with common prompts), multi-model cache (add model_name field and filter on it).
