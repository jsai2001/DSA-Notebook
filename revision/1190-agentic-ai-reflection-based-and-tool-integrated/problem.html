Reflection-based and tool-integrated Agentic AI Fundamentals

Agentic AI Fundamentals › 8. Agent Architectures › Reflection-based and tool-integrated

  • Reflection-based: the agent produces output, critiques it, refines it iteratively and reaches a validated decision. Self-critique prevents false positives, such as not calling police on someone just picking something up.
  • Tool-integrated: the agent uses a web search engine, image processing software and other external tools to go beyond its pre-programmed functions.
