Routing plus multi-agent: a router classifies each request and hands it to a specialist, reusing agents already built.

Graph: Router → PRODUCT | ORDER | SMALLTALK | END. Every destination goes to END (one-way; control does not return to the router).

  • Router: LLM classifies into one word. Product_Agent: section 4 agent. Orders_Agent: section 5 agent. Small_Talk: LLM with a small-talk prompt.
  • The conditional edge maps the router's output text straight to a node name.
