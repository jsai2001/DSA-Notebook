Processes, permissions and users Linux

Linux › 1. Linux Basics › Processes, permissions and users

Q. Process vs. thread? A process is an independent program with its own memory (Firefox). A thread is a lightweight unit inside a process and shares its memory (a browser tab).

Q. How do Linux file permissions work? Give chmod examples. Permissions apply to owner, group and others, each with read (4), write (2) and execute (1).

Q. What are the basic Linux file types? Regular (-), directory (d), symbolic link (l), hard link, block device (b), character device (c) and named pipe (p). Check with ls -l.

Q. What is the purpose of the root user? Root (UID 0) has full system access for admin tasks (sudo apt update). Use it cautiously to avoid damage.

Q. sudo vs. su? sudo runs a single command as root (sudo cmd). su starts a full root session (su -).
