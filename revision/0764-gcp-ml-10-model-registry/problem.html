GCP for Machine Learning › 10. Model Registry

A central repository for the model lifecycle in Vertex AI.

CapabilityDescription
Organize modelsOne place for custom, AutoML, BigQuery ML models
Version managementMultiple versions, default version, aliases and labels
DeploymentDeploy registered models to Endpoints
LineageModel details, artifacts, container images

Supported types: custom (TensorFlow, PyTorch…), AutoML (text, tabular, image, video), BigQuery ML (trained with SQL).

Workflow: import/create model → assign version → add aliases/labels → deploy to Endpoint → predict.
