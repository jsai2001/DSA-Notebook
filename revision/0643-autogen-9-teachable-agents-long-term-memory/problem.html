AutoGen › 9. Teachable Agents (Long-term Memory)

Problem with standard LLM assistants: memory is lost when the chat ends, in-context learning is not persistent, context windows fill up, and users repeat instructions every session.

Teachable agent: learns from user interaction and keeps memos in a vector database (ChromaDB) that survives restarts. A Teachability capability object is added to a ConversableAgent. Flow: teach (fact/preference/skill) → memo embedded and stored → later query is vectorized → similarity search retrieves relevant memos → response uses them.
