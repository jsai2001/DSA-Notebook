GitHub Actions › 11. Python and GitHub Actions › Triggering a workflow through the API

Q. How do you trigger a workflow programmatically via the GitHub API? Use the "Create a workflow dispatch event" endpoint, POST /repos/{owner}/{repo}/actions/workflows/{workflow_id}/dispatches, with requests and a PAT. A 204 response means success.
