Model registry MLOps

MLOps › 6. Model Management › Model registry

A repository for storing and tracking models: a queryable database of the model plus metadata, with status changes and audit trails. It is to models what the feature store is to data and a code repo is to code. Usually one central registry is shared by all ML teams.

StoredDetail
Model artifactSerialized model (e.g. pickle)
MetadataUnique ID, version, description
HyperparametersThose used for this model
StatusCurrent life cycle stage
Audit trailTimestamps of state changes, test pass/fail, deployment
Lineage linksInput data version, code/notebook version, experiment-tracking results

MLOps benefits: traceability (recreate the model), life cycle tracking, collaboration across teams and time, automation of model creation and consumption, governance (access control, auditing).
