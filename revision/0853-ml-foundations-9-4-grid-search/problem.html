Validation curves tune one hyperparameter. GridSearchCV brute-forces every combination with cross-validation.

Baseline decision tree: same as Section 7.3 (R² ≈ 0.73).

  • 3 x 3 x 3 = 27 combinations x 5 folds = 135 fits. Each added 3-value parameter multiplies the total by 3 (81 combinations, 405 fits).
  • Pass only training data; grid search makes its own 5 folds internally (train 80%, validate 20%, rotate), tracking mean and std per combination.

Attributes ending in _ are learned from fitting (sklearn convention). Apply with ** unpacking:

Default for comparison: identical pipeline but dt = DecisionTreeRegressor(random_state=42) and no set_params, giving R² ≈ 0.74. Tuning gained +0.05 (0.74 to 0.79).
