LangChain Level Up › 10. Deploying Chains as a REST API with LangServe › 10.1 Server, routes, run

Workflow: create FastAPI server → create runnables → add_routes → run with Uvicorn → Swagger UI at /docs.

Each add_routes(app, runnable, path=...) call auto-creates endpoints under that path:

EndpointMethodPurpose
<path>/invokePOSTSingle input
<path>/batchPOSTMultiple inputs
<path>/streamPOSTStream output
<path>/stream_logPOSTStream with logging
<path>/docsGETSwagger UI for the route
/docsGETGlobal Swagger UI
