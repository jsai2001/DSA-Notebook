API key: sign up at tavily.com, create a key in the dashboard, put it in .env.

ReAct (Reasoning + Acting): a prompt template that makes the LLM alternate Thought → Action → Observation until it has a final answer; improves accuracy and transparency.

Gotchas: tool not called → clear description, register with both caller and executor, mention tool in the system message. Infinite loops → termination condition, max rounds/turns. Set human_input_mode by tool risk; validate tool inputs; rate-limit external APIs. Tool chaining (search result → calculator) happens as sequential tool calls.
