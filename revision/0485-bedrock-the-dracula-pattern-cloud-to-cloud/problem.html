You "suck the logic out" of the better model and move it to a cheaper one through prompt refinement. Develop once on premium, optimize for production on cheaper.

  1. Premium development. Build a robust prompt on Claude 3 Opus / 3.5 Sonnet. Document it. Add validation (XML, JSON, YAML or compilable code).
  2. Transfer testing. Use Compare Mode or API calls (for example a Rust CLI). Find quality gaps.
  3. Iterative refinement. Ask the premium model to rewrite the prompt so the cheaper model (Haiku) produces the same output. Repeat, validating with structured formats.
  4. Deploy on the cheaper model with the optimized prompt. Prompt routing in Bedrock can pick models automatically.

Rule: treat prompts as software, not human language. Validate with JSON, XML, linting and unit tests.
