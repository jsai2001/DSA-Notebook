Q16. Walk through the lifecycle of an execution environment (Init, Invoke, Shutdown).

  • Init: AWS creates the microVM, downloads code, starts the runtime and runs your initialization code (everything outside the handler). Extensions register here.
  • Invoke: the handler runs for each event. A warm environment skips Init and goes straight here.
  • Shutdown: when the environment is idle or reclaimed, Lambda sends a shutdown signal and extensions get a short window to clean up. Your handler is not called.

Q26. What happens during Shutdown, and how can you use extension hooks? When Lambda reclaims an idle environment, external extensions receive a SHUTDOWN event with a limited window (typically up to about 2 s) to flush logs and metrics, close connections or export telemetry. Use these hooks to clean up gracefully instead of losing buffered data.
