GitHub Actions › 6. Reusable actions and workflows › Popular marketplace actions

Marketplace actions reduce boilerplate and are maintained by GitHub or the community.

  • actions/checkout: clones the repository.
  • actions/setup-node: sets up Node.js at a given version.
  • actions/cache: caches dependencies.

Pin versions (for example @v4) to avoid breaking changes, review the source of lesser-known actions, and prefer official actions/* actions. Pair cache with setup actions.
