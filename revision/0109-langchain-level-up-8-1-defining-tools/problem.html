LangChain Level Up › 8. Agents & Tools over MongoDB (OpenAI Tools Agent) › 8.1 Defining tools

Tools are functions decorated with @tool (name = function name, description = docstring, arguments = typed parameters). The docstring is mandatory; the LLM reads it to decide when/how to use the tool, and validation fails without it.

Vector search tool: vector_search_index.py holds the RAG chain from Section 7 ({"context": retriever, "question": RunnablePassthrough()} | custom_rag_prompt | llm | StrOutputParser()); agent.py wraps it as a tool.
