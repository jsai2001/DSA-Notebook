GitHub Actions › 2. Workflow syntax and triggers › Environment variables and contexts

Q. How do you define environment variables? Use env at workflow, job or step level.

Q. What is the env context compared with github and secrets?

  • env: custom variables (${{ env.VAR }}).
  • github: event data (${{ github.sha }}).
  • secrets: secure data (${{ secrets.KEY }}).
