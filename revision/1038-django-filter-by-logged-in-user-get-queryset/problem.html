Django › 9. User-Specific Data › Filter by logged-in user (get_queryset)

  • Chain: GET -> get() -> get_queryset() -> DB query -> template. Default get_queryset() returns Model.objects.all(); overriding it customises the query.
  • To find what to override, read the class on ccbv.co.uk (e.g. ListView's get calls get_queryset).
  • self.request.user is the current user in any CBV.
