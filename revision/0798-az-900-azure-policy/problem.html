Azure Policy AZ-900

AZ-900 › 10. Governance and compliance › Azure Policy

Defines rules applied when resources are created and managed (for example, VMs must be a certain size, resources must be in a certain region, certain resource types must deploy together).

EffectBehavior
AppendAdds properties to a resource (for example auto-add a tag)
AuditLogs a warning on non-compliance
AuditIfNotExistsLogs a warning if a required related resource is missing
DeployIfNotExistsDeploys the required related resource if missing
DenyBlocks the create or update
DisabledPolicy is off
