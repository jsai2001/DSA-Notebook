Angular › 6. Standalone Components and Zoneless › Standalone (Angular 14+)

Use a component, directive or pipe without assigning it to a module. Simpler structure, and compatible with module-based code so migration can be gradual.

  • Set standalone: true (default is false as of Angular 16). Applies to components, pipes and directives.
  • The piece declares its own imports (built-in CommonModule, other standalone pieces, router directives, pipe modules) and optional providers. Imports are not inherited from a module.
  • CLI: ng generate component component-name --standalone.
