7.3 FLARE (Forward-Looking Active REtrieval) RAG with LlamaIndex

RAG with LlamaIndex › 7. Advanced RAG: Post-Retrieval & Other Techniques › 7.3 FLARE (Forward-Looking Active REtrieval)

Most RAG retrieves once. For long-form generation one retrieval is not enough. FLARE retrieves actively during generation, deciding when and what to retrieve (paper: Active Retrieval Augmented Generation).

  1. Predict (look ahead to) the upcoming sentence. 2. Use it as a retrieval query. 3. If it has low-confidence tokens, regenerate it with the retrieved documents. 4. Repeat until the response is complete or max_iterations is hit.
VariantBehavior
FLAREInstructPrompts the LLM with retrieval-encouraging instructions to emit search queries when needed (implemented in LlamaIndex as FLAREInstructQueryEngine)
FLAREDirectUses the LLM's own generated sentence as the query if it contains uncertain tokens

Confidence-based retrieval triggers only when the model lacks knowledge; queries can be masked sentences (implicit) or generated questions (explicit).

Other FLAREInstructQueryEngine options: llm, instruct_prompt, lookahead_answer_inserter.
