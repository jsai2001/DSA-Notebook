Kubernetes › 4. Networking › Service types

Q. What is a ClusterIP service, and how does it work? The default Service type. It gives a virtual IP for internal Pod access, load balanced by kube-proxy.

Q. Explain the difference between ClusterIP, NodePort, and LoadBalancer.

  • ClusterIP: internal only.
  • NodePort: exposes on node ports (30000-32767).
  • LoadBalancer: external IP from the cloud.

Q. How does Kubernetes handle external traffic to services? Through NodePort (node IP:port), LoadBalancer (cloud IP), or Ingress (HTTP routing).

Q. What is an Ingress controller, and why is it used? It manages HTTP traffic. It routes by host and path, handles TLS, and cuts LoadBalancer costs.

Q. What is the purpose of kube-proxy in networking? It sets up Service IPs and load balances traffic to Pods using iptables or IPVS.
