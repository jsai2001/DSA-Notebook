Advanced RAG › 1. Core Concepts and RAG Pipeline

Vector database: works with unstructured data as vectors. "Database" is a misnomer; it is a compute engine for vector data. Embeddings are long lists of numbers (hundreds to thousands).

Why "embeddings": they come from the second-to-last layer of a deep neural network. That layer holds what the network learned, before the predictive layer is applied.

Embedding models: deep neural networks that turn data into vectors. Two rules:

RuleWhy
Match data type to model typeImage models for images, text models for text. Even multimodal models need the input type specified.
Same model for indexing and retrievalOnly same-size vectors can be compared, so the query must use the model that vectorized the data.

LLMs in RAG: the interface to your data. Most (incl. GPT-4) are transformers that predict the next token. They are trained on public data and have no access to yours, which is the gap RAG fills.

RAG pipeline: question → embedding model → vector DB similarity search → relevant context → LLM (question + context) → answer.
