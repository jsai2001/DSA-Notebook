Amazon Bedrock › 4. Compare Mode and the Dracula Pattern

Compare Mode runs the same prompt against two models side by side (quality, speed, cost, style). Setup: Playground > Chat, select the first model and system prompt, click Compare Mode, select a second model, paste the same system prompt, close both config panels, then type a prompt. Each model's config panel can be toggled independently.

Example system prompt used on both models (Claude 3.5 Sonnet v2 vs Claude 3 Haiku):

Techniques in that prompt: placeholders for task/input/output, a length limit, "just code", a required one-line comment, and a working compilable example with expected output. A concrete code example beats natural-language description. Reliability ranks: natural language only (low), plus format instructions (medium), plus working code example (high).

AspectClaude 3.5 SonnetClaude 3 Haiku
Code qualityCorrect, reproducibleCorrect but missing elements and formatting issues
Prompt adherenceFollows all instructions, consistent across "add", "subtract"Varies per prompt, needs prompt refinement
CostHigherLower
SpeedSlowerFaster

This is a classic engineering tradeoff: best performance now, cheaper later. Other factors: energy use, carbon footprint, latency, reliability.
