Sharing artifacts between jobs Jenkins

Jenkins › 10. Artifacts, Fingerprints and Test Reports › Sharing artifacts between jobs

The Copy Artifact plugin lets one job read artifacts from another through the copyArtifacts step. Install it under Manage Jenkins, Plugins. The job that creates the artifact must explicitly grant permission with copyArtifactPermission (a comma-separated list such as 'job1,job2'; '*' allows every job and should be used cautiously). Without permission the pipeline fails with Permission to copy artifact is missing for create-artifact-job.

projectName is the source job, selector chooses the build (lastSuccessful, lastCompleted, or a specific build number), target is the workspace directory to copy into (default: workspace root) and fingerprintArtifacts records the usage.
