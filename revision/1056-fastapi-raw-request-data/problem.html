Raw request data FastAPI

FastAPI › 4. Accepting Data › Raw request data

Use a Request parameter for the raw body, e.g. an image whose size you return. Reading the body needs await, so the handler must be async. Never accept unbounded input from the internet: check the size.

BytesIO turns raw bytes into a file-like object for libraries such as PIL. Headers: request.headers.get('Header-Name').
