Q75. Detect Terraform drift. Query AWS, compare with state-file data, report discrepancies (missing resources, modified attributes).

Q76. Credentials exposed in workflow logs.

  • Keep credentials in GitHub Secrets.
  • Use OIDC to assume an IAM role instead of long-term keys (workflow below).
  • Mask sensitive values with ::add-mask::.
  • Do not log sensitive data in scripts.

(OIDC also needs the job to have permissions: id-token: write.)

Q77. Monitor CloudWatch alarms and trigger an Ansible playbook. Query alarms, and on ALARM state run ansible-playbook via subprocess. Run on a schedule in GitHub Actions.
