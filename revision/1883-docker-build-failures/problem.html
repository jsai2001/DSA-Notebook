Build failures Docker

Docker › 15. On-Call: Image and Build Problems › Build failures

Q. Build fails: "COPY failed: no such file or directory"?

Fix: COPY ./xyz /app/xyz

Verify file paths and that the files are in the build context.

Q. Missing dependency in a custom image?

Add: RUN apt-get update && apt-get install -y <dependency>

Check logs, update the Dockerfile, and test after the rebuild.

Q. Build fails due to a network timeout?

Use a mirror: RUN echo "deb http://mirror.example.com/ubuntu focal main" > /etc/apt/sources.list

Verify the network, use reliable mirrors, and cache packages locally.

Q. Inconsistent Dockerfile builds?

Pin versions: FROM node:16.13.2; RUN npm install express@4.17.1

Pin package versions, avoid variable outputs, and standardize the build environment.
