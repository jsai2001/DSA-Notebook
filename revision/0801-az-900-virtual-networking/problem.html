AZ-900 › 6. Compute and networking › Virtual networking

VPN Gateway: encrypted connections between Azure VNets and other networks. Azure creates a managed gateway subnet with 2+ VMs (not accessible to you). Max 1.25 Gbps, and encryption adds overhead.

Connection typeConnects
VNet-to-VNetTwo Azure VNets
Site-to-SiteAzure VNet and an on-prem network
Point-to-SiteOne device (phone, laptop) and an Azure VNet

VPN Gateway vs peering: for two Azure VNets, peering is faster (no encryption overhead, no 1.25 Gbps cap). Use VPN Gateway when you need encryption or a non-Azure network.

ExpressRoute: dedicated private connectivity from on-prem to Azure. Traffic never crosses the internet. The connection is a circuit: you → third-party provider (usually an ISP) → Microsoft Enterprise Edge (MSEE) → Azure.

VPN GatewayExpressRoute
SpeedUp to 1.25 GbpsUp to 10 Gbps (100 Gbps with ExpressRoute Direct)
PathInternet, encryptedDedicated fiber via MSEE
