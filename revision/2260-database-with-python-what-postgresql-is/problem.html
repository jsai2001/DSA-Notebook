What PostgreSQL is Database with Python

Database with Python › 5. PostgreSQL with Python › What PostgreSQL is

  • An object-relational database with tables, columns and rows, plus table inheritance and function overloading.
  • Extensible: custom data types, functions in other languages, and plugins that can replace system components.
  • Follows the SQL standard more closely than MySQL, is ACID compliant, highly scalable, and stable with little maintenance.
  • Trade-offs: more complex to work with. New client connections are slower because each one forks a process (about 10 MB of memory per connection). MySQL can be faster for read-heavy apps and is more popular, so Postgres has fewer third-party tools and developers.
  • Client-server model, so Python needs a driver such as psycopg2, which follows the Python Database API like sqlite3 and mysql-connector.
