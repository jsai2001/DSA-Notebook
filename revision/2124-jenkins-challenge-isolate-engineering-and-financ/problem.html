Challenge: isolate Engineering and Finance Jenkins

Jenkins › 7. Security, Credentials and Access Control › Challenge: isolate Engineering and Finance

Goal: two teams whose users cannot touch each other's folders.

  1. Create users engineering and finance (Manage Users, Create User).
  2. Select Project-based Matrix Authorization Strategy; give admin Overall Administer and both team users Overall Read. A system-user warning may appear and can be dismissed for the exercise but should be reviewed in production.
  3. Create folders Engineering Jobs and Finance Jobs (New Item, Folder). In each, enable Project-based security and give the matching user all permissions.
  4. Log in as engineering: only Engineering Jobs is visible, with no Manage Jenkins and no Finance Jobs. Repeat for finance.

Overall Read is required for a user to see anything at all. Test by logging in as each restricted user, use descriptive folder names, and back up the configuration to recover from lockouts.
