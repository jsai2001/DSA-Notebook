Azure AI Services › 9. Azure AI Foundry (AI Studio) and Azure OpenAI

Foundry is the enterprise platform to build, test, deploy, and manage AI apps (full MLOps/DevOps lifecycle), at ai.azure.com. It uses models from across the industry, beyond what AI Services alone offer.

Typical AI project lifecycle (can be done visually in Foundry):

  1. Data: ingest, clean, transform, visualize.
  2. Split (e.g., 20% train / 80% validate, as stated in the course).
  3. Train (given these inputs, produce this output).
  4. Validate on held-out data.
  5. Deploy as an API protected by Entra ID, scaled with Kubernetes.
  6. Monitor inference and loop back (more data, retrain, tweak).
