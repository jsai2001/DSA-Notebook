7. Memory CrewAI

CrewAI › 7. Memory

Memory lets agents reason better, learn from earlier interactions, keep context during a session, and improve with use (fine-tuning strategies from past errors). It goes beyond the LLM context window.

TypeStoresMechanism
Short-termRecent interactions and outcomesTemporary, uses RAG; gives context for the current task
Long-termLessons and patterns from past runsPersists insights, refines knowledge over time
EntityPeople, places, organizationsDeeper understanding and relationship mapping
ContextualBest composition of the three aboveKeeps coherence across a sequence of tasks
ExternalOutside providersMemGPT, GraphRAG, Mem0

Benefits map: contextual awareness (short-term + contextual), experience accumulation (long-term), entity understanding (entity).

Memory is off by default (memory=False). Enable on an agent, or on the crew for all agents. Default embeddings are OpenAI's; change them with embedder.
