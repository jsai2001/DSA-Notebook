CNN = convolutional layer + pooling layer.

  • Convolution: slide a learnable filter (e.g. 3×3) over regions of the image; each output cell = element-wise multiply the window with the filter, then sum. Extracts local context.
  • Max pooling: compress the convolution output by taking the max of each region (e.g. max(12, 20, 8, 12) = 20).

Vision Transformer (ViT): takes attention from language transformers and applies it to images.

  • Pipeline: image → split into N×N patches (like words) → patch embeddings → add [CLS] token + positional encoding → transformer encoder (attention) → MLP head (classification, segmentation, etc.).
  • [CLS] token: special token whose output represents the whole image (the image embedding).
  • Positional encoding: tells the model where each patch sits.
