Similarity search retrieves dataset content similar to a query (used in information retrieval, image recognition, recommenders, NLP). Embeddings are vector representations of text that preserve semantic relationships; text → embedding model → vector → vector store. Query vectors are compared with stored vectors (cosine similarity) and the top-k closest are returned.
