8. Services Angular

Angular › 8. Services

Services separate and reuse code: API calls, calculations, business logic, anything that does not change the UI directly. They keep components small. Services and dependency injection go together. Files: *.service.ts.

@Injectable({ providedIn: 'root' }) creates one singleton for the whole app, so every consumer sees the same data (caching, shared state). It is the CLI default. providedIn: null (or bare @Injectable()) means you must add it to a providers array. See section 11.
