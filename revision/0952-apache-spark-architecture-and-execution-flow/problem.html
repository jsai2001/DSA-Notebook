Apache Spark › 2. Spark Capabilities for ETL › Architecture and execution flow

  • The driver node runs the Spark program. Executor nodes in the cluster do the work in parallel.
  • Flow: read source, convert to DataFrame/RDD (partitioned across executors), transform (map/filter, local on each executor, no data movement), action (reduce/group by, shuffle between executors), collect (partitions merged to the driver), write to destination.
OperationData movementBottleneck risk
Transforms (map, filter)None, local on partitionsLow, fully parallel
Actions (reduce, group by)Shuffle between executorsHigh (I/O and memory)
