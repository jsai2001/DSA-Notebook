Infrastructure as Code (IaC) AZ-900

AZ-900 › 10. Governance and compliance › Infrastructure as Code (IaC)

Uses a DevOps approach with a descriptive (declarative) model to define and deploy networks, VMs, load balancers and so on. Same source gives the same binary, and the same IaC model gives the same environment every time. ARM templates (JSON) and Bicep are the Azure options.
