Angular › 7. Pipes › Custom pipes

A pipe is a class decorated with @Pipe that implements PipeTransform, ends in Pipe, and has a transform method (build error if missing). The first argument is the template value, extra arguments are pipe arguments, and it must return a value.

@Pipe properties:

PropertyNotes
namecamelCase, no hyphens (build error)
puredefault true: runs only when the input reference changes (fast). false runs on every change detection cycle, so use sparingly
standalonetrue for standalone architecture, false for module architecture
