Infrastructure as Code (IaC) AWS CloudFormation

AWS CloudFormation › 1. Infrastructure as Code and Why CloudFormation › Infrastructure as Code (IaC)

Write a template in JSON or YAML that describes what you want. One operation creates everything in it. Like an architect's blueprint, you describe the result and AWS handles the details. CloudFormation can build S3 buckets, EC2 instances, whole application environments, or any mix of AWS resources. Nearly anything you can create in the console can be described in a template.
