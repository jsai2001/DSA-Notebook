Update and Delete Flask

Flask › 6. Database Operations with Flask-SQLAlchemy (CRUD) › Update and Delete

Update flow: form with a hidden record-ID field -> route finds the record -> modify fields -> commit. Delete flow: button form carries the ID -> route finds the record -> delete -> commit.

templates/users.html with inline update and delete forms:

  • Update needs no db.session.add(): SQLAlchemy tracks changes on already-loaded objects.
  • Hidden inputs pass the record ID without showing it. Delete takes the ID from the URL.
  • Data-modifying routes use methods=["POST"], never GET.
