8. Cloud Scheduler (Cron) Google Cloud (GCP)

Google Cloud (GCP) › 8. Cloud Scheduler (Cron)

  • Fully managed cron service. Triggers HTTPS endpoints or Pub/Sub topics on a schedule.
  • Use cases: daily summary emails at 7am, deactivating users inactive for a month at midnight, a weekly Sunday-midnight backup script.
  • Job fields: name (unique in project), description, frequency (Unix cron), timezone, target.
