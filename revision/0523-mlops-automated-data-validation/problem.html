Automated data validation MLOps

MLOps › 4. Data Processing & Management › Automated data validation

New data keeps arriving after deployment. Validate it against the original training-set patterns to catch deviations before they hurt the model.

ValidationWhat to check
FeatureMissing/erroneous data, formats, ranges (machine-generated data can be wrong too)
DistributionMean, std, quartiles vs baseline; class distribution of categoricals, so new data belongs to the same population as training data
Out-of-distributionOutliers beyond quartiles (continuous); new class values (categorical)
CorrelationFeature-target and feature-feature correlation vs baseline (detects multicollinearity changes)
