AutoGen › 1. Core Concepts (interview essentials)

  • AI agent = LLM + tools + memory + context. Components: an LLM (language understanding), document access, a toolkit (APIs, calculators), conversation ability, and a database (memory).
  • AutoGen is a multi-agent conversational framework (Microsoft). Agents have different roles and solve tasks using different tools and patterns. An agent can send messages, receive messages, and generate replies, powered by an LLM, a code executor (e.g. IPython kernel), human input, or a combination.
  • Why multi-agent instead of one big LLM? Specialization (each agent does one thing well), collaboration/multiple perspectives (better quality), scalability (add agents), flexibility (custom roles), efficiency (parallel work).
  • Agents vs human assistants: available 24/7, no fatigue, consistent, many tasks at once, learn continuously. Framing: agents are collaborators that augment people, not replacements.
  • Design patterns taught: Reflection (self/peer review), Tool Use (functions/APIs), Multi-Agent Collaboration (sequential chats, nested chats, group chat). Also human-in-the-loop and agent memory (teachability).
  • Conversation shapes: two-way (agent ↔ agent), multi-way (group), nested (hierarchical). Collaboration shapes: sequential, parallel, hierarchical (manager-worker).
  • Problem-solving approach: break a complex problem into subtasks, assign to specialized agents, let them collaborate, synthesize the result. Example team: Researcher gathers → Analyst analyzes → Writer reports. Other teams seen in the course: architect/developer/tester/documenter (software), researcher/outliner/writer/editor (content), collector/analyst/visualizer/reporter (BI).
  • Course map: multi-agent conversations → research assistant (sequential chats) → nested chats → tool use/internet → coding copilot → teachable agents → group chat company.
