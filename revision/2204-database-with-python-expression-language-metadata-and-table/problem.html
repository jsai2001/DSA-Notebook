Expression language: MetaData and Table Database with Python

Database with Python › 3. SQLAlchemy Core and ORM › Expression language: MetaData and Table

A MetaData object tracks the tables (like a dictionary of table name to Table object). A Table holds the name, metadata and columns. sqlalchemy.select(table) builds the query in Python. Use sqlalchemy.text() for raw SQL the expression language cannot express, which keeps all access inside SQLAlchemy.
