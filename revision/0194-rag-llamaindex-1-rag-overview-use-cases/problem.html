RAG with LlamaIndex › 1. RAG Overview & Use Cases

Retrieval Augmented Generation (RAG) enhances an LLM by connecting it to external data sources, including private datasets.

LLM limitationWhyHow RAG helps
Stale informationTrained on static internet scrapesRetrieves current data from external stores and injects it into the context window
No source attributionKnowledge is baked into weightsThe answer can be traced back to retrieved sources
HallucinationsTrained for natural-sounding language, not truthfulnessGrounding data can be added, updated, or deleted in real time
Generic answersNo domain dataPlug in domain-specific data

RAG in three steps: Retrieve context from an external source → Augment the prompt with it → Generate the answer with the LLM.
