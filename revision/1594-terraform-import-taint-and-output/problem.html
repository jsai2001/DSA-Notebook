Import, taint and output Terraform

Terraform › 2. Workflow and Commands › Import, taint and output

Q. How do you import existing infrastructure into Terraform? Define the resource block, then import it.

Q. What is terraform taint, and when do you use it? It marks a resource for recreation on the next apply. Use it for corrupted or stuck resources.

Q. How do you roll back changes if something fails? Revert the configuration and apply again. There is no automatic rollback, so rely on Git and backups.

Q. What does terraform output do? It shows output values after apply.
