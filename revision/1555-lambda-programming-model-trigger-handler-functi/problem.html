Programming model: trigger, handler, function code AWS Lambda

AWS Lambda › 2. Console, programming model and triggers › Programming model: trigger, handler, function code

  1. Triggers invoke the function: API Gateway (HTTP requests), DynamoDB (record changes), S3 (file creation or modification), SQS (new messages).
  2. Handler is the entry point. Its inputs are the event (data from the trigger, shape varies by trigger), the context (runtime information such as function name and remaining time) and an optional callback (returns data to the invoker; not needed with async/await).
  3. Function code is your business logic: API calls, data processing, calls to other AWS services.

Parse the event carefully per trigger, and log it with console.log to see it in CloudWatch. The context object offers context.functionName and context.getRemainingTimeInMillis().
