Q. How do you create a custom network?

Q. How do containers communicate? On the same network, by IP or by name (custom networks). External access needs port mapping.

Q. How does Docker DNS resolution work? Custom networks resolve container names automatically. The default bridge does not.

Q. What is --link and why is it deprecated? It links containers on the default bridge. It is outdated; use custom networks.
