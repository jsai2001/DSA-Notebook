The three execution models in the course AWS Lambda

AWS Lambda › 2. Console, programming model and triggers › The three execution models in the course

  1. Synchronous: the invoker waits for the response (blocking). Example: API Gateway handling HTTP requests.
  2. Asynchronous: the invoker gets an acknowledgment and does not wait. Example: S3 triggering a function on file upload.
  3. Poll stream-based: Lambda polls a stream or queue (SQS, Kinesis) and invokes the function when records are available.
