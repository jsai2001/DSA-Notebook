CI/CD and zero-downtime Docker

Docker › 10. Practical Dockerfile and Compose Scenarios › CI/CD and zero-downtime

Q. How do you do CI/CD with Docker? Build and push in CI (for example GitHub Actions), then deploy via Compose or Swarm.

Q. How do you do a zero-downtime update? Use a Swarm rolling update with docker service update.
