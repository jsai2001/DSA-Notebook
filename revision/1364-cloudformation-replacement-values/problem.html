Replacement values AWS CloudFormation

AWS CloudFormation › 6. Creating, Updating and Deleting Stacks › Replacement values

ValueMeaning
FalseIn-place update, no teardown
TrueThe resource is destroyed and recreated
ConditionalDepends on context

Changing the instance type is Conditional: usually non-destructive, unless the instance is in an auto-scaling group. Changing the AMI is True, because a new base image needs a new instance.
