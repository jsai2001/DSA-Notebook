What SQLAlchemy is Database with Python

Database with Python › 3. SQLAlchemy Core and ORM › What SQLAlchemy is

A popular Python SQL toolkit and ORM that lets you use databases in a Pythonic way and works with Flask and other frameworks, on SQLite, MySQL and Postgres.

  • Core: schema-centric. It works with tables, keys and SQL concepts through the SQL Expression Language, a mild abstraction of SQL that is consistent across databases.
  • ORM: domain-model-centric. It abstracts database concepts into classes and uses the unit-of-work pattern to keep objects and the database consistent. It is built on Core, so you can use both together.
  • Pros: simplifies the data layer, especially for people who do not know SQL, and queries are fast out of the box.
  • Cons: can hide the SQL and move complexity into application code. Experts may write faster SQL by hand.
  • SQLAlchemy 2.0 unifies Core and ORM and cuts down the number of ways to do one task.
