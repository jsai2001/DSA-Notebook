A RAG system is only as good as the data it retrieves. Real PDFs have inconsistent layouts, images/charts (need OCR), tables, and header/footer noise; the course deliberately uses simple book PDFs. Consider: document content, document elements (title, narrative text, list items, tables, images), and element metadata (filename, filetype, page number, section) for filtering and hybrid search.
