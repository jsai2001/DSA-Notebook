8.4 Ensemble query engine (1/2) RAG with LlamaIndex

RAG with LlamaIndex › 8. Modular RAG › 8.4 Ensemble query engine

Run several query engines (top-k vector, keyword table, knowledge graph, etc.) and let an LLM rate each result's relevance and synthesize one answer. Steps: build indexes over the same nodes → query engines with a QA prompt that asks for a relevance score → wrap each as a QueryEngineTool with a clear description → RouterQueryEngine with LLMMultiSelector (the LLM can pick more than one tool) → TreeSummarize combines the answers. A selector can choose a data source, decide between summarization and semantic search, or combine multiple choices.
