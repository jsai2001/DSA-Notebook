  • Store AWS_ACCESS_KEY_ID and AWS_SECRET_ACCESS_KEY in GitHub Secrets.
  • Set them with the aws-actions/configure-aws-credentials action (the step shown in Q62).
  • Prefer IAM roles with temporary credentials via OIDC (see Q76).
  • Never hardcode credentials in scripts or workflow files.
