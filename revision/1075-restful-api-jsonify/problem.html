jsonify RESTful API

RESTful API › 3. Returning JSON, Status Codes, URL Parameters and Variables › jsonify

jsonify turns keyword arguments or a dict into a JSON response and sets Content-Type: application/json. Without it, the endpoint returns plain text.

Several pairs are allowed: jsonify(message="...", status="success") returns {"message": "...", "status": "success"}.
