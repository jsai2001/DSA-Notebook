URL (query) parameters RESTful API

RESTful API › 3. Returning JSON, Status Codes, URL Parameters and Variables › URL (query) parameters

  • Sent after ? as key/value pairs: ?name=Bruce&age=28. Read with request.args.get('name').
  • Values are strings, so cast them (int(...)).
  • Business rules stay in the API, so the frontend only builds the URL. Validate missing or non-numeric values, and sanitize anything that reaches a DB query.
