Adding a graph to a dashboard AWS CloudWatch

AWS CloudWatch › 10. Dashboards › Adding a graph to a dashboard

  • Dashboards > create (for example "Metrics") or edit an existing one > add widget. Widget types include line graph, alarm status, text and logs. Use Line for time series.
  • Option 1: build the metrics and math inside the widget.
  • Option 2: from an existing graph choose Actions > Add to dashboard, pick the dashboard and widget type (Line), give a title (for example "MathExpression") and add it.
  • Save the dashboard to persist it. Add several widgets for the metrics the business needs.
