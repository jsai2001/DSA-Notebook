Task-level tools CrewAI

CrewAI › 8. Tasks › Task-level tools

Task tools override agent tools for that task, which reduces non-determinism. If only the agent has tools, it uses its own; if only the task has tools, the task's are used. Example uses: search tool on a research task (ground it in web data), database query tool on a summary task.
