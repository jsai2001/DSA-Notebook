Creating a heartbeat canary AWS CloudWatch

AWS CloudWatch › 12. Synthetics Canaries › Creating a heartbeat canary

CloudWatch > Application monitoring > Synthetics Canaries > Create canary. Creation methods:

  • Blueprint: predefined templates (heartbeat monitoring) for beginners.
  • Inline editor: write a custom script.
  • Import from S3: reuse a script stored in S3.

For the heartbeat blueprint, set a name, the endpoint URL (remove stray parts such as #), optional additional endpoints, screenshots (on by default) and a schedule (continuous, a cron expression, or run once). The blueprint script is the same pattern as above with executeHttpStep('Check Page Load', ...) against /.
