Q. A cluster is running out of resources. How do you analyze usage with Python and suggest optimizations? Use the kubernetes client and Metrics API to compare usage with limits.

Q. A Python script calling the Kubernetes API is timing out on a large cluster. How do you optimize it?

  • Use pagination: limit results with limit and continue.
  • Increase the timeout: adjust the HTTP client timeout.
  • Cache results: store frequently accessed data locally.
  • Parallelize requests: use concurrent.futures.
