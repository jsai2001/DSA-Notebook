Example 1: Weather MCP Model Context Protocol

Model Context Protocol › 3. Examples, Use Cases and Finding Servers › Example 1: Weather MCP

Prompt: "My family's going on a two-day roadtrip to Squamish tomorrow. What clothes should we bring to fit with the weather?"

  1. Claude identifies the Weather MCP and detects the tools get_forecast and get_current_weather.
  2. The user approves the tools.
  3. The server calls the Open-Meteo API and sends the data to Claude.
  4. Claude answers with clothing advice (for example, bring winter rain gear).

Point: language models have no access to current weather; MCP bridges that gap.
