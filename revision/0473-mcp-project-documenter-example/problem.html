Model Context Protocol › 10. Using MCP in Cursor and the Documenter Workflow › Project Documenter example

Automates documentation: read project files, summarize them into project.md, generate/update README.md, and assess README quality. Real implementation: mcp-server-examples/projectDocumenter (TypeScript, SDK ^1.7.0, zod, fs/promises).

KindNameBehavior
Toolgenerate-project-mdCollect project code into project.md, respecting .gitignore (adds project.md to it)
Tooldocument-projectGenerate project.md and a README; updateExisting boolean defaults to true
Toolupdate-readmeWrite given content to README.md
Toolassess-readme-qualityReview the README against modern documentation standards
Resourcesproject-md://{projectPath}, readme://{projectPath}Read the files, or return a "not found" text
Promptsgenerate-readme, assess-readmeInstruct the model to read project.md first, then write or evaluate the README (criteria: comprehensiveness, clarity, structure, accuracy, usefulness)

Pattern shared by every tool: validate that projectPath is a directory (fs.stat), return isError: true with a message on failure, and wrap the work in try/catch.

(Condensed from the exercise file, which wraps each step in nested try/catch.) The server starts with new StdioServerTransport() inside an async main() that logs to console.error (stdout is reserved for the protocol) and exits with code 1 on failure.

test-server.sh builds with npm run build, creates a temp project with sample files (or uses a path you pass), and launches npx @modelcontextprotocol/inspector node dist/index.js so you can try the generate-readme prompt/tools.

Development workflow for such an MCP: identify a repetitive task (README creation, 30-60 minutes per project), design the tools (read, write, validate), implement with least privilege (read-only where possible, validated paths, limited directories, sanitized inputs), test extensively (normal use, traversal, invalid input, edge cases, adversarial prompts), deploy and monitor (log operations, review unexpected behavior).
