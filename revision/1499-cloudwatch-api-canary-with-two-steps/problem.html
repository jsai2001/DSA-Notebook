API canary with two steps AWS CloudWatch

AWS CloudWatch › 12. Synthetics Canaries › API canary with two steps

Create canary > blueprint API Canary, name serverlessapi. Choose "I'm using Amazon API Gateway", pick the API (cloudwatchapi) and stage (Production); the hostname fills in. Add two HTTP requests:

  1. Create new item: POST to the base URL with a JSON payload (id, name). Untick "Continue if step fails" so the run stops if the POST fails.
  2. Get created item: GET by id, path such as /production/5.
