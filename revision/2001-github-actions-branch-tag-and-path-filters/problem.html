Branch, tag and path filters GitHub Actions

GitHub Actions › 2. Workflow syntax and triggers › Branch, tag and path filters

Q. How do you run a workflow only on specific branches or tags? Use branches or tags filters under the event.

Q. How do you run a workflow only when certain files change (for example .py files)? Use a paths filter.

Q. How do you run jobs by change type in a monorepo (frontend vs backend)? Use paths (or if with change detection).

Q. How do you run a job only when README.md changes? Check the commit's modified files with an if on the job.
