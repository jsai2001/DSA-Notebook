Q. What is the difference between a Freestyle job and a Pipeline job?

  • Freestyle: configured in the GUI, roughly single-stage; simple but limited, and the config lives inside Jenkins (harder to version and review).
  • Pipeline: defined as code in a Jenkinsfile (Groovy); supports multi-stage flows, parallelism, when and input; lives in source control (auditable, reusable, portable).

Q. What are Jenkins plugins, and how do they extend core functionality? Plugins are add-ons for SCM integrations (Git), build tools, pipeline steps, credential providers, cloud agents (Kubernetes, EC2), notifications and more. Jenkins core is intentionally minimal; almost all real functionality comes from plugins, managed under Manage Jenkins, Plugins.
