Start with Playground > Chat: Select Model, pick provider and model (for example Anthropic, Claude 3.5 Sonnet), Apply, optionally add a system prompt, chat.

A system prompt sets persistent instructions for every response in the session. It enforces methodology, output format and consistent style.
