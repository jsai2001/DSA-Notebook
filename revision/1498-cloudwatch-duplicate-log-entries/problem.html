Duplicate log entries AWS CloudWatch

AWS CloudWatch › 18. Troubleshooting Logs › Duplicate log entries

Q. Log entries are duplicated. What is the usual cause? Several writers send the same logs. Check for more than one agent process or an application logger that also ships logs, and keep a single stream.

Check my-app-logs for duplicate streams and review the application code or agent config.
