Angular › 3. Decorators and Modules › Modules (NgModule)

  • A module groups closely related components, services, pipes and directives. Files are named *.module.ts.
  • Standalone (Angular 14+) lets you use these pieces without a module. Modules are still the norm in existing projects.
  • The module class body is empty. The decorator metadata does the work; the class only tells Angular what to load.
  • Only the root module has bootstrap (usually one component). Use one root module plus feature modules.
PropertyMeaning
declarationscomponents, directives, pipes owned by this module. Each can belong to one module only (compiler error otherwise)
importsexternal modules whose exports are usable in this module's templates
exportscode made available to modules that import this one
providersservices for dependency injection. Rule: modules go in imports, services in providers
bootstrapcomponent(s) to load at launch, root module only

exports, providers and the other properties are optional and can be omitted or left as empty arrays.
