What SQLite is Database with Python

Database with Python › 2. SQLite with Python › What SQLite is

SQLite is a lightweight RDBMS used from Python through the sqlite3 module, which follows the Python Database API.

  • Serverless: runs inside the application, with the database stored as a file on disk, so access is fast.
  • No drivers or server configuration needed, and self-contained, so it is portable (phones, game consoles).
  • ACID compliant: transactions are atomic, consistent, isolated and durable, with no partial state even after a crash.
  • Good for prototyping, with the option to move to a larger database later. Use the same database locally and in production to avoid surprises.
  • SQLite has no datetime type. Use TEXT, REAL or INT (the course uses INT for a year).
