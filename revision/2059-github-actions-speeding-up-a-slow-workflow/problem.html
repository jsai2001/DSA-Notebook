Speeding up a slow workflow GitHub Actions

GitHub Actions › 5. Caching, artifacts and performance › Speeding up a slow workflow

Q. A workflow takes too long and delays feedback. How do you optimize it? Cache dependencies, parallelize jobs, skip unnecessary steps with if, optimize commands and use faster runners.

Q. A workflow is too slow (about 20 minutes). What do you do? The same measures: cache, parallelize, skip steps.

Q. A workflow fails intermittently because of network issues while downloading dependencies. How do you fix it? Cache dependencies, use a proxy, retry steps and increase timeouts.
