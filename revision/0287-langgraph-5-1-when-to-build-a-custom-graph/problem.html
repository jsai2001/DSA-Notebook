5.1 When to build a custom graph LangGraph

LangGraph › 5. Custom Orders Agent (hand-built graph) › 5.1 When to build a custom graph

create_react_agent is a ready-made graph. Build your own StateGraph for control over nodes, edges, state and routing. Nodes communicate through agent state, not edges.

Use case: Orders chatbot over data/Laptop Orders.csv (Order ID, Product Ordered, Quantity Ordered, Delivery Date) that gets order details and updates quantities (DataFrame standing in for an RDBMS).

Graph: orders_llm → conditional edge (tool call?) → yes: orders_tools → back to orders_llm; no: END. The LLM loops until it answers without a tool call.
