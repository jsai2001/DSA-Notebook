RDS and Aurora AWS

AWS › 5. Databases › RDS and Aurora

Q. What is Amazon RDS and which databases does it support? Managed relational databases: MySQL, PostgreSQL, MariaDB, Oracle, SQL Server and Aurora.

Q. What is Multi-AZ in RDS? Enable Multi-AZ and RDS syncs the primary to a standby in another AZ for failover.

Q. Aurora vs. RDS?

  • Aurora: faster, scalable, six-copy storage.
  • RDS: standard engines, simpler.
