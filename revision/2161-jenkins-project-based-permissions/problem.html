Project-based permissions Jenkins

Jenkins › 7. Security, Credentials and Access Control › Project-based permissions

Project-based matrix authorization sets permissions per job or folder instead of globally.

  1. Configure Global Security, choose Project-based Matrix Authorization Strategy.
  2. Recreate the matrix, since global settings do not carry over: admin with Overall Administer, other users with Overall Read.
  3. Open a job (for example complex-pipeline), Configure, enable Project-based security, add the user and grant Build, Delete and so on.

The user then sees only the jobs they have rights on.
