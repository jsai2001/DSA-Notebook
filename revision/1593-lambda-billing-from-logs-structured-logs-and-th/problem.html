Q84. How do you compute total billable duration from REPORT logs? Each REPORT line shows Billed Duration (ms, rounded up to the nearest 1 ms) and Memory Size. Cost is about the sum of (Billed Duration in seconds x Memory in GB) x price per GB-second, plus the per-request cost. Sum Billed Duration across invocations (or use CloudWatch Duration x count) to estimate billable time.

Q85. How do you write structured JSON logs for aggregators? Emit single-line JSON so CloudWatch Logs Insights and aggregators (Datadog, ELK) can parse fields. Set the function's log format to JSON (advanced logging controls) and/or log JSON yourself with a request id or correlation id.

Q86. What is the context object, and what does it provide? Runtime information about the invocation: aws_request_id, function_name, function_version, memory_limit_in_mb, log_group_name/log_stream_name, invoked_function_arn and get_remaining_time_in_millis() (time left before timeout, useful to bail out or checkpoint).
