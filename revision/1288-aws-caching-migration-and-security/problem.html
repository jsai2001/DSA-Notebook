Caching, migration and security AWS

AWS › 5. Databases › Caching, migration and security

Q. What is Amazon ElastiCache? An in-memory cache (Redis or Memcached) that speeds up apps by reducing database load.

Q. How do you migrate an on-prem database to AWS? Use DMS: bulk move, then sync changes, then switch the app.

Q. How do you secure an AWS database? IAM, encryption (KMS and SSL), private subnet, logs and backups.
