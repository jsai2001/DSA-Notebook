Database with Python › 5. PostgreSQL with Python › Library challenge: tables and models

Create a Postgres database library with authors, books and a junction table AuthorBooks (bookauthor_id, author_id, book_id). The junction table allows many books per author and many authors per book. Tables are defined explicitly (no automap) and created with Base.metadata.create_all(engine). Install with pip3 install sqlalchemy psycopg2.
