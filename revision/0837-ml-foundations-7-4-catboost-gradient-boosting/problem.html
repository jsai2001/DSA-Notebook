ML Foundations › 7. Model Creation › 7.4 CatBoost (gradient boosting)

Golf analogy: a decision tree is one swing; boosting is many swings where each corrects the previous error. CatBoost builds about 1000 sequential trees, each fixing the previous trees' errors.

CatBoost doesn't accept Polars, so add a pandas conversion step, and y must be a 1-D NumPy array.

R² ≈ 0.9, the best so far.
