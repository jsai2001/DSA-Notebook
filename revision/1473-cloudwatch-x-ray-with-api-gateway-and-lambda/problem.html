X-Ray with API Gateway and Lambda AWS CloudWatch

AWS CloudWatch › 13. X-Ray Tracing › X-Ray with API Gateway and Lambda

  1. API Gateway console > the API > Stages > production > Logs and Tracing > enable X-Ray Tracing, save.
  2. Lambda console > the function > Configuration > Monitoring and operations tools > Edit > enable Active tracing, save.
  3. Send traffic (1,000 requests, one failure in three) with the API tester.
  4. CloudWatch > X-Ray Traces > Service Map shows Client to API Gateway (production stage) to Lambda. API Gateway has a red circle (about 35% of requests fail with 502); Lambda has a yellow circle (400 errors for invalid payloads).
  5. Select the API > View traces, open a failed 502 trace. The flow ends at Lambda returning a non-OK status; Exceptions shows "One or more parameter values were invalid, missing the key ID in the item". Fix the missing key in the payload.
