Kubernetes › 6. Configuration and Secrets › ConfigMaps and Secrets

Q. What is a ConfigMap, and how is it used? It stores non-sensitive config data, used as env vars or files in Pods.

Q. What is a Secret, and how does it differ from a ConfigMap? A Secret stores sensitive data (for example passwords) and is base64-encoded. A ConfigMap holds plain text.

Q. What is the difference between a base64-encoded Secret and a plain-text ConfigMap?

  • Secret: encoded for obscurity.
  • ConfigMap: raw text for configs.
