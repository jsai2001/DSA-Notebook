Model versioning MLOps

MLOps › 6. Model Management › Model versioning

Versions establish lineage and manage the life cycle. The scheme should resemble software versioning (numbering is org-specific).

  • Linked baselines: model version, data version and code version tied together.
  • Traceability: from a model version, find its input data and hyperparameters.
  • Performance tracking across versions.
  • Stable references for integration and testing until they finish.
  • Enables structured life cycle management.
