Virtual networking (1/2) AZ-900

AZ-900 › 6. Compute and networking › Virtual networking

A VNet is your own network in Azure with an IP address space in CIDR (for example 10.0.0.0/16, 65,534 usable IPs), split into subnets. Typical multi-tier layout: web tier (internet-facing), middle tier (business rules), data tier (no direct internet). Only the web tier should face the internet, and the web tier should not talk straight to the data tier.

VNet peering connects two VNets over Microsoft's private backbone, not the internet. Same region or different regions (Global VNet Peering). Peered traffic is not encrypted.

Azure DNS hosts DNS records (A, CNAME, MX...). Public zones are internet-facing, private zones only resolve inside Azure VNets.
