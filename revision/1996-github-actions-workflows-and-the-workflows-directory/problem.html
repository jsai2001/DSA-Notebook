Workflows and the workflows directory GitHub Actions

GitHub Actions › 1. CI/CD and GitHub Actions basics › Workflows and the workflows directory

Q. What is a workflow in GitHub Actions, and how is it defined? A workflow is an automated process made of jobs, triggered by events. It is defined in a YAML file under .github/workflows/, specifying a name, triggers (on) and jobs.

Q. What is the purpose of the .github/workflows directory? It holds all workflow YAML files. GitHub looks there to find and run automation when events occur.

Q. What are the key components of a workflow file?

  • name: workflow label.
  • on: event triggers (for example push).
  • jobs: tasks to run, each with runs-on (runner type) and steps (actions or commands).

Q. What is the typical structure of a .yml workflow file? name, on (triggers), then jobs containing runs-on and steps.

Q. What is the purpose of the on keyword? It defines the events (such as push or pull_request) that trigger the workflow.
