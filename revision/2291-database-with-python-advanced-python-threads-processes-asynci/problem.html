Q. What are multithreading and the GIL? The GIL limits CPU-bound parallelism in CPython, so threads are good for I/O.

Q. Multiprocessing vs multithreading? Multithreading shares memory and is GIL-limited. Multiprocessing uses separate memory and has no GIL.

Q. What is asyncio? Python's async programming library.

Q. What are closures? Nested functions that keep the outer scope.
