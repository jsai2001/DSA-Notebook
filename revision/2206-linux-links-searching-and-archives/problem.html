Q. Soft vs. hard links? A soft link (ln -s) is a path reference. It breaks if the target is deleted and can cross file systems. A hard link (ln) shares the same inode, persists if the target is deleted and must stay on the same file system.

Q. How do you find files with find and locate? find /home -name "file.txt" searches in real time. locate file.txt is faster because it uses a database.
