Gotcha: the notebooks spell it similiarty_top_k. The correct retriever argument is similarity_top_k; the misspelled keyword is silently passed through as a kwarg, so the default (2) may be what actually applies. The default similarity_top_k is 2.

MMR (Maximal Marginal Relevance) balances relevance and diversity: iteratively pick items that are relevant to the query but different from already-selected items.

MMR = argmax [ λ · Relevance(item, query) − (1 − λ) · max Similarity(item, selected) ]

λ near 1 favors relevance, near 0 favors diversity (mmr_threshold is λ). It depends on embeddings, so chunk size affects it. Enable with vector_store_query_mode="mmr".
