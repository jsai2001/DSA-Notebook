Core vs ORM: which to use Database with Python

Database with Python › 3. SQLAlchemy Core and ORM › Core vs ORM: which to use

Core is closer to raw SQL and suits people comfortable with SQL concepts. The ORM suits object-oriented code. Both fit web apps, data tools and scripts. Switching databases (Postgres to MySQL or SQLite) mostly means changing the connection string passed to create_engine.
