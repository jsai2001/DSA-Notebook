Explaining what clusters represent matters more than producing them. Three methods:

1. Summarize by group mean (pandas). Each column is a cluster and each row a feature. Red is low and blue is high, so you can describe each cluster in business terms (for example, "cluster 4 is the high-demand, high-price cluster").

Real data used: Australian electricity (datasets library).

2. Surrogate model. Train a decision tree to predict the cluster labels (supervised: X plus cluster labels), then read the tree to explain the clusters. Start at the root; each node asks "is feature < value?" (left = yes, right = no); a leaf is the predicted cluster. The tree also shows which features matter most. In the electricity example, date was the first split, class 4 = high date/period/demand, class 2 = low across the board.

3. Visualize in 2D/3D with PCA, t-SNE, or UMAP (see section 4).
