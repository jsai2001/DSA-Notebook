Namespaces AWS CloudWatch

AWS CloudWatch › 3. Metrics › Namespaces

  • AWS namespaces hold metrics from services (AWS/ApiGateway, AWS/Lambda, AWS/EC2, DynamoDB).
  • Custom namespaces hold user-defined metrics.

Console path: CloudWatch > Metrics > All metrics > pick namespace > dimension (for example By Api Name, By Function Name) > metric. Use Graphed metrics to change statistic (Average vs Sum) and period (5 minutes down to 1 second). Clear old selections so graphs do not accumulate previous metrics.
