Autoscaling Kubernetes

Kubernetes › 8. Scaling and Availability › Autoscaling

Q. What is Horizontal Pod Autoscaling (HPA), and how does it work? It scales Pod replicas based on CPU or memory and needs the metrics server.

Q. How do you configure HPA based on custom metrics? Use Prometheus Adapter and set the custom metric target in the HPA spec.

Q. What is Vertical Pod Autoscaling (VPA), and when is it useful? It adjusts Pod resource limits, which helps optimize fixed workloads.

Q. How do you scale an application for sudden traffic spikes? Use HPA or scale manually with kubectl scale, plus the cluster autoscaler.
