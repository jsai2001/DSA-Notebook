Core libraryPurpose
torchTensors, autograd, base workflows
torch.nnLayers (Linear, Conv2d), losses, activations
torch.optimOptimizers: SGD, Adam, RMSprop
torch.autogradAutomatic differentiation
torch.utils.dataDataset, DataLoader
Supporting libraryDomain
TorchVisionVision: pretrained models, datasets, transforms
TorchAudioAudio: datasets, transforms, speech models
TorchTextNLP: datasets, preprocessing, embeddings
TorchServeServe models at scale with REST APIs
torch.distributedMulti-GPU / multi-node training
Advanced toolPurpose
torch.compileCompile models for speed (2.x)
torch.jit / TorchScriptStatic graph, export without Python runtime
torch.fxProgram transformation and analysis
torch.multiprocessingParallel data loading / distributed training

Ecosystem add-ons: PyTorch Lightning (less boilerplate), Hugging Face Transformers (NLP/multimodal models), fastai, docTR (OCR), vLLM (high-throughput LLM inference), DeepSpeed (distributed training, Microsoft), depyf (debug compiler bytecode).
