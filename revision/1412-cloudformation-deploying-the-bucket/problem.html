AWS CloudFormation › 8. S3 Static Website Template (JSON) › Deploying the bucket

  1. CloudFormation, Create Stack, Template is ready, Upload a template file (S3.template).
  2. Enter a stack name (for example demo).
  3. Optionally add tags (purpose: demo); they attach to the stack and everything it creates.
  4. Leave advanced options at the defaults, then Next, Review, Create Stack.
