Run in GitHub Codespaces (browser dev environment; no local setup, consistent across team; pick the 4-core/16 GB machine), locally, or in Google Colab (each notebook pins its installs in the first cell).

01_Getting_Started/install.sh automates all of the above (checks that conda exists, creates env, installs the packages, links the kernel): chmod +x install.sh && ./install.sh.
