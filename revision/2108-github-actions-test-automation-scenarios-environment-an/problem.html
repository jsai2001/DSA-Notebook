GitHub Actions › 12. Test automation with GitHub Actions › Test automation scenarios: environment and security

Q. The workflow is too slow. How do you optimize it? Cache dependencies, parallelize, run affected tests and use faster runners.

Q. A Bash script fails because of a missing dependency. How do you resolve it? Install the dependency, use Docker or check for tools.

Q. How do you ensure PRs pass tests before merging? Enable branch protection and require the test workflow status.

Q. A test script exposes credentials in logs. How do you mitigate it? Use secrets, mask logs and audit scripts.

Q. How do you set up a test database? Use a service container such as PostgreSQL.

Q. How do you automate a daily test report? Schedule the workflow, run a Python report script and upload the artifact.
