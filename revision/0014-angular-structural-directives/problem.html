Structural directives Angular

Angular › 5. Templates and Data Binding › Structural directives

Start with * and add or remove elements from the DOM (not CSS hide/show).

  • *ngIf="cond": renders when truthy. else templateRef renders the alternate when falsy. *ngIf="obs$ | async as value" unwraps an observable into a local variable.
  • *ngFor="let item of items": repeats an element per array item.
  • <ng-template #name>: content that does not render unless a trigger (such as else) asks for it.

With players$ = this.api.getAllPlayers$() the <ul> renders. With of(undefined) the loading template renders.

Composing pages from components: use the selector as an element.

Any CSS framework works (Bootstrap here is optional). Check changes with npm start.
