ML Foundations › 8. Model Evaluation › MSE, RMSE, MAE

.score() takes (X_test, y_test). Every sklearn.metrics function takes (y_true, y_predicted).

MSE is in squared units, hard to interpret. Errors are squared (or absolute-valued in MAE) so positive and negative errors don't cancel.

Note: squared=False is deprecated in newer scikit-learn (use root_mean_squared_error); the course pins 1.4.1 where it works.
