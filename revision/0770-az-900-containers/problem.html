Containers AZ-900

AZ-900 › 6. Compute and networking › Containers

A container is an isolated environment where an app and its dependencies run.

  1. Built from an image (like a zip of OS pieces, code, modules, web servers).
  2. Images live in a repository.
  3. A container runtime (Docker) downloads and runs the image.

Containers hold only user-mode OS components and rely on the host's kernel. A Linux image needs a Linux host, and a Windows image needs a Windows host.
