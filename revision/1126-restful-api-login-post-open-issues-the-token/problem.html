Login (POST, open): issues the token RESTful API

RESTful API › 7. Security: Registration, JWT, Login, Email › Login (POST, open): issues the token

Accepts JSON (request.is_json) or form data. A matching email and password returns an access_token (200), otherwise 401. POST for login is common though debated.

Clients then send the token as Authorization: Bearer <token> to protected routes.
