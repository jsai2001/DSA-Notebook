Model Context Protocol › 1. Core Concepts and Architecture › Components

The request flows down the chain and the result returns up the same chain.

ComponentRoleExamples
MCP HostApplication that wants data accessClaude Desktop, Cursor
MCP ClientExtension inside the host that maintains the protocol connectionBuilt into the host
MCP ServerPackage that exposes resources/tools/promptsWeather MCP, GitHub MCP, your code
Data source / toolThe thing being accessedDatabase, API, file system

Flow: User -> AI chat app (host + client) -> MCP server -> data source/tool, then back.

MCP servers are language-agnostic: function calling where the functions are plugins. SDKs exist for Python and TypeScript. The server can run locally on your machine or be published for others.
