Q52. How do Lambda Authorizers work with API Gateway? A Lambda Authorizer is a function API Gateway calls before the target function to authenticate and authorize a request. Token authorizers inspect a bearer token. Request authorizers inspect headers, query and context. It returns an IAM policy (Allow or Deny) plus optional context, and API Gateway caches the result by key and TTL.

Q53. How do you stop an arbitrary S3 bucket from triggering your function? On the function's resource-based policy, scope the S3 principal with a SourceArn condition (the specific bucket ARN) and SourceAccount. Only that bucket can invoke the function, which prevents a confused-deputy case where another bucket or account triggers it.

Q55. Can a function in Account A be triggered by an S3 event in Account B? Yes. Add a resource-based policy on the Account A function that allows the S3 service principal with SourceAccount = Account B and SourceArn = the Account B bucket. Configure the Account B bucket notification to point at the Account A function ARN. Cross-account access needs explicit permissions on both sides.
