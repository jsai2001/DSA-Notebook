Routes and view functions Flask

Flask › 3. Routes, Views and URL Parameters › Routes and view functions

A route maps a URL to a Python function via @app.route(). A view function runs when the route is hit and does the work: return HTML, render a template, redirect, query a database. A view can return an HTML string directly, for example return "<h1>Welcome to My Blog</h1>".

render_template("index.html") serves an HTML file from templates/ instead of a raw string (the only change from the first app).
