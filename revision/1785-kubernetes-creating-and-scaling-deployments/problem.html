Kubernetes › 17. Kubernetes with Python › Creating and scaling Deployments

Q. How do you deploy a Kubernetes Deployment with the kubernetes client? Build a V1Deployment and create it with AppsV1Api.

Q. How do you scale a Deployment programmatically? Use AppsV1Api.patch_namespaced_deployment_scale with the deployment name and namespace.
