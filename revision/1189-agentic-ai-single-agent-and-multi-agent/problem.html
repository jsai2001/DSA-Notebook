Single-agent and multi-agent Agentic AI Fundamentals

Agentic AI Fundamentals › 8. Agent Architectures › Single-agent and multi-agent

  • Single-agent: one agent interacts with the environment. Suited to well-defined problems and needs no feedback from other agents.
  • Multi-agent: several agents collaborate, with different execution paths, using each agent's specialized capabilities. Example: automated firmware upgrade through camera-to-server communication.
