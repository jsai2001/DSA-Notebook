5. Linear Regression ML Algorithms

ML Algorithms › 5. Linear Regression

Supervised: pass X and a numeric y. It fits the line (weights) that minimizes the sum of squared errors.

$$y = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + ... + \beta_n x_n$$

β₀ is the intercept and each β is the weight (slope) of one feature column.

$$\text{slope} = \frac{\sum (x_i - \bar{x})(y_i - \bar{y})}{\sum (x_i - \bar{x})^2} \qquad \text{intercept} = \bar{y} - \text{slope} \times \bar{x}$$
