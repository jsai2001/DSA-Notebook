GraphQL › 8. Queries in Depth: List, Aliases, Fragments › Aliases

Aliases run several queries (even the same one with different arguments) in one request and label each result. The response key is the alias, not the query name. Pure query syntax, no server change. Without aliases you would need one request per product.
