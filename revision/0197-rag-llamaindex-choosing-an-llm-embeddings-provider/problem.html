Selection criteria: business objective/use case; tested capability (accuracy, relevance); license (commercial vs non-commercial, attribution; Mistral is the most permissive); language support; security and privacy (encryption, GDPR/HIPAA); cost and latency; community and support.

API keys: OpenAI (platform.openai.com → API Keys → Create new secret key; shown once) and Cohere (dashboard → API Key; viewable later). Never commit keys.
