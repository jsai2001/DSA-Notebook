GCP for Machine Learning › 1. Setup, Prerequisites and Cost Control

Vertex AI covers LLM integration, custom model development/tuning/deployment, notebooks, APIs, Google AI Studio for quick prototyping, and end-to-end MLOps.

Prerequisites: ML basics, Python ML libraries, Jupyter notebooks, GCP core services (buckets, VMs, IAM/permissions).

Cost rules for learning (and for real work):

  • Use a dedicated project and delete it when done (simplest cost control).
  • Set a billing alert/budget.
  • Use only what you need. GPUs/TPUs are costly.
  • Stop services when idle. VMs and notebooks bill while running.

Variant (course conclusion): same flow with ml-continued-learning, budget 100 and thresholds 0.5/0.8/1.0, plus enabling several APIs in one command: gcloud services enable aiplatform.googleapis.com notebooks.googleapis.com bigquery.googleapis.com.
