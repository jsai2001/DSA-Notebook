Canary recorder plugin AWS CloudWatch

AWS CloudWatch › 12. Synthetics Canaries › Canary recorder plugin

The CloudWatch Synthetics Recorder browser extension records user flows (click, log in, type) and generates the script, so you do not write it by hand.

  1. Create canary > Canary Recorder > install the Chrome extension.
  2. Open the target app (scorekeep), click Start recording, perform the actions (set user and game to "Canary", create a session), click End recording, and copy the script.
  3. Name the canary (scorekeepapp) and paste or upload the script.

Limits: the app URL is hardcoded and default step names are generic.
