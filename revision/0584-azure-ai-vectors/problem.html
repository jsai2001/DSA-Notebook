Azure AI Services › 5. Search › Vectors

  • Vector embeddings map words, phrases, or documents into a multidimensional space, so similarity can be computed. Benefits: semantic similarity, finding relevant documents, ranking by relevance.
  • At index creation, add a vector search section: algorithm (HNSW or exhaustive KNN), compression (scalar and binary quantization, oversampling, re-ranking with original vectors), and profiles (combinations of algorithm + compression).
  • At query time: POST the natural-language query to an embeddings endpoint to get a vector query, then POST that to the search endpoint.
