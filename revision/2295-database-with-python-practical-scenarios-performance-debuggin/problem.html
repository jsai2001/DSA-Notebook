Q. How do you optimize a script for large datasets? Use generators, NumPy or chunking.

Q. How do you debug a Python program? Use print(), pdb or IDE breakpoints.

Q. How do you handle memory leaks? Use tracemalloc and close resources.

Q. How do you process a large CSV without loading it all? Stream it row by row.
