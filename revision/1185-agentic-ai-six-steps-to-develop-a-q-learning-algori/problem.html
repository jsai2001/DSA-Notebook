StepComponentDescriptionExample
1Define environmentAll possible states, actions and interaction rulesEverything the agent can do and the responses it gets
2Identify statesA representation of the situation at one point in timeDark outside is a state the camera agent understands
3Define actionsThe actions the agent can takeCamera changes aperture for darkness; jet engine triggers fire suppression
4Establish reward signalNumerical values received after an action in a stateA "digital doggy treat"; goal is to maximize cumulative reward
5Develop policyStrategy mapping states to actionsAirline policy: never shut down a jet engine in flight
6Define value functionEstimates expected cumulative reward of a state under a policyAssesses long-term benefit of states and actions

After these steps the agent interacts, updates the Q-table and keeps improving.
