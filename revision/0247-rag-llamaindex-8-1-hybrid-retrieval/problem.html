8.1 Hybrid retrieval (1/3) RAG with LlamaIndex

RAG with LlamaIndex › 8. Modular RAG › 8.1 Hybrid retrieval

Combines vector search (semantic similarity) with keyword / full-text search (BM25).

SearchStrengthWeakness
Vector (dense)Finds semantically similar text without exact keywordsCan miss exact keyword matches
Keyword (BM25)Fast exact keyword matchingMisses semantic relationships
HybridBothMore setup

Hybrid search needs a docstore (BM25 reads from it) plus a vector store created with enable_hybrid=True.

vector_store_query_mode values

ModeBehavior
defaultPure dense vector search
hybridVector + keyword search; alpha weights them (alpha=0 → BM25 only, alpha=1 → vector only)
semantic_hybridHybrid plus a semantic reranking step
sparseSparse vectors (mostly zeros, good for exact keywords/details); needs a sparse embedding model (e.g., FastEmbed prithvida/Splade_PP_en_v1) and sparse_top_k (nodes fetched from each of the sparse and dense queries)
text_searchExact keyword matches only

similarity_top_k is the final node count after fusion; hybrid_top_k is the top-k for hybrid mode.
