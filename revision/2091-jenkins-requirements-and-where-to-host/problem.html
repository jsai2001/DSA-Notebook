Requirements and where to host Jenkins

Jenkins › 2. Installing a Jenkins Server › Requirements and where to host

The course setup is Ubuntu 20.04 LTS, OpenJDK 11 and Jenkins 2.332.1, with NGINX as a reverse proxy in front of Jenkins. Prefer a public cloud host (AWS, Google Cloud, Azure) because GitHub webhooks need a public URL. A local install (Windows, macOS, Linux) works for manual job runs but cannot receive webhooks. The whole setup takes about 15 minutes.
