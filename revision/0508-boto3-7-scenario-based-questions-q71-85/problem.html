Boto3 › 7. Scenario-Based Questions (Q71-85)

Q81. Create with boto3, hand off to Terraform. Tag resources for identification, generate Terraform config, bring them under management with terraform import, then validate that state matches AWS.

Q82. Slow boto3 script in a workflow. Paginate, cache results to avoid repeat calls, parallelize with ThreadPoolExecutor, use batch APIs.

Q83. Ansible fails because boto3-created resources are not ready yet. Use boto3 waiters, add retries in the playbook, and run boto3 and Ansible as separate dependent workflow steps.

Q84. Export EKS logs to S3. Use CloudWatch Logs create_export_task to an S3 bucket; schedule it in GitHub Actions.
