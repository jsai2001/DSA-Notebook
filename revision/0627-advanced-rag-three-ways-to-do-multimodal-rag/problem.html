MethodModelsVector storesComplexityUsage
1. Single multimodal model (canonical)11LowMost common
2. Multiple models (one per data type)NNHighRare, manual
3. Multiple multimodal modelsNNVery highAlmost never

Method 1: one model (e.g. CLIP for images + text), one embedding model, one vector store, same dimensionality, so images and text compare directly. LangChain/LlamaIndex route text vs image encoding for you; natively you call different encoders.

Method 2: separate store per model. Different models give different dimensionalities, and even when dimensions match, embeddings from different training contexts are not meaningfully comparable.

Method 3 reasons: (a) too many data types (video, audio, images, tables) for one model; (b) re-ranking, using models trained on different data as a "second opinion".
