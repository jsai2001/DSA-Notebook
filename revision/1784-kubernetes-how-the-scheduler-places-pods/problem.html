Kubernetes › 7. Scheduling and Resources › How the scheduler places Pods

Q. How does the scheduler decide where to place a Pod? It filters nodes (resources, taints), then scores them based on policies (for example least usage).

Q. What is a node selector, and how does it work? It matches Pods to nodes by labels (for example nodeSelector: disk=ssd).

Q. What is a taint and toleration, and how are they used?

  • Taint: repels Pods from nodes.
  • Toleration: allows Pods to ignore taints.
