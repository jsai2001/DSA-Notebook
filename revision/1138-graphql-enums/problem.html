An enum restricts a field to a fixed set of named values. It is more descriptive and extensible than a Boolean. Values are ALL_CAPS by convention. Here soldout: Boolean becomes an enum, in both the type and the input:

Switching Boolean to enum is a breaking change: old values fail with

Use soldout: ONSALE (was false) or soldout: SOLDOUT (was true), unquoted. After a schema change, restart the server (rs) and refresh GraphiQL. The response returns the enum as a string ("soldout": "ONSALE").
