Running a query AWS CloudWatch

AWS CloudWatch › 6. Logs Insights › Running a query

CloudWatch > Logs > Logs Insights. Pick the timeframe (default last 1 hour; use Custom for others), pick the log group (each service writes to its own group, for example the Lambda "Put Item Function" group), then write and run the query. Limit results to reduce query cost, since more results cost more. If nothing shows, generate successful and failed requests first.
