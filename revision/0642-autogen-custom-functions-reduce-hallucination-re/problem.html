Safety/gotchas: keep human_input_mode="ALWAYS" on the executor and review code before execution; set sensible timeout; use an isolated work_dir. Custom functions need docstrings and type hints; if they are ignored, check format_functions_for_prompt was applied and that the functions were passed to the executor. Failed runs: check timeout, work dir exists, required libraries installed.
