Vector Databases › 9. Use case 1: LLM semantic cache › Workflow

User prompt -> embed -> search cache (top-1) -> distance below threshold? Hit: return cached response. Miss: call LLM, store prompt + embedding + response, return response.

What is stored per entry: prompt text, prompt embedding (vector), response text. Requirements: one embedding model for all prompts, a distance threshold, a vector DB.
