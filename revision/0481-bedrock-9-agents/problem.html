Amazon Bedrock › 9. Agents

An agent selects a foundation model and does a very specific task. It follows the small-function principle: clear input, one unit of work, return value. Chain simple agents rather than building one complex one.

Agent = Foundation Model + Instructions + (optional) Knowledge Base + (optional) Code Interpreter

Agents can be tested in the console, called by API (Bash, Rust, Lambda), and orchestrated with other agents and knowledge bases. All agents go through the Bedrock Foundation Model Gateway (unified API), so an agent can pick an expensive model for complex tasks and a cheaper one for simple tasks, and you can upgrade models without changing agent code.

CapabilityExample
Text extractionStrip whitespace, format messy input, resize
Summation / computationExtract numbers from text and add them
Code interpreterAnalyze a failed build traceback and generate a fix
Automated testingRun a test, iterate if it fails

CI/CD pattern: build fails with a traceback, Agent 1 extracts the error and relevant code, Agent 2 (code interpreter) generates a small fix and corrects the test, Agent 3 re-runs the build. Pass means done, fail loops back to Agent 1. This try, fail, fix, retry loop is one of the most powerful agentic patterns.
