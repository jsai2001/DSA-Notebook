Q80. How do Lambda Extensions work, and what are internal vs external extensions? Extensions plug tools (observability, security, config) into the Lambda lifecycle through the Extensions API. Internal extensions run in-process inside the runtime (wrapper scripts, language agents). External extensions run as separate processes alongside the function, can start during Init and keep running through Invoke and Shutdown. They suit shipping logs and metrics and caching secrets without blocking the handler.
