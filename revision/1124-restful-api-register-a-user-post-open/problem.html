Register a user (POST, open) RESTful API

RESTful API › 7. Security: Registration, JWT, Login, Email › Register a user (POST, open)

Expects form fields email, first_name, last_name, password. Duplicate email returns 409, success returns 201. No Marshmallow is needed for the existence check.

Test with a new email (201) and with the seeded test@test.com (409). This is minimal: real apps add validation, password hashing and possibly approval workflows. Passwords here are stored in plain text for the demo only.
