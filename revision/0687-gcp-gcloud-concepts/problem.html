Google Cloud (GCP) › 2. Console, Cloud Shell and gcloud SDK › gcloud concepts

  • Command groups (a menu of commands or more groups), commands, configurations (named sets of properties; the default one is called default), properties (individual settings, in section/property form).
  • alpha and beta groups hold commands still in development. They may change and give early access to features not yet generally released.
  • Multiple configurations let you switch projects without setting and unsetting each property.
