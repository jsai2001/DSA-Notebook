LlamaIndex is a data framework for context-augmented LLM apps (LLM + private/domain data). Python and TypeScript SDKs exist; the course uses Python.

CapabilityWhat it is
Data connectors (Readers)Ingest from APIs, PDFs, SQL, etc.
IndexesIntermediate data structures optimized for LLM retrieval
Query enginesRetrieval interface that returns a synthesized answer
Chat enginesMulti-turn conversational interface over your data
Data agentsLLM-powered workers augmented with tools

Three kinds of packages: llama-index-core (loading, indexing, querying, evaluating; no integrations), integrations (LLMs, embeddings, vector stores, readers; each installed separately), and Llama Packs (community templates, often implementing techniques from papers). LlamaHub (llamahub.ai) catalogs all of them (150+ data loaders, 35+ agent tools, 50+ packs, 50+ LLMs, 25+ embeddings, 40+ vector stores); sort packs by downloads to find the popular ones.

Pipeline: Your data → Reader → Index (backed by a vector store such as Qdrant) → Query/Chat engine → LLM → Response.
