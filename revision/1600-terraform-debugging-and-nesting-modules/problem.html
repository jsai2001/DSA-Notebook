Debugging and nesting modules Terraform

Terraform › 4. Modules › Debugging and nesting modules

Q. How do you debug module issues? Use logs (TF_LOG=DEBUG), plan, and temporary outputs.

Q. Can you nest modules, and is there a depth limit? Yes, modules can call modules. There is no hard limit, but keep nesting shallow (2-3 levels).

Q. How do you update a module without breaking infrastructure? Test the new version, pin it, and check the plan for no recreation.
