Q. How do you manage disk space on the controller?

  • Build discarder: cap builds and artifacts kept per job (buildDiscarder).
  • Artifact retention: keep artifacts for fewer builds than logs.
  • Clean workspaces (cleanWs), offload artifacts to external storage (Artifactory, Nexus, S3) and monitor JENKINS_HOME disk.

Q. How do you clean workspaces after a build? Use the Workspace Cleanup plugin's cleanWs step, typically in post { always { } }, which frees disk and avoids stale files contaminating later builds.
