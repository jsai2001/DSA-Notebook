Ports and DNS Docker

Docker › 13. On-Call: Networking Problems › Ports and DNS

Q. Containerized app not accessible via the mapped port?

Verify the port mapping, that the app binds to 0.0.0.0, and that no host service conflicts.

Q. Port conflict: "Bind for 0.0.0.0:80 failed"?

Check for conflicting containers (docker ps) and avoid duplicate port usage.

Q. Container cannot resolve DNS names?

Verify host DNS, check network policies (port 53), and restart after DNS changes.
