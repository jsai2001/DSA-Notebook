Cloud Logging Google Cloud (GCP)

Google Cloud (GCP) › 9. Operations Tools: Logging, Debugger, Trace › Cloud Logging

  • Collects logs from all systems and apps. Auto-collected for App Engine, GKE, Cloud Run and Cloud Functions.
  • Other sources: Logging Agent (Compute Engine or AWS EC2), logging libraries (apps elsewhere), the Logging API (REST), and the gcloud CLI.
  • In Node.js on App Engine, console.log() is captured automatically. Libraries such as Winston or Bunyan also work.
