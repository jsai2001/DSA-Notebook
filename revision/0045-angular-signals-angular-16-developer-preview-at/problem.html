Reactive pattern: data is wrapped in getters and setters so Angular tracks changes and updates only what changed, instead of checking every component. The API may change, so check the docs.

signal(initialValue) returns a WritableSignal; the type is inferred, or given explicitly. Read a signal by calling it.

MethodUse
set(value)replace the value
update(fn)return a new value from the current one (immutable, recommended)
mutate(fn)change the current value in place (mutable, no return).

MessageService with these calls is in section 8.

computed() derives a read-only value from other signals. It is cached (recalculates only when dependencies change) and lazy (evaluated only when read), which suits filtering large arrays and heavy calculations.
