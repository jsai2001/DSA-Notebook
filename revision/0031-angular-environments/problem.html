Environment files change values (API URLs, keys, feature flags, footers) per build target without if logic. All files must have the same properties and types.

Always import from the production file (environment.ts). At build time the CLI replaces that import with the file for the active target.

Replacement flow: development builds swap the import to src/environments/environment.development; production builds keep src/environments/environment.

Feature flags (enableAnalytics, enableDebugMode, maxRetries) are plain key-value entries of the same kind.
