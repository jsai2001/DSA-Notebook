2. Admin and Built-in Auth Django

Django › 2. Admin and Built-in Auth

The admin site (/admin/) ships with Django and gives staff a web UI over the data. Red warnings at runserver mean migrations are not applied yet.

  • Admin features: list, filter, search, create/edit/delete (with confirmation), action history. Users and Groups are real DB tables.
  • Passwords are stored hashed (you only see random characters). Admin enforces password validation.
  • For a system without user input (e.g. a blog), you can create all data in admin and only use views to display it.
