Query engines that evaluate their own output and retry when it isn't good enough.

EngineEvaluatorOn failure
RetryQueryEngineRelevancyEvaluatorTransforms the query using the evaluation result and re-queries, up to max_retries
RetrySourceQueryEngineRelevancyEvaluatorEvaluates each source node, builds a new index from only the passing nodes, retries on it
RetryGuidelineQueryEngineGuidelineEvaluator (custom guidelines)Transforms the query from feedback (FeedbackQueryTransformation, optionally resynthesize_query=True) and retries

Each retry engine takes max_retries; if the response passes evaluation it is returned, and if max_retries is 0 the first response is returned unevaluated. Each retry costs extra LLM calls (evaluation plus re-query).
