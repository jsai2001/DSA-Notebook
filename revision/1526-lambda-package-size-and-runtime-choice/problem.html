Q24. How does package size affect cold start duration? Larger packages take longer to download and unpack during Init. Keep them lean: prune unused dependencies, use layers for shared libraries, tree-shake or minify, and avoid bundling large assets you do not need at runtime.

Q25. How do compiled languages (Go, Rust) compare with interpreted ones (Python, Node.js) for cold starts? Go and Rust usually have very fast cold starts and low memory overhead because they ship a native binary with no heavy runtime to boot. Python and Node.js are also fairly light. Java and .NET historically have the slowest cold starts because of JVM/CLR startup and class loading (mitigated by SnapStart and Provisioned Concurrency).
