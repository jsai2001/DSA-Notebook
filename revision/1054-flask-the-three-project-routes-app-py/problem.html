The three project routes (app.py) Flask

Flask › 3. Routes, Views and URL Parameters › The three project routes (app.py)

FunctionPurpose
render_template()Render HTML from templates/ combined with data
requestIncoming request data: method, form, query params, headers
redirect()Tell the client to go to another URL
url_for()Build a URL from a view function name (no .html)
  • /form accepts GET (show empty form) and POST (process data) via methods=["GET", "POST"]; request.method tells which.
  • POST-Redirect-GET: after a POST, redirect so a refresh does not resubmit.
  • Keep route paths and function names matching (/form -> form()).
  • url_for() takes the function name; render_template() takes the filename.
