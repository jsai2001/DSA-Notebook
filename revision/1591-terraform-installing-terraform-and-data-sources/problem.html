Terraform › 1. Terraform Basics › Installing Terraform and data sources

Q. How do you install Terraform, and what is needed? Download the binary, add it to PATH and verify. You need an OS, internet access and optionally Git.

Q. What is the difference between a resource and a data source? A resource is managed infrastructure (Terraform creates and deletes it). A data source is a read-only lookup of something that already exists.
