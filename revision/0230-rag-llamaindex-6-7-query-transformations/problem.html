6.7 Query transformations (1/2) RAG with LlamaIndex

RAG with LlamaIndex › 6. Advanced RAG: Pre-Retrieval & Indexing › 6.7 Query transformations

Rewrite or decompose the user query before retrieval. Three techniques:

1. Query expansion / rewriting: an LLM generates several alternate queries (few-shot prompt), each sent for retrieval.

2. SubQuestionQueryEngine: decomposes a complex query into sub-questions, each aimed at a specific data source (a QueryEngineTool), runs them, then synthesizes the final answer. Suited to compare/contrast, multi-part, and multi-document questions.
