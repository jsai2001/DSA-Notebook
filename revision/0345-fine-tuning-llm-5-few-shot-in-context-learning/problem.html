5. Few-Shot & In-Context Learning Fine-Tuning LLMs

Fine-Tuning LLMs › 5. Few-Shot & In-Context Learning

Few-shot learning = put worked examples in the prompt so the model learns task format and output style. In-context learning (ICL) is essentially the same technique. Works across tasks and helps smaller models most. No weights change (contrast with Sections 8+).

Rules of thumb: 2–3 high-quality examples, separated by blank lines, matching the desired output format; mind the 512-token input limit.
