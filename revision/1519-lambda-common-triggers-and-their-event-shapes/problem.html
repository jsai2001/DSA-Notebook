Common triggers and their event shapes AWS Lambda

AWS Lambda › 2. Console, programming model and triggers › Common triggers and their event shapes

  • API Gateway: routes an HTTP request (for example GET /hello) to the function. Used for serverless web backends.
  • S3: fires on object create, update or delete. Used to enrich files or start workflow steps (process images on upload).
  • DynamoDB (Streams): fires when a record is created, updated or deleted. Used for transactions or stored-procedure-like logic in a NoSQL database.
  • SQS: fires on new queue messages. Decouples functions for scalable architectures.
  • Kinesis: fires on new stream events. Handles high-volume real-time data (IoT, analytics).

Each trigger gives a different event shape, so always validate it. The function needs IAM permission to the triggering service (for example s3:GetObject, sqs:ReceiveMessage), scoped finely.
