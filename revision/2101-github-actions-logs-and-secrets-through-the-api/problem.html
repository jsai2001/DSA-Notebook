Logs and secrets through the API GitHub Actions

GitHub Actions › 11. Python and GitHub Actions › Logs and secrets through the API

Q. How do you download workflow logs with the GitHub API? Use GET /repos/{owner}/{repo}/actions/runs/{run_id}/logs, which returns a ZIP file.

Q. How can Python automate the creation of Actions secrets? Use PUT /repos/{owner}/{repo}/actions/secrets/{secret_name}. The value must be encrypted with the repository's public key (PyNaCl sealed box).
