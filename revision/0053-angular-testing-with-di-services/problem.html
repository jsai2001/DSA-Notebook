Testing with DI (services) (1/2) Angular

Angular › 15. Testing and Linting › Testing with DI (services)

Services use DI, so configure TestBed, fetch instances with TestBed.inject, replace HTTP with HttpClientTestingModule, and stub the HTTP method with a Jasmine spy. Put configureTestingModule in beforeEach so each test gets a clean copy. declarations can be empty or omitted.

Without the spy, the test times out because the testing module never answers the request. With spyOn(...).and.returnValue(of(data)) the call returns immediately with no network. Observable tests need done so Jasmine waits for the subscription.
