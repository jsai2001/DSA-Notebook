Model Context Protocol › 6. Testing with MCP Inspector and Troubleshooting › Two ways to launch it

MethodCommandWhen
Local development (inside the venv)mcp dev server.pyActive coding, fast iteration; needs the venv activated and the MCP SDK installed in it
Dynamic invocation (via npx)npx @modelcontextprotocol/inspector uv run server.pyFinal testing; works outside the venv and mimics how a client spins up the environment

After deactivate, mcp dev server.py fails with command not found: mcp because the SDK lives in the venv, not globally. Use Method 2 then.
