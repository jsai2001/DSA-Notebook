Hardening, SELinux and logs Linux

Linux › 4. Networking and Security › Hardening, SELinux and logs

Q. How do you harden a Linux system? Update packages, disable root SSH, use keys, set a firewall (ufw), enable SELinux and monitor logs.

Q. What is SELinux? A kernel module for mandatory access control. It restricts processes via policies (Targeted mode).

Q. How do you monitor system logs? Read /var/log (tail -f /var/log/syslog) and use journalctl -u sshd for systemd logs.
