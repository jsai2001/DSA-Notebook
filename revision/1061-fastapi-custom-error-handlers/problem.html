Custom error handlers FastAPI

FastAPI › 5. Sending Data › Custom error handlers

FastAPI handles most errors, but an unknown exception type gives 500 Internal Server Error.

Register a handler for it:

  • The handler is async def (request, exc) and returns a JSONResponse with custom status, content and headers.
  • Custom headers conventionally start with X-; header names are case-insensitive.
  • Security: do not put raw exception text in responses; it can leak tokens, addresses or other sensitive data.
