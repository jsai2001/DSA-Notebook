Metrics and dashboards Kubernetes

Kubernetes › 10. Monitoring and Troubleshooting › Metrics and dashboards

Q. What is Prometheus, and how is it used with Kubernetes? It monitors metrics by scraping cluster and app data for alerts and visualization.

Q. How do you monitor resource usage in a cluster? Use kubectl top, Metrics Server, or Prometheus/Grafana.

Q. What is the Kubernetes Dashboard, and how do you access it? A UI for cluster management, reached through kubectl proxy and a token.
