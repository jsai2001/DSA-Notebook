Kernel modules, udev and cgroups Linux

Linux › 5. Advanced Linux Topics › Kernel modules, udev and cgroups

Q. What is a kernel module and how do you load or unload one? It extends the kernel (drivers). modprobe module loads, modprobe -r unloads, lsmod lists.

Q. What is udev for? It manages /dev nodes dynamically for hardware (/dev/sdb for a USB drive).

Q. What are cgroups? They limit and isolate resources (CPU, memory) for processes and are used by containers (cgcreate).
