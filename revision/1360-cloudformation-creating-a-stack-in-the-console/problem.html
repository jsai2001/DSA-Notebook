Creating a stack in the console AWS CloudFormation

AWS CloudFormation › 6. Creating, Updating and Deleting Stacks › Creating a stack in the console

  1. CloudFormation, Create Stack, With new resources (or Template is ready).
  2. Upload a template file.
  3. Enter a stack name (for example BasicStack).
  4. Optionally add tags (for example Creator: <your-name>). Tags attach to the stack and to every resource it creates.
  5. Leave failure, rollback and deletion options at the defaults, then Next, Review, Submit.

To find a current AMI, search the console for AMI Catalog and copy the Amazon Linux x86 AMI ID.
