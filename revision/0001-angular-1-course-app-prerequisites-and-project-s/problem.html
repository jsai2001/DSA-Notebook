Angular › 1. Course App, Prerequisites and Project Structure

  • Prerequisites: TypeScript, HTML/CSS, npm. Any modern browser and OS.
  • Dev environment: GitHub Codespaces (cloud VS Code). Start with npm start. Codespaces port forwarding needs the host bound to 0.0.0.0 with the host check disabled (see the start script in section 2).
  • Example app Gem Finder: All Players page (search by name), Profile page (score, gems, ID), Leaderboards (top 5 scores and gem counts), Message inbox (unread, delete), routing with page titles and browser history.
  • app-root in index.html is where Angular mounts the app. The name is a convention. Bootstrap CSS is optional styling. styles.css holds global styles. JSON files in assets/mocks/ stand in for a backend.

Root files: angular.json (CLI config), package.json (deps and scripts), tsconfig.json (TypeScript), .eslintrc.json (lint rules).
