PyTorch Essential › 6. Indexing, Slicing, Stack, Unbind, Math Functions

Indexing accesses a single element, exactly as in NumPy. Use .item() to get a plain Python number.

Slicing accesses a range: tensor[start:end:step] (start inclusive, default 0; end exclusive, default last; step default 1).

2-D indexing and slicing

Conditional (boolean mask) indexing

torch.stack() joins tensors along a new dimension.

torch.unbind() splits a tensor along a dimension: dim=0 (default) gives one tensor per row, dim=1 one per column.

Five types of math functions

TypePurposeExamples
PointwisePer elementadd, mul, div, neg, true_divide, ceil, floor, clamp, logical, trigonometric
ReductionReduce to single/smaller valuesmean, median, mode, std
ComparisonCompare valuesmin, max, sort
Linear algebraMatrix/tensor computations
Spectral & otherTransforms/analysisFFT

Gotchas: torch.mean() only accepts floating-point tensors. torch.mode() returns a namedtuple (values, indices).
