Configuration and creating the database Flask

Flask › 6. Database Operations with Flask-SQLAlchemy (CRUD) › Configuration and creating the database

  • SQLALCHEMY_DATABASE_URI: sqlite:/// for development; swap for PostgreSQL/MySQL.
  • SQLALCHEMY_TRACK_MODIFICATIONS = False skips tracking every object change (performance).

FLASK_APP is required for flask shell and flask run. db.create_all() creates health_tracker.db with all tables defined by models. After adding a model, run it again (importing the model too, e.g. from app import db, User).
