Angular › 13. Routing and Navigation › Router in templates

<router-outlet> is a built-in component that anchors where route content renders. The routed component is inserted as a sibling right after it. routerLink replaces href for internal navigation. routerLinkActive="cls" adds a CSS class while the link's route is active.

routerLink values:

Square brackets are required for dynamic values. [routerLink]="['/profile', player.id]" yields /profile/123, /profile/456 and so on.

Active styling: the active link gets the class, the others do not (<a class="nav-link active" routerLink="players"> vs <a class="nav-link" routerLink="leaderboards">).
