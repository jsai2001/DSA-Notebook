4. Organizing Files by Type Python Automation

Python Automation › 4. Organizing Files by Type

A script that sorts files in the current directory into category folders, with unknown types going to MISC.

  • os.scandir() iterates the current directory. Path(item).suffix gives the extension. .mkdir() creates a folder. .rename() moves the file.
  • Flow: dictionary maps categories to extensions, pickDirectory looks up the category, organizeDirectory skips directories, creates missing category folders, and moves each file.
  • .lower() makes extension matching case-insensitive. Check the result with ls.
