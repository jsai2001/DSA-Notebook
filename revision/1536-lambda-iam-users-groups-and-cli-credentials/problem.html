IAM users, groups and CLI credentials AWS Lambda

AWS Lambda › 5. Security and permissions › IAM users, groups and CLI credentials

In the console: create a group (for example NewAdmin) with the AdministratorAccess policy, then create a user (for example LambdaUser) with console access and an auto-created password, and add it to the group. The sign-in URL and temporary password are shown once, so save them. For programmatic access, open the user's Security credentials, create an access key for the CLI, store it securely and run aws configure (access key ID, secret access key, default region such as us-east-1, output format json). Keys end up in ~/.aws/credentials.
