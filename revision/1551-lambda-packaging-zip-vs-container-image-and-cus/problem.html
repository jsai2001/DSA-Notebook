Q13. Zip archives vs OCI container images? Zip: upload code and dependencies as an archive (50 MB zipped for direct upload, 250 MB unzipped). Container image: an OCI image up to 10 GB, giving room for large dependencies or ML models and letting you use familiar container tooling. Zip is simpler and faster for small functions. Containers suit large or complex dependency sets.

Q14. What are the unzipped code and dependency size limits? Zip deployment: 250 MB unzipped (code and layers combined). Direct zip upload: 50 MB, larger packages go via S3. Container image: up to 10 GB.

Q15. What are Custom Runtimes, and how do you implement one with the Runtime API? A custom runtime lets you run a language Lambda does not support natively. You provide a bootstrap executable that implements the Runtime API loop: poll /runtime/invocation/next for events, run your handler, and POST the result to /runtime/invocation/{id}/response (or /error). Ship it as a zip (on the provided.al2023 or provided.al2 base) or as a container image.
