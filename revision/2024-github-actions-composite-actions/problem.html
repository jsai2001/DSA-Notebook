GitHub Actions › 6. Reusable actions and workflows › Composite actions

Q. What are composite actions, and how do you create one? A composite action bundles steps into one reusable unit. Create it in .github/actions/my-action/action.yml. Each run step needs a shell.

Use it with uses: ./.github/actions/my-action.
