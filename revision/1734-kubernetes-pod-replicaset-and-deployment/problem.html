Pod, ReplicaSet and Deployment Kubernetes

Kubernetes › 3. Pods and Workloads › Pod, ReplicaSet and Deployment

Q. What is the difference between a Pod and a Deployment? A Pod is a single instance of containers. A Deployment manages Pods with replicas, updates, and self-healing.

Q. What is a ReplicaSet, and how does it relate to a Deployment? A ReplicaSet ensures a set number of Pods run. A Deployment creates and updates ReplicaSets for rollouts.

Q. Explain the lifecycle of a Pod. Pending → Running → Succeeded/Failed → (Unknown if lost). It is managed through init containers and probes.

Q. What are labels and selectors, and how are they used?

  • Labels: key-value tags (for example app=nginx).
  • Selectors: filter objects by labels for routing or management.
