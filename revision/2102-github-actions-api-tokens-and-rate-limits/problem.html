GitHub Actions › 11. Python and GitHub Actions › API tokens and rate limits

Q. How do you secure GitHub API tokens in Python scripts for Actions automation?

  • Store tokens in Actions secrets and read them with ${{ secrets.TOKEN }}.
  • Pass secrets to scripts as environment variables.
  • Never hardcode tokens in scripts or the repo.
  • Use short-lived tokens with minimal permissions.
  • Audit and rotate tokens regularly.

Q. How do you handle GitHub API rate limits in Python?

  • Monitor the X-RateLimit-Remaining header.
  • Use exponential backoff (backoff, ratelimit).
  • On HTTP 429, wait for the Retry-After duration.
  • Use conditional requests (ETags, If-Modified-Since) to reduce calls.
