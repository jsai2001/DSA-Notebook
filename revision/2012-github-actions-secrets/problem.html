GitHub Actions › 4. Secrets, tokens, permissions and security › Secrets

Q. How does GitHub Actions handle secrets, and why does it matter? Secrets are encrypted variables set in repository settings and read as ${{ secrets.NAME }}. They are masked in logs. They keep sensitive data such as API keys out of the code.

Q. How do you use a secret in a step? Pass it through env.

Q. How do you secure a workflow that calls an external API needing auth? Store the key in secrets, reference ${{ secrets.KEY }}, and keep it out of logs.
