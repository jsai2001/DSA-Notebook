Vector Databases › 6. Partitions and indexes › Partitions

  • A partition is a physical subdivision of a collection that stores related data together, so queries scan fewer data blocks (fewer disk reads, better cache use).
  • Every collection has an automatic _default partition (data goes there when none is given).
  • Typical keys: tenant ID (multitenancy), date/month (time series), region, device ID, user ID.
  • Guidance: partition by frequently filtered fields, keep the number of partitions small (<100), search specific partitions.
