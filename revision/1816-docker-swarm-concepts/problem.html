Q. Swarm vs Kubernetes?

  • Swarm: simple, Docker-native.
  • K8s: complex, feature-rich.

Q. Manager vs worker node?

  • Manager: runs the cluster.
  • Worker: runs tasks.

Q. What is the purpose of docker service? It manages Swarm services: create, list, update.

Q. How does Swarm load balance? A built-in routing mesh spreads traffic.
