Migration options AZ-900

AZ-900 › 7. Storage and data migration › Migration options

Azure Migrate moves servers, databases and web apps (from on-prem or other clouds) in three steps:

  1. Discovery: the Azure Migrate Appliance (on a dedicated Windows server) collects metadata and performance data and sends it to Azure. About 1 hour for up to 500 servers.
  2. Assessment: group resources. Azure recommends VM sizes and disk types from the performance data.
  3. Migration: automated, with test migrations to catch problems first.

Azure Data Box moves massive data into Azure Storage, especially with limited connectivity:
