AWS Lambda › 12. Scenario-based questions › Protecting a legacy database from spikes

Q97. API Gateway + Lambda is overloading a legacy database during spikes. How do you decouple and protect it? Insert a buffer: API Gateway to Lambda writes to SQS (or Kinesis) and returns 202 immediately. A worker Lambda with an ESM MaximumConcurrency cap (and/or reserved concurrency) drains the queue at a rate the DB can handle. Add RDS Proxy for connection pooling. A synchronous spike becomes a smoothed, throttled async flow that shields the database.
