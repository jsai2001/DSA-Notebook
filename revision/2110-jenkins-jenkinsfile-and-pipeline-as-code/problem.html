Q. What is a Jenkinsfile, and why store it in source control? A Jenkinsfile is a text file defining the pipeline, committed alongside the code. Benefits: version control and code review, auditable history, reproducibility across branches and environments, self-documenting pipelines, and Multibranch pipelines that build every branch and PR automatically. It also supports a GitOps approach where the repository is the single source of truth for application code, tool configuration and CI changes, which can be reviewed and merged through automated processes. A Jenkinsfile can hold tools, options, triggers and more.
