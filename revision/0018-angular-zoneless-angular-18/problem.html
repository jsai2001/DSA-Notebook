Angular › 6. Standalone Components and Zoneless › Zoneless Angular (18+)

Architecture without ZoneJS. Experimental and opt-in at the time of the course, with an incomplete, unstable API. Benefits: fewer change detection cycles, smaller bundles, faster startup, better debugging, better third-party API compatibility. Risks: API can change, may require dependency, code and unit-test changes. Try it on new projects; wait for stability on existing ones.
