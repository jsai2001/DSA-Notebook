4.2 Ingestion Pipeline RAG with LlamaIndex

RAG with LlamaIndex › 4. Introduction to RAG: Pipelines, Prompts, Data Prep › 4.2 Ingestion Pipeline

A higher-level abstraction over the low-level load/parse/index APIs: applies transformations (split, embed, extract metadata), returns nodes or inserts them into a vector store.

  • Caching: each (node, transformation) pair is hashed and cached; identical later runs reuse results.
  • Docstore attached = document management: tracks doc_id → document_hash. Same id + changed hash → reprocess; same id + same hash → skip. Without a vector store it can only detect/remove duplicate inputs; with a vector store it handles upserts of updated documents.
  • Persistence: pipeline.persist() saves the cache and docstore (default ./pipeline_storage).
