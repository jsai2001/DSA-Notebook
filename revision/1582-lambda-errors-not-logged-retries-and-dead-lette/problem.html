Errors not logged, retries and dead letter queues AWS Lambda

AWS Lambda › 13. On-call troubleshooting › Errors not logged, retries and dead letter queues

Symptom: Lambda errors not logged. Confirm the role allows logs:CreateLogGroup, logs:CreateLogStream and logs:PutLogEvents, and add logging in code.

Symptom: Lambda retrying indefinitely. Set a retry limit and configure a DLQ (Configuration > Asynchronous invocation).

Symptom: unexpected DLQ messages. Check logs, verify retries and inspect the event source and the DLQ messages. Log the event so you can see what failed.
