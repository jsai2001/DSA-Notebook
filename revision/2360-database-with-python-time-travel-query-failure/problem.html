Q. A Time Travel query fails with "Invalid timestamp". How do you troubleshoot it? Check the table's retention period, make sure the timestamp is within it, use the right timestamp format (UTC with ::TIMESTAMP_TZ), and verify the AT (TIMESTAMP => ...) syntax.
