ReadJDBCPartition by column values; each executor reads a subset
ReadKafkaEach executor reads a subset of Kafka partitions
WriteJDBCEach executor writes in parallel (configurable); writes can be batched to cut network I/O
WriteKafkaExecutors write to topics in parallel
  • Predicate pushdown: filters are pushed to the data source so unwanted records are never read into memory. The optimizer does it automatically.
  • Map and filter are parallel. Reduce introduces shuffling.
  • Do map-type work and filtering early, reduce shuffling by using the right partitions, and repartition as needed.
  • Pipeline speed is set by its slowest bottleneck.
