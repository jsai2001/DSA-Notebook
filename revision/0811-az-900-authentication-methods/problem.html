Authentication methods AZ-900

AZ-900 › 8. Identity, access and security › Authentication methods

Single sign-on (SSO): authenticate once and reuse for all resources. Azure AD Connect extends SSO to on-prem. Two methods:

  • Password Hash Synchronization: the password is hashed, the hash is stored in Azure AD, and logins compare hashes.
  • Pass-Through Authentication: credentials go to an on-prem agent and are validated against on-prem AD, and the result goes back to Azure AD via AD Connect.

Multi-factor authentication (MFA): factors are something you know (password, PIN), have (phone, security key) and are (fingerprint, face, retina).

  • Two-factor = two factors. Three-factor = all three. Azure MFA uses two-factor.
  • Needs Azure AD Premium (not the free tier).
  • Enabled per user.
  • Guest users need a conditional access policy for MFA.
