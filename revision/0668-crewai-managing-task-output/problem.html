Managing task output CrewAI

CrewAI › 8. Tasks › Managing task output

Default output is a raw string, passed automatically to dependent tasks. Three parameters change the shape:

ParameterTakesReturnsUse for
output_pydanticPydantic model classPydantic instanceStructured data inside Python
output_jsonPydantic model classdict (JSON)External APIs
output_fileFile path (relative or absolute)Written to diskDocuments, articles

output_pydantic and output_json take the same model and differ only in return type.

After crew.kickoff(), task.output returns a TaskOutput. .raw is always available; .pydantic needs output_pydantic; .json_dict needs output_json.
