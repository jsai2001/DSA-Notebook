Angular › 3. Decorators and Modules › Decorators

  • Functions that return functions. Not Angular-specific, but Angular cannot be used without them. They supply metadata that tells Angular what a class is and how to inject it.
  • Syntax: @Name() or @Name(config). Starts with @, always has parentheses, no semicolon.
  • Common mistakes: @Component (no parentheses), @Component() (missing required config), @Component({}); (semicolon). Modern Angular reports these at compile time (ng build / ng serve); older versions failed at runtime.
