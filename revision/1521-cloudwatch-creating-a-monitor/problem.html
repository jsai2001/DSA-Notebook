Creating a monitor AWS CloudWatch

AWS CloudWatch › 15. Internet Monitor › Creating a monitor

CloudWatch > Application monitoring > Internet Monitor > Create monitor.

  1. Name it (for example demo2).
  2. Add resources: Amazon VPCs, CloudFront distributions, Network Load Balancers or WorkSpaces directories.
  3. Set the percentage of internet traffic to monitor (100% if unsure).
  4. Optionally publish internet measurements to an S3 bucket with a prefix (for example internet_monitor).
  5. Review and create.

The first data appears after about 10 minutes and meaningful data after a few hours. With no traffic there is no data. Generate traffic with the serverless API and a request tool, or with CloudWatch canaries. Delete the monitor when finished to avoid charges.
