Q. How do you deploy to Kubernetes with Helm without cluster-admin credentials in the codebase? Store the kubeconfig or token as a Jenkins credential (better, use a cloud IAM/OIDC identity or a Vault-issued short-lived token), bind it only for the deploy block with withCredentials, and use a least-privilege service account scoped to the target namespace rather than cluster-admin. Run the deploy on an ephemeral agent and never commit secrets.
