Amazon Bedrock › 8. Programmatic Knowledge Base Queries

Console is for testing. Production needs programmatic access via bedrock-agent-runtime. AWS CloudShell is a browser terminal with the AWS CLI pre-installed and pre-authenticated, so it is the fastest place to prototype.

PartPurpose
bedrock-agent-runtimeRuntime operations service (inference, retrieval)
retrieve-and-generateVector search plus generation in one call: retrieve chunks, then Claude synthesizes
--knowledge-base-idWhich knowledge base
--model-arnLLM for generation (Claude 3 Sonnet)
--input '{"text": "..."}'The query
| jqPretty-print JSON

Other queries only change the --input text (for example "What is MLOps?"). Answers come from your synced data, not generic model knowledge.

Production path: CloudShell + Bash, a reusable Bash script, Rust CLI, AWS Lambda (Cargo Lambda), then orchestration with agents and other knowledge bases.
