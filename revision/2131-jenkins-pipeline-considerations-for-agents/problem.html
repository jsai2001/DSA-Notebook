Pipeline considerations for agents Jenkins

Jenkins › 8. Agents and Distributed Builds › Pipeline considerations for agents

  1. Agent selection: agent any runs on the first available agent. With several nodes use labels to pick agents with the right capabilities.
  2. Tools: configure tools (for example Maven) under Manage Jenkins, Global Tool Configuration, with a name such as Maven-3.8.4 and automatic install enabled, then reference them in the tools block. Jenkins provisions the right version on whichever agent runs the stage. For containers, bake tools into the agent image instead.
  3. Code checkout: the first checkout happens on the controller only to read the Jenkinsfile. Code is not automatically on the agent, so add a checkout step.

Q. How do you manage tool installations across different agents? Define installers in Global Tool Configuration and reference them with a tools block.
