Q. How does a blue-green deployment run on AWS and EKS?

  • Code commit: developers push to GitHub or Bitbucket.
  • CI/CD trigger: GitHub Actions builds and tests Docker containers.
  • Green deployment: the new version is deployed to the Green environment (Kubernetes on EKS).
  • Validation: test Green with CloudWatch monitoring.
  • Traffic switch: route traffic to Green through AWS ELB or Kubernetes Ingress.
  • Monitoring: track CPU and latency in CloudWatch.
  • Rollback: switch back to Blue if issues arise.
