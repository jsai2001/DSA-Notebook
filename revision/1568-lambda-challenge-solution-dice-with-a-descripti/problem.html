The solution function (RollADiceWithSidesFunction, folder roll-dice-sides/) uses the same validation and returns "The result is N. You rolled a dice of S sides." Test locally with sam build and sam local start-api, then deploy with sam deploy (the saved samconfig.toml is reused) and watch the CloudFormation stack. The same API Gateway serves several functions (/hello, /roll).
