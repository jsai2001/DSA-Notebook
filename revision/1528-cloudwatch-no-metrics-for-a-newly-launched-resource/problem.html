No metrics for a newly launched resource AWS CloudWatch

AWS CloudWatch › 16. Troubleshooting Metrics › No metrics for a newly launched resource

Q. A new instance has no metrics. What now? Make sure the CloudWatch agent is installed, the IAM permissions are right, and the namespace and region are correct.

Console: check the namespace (for example AWS/EC2), run AWS-ConfigureCloudWatchAgent from Systems Manager > Run Command, and attach CloudWatchAgentServerPolicy to the role.
