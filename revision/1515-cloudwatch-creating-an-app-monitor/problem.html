Creating an app monitor AWS CloudWatch

AWS CloudWatch › 14. CloudWatch RUM › Creating an app monitor

CloudWatch > Application monitoring > RUM > Add app monitor. Settings: name (demoapp), application domain (localhost for development, the real URL in production), data collection defaults (performance telemetry, JavaScript errors, HTTP errors), cookies, session sampling (lower it in production to save cost), and authorization through an identity pool (create a new one for the demo to skip a manual Cognito setup).
