Choosing a model Azure AI Services

Azure AI Services › 9. Azure AI Foundry (AI Studio) and Azure OpenAI › Choosing a model

Start from an existing model, optionally fine-tune it with your data (fine-tuned = base model + your data). Balance accuracy against cost: the most accurate model costs more compute and time. Foundry gives a sortable table and charts for comparison.

CriterionMeasures
AccuracyHow well predictions match actual values
CoherenceOutput flows naturally like human language (interpretability, consistency, robustness)
GroundednessConnection to the real world (context, common sense, physical constraints)
FluencyLanguage proficiency, natural and effortless
RelevanceFit to the task, context, and user needs
SimilarityCloseness of the response to the source (ground truth)
