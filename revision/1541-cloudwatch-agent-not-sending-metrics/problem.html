Q. The CloudWatch agent is not sending metrics. What do you check? Agent status, configuration, and restart it.

Edit /opt/aws/amazon-cloudwatch-agent/etc/amazon-cloudwatch-agent.json (set the namespace, for example CustomMetrics, and metrics_collected such as cpu with cpu_usage_active), restart, and verify the namespace in CloudWatch > Metrics:
