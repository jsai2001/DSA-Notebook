Troubleshooting a failing container Docker

Docker › 3. Running and Managing Containers › Troubleshooting a failing container

Q. How do you debug a failing container? Check logs, inspect it, and run it interactively.

Q. How do you troubleshoot a container that keeps exiting? Check logs and the exit code, run it interactively, and check the CMD.

Q. A container overuses memory. What do you do? Check docker stats, cap it with -m, and debug the app.

Q. A failed image build. How do you fix it? Check the logs, test each step, and rebuild with --no-cache.
