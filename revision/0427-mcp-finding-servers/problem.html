Model Context Protocol › 3. Examples, Use Cases and Finding Servers › Finding servers

  • Official Anthropic servers: modelcontextprotocol.io (Get Started, Example Servers); repo github.com/modelcontextprotocol/servers. Python and TypeScript. Includes GitHub, Sentry, Brave Search, Slack, Google Maps, PostgreSQL, filesystem, fetch.
  • Community directories: mcp.so (curated list) and pulsemcp.com (marketplace plus client list).
  • Learning resources: official docs (including debugging docs), the course exercise repo, community examples. LLMs are good at writing MCP servers, so you do not need to be a seasoned coder.
