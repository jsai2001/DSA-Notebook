Angular › 4. Components

A component is the main building block; Angular cannot be used without them. Four parts: HTML template, CSS styles, TypeScript class (behavior), and selector (where it goes in the DOM). Used for routed pages (pages/) and reusable UI pieces (components/). Both are written the same way.
