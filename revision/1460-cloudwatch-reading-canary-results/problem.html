Reading canary results AWS CloudWatch

AWS CloudWatch › 12. Synthetics Canaries › Reading canary results

The canary home page lists canaries and the last run status (passed or failed). Per run you get:

  • the executed steps,
  • screenshots of the app,
  • logs for debugging,
  • a HAR file of the network requests made during the page load (like the browser Network tab), useful for spotting slow components.
