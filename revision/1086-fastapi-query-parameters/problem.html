Query parameters FastAPI

FastAPI › 4. Accepting Data › Query parameters

Appended after ?, separated by &: GET /logs?start=2024-01-01T00:00:00&end=2024-01-02T00:00:00&level=ERROR

  • Function parameters map to query parameters; type hints drive conversion (datetime parsed from ISO).
  • A parameter with a default (level: str = None) is optional.
  • Conversion failures return 422 Unprocessable Entity automatically.
  • Raise HTTPException with the right status for your own validation errors.
  • /docs shows generated OpenAPI documentation.
