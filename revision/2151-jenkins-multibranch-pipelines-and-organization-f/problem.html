Multibranch pipelines and organization folders Jenkins

Jenkins › 5. Triggers and SCM Integration › Multibranch pipelines and organization folders

Q. What is a Multibranch Pipeline? It scans a repo and creates and runs a pipeline for every branch and PR that contains a Jenkinsfile. New branches create new jobs and deleted branches remove them. Each branch builds with its own Jenkinsfile, so per-branch CI needs no manual job setup.

Q. What is the GitHub Organization Folder or GitLab Group plugin? They scan an entire GitHub org or GitLab group and auto-create a Multibranch Pipeline for every repo containing a Jenkinsfile. New repos are picked up on the next scan or webhook.

Q. How do you build pull requests and report status back? Use a Multibranch Pipeline with the GitHub or GitLab Branch Source: it discovers PRs and builds them, and Jenkins reports commit status (pending, success, failure) to the PR automatically (or with githubNotify or the GitLab status). Combine with branch protection to require the check before merge.
