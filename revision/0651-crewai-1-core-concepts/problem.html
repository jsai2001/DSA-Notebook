1. Core Concepts CrewAI

CrewAI › 1. Core Concepts

CrewAI is a Python framework for building multi-agent systems: a team of LLM-powered agents, each with a role and tools, handing results to the next agent. Prerequisites: LLM basics, knowledge of what AI agents are, Python.

Building blockWhat it is
CrewTop-level orchestrator. Holds agents and tasks, picks execution order, starts the run, collects the result (acts like a project manager).
AgentAutonomous, LLM-powered team member with a role. Uses tools, can delegate and receive tasks, makes its own decisions. The only autonomous component.
TaskActionable step that breaks down the crew's goal. Needs a clear objective, optional tools, and output that can be handed to the next agent. Good task breakdown is critical to success.
ProcessWorkflow management: how tasks are assigned and in what order. sequential or hierarchical.

Supplementary components: Tools (external actions), Memory (retain information across tasks), Knowledge (domain-specific information).

Example: an article crew = research, analyze, outline, write tasks. Email task = email agent with email tools.

Success formula: accurately defined agents + well-described tasks.
