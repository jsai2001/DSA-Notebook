AZ-900 › 11. Managing and deploying resources › Azure Arc

Extends Azure management and governance to resources outside Azure (on-prem or other clouds). Install the Azure Connected Machine Agent on a machine (single or at scale). It becomes a hybrid machine with an Azure resource ID and can join resource groups.

Arc featurePurpose
Arc-enabled serversPhysical/virtual Windows or Linux machines outside Azure
Arc-enabled KubernetesKubernetes clusters outside Azure
Arc-enabled data servicesOn top of Arc Kubernetes: SQL Managed Instance, PostgreSQL
Arc-enabled application servicesOn top of Arc Kubernetes: Web Apps, Functions, Logic Apps, API Management, Event Grid
