Adding an API Gateway trigger and reading query strings AWS Lambda

AWS Lambda › 2. Console, programming model and triggers › Adding an API Gateway trigger and reading query strings

In the function choose Add trigger > API Gateway, create a new API with security Open (no authentication, for learning only) and click Add. The trigger shows an endpoint such as https://<api-id>.execute-api.<region>.amazonaws.com/default. The new API is of type HTTP, authorization none, CORS off, any HTTP method, with a stage (default) for versioned deployments. One API can trigger several functions through different resource paths. Production APIs need authentication (Cognito or Lambda authorizers) and CORS.

Query string parameters arrive in event.queryStringParameters. Always check they exist.

?name=Marcia returns Hello Marcia!, and no parameter returns Hello from Lambda!.
