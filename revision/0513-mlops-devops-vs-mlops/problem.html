MLOps › 2. MLOps Foundations › DevOps vs MLOps

  • DevOps: combines development, testing and operations in one integrated workflow with agile practices and heavy automation. The same team owns all three, unlike traditional separate teams. Cycle: Plan → Code → Build → Test → Release → Deploy → Operate → Monitor → Plan.
  • MLOps: a set of best practices (not a product or technique), supported by automation and tools. It:
    • extends DevOps to building and serving ML;
    • integrates data engineering and model development into the software life cycle;
    • manages all 4 artifact types;
    • enables continuous model development and integration, which shortens time to market;
    • includes deployment, serving, monitoring, performance analytics and feedback.
