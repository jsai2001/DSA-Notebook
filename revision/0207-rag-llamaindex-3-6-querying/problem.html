3.6 Querying (1/2) RAG with LlamaIndex

RAG with LlamaIndex › 3. LlamaIndex Fundamentals › 3.6 Querying

Querying is a prompt call to the LLM with retrieved context. Under the hood: Retrieval (top-k) → Postprocessing (rerank/filter/transform nodes) → Response synthesis (query + context + prompt → LLM).

Chat engine = multi-turn querying with memory.

chat_modeBehavior
simplePlain LLM chat, no knowledge base (SimpleChatEngine)
condense_questionRewrite history + last message into a standalone question, then query the engine (CondenseQuestionChatEngine)
contextRetrieve text for each user message and use it as context (ContextChatEngine)
condense_plus_contextCondense to a standalone question, retrieve context for it, then answer (CondensePlusContextChatEngine)
reactReAct agent loop with query-engine tools
bestPicks the best engine for the LLM: OpenAIAgent if function calling is supported, otherwise ReActAgent

Customizing the query pipeline (low-level composition): control retrieval top_k, add postprocessors (e.g., minimum similarity), choose a response synthesizer.
