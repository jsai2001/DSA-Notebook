AspectClassical MLGenerative AI (LLMs)
Use casesForecast sales, churn, segmentationEssays, code, music
TraitsInterpretable, lightweight, cheapPowerful, resource-heavy
DeterministicYes, same input gives same outputNo, can vary between runs
AdoptionMost real data work todayGrowing, often overkill
  • Determinism is an underrated benefit of classical ML.
  • Fine-tuning LLMs and RAG rest on the same ML principles.

Why scikit-learn:

  • Consistency: a simple regression and a complex algorithm share the same API.
  • Breadth: classification, regression, unsupervised learning, model selection, feature prep, pipelines.
  • Docs: scikit-learn.org with an example catalog.
  • Ecosystem: Pandas (data), NumPy (compute), Matplotlib (plots).
