Jenkins › 4. Parameters, Conditions and Approvals › Pipeline parameters

Parameters are variables that receive values when a job is triggered. They live in a parameters block at the top of the pipeline and are read with params.NAME (or just NAME); in strings use $NAME or ${NAME}. Use capitals for names. Each parameter needs a name, a default value and a description.

Parameter types:

  • string: single-line text field.
  • text: multi-line text field.
  • booleanParam: checkbox.
  • choice: dropdown; the first option is the default.
  • password: masked input for sensitive data such as API keys.
