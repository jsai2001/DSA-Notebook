Windows setup: start and verify AWS CloudWatch

AWS CloudWatch › 8. CloudWatch Agent › Windows setup: start and verify

Check Systems Manager > Parameter Store for AmazonCloudWatch-windows first; if it is missing, troubleshoot IAM permissions and region.

The service should be Running. Then check CWAgent metrics and the system log group. CollectD is not supported on Windows. To cut cost, use standard resolution and limit event log levels.
