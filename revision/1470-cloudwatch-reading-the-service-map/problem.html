AWS CloudWatch › 13. X-Ray Tracing › Reading the service map

Nodes are services and edges are interactions. In Scorekeep: the client, an ECS container, an SNS topic for real-time updates, and DynamoDB tables game, session, state and user. Zoom with the scroll wheel or buttons. Click a node (for example the ECS container) for response time metrics. The circle around a node shows request status: yellow for slow requests, red for failed requests (50% red when half fail).
