Pitfalls Vector Databases

Vector Databases › 2. Vector fundamentals › Pitfalls

  • Mixing embedding models between data and query; dimension mismatch.
  • Not normalizing vectors when using cosine; wrong metric for the data.
  • Re-vectorizing at query time instead of pre-computing and storing embeddings.
  • Keep the embedding model version-controlled; keep preprocessing consistent.
