Helper plus tools. get_location exists because LLMs may guess wrong coordinates; geocoding gives accurate ones. The first-pass get_current_weather/get_forecast in the lesson (string error messages) are earlier steps of this file.

The helper returns None on any failure, so each tool returns an error value instead of crashing the server.

The exercise file open-meteo-weather/server.py is the same helper with two tools, but its get_forecast formats the daily arrays into a text string (the "don't pre-format" anti-pattern above) and its get_current_weather returns the raw dict.
