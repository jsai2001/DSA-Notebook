AWS Lambda › 10. Infrastructure as Code and AWS SAM › The same project with Python

For Python use CodeUri: hello_world/, Handler: app.lambda_handler and Runtime: python3.9 (or another supported Python version) in the same template. The handler lives in hello_world/app.py, referenced as app.lambda_handler.

hello_world/requirements.txt lists dependencies (empty by default).

SAM suits Lambda because it has a short serverless-focused YAML syntax, built-in local testing and tight AWS integration. Terraform is better for multi-cloud or complex infrastructure but needs more detailed configuration.
