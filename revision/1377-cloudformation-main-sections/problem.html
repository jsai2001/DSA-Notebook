AWS CloudFormation › 3. Template Anatomy › Main sections

SectionPurpose
AWSTemplateFormatVersionOne line of boilerplate, unchanged since 2010; the format version tells CloudFormation which interpreter to use
DescriptionWhat the template does; instructions for the user
ParametersInputs filled in at launch time (names, instance types, counts)
ResourcesThe required section: the AWS resources to create (instances, security groups, S3 buckets, VPCs, subnets)
OutputsValues you want easy access to after creation, through the console, CLI or API

Metadata, Mappings, Conditions and Transform are additional sections for more advanced templates.
