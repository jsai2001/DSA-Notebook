Lambda and Elastic Beanstalk AWS

AWS › 2. Compute: EC2, Lambda and Containers › Lambda and Elastic Beanstalk

Q. What is AWS Lambda and when do you use it? Serverless compute that runs code on events. Use it over EC2 for short, event-driven tasks such as file processing.

Q. Elastic Beanstalk vs. EC2 vs. Lambda?

  • Elastic Beanstalk: PaaS, auto-manages deployment.
  • EC2: full control, manual.
  • Lambda: serverless and event-based.
