FastAPI › 4. Accepting Data › Request body (Pydantic models)

JSON in the body is the most common way to pass data. Pydantic validates it.

  • Keep API models separate from DB models; layers may store data differently (dollars vs cents).
  • Field(min_length=2), Field(gt=0) are validated automatically; failures give 422 with detailed messages.
  • A return annotation (-> Sale) adds the response schema to /docs.
  • {key} in the route is a path parameter bound to the key argument.
  • Pydantic has specialized types, e.g. PastDatetime for datetimes that must be in the past.
