Attaching a function to a VPC AWS Lambda

AWS Lambda › 6. Networking and VPC › Attaching a function to a VPC

Q45. What happens when a function is attached to a VPC? The function can reach private VPC resources (RDS, ElastiCache, internal services) through Elastic Network Interfaces. It then follows VPC routing, so it loses default internet access unless you add a NAT gateway (private subnets) or a VPC endpoint. Thanks to AWS Hyperplane, ENIs are shared and set up at function create or update time, so VPC attachment no longer adds a per-invoke cold-start penalty.

Without a VPC, functions run in an AWS-managed network with internet access.

Q46. What is an ENI, and how does Hyperplane optimize VPC access? An ENI is a virtual network card that gives the function an IP inside your VPC. Historically Lambda created an ENI per concurrent environment (slow and IP-hungry). Hyperplane now creates shared, network-mapped ENIs per function, subnet and security-group combination at create or update time and multiplexes many execution environments through them. That removes per-invocation ENI setup and its cold-start cost.
