HTTP protocol FastAPI

FastAPI › 2. REST, HTTP and JSON Fundamentals › HTTP protocol

HTTP is a textual protocol over sockets. Raw request via Netcat:

  • Request: request line (verb, path, version), headers, empty line, body.
    • Host is the only required header.
    • Connection: close closes the connection after the response.
    • Content-Length counts body bytes only (75 here), not headers.
  • Response: status line (HTTP/1.1 200 OK), headers, empty line, body.
  • Common codes: 200 OK, 404 Not Found.
