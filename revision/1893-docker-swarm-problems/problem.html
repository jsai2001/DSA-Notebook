Docker › 17. On-Call: Compose and Swarm Problems › Swarm problems

Q. Swarm service stuck in "pending"? Check node resources (docker node ls), logs (docker service logs <service>) and constraints. Scale or adjust (docker service update). Ensure enough nodes and check placement constraints.

Q. Swarm service not scaling? Check resources (docker node ls), update replicas (docker service scale <service>=3), and review logs (docker service logs <service>). Ensure node capacity and check constraints.

Q. Swarm node marked "Down"? Check status (docker node ls) and logs (journalctl -u docker), then restart the node (docker node update --availability active <node>). Verify the network, the Docker daemon and node health.

Q. Swarm service not load balancing? Check the routing mesh (docker network inspect ingress), verify replicas (docker service ps <service>), and test endpoints (curl <node_ip>). Ensure correct ports and check the load balancer config.
