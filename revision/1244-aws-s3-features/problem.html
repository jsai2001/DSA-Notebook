AWS › 3. Storage › S3 features

Q. What is an S3 bucket and what are its use cases? An object container used for web hosting, backups, data lakes and content delivery.

Q. What is S3 versioning? It keeps all versions of an object so older ones can be retrieved. It costs more.

Q. What are the S3 storage classes? Standard (frequent access), IA (less used), One Zone-IA (cheap, risky), Glacier (archive), Deep Archive (rare access), Intelligent-Tiering (automatic).

Q. How do you secure S3 data? IAM and bucket policies, SSE-S3 or KMS encryption, versioning, block public access and access logs.
