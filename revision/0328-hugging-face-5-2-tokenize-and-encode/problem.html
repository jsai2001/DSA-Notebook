5.2 Tokenize and encode Hugging Face Transformers

Hugging Face Transformers › 5. Transfer Learning (Sentiment Model) › 5.2 Tokenize and encode

The data is already clean, so go straight to tokenizing. Use the tokenizer class that matches the checkpoint (DistilBertTokenizer).

Tokenizing adds two features, input_ids and attention_mask:

  • input_ids: IDs from the embedding matrix. Start with 101 (begin of string), end with 102 (end of string), right-padded with zeros to the max length.
  • attention_mask: 1 for real tokens, 0 for padding. The model only attends to tokens with mask 1.
