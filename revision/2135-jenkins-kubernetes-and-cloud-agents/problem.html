Q. What is the Kubernetes plugin, and how does it spin up agents? It runs each build in an ephemeral pod created on demand in a cluster and deletes it afterwards. You define a cloud pointing at the cluster and pod templates, and Jenkins scales agents elastically with zero idle cost, ideal for bursty CI.
