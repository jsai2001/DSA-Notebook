Vector Databases › 10. Use case 2: RAG concepts › Question-answering pipeline

User prompt -> validation and metadata -> embed -> query knowledge base (top-K, with scalar filters) -> build context -> augment prompt -> LLM -> answer (plus sources).

(Build filter expressions from validated values; interpolating raw user input into expr invites injection.)

Top-KTrade-off
1precise, may miss context
3balanced (recommended start)
5more comprehensive, more noise
10too much context

Prompt augmentation: instruct the model to use only the context, allow "I don't know", ask for citations.

Temperature: 0.0 deterministic/factual, 0.3 recommended for RAG, 0.7 general chat, 1.0 creative.
