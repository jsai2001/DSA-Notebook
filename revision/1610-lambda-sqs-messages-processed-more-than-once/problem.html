SQS messages processed more than once AWS Lambda

AWS Lambda › 12. Scenario-based questions › SQS messages processed more than once

Q98. A Lambda on SQS runs fine but messages process multiple times. Why, and how do you fix it? Standard SQS is at-least-once, so duplicates are expected. A message also reappears if the visibility timeout expires before processing finishes, or if part of a batch fails and the whole batch returns. Fixes: set visibility timeout at least 6x the function timeout, enable partial batch responses (ReportBatchItemFailures) so only failed messages retry, make processing idempotent, or use a FIFO queue.
