CloudWatch and CloudTrail AWS

AWS › 7. Monitoring, Logging and Management › CloudWatch and CloudTrail

Q. What is Amazon CloudWatch? It monitors metrics and logs for EC2, RDS, Lambda and more.

Q. How do you set up a CloudWatch alarm? Pick a metric (for example CPU), set a threshold and an action (for example SNS).

Q. CloudTrail vs. CloudWatch?

  • CloudTrail: API activity logs.
  • CloudWatch: performance metrics.

Q. Metric vs. log in CloudWatch?

  • Metric: numbers (CPU).
  • Log: text (errors).

Q. How do you set up centralized logging? A CloudWatch Logs group, streamed through the agent, with S3 or Kinesis for scale.
