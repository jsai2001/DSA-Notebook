Container fails to start Docker

Docker › 12. On-Call: Container Failures › Container fails to start

Q. Container fails to start: "OCI runtime create failed: no such file or directory: /bin/bash"? The image lacks /bin/bash or the entrypoint is wrong.

  • Install bash: RUN apt-get update && apt-get install -y bash
  • Or use /bin/sh: docker run -it --entrypoint /bin/sh <image_name>
  • Ensure the base image has the required shell. Minimal images (for example alpine) may only have sh.

Q. Container stuck in "Created" state?

  • Recreate if needed: docker rm <container_id> && docker run <image_name>
  • Verify the Docker daemon (systemctl status docker), resources and architecture compatibility.
