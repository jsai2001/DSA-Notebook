Create tables with a foreign key Database with Python

Database with Python › 4. MySQL with Python › Create tables with a foreign key

The projects database holds projects (id, title, description) and tasks (id, project_id, description). The foreign key means a task cannot exist without a valid project, and tasks must be deleted before their project unless the key uses ON DELETE CASCADE. MySQL uses AUTO_INCREMENT (SQLite uses AUTOINCREMENT).

To delete tasks automatically with their project, use FOREIGN KEY (project_id) REFERENCES projects(project_id) ON DELETE CASCADE. A completed column could track task status, but the example deletes finished tasks instead.
