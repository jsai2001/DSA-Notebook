Template, resource and stack AWS CloudFormation

AWS CloudFormation › 2. Core Concepts and Terminology › Template, resource and stack

ConceptAnalogyDescription
TemplateRecipeText file describing what to build; reusable and customizable
ResourceItems on the plateOne cloud object (EC2 instance, DynamoDB table, Lambda function, API Gateway)
StackThe prepared mealOne instantiation of a template: the set of resources it creates

One template can create many stacks. Swapping a few values (instance size, environment name) gives a variant from the same template.
