2. Reading and Writing Files Python Automation

Python Automation › 2. Reading and Writing Files

Example data: a drive test results file, one line per person as name age P/F. After .split() (splits on whitespace by default), index 0 is the name, 1 the age, 2 the pass/fail flag.

  • "r" opens read-only. "w" creates the file or overwrites an existing one.
  • Close every file you open (.close()) to avoid unintended changes and leaks. A with open(...) as f: block closes it for you (used in Section 5).
  • Save the script in the directory that holds the files, so relative paths resolve.
