Choosing a vector database RAG with LlamaIndex

RAG with LlamaIndex › 2. Environment, Providers & Vector DB Setup › Choosing a vector database

Criteria: similarity search performance (cosine/Euclidean), horizontal scalability, framework integration (LlamaIndex, LangChain), data types supported, incremental/real-time indexing, retrieval flexibility (top-k, thresholds, metadata filters), persistence and recovery, community/docs, ease of deployment (cloud/on-prem), cost and license.

Why Qdrant here: popular on LlamaHub, clear docs, open development, built-in auth in the dev version, generous free hosted tier (4 GB disk, 1 GB RAM, 1 cluster with multiple collections).

Qdrant Cloud setup: sign in → create cluster (lil_llama_index) → copy API key immediately (not viewable again) → copy cluster URL → put both in .env.
