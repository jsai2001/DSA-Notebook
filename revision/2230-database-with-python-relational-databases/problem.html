Database with Python › 1. Databases and the Python Database API › Relational databases

  • A collection of data with predefined relationships, organized into tables of rows and columns.
  • Columns hold one kind of data (Name, GPA, Class Year). A row is one record and needs a unique identifier (an ID column).
  • A foreign key links rows across tables, so data is read in relation to other data.
  • An RDBMS (SQLite, MySQL, Postgres) manages the tables and is queried with SQL. Syntax differs slightly by RDBMS.
