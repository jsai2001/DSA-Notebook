2.1 K-Means ML Algorithms

ML Algorithms › 2. Clustering: K-Means, Choosing K, Interpreting Clusters › 2.1 K-Means

Unsupervised: you pass data without labels and get cluster labels back.

Algorithm:

  1. Choose k.
  2. Pick k random points as initial centroids.
  3. Assign each point to its nearest centroid.
  4. Move each centroid to the middle of its cluster.
  5. Repeat 3-4 until centroids stop moving (converge).

K-means uses distance, so features must be on the same scale.
