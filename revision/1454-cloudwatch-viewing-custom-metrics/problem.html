AWS CloudWatch › 4. Custom Metrics › Viewing custom metrics

CloudWatch > Metrics > All metrics > custom namespace > choose dimensions (Endpoint, Environment, HttpMethod) > ResponseTime. In Graphed metrics use Statistic Sum for small values and a short period (such as 5 seconds) to see recent data. Dimensions add context so you can filter and slice the metric.
