Connecting an RDS Instance to an EC2 Instance (2/2) Terraform

Terraform › 16. Hands-On: Complete Stacks › Connecting an RDS Instance to an EC2 Instance

  1. VPC and subnet: create the network for the resources.
  2. Security groups: the EC2 group allows outbound traffic. The RDS group allows MySQL (port 3306) from the EC2 security group.
  3. RDS subnet group: tells the RDS instance which subnets to use.
  4. RDS instance: a MySQL instance with the given configuration.
  5. EC2 instance: placed in the same subnet with its security group.

Connect from the EC2 instance using the RDS endpoint (for example my-rds-instance.abcdef123456.us-east-1.rds.amazonaws.com), port 3306 and the username and password.
