6.5 Metadata extraction RAG with LlamaIndex

RAG with LlamaIndex › 6. Advanced RAG: Pre-Retrieval & Indexing › 6.5 Metadata extraction

Chunks can look alike; metadata disambiguates them and enables filtering. Effectiveness depends on the quality of the tags.

Manual metadata: add a dict entry per document.

Automatic extraction: extractors use an LLM and run as transformations in the ingestion pipeline.

ExtractorAdds
SummaryExtractorSummary of the node, optionally of previous/next nodes (summaries=["prev","self","next"])
QuestionsAnsweredExtractorQuestions the node can answer (questions=N)
TitleExtractorA title over node context (nodes=5)
KeywordExtractorUnique keywords, comma separated (keywords=10)

Design choices: which extractors; extraction LLM (gpt-4o quality vs gpt-3.5-turbo cost); questions per node; summary scope; splitter; chunk size/overlap. More metadata means a slower, costlier ingestion.
