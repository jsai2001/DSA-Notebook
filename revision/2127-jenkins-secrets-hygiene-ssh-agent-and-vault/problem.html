Q. Why never hardcode tokens or passwords in steps, and how do you mask output? Hardcoded secrets leak into SCM, build logs and job config and cannot be rotated centrally. Use the Credentials store with withCredentials (Jenkins masks bound values in logs). The Mask Passwords plugin can redact custom secret strings. Do not echo secrets.

Q. What does the SSH Agent plugin do? It starts an ssh-agent for a build and loads a stored SSH private-key credential into it, so git, ssh and scp authenticate without the key being written to disk. The key is available only inside the wrapped block.

Q. How do you integrate Jenkins with Vault or AWS Secrets Manager? Use the HashiCorp Vault or AWS Secrets Manager Credentials Provider plugin. Secrets stay in the external manager (single source of truth, rotation, audit) and are fetched at runtime, so there are no long-lived copies in Jenkins.
