Agentic AI Fundamentals › 12. Security Challenges › Untrusted external entities

An agent interacts with other systems (may be compromised), other humans (may be malicious), owned data (may be corrupted) and unowned data (may be manipulated). Risks: data breaches, manipulation, and agent reprogramming by bad actors. No perfect security solution exists, so understand the challenges first, then reduce risk.
