Q27. Throttling and rate limits. Exponential backoff, either through boto3's retry configuration or manual retries.

Q28. Create an SQS queue and send a message. create_queue returns QueueUrl, which send_message needs.

Q29. VPC subnet and security group. VPC resources are created through the EC2 client.

Q30. STS assume role for cross-account access. assume_role returns temporary AccessKeyId, SecretAccessKey and SessionToken; pass them to a new client.
