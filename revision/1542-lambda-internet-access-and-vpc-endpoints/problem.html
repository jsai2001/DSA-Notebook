Q47. How can a VPC-bound function reach the public internet? Place the function in private subnets and route 0.0.0.0/0 through a NAT gateway in a public subnet, which reaches the internet via an Internet Gateway. A function in a public subnet cannot reach the internet directly because it has no public IP. For AWS services without internet, use VPC endpoints.

Q48. How do VPC Endpoints (PrivateLink) let a private function reach AWS services? VPC endpoints keep traffic on the AWS private network. Gateway endpoints (S3, DynamoDB) add a route-table entry. Interface endpoints (PrivateLink) create an ENI with a private IP for services such as Secrets Manager, SQS and KMS. A private, no-NAT function can then reach those services securely and often more cheaply.
