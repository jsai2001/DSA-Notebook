4.3 Query Pipeline RAG with LlamaIndex

RAG with LlamaIndex › 4. Introduction to RAG: Pipelines, Prompts, Data Prep › 4.3 Query Pipeline

A declarative API to chain LLMs, prompts, retrievers, rerankers, and other pipelines, either as a sequential chain or a DAG. Fewer lines, better readability.

Pattern 1: chain. Use when each module takes one input. Here two prompts wrap a retriever.

Pattern 2: explicit modules and links. Needed when one input feeds several modules (use InputComponent) or for DAGs.
