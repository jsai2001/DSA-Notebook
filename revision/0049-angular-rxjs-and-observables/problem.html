Angular › 14. Reactive Programming: Signals, effect, async Pipe, RxJS › RxJS and observables

Reactive programming handles data that changes over time. An Observable is a stream of values over time from the RxJS library; Angular's HttpClient returns them. pipe() composes operators where each output feeds the next. The service in section 8 shows delay and map.

Common operators:

  • Transformation: map, pluck, scan
  • Filtering: filter, take, skip
  • Combination: merge, concat, combineLatest
  • Errors: catchError, retry
  • Utility: tap (side effects), delay, timeout

Observables vs Promises. Observables: multiple values, lazy (run only when subscribed), cancellable, rich operators. Promises: single value, eager, not cancellable, limited transformation.
