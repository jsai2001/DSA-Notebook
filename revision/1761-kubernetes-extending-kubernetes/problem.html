Kubernetes › 12. Advanced Topics › Extending Kubernetes

Q. What is a Custom Resource Definition (CRD)? It extends the API with custom resources (for example MyApp).

Q. How do you extend Kubernetes with custom controllers? Write logic (for example in Go) that manages CRD instances.

Q. What is a Kubernetes operator, and how does it work? A custom controller that manages an application's lifecycle via CRDs.

Q. What is a sidecar container, and how is it used? A helper container in a Pod that adds logging, proxying, and similar functions.
