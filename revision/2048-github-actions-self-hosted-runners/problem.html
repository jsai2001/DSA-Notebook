Self-hosted runners GitHub Actions

GitHub Actions › 9. Debugging, local testing and limits › Self-hosted runners

Self-hosted runners are your own machines, set up in repository Settings > Actions > Runners by installing the runner application and registering it.

  • Pros: full control over hardware, OS and software; access to internal resources such as private registries; cost-effective at high usage.
  • Cons: you maintain and scale them, GitHub does not support runner issues, and security is your responsibility.
  • Practices: use ephemeral (one-time) runners, monitor status and logs, and restrict access with labels.
