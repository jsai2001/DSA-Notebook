RAG with LlamaIndex › 4. Introduction to RAG: Pipelines, Prompts, Data Prep › 4.6 Response synthesizers / response modes

Control how retrieved chunks are combined and sent to the LLM. Listed by dir(ResponseMode).

ModeBehaviorTrade-off / use
refineAnswer from node 1, then refine through nodes 2..N with one LLM call per nodeDetailed answers, most LLM calls
compactPack chunks into larger ones that fill the context window, then refineFewer calls than refine (default-style choice)
simple_summarizeMerge all chunks into one callFast; fails if merged text exceeds context window; may truncate
tree_summarizeBuild a summary tree bottom-up, return the rootBest for comprehensive multi-document summaries
generationIgnore context, LLM onlyOpen-ended generation
no_textRetrieval only; inspect response.source_nodesDebugging retrieval
accumulateRun the query against each chunk, concatenate answersSame question per chunk
compact_accumulatePack chunks first, then accumulateFaster than accumulate
