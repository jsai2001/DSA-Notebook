Q. How do you use Ansible to apply a Kubernetes manifest and verify it? Apply pod.yaml, read the phase with jsonpath, and fail the play if the Pod is not Running.

Q. How do you use Ansible to install kubectl and check the cluster?

Run it with ansible-playbook install_kubectl.yml.

Q. How do you use Ansible to update a ConfigMap and restart the Pods? Apply configmap.yaml, then restart the Deployment.
