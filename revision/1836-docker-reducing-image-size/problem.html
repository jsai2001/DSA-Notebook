Reducing image size Docker

Docker › 2. Docker Images and Dockerfiles › Reducing image size

Q. How do you reduce image size? Use a small base (for example alpine), chain RUN commands, clean up after installs, and use multi-stage builds.

Q. What is a multi-stage build and why use it? It separates build from runtime, so the final image is smaller.

Q. How do you reduce Docker image size in practice (on-call view)? Use lightweight images, clean up after installs, minimize layers, and copy only the built output from a builder stage.
