AWS CloudWatch › 11. Alarms › Alarm actions with Auto Scaling: create the group

EC2 > Auto Scaling Groups > Create. Name scalingdemo. Create a launch template (simplegroup: Amazon Linux, an instance type such as t2.micro, a key pair, default VPC and subnet, auto-assign public IP). Set capacity minimum 1, maximum 2, desired 1. The maximum must be above 1 or scaling cannot add an instance.
