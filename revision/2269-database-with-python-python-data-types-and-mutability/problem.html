Q. Lists vs tuples vs sets? Lists [1, 2] are mutable, ordered, and allow duplicates. Tuples (1, 2) are immutable, ordered, and allow duplicates. Sets {1, 2} are mutable, unordered, and have no duplicates.

Q. == vs is? == checks value equality. is checks identity (same memory location).

Q. Mutable vs immutable objects? Mutable: lists, dicts, sets. Immutable: int, str, tuple.

Q. What are Python's built-in data types? Numeric (int, float, complex), sequence (str, list, tuple), mapping (dict), set (set, frozenset), boolean (bool), and None.

Q. range() vs xrange()? In Python 2, range() returns a list and xrange() an iterator. In Python 3 only range() exists and it behaves like xrange().
