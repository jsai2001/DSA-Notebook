Set the provider key first (OPENAI_API_KEY, ANTHROPIC_API_KEY, GOOGLE_API_KEY). kickoff(inputs={...}) triggers the run; keys map to {placeholders} in tasks. With verbose=True you see the ReAct loop (thought, action, observation) and a completion message.

kickoff() returns a CrewOutput:

AttributeReturns
.rawRaw string (always)
.pydanticPydantic model, if output_pydantic is set on the final task
.json_dictdict, if output_json is set on the final task
.tasks_outputList of TaskOutput, one per task (same .raw/.pydantic/.json_dict)
.token_usageToken breakdown dict
