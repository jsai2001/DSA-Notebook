Securing a workflow GitHub Actions

GitHub Actions › 4. Secrets, tokens, permissions and security › Securing a workflow

Q. How can you secure a workflow against unauthorized access or misuse? Use secrets, limit GITHUB_TOKEN permissions, pin actions to a version or commit SHA, use environments, control concurrency and audit workflows. Avoid logging secrets.

The token is limited to reading contents and writing issues, checkout is pinned, the secret is passed through env, and only one run per branch executes at a time.
