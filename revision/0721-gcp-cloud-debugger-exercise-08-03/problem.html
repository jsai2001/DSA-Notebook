Cloud Debugger (Exercise 08_03) Google Cloud (GCP)

Google Cloud (GCP) › 9. Operations Tools: Logging, Debugger, Trace › Cloud Debugger (Exercise 08_03)

  • Takes snapshots and inspects variable state on live traffic, useful for bugs that are hard to reproduce locally. Works with App Engine, Compute Engine, GKE, Cloud Run and VMs elsewhere.
  • Setup: open Debugger, make sure the version with 100% traffic is selected, pick the file, press Check to sync and activate.
  • Snapshot: click a line number. On the next request it captures the call stack and variable values. Supports conditions (e.g. i === 1 for the second loop pass) and expressions (e.g. helloArray[i]).
  • Logpoint: pick a line, give a condition (e.g. true) and a log message with {expression} syntax (e.g. "value of response is {response}"). It adds logs to the running app without changing source or redeploying.
