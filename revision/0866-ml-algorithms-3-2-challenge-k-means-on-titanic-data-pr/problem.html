Task: drop missing values, drop categorical features, scale, run K-means, use the elbow method.

Select the columns you want (positive selection) rather than dropping the ones you don't. It is clearer and less error-prone.

Why standardize: clustering uses distance. fare reaches about 150 and age about 80, while other columns are 0-3, so large-range features would dominate. set_config(transform_output='pandas') makes transformers return DataFrames instead of NumPy arrays.

Result: about 5 clusters by the ruler technique; if the ruler touches several spots, pick the simpler one. Much of ML is reusable code patterns: plug in your own data.
