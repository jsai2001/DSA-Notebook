Points to remember:

  • Kafka value arrives as bytes, so cast and parse with from_json plus an explicit schema.
  • Each .start() is a separate streaming query. Only the last one blocks with awaitTermination().
  • Kafka sink needs checkpointLocation. foreach runs the Python writer per row.
  • Windowing uses window() + withWatermark(), then groupBy and aggregate.
