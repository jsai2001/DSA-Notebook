Object types, lists, non-null GraphQL

GraphQL › 4. Types: Scalars, Objects, Lists, Enums, Input › Object types, lists, non-null

An object type groups fields into a shape. [Store] is a list of Store objects. ! means non-null. In [Store]! the ! applies to the list itself (the list must be present, an empty array is fine), not to the items.

SyntaxMeaning
[Store]Optional list of Store objects
[Store]!List must be present
ID!Required scalar
