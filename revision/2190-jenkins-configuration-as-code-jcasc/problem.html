Q. What is JCasC, and how does it replace manual UI administration? The configuration-as-code plugin defines the whole controller configuration (security realm, clouds, tools, credentials, global settings) in a declarative YAML file. Instead of clicking through Manage Jenkins, you version the YAML and apply it, which makes the controller reproducible, reviewable and recoverable.

Q. How do you export the existing configuration to jenkins.yaml? Go to Manage Jenkins, Configuration as Code, View/Download Configuration to export the live config as YAML. Trim it, move secrets to environment variables or ${VAR} references, commit it, and point CASC_JENKINS_CONFIG at it so later startups load it.
