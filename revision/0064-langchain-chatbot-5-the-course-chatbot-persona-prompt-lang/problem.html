LangChain Chatbot › 5. The course chatbot: persona prompt + LangChain chain

Idea: extracted text + instruction block in one prompt, so the model answers only from that text and refuses everything else.

  • Persona: "Mr. Landon", hotel manager, for a consistent voice.
  • Scope limit: fixed refusal "I can't assist you with that, sorry!" for off-topic questions.
  • {question}: PromptTemplate(input_variables=["question"]) placeholder.
  • temperature=0: deterministic, factual.
  • prompt_template | llm: the pipe operator (LCEL) builds a chain; run it with .invoke({...}).
