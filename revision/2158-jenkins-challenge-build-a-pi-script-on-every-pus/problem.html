Jenkins › 6. Connecting Jenkins to GitHub › Challenge: build a Pi script on every push

Task: connect a repo (for example pi-challenge) holding a Jenkinsfile and algorithm/pi.sh to a Jenkins pipeline job, trigger a build on every push, and show the status badge in README.md. Steps follow the sections above: create the repo and job, enable the GitHub hook trigger, run a first build, add the webhook, edit pi.sh and commit (for example "Improve calculation of pi") to confirm a build fires with the new commit message, then install Embeddable Build Status and add the badge. The badge commit triggers another build.
