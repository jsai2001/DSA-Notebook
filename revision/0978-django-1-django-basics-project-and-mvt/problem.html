Django › 1. Django Basics, Project and MVT

  • Django is an open source Python web framework: fast to build with, strong built-in security, built-in user authentication. It came out of a newspaper, so its docs are excellent. Learning to find answers in the docs (https://docs.djangoproject.com/) is itself a career skill.
  • Prerequisites: Python 3.8+ (virtualenv), Django 3.2+, HTTP basics.
  • manage.py: entry point (run server, DB tasks). settings.py: config (DEBUG, INSTALLED_APPS, database). urls.py: URL routing.
  • DEBUG = True: detailed error pages. An undefined path shows a 404 page listing the available URLs.
