URL variables and conversion filters RESTful API

RESTful API › 3. Returning JSON, Status Codes, URL Parameters and Variables › URL variables and conversion filters

  • Parts of the path become variables with <name>. URLs are cleaner (/url_variables/Bruce/28 instead of ?name=Bruce&age=28) and request.args.get() is not needed.
  • Variable names in the route must match the function parameters in name and count.
  • A converter restricts and converts the type: <converter:variable>.
ConverterAccepts
string (default)any text without slashes. It is string, not Python's str
int / floatnumbers, converted automatically
pathtext including slashes (file paths)
uuidUUID strings
  • Gotcha: in the route the converter comes before the name (int:age). In the signature the type hint comes after (age: int).

/url_variables/Bruce/28 returns 200. /url_variables/Bruce/14 returns 401. Document endpoints (Swagger/OpenAPI) with their expected types.
