Scaling processing Apache Spark

Apache Spark › 6. Best Practices › Scaling processing

  • Filter unwanted data early (less data in memory and between executors).
  • Do reduce operations as late as possible (less shuffling). Do parallel work (map, filter) early.
  • Repartition as needed, since some operations create too many partitions.
  • Cache intermediate results that are reused.
  • Avoid actions that send data to the driver. Collect only at the end.
