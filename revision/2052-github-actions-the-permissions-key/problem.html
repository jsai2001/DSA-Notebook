The permissions key GitHub Actions

GitHub Actions › 4. Secrets, tokens, permissions and security › The permissions key

The permissions key sets the scope of GITHUB_TOKEN. Default permissions can be too broad, so set them explicitly (least privilege). Common scopes: contents: read/write, issues: read/write, pull-requests: write. Workflow-level permissions apply to all jobs; job-level permissions override them for that job.

This workflow only writes to issues, so the token is limited to that.
