Launching Jenkins on AWS EC2 Jenkins

Jenkins › 2. Installing a Jenkins Server › Launching Jenkins on AWS EC2

  1. Launch an EC2 instance with an Ubuntu Server 20.04 LTS AMI and type t2.micro (free tier). Raise the root volume to 30 GB for NGINX, Jenkins, plugins and Docker images. Tag it Name: Jenkins server.
  2. Create a security group Jenkins server allowing HTTP port 80 from 0.0.0.0/0 (GitHub and browser access).
  3. Create an RSA key pair, download it and protect the file.
  4. Allocate an Elastic IP and associate it with the instance for a fixed address and persistent DNS.
  5. Connect: chmod 600 jenkins-server.pem, then ssh -i jenkins-server.pem ubuntu@<public-dns>, then sudo su -.
  6. Save the install script as install.sh and run source install.sh. It updates Ubuntu, installs NGINX and Jenkins, installs the suggested plugins, skips the setup wizard and prints the admin credentials.
  7. Open the public DNS in a browser, log in with the printed admin password, optionally create a new admin user, and accept the default Jenkins URL.

Afterwards verify that NGINX proxies requests to Jenkins on port 8080.
