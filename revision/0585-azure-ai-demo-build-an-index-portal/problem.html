Azure AI Services › 5. Search › Demo: build an index (portal)

  1. Create Azure AI Search resource (Free tier is enough for tests, with limited replicas/HA).
  2. Import data (SQL, Blob, Cosmos DB, or samples; demo uses hotels-sample). Other entries: Add indexes, Import and vectorize data, Search Explorer.
  3. Set index field attributes:
AttributeMeaning
RetrievableValue is returned in results
FilterableFilter on exact values
SortableSort results by it
FacetableAuto facets to narrow results
SearchableAffects relevance
SuggesterAutocomplete and misspelling suggestions
  1. Create an indexer: full crawl first, then incremental (needs change tracking on the data source; samples lack it, so one-time only).
  2. Verify under Search Management (Indexes document count, Indexers status, Data Sources, Skill Sets) and test in Search Explorer (same as REST/SDK). hotel returns all hotel results; hotel with pool in New York returns filtered matches.
