Database with Python › 2. SQLite with Python › Create a SQLite database and table

Steps: import sqlite3, connect (creates the file if missing), get a cursor, run CREATE TABLE IF NOT EXISTS, commit, close. Run with python3 app.py; movies.db appears in the working directory (a full path in connect stores it elsewhere).

The schema is kept simple. A better design would link to a separate directors table to avoid repetition or to allow several directors.
