Reinforcement learning (RL) is learning by interacting with an environment. The agent takes an action in a state and the environment returns a reward or punishment. The agent learns to maximize rewards and avoid penalties. Practical scenarios: autonomous driving, and jet engine troubleshooting that automatically finds the safest outcome.
