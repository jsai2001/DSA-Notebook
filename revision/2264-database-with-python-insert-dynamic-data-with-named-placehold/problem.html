insert_sale takes a cursor and the sale values, computes order_total = quantity * price * (1 - discount) (best moved into its own function for single responsibility), and passes a dictionary to named placeholders %(key)s. Parameterized execution prevents SQL injection. Possible improvements: a separate product database for prices, auto-assigned order numbers, error handling, and more SQL functions (SELECT, UPDATE, DELETE).
