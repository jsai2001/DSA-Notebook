Angular › 15. Testing and Linting › Unit testing basics

Default stack: Jasmine (framework) and Karma (runner). Specs live in *.spec.ts, generated by the CLI.

Karma builds the app, opens a browser, reruns tests on file save (watch mode). Green is pass; red shows expected vs actual and a stack trace. If Karma shows "No binary for Chrome browser", close and reopen the Karma tab.

  • describe('Name', () => {...}) groups specs into a suite (use the class name).
  • beforeEach(() => {...}) runs before every spec for a fresh instance. Declare shared variables with let at suite level and assign them in beforeEach.
  • it('should ...', () => {...}) is one spec; start the label with "should".
  • expect(actual).toBe(expected) asserts. Follow Arrange-Act-Assert, with named expected/actual variables.
