Project setup Google Cloud (GCP)

Google Cloud (GCP) › 2. Console, Cloud Shell and gcloud SDK › Project setup

  • Sign in to the Cloud Console, create a billing account (a free trial is offered), then create a project from the top nav bar.
  • Each project gets a name plus an auto-generated Project ID (globally unique, used in URLs and config). Organization and location can stay at defaults.
