MLOps › 4. Data Processing & Management › Data versioning (e.g. DVC)

Version control for data. It creates an immutable baseline for raw, intermediate or feature datasets, at feature, record or dataset level (tool-dependent). A version can be referenced for training and testing.

BenefitDetail
TraceabilityLink a data version to a specific model and experiment number
ReproducibilityRecreate a model with an older data version even after the data changed
Change logWhat changed in the feature store over time
RollbackReturn to last known good state after bad processing
Parallel workScientists use a fixed version while data evolves, so data evolution is decoupled from model development
