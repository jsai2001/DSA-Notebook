Q. Types of inventories?

  • Static: a manual host list (file).
  • Dynamic: a script or plugin pulls hosts (for example from AWS).

Static suits small setups; dynamic scales.

Q. Dynamic vs static inventory? Dynamic auto-fetches hosts from sources such as AWS via scripts or plugins. Static is a fixed, manual file. Dynamic scales, static is simple.
