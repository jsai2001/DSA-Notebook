PV, PVC and StorageClass Kubernetes

Kubernetes › 5. Storage › PV, PVC and StorageClass

Q. What is a Persistent Volume (PV)? A cluster storage resource that abstracts disks (for example NFS or cloud disks) for Pods.

Q. What is a Persistent Volume Claim (PVC), and how does it relate to a PV? A user request for storage. It binds to a matching PV for Pod use.

Q. Explain static vs dynamic provisioning.

  • Static: an admin pre-creates PVs.
  • Dynamic: PVs are created on demand through a StorageClass.

Q. What is a StorageClass, and how does it work? It defines storage types (for example SSD) for dynamic PV provisioning.
