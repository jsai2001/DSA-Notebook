Jenkins › 5. Triggers and SCM Integration › Downstream jobs, remote triggers and webhook plugins

Q. How do you trigger downstream jobs and pass parameters? Use the build step with parameters. wait and propagate control blocking and result propagation.

Q. How do you trigger a build remotely with cURL and an API token? Create a user API token, then POST to the job's build or buildWithParameters endpoint (with a crumb if CSRF protection is on). Trigger tokens can also be set per job.

Q. What is the Generic Webhook Trigger plugin? It lets any system trigger a job through one webhook URL and extracts fields from the JSON or XML payload into variables with JSONPath. The variables can feed an optional filter that decides whether to build.
