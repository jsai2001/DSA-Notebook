PyTorch Essential › 2. Environment: Google Colab & GPU Check

Colab (colab.research.google.com) is free, browser-based Jupyter with free GPU and needs only a Google account. Alternatives: a local machine (complex setup) or AWS/GCP/Azure (GPU instances cost money). Colab's free GPU has usage limits, which are enough for learning.

Verify PyTorch and the GPU:

Enable the GPU: Runtime → Change runtime type → choose T4 GPU → Save, then re-run. torch.cuda.is_available() now returns True.
