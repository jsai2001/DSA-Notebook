Pipeline script from SCM Jenkins

Jenkins › 5. Triggers and SCM Integration › Pipeline script from SCM

Jenkins supports several SCMs (Git, Subversion); Git is the most popular and needs the Git plugin.

  1. Choose Pipeline script from SCM in the job.
  2. Pick the SCM (Git).
  3. Enter the repository URL and credentials if the repo is private (public repos need none).
  4. Set the branch specifier (set it to the repo's default branch, for example main).
  5. Set the script path to the Jenkinsfile (root by default).
  6. Save and build.

Jenkins checks out the repository and takes the project configuration from the Jenkinsfile.
