Q. How do you inject credentials securely? withCredentials binds a stored credential to environment variables for the duration of a block, then unbinds it, and Jenkins masks the values in logs. Alternatively use credentials('id') in an environment block. For username and password credentials it sets one variable holding username:password plus two derived variables, <NAME>_USR and <NAME>_PSW.

Use the string form of withCredentials for secret text credentials. Recreate the permission matrix when switching strategies and test as a restricted user.
