Kubernetes › 17. Kubernetes with Python › Operators and custom controllers

Q. What is a Kubernetes operator, and how can Python create one? An operator is a custom controller that extends Kubernetes to manage complex applications. It uses custom resources and controllers to automate tasks like scaling or backups. In Python, use kopf (Kubernetes Operator Pythonic Framework) or the kubernetes client to define custom resources (CRDs), reconcile desired and actual state, and deploy the operator as a Pod in the cluster.

Q. How can Python create a custom Kubernetes controller? A controller watches changes to custom resources and reconciles the desired state. Use the kubernetes client with watch.Watch to monitor CRDs, or use kopf or operator-sdk.

Q. A Python operator is not responding to custom resource events. How do you troubleshoot it?

  • Check logs: inspect operator logs for errors.
  • Verify RBAC: the operator needs permission to watch custom resources.
  • Test event handling: simulate events to verify the handler.
  • Debug code: add logging to the event loop.
