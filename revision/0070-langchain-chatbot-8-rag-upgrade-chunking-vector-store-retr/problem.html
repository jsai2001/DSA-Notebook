LangChain Chatbot › 8. RAG upgrade: chunking, vector store, retrieval, memory

Use when data is too big for the prompt. Flow: load, split into overlapping chunks, embed, store in FAISS, retrieve top-k similar chunks per question, LLM answers from them.

  • RecursiveCharacterTextSplitter(chunk_size=1000, chunk_overlap=200): overlap preserves context across chunk edges.
  • OpenAIEmbeddings: text to vectors; as_retriever(search_kwargs={"k": 3}): top 3 chunks.
  • chain_type="stuff": retrieved chunks go into one prompt.
  • ConversationBufferMemory: chat history so follow-ups work.

Caution: the snippets use older import paths and APIs (langchain.vectorstores, langchain.memory, ConversationChain, llm(prompt)) that newer LangChain moved or deprecated; check current docs.
