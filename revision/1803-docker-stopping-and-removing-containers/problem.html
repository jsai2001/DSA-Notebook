Stopping and removing containers Docker

Docker › 3. Running and Managing Containers › Stopping and removing containers

Q. stop vs kill?

  • stop: graceful (SIGTERM).
  • kill: instant (SIGKILL).

Q. rm vs rm -f?

  • rm: removes stopped containers only.
  • rm -f: stops and removes.

Q. What happens to data when a container stops? In-memory data is lost. The file system persists until the container is deleted. Use volumes for durable data.
