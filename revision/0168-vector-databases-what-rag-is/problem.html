Vector Databases › 10. Use case 2: RAG concepts › What RAG is

Retrieval-Augmented Generation = curated knowledge base (context) + LLM (language skills). Retrieve relevant context, augment the prompt with it, let a standard LLM generate a grounded answer. Most popular enterprise LLM use case.

  • Enterprise data access, multiple formats (PDF, tickets/DB, HTML, CSV), curated (only relevant, clean content), continuously updated (new doc is searchable minutes after processing; no retraining).
  • Reduces hallucination because the answer is grounded in retrieved facts.
  • Hybrid search: vector similarity plus scalar filters (e.g. product == 'Product A' AND date > '2024-01-01').
  • Uses off-the-shelf LLMs (GPT-4, Claude, Gemini, Llama 2): no training, provider updates, lower cost, faster deployment.
