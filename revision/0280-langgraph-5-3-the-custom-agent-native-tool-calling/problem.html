LangGraph › 5. Custom Orders Agent (hand-built graph) › 5.3 The custom agent (native tool calling)

  • State: Annotated[list[AnyMessage], operator.add]. The operator.add reducer appends each node's returned messages instead of overwriting.
  • model.bind_tools(tools) lets the LLM emit structured tool_calls.
  • is_tool_call is the conditional edge: {True: "orders_tools", False: END}.
  • call_tools wraps each result in a ToolMessage with the tool_call_id, which matches results to requests.
  • The system prompt is prepended on every LLM call, not stored in state.
  • compile(checkpointer=MemorySaver()) gives per-thread_id memory.
