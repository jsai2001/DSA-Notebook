Trees don't need standardization.

The test score peaks at depth 3, the best choice: simple, no overfitting, good on unseen data. The test curve is jagged because the split matters (changing random_state changes it). For a more stable estimate use k-fold cross validation: split into k chunks (typically 5), hold out each in turn, train on the rest, and average the scores. This is a concept only here; the course shows no code for it.
