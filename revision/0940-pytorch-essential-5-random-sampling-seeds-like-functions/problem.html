PyTorch Essential › 5. Random Sampling, Seeds & _like Functions

Why random tensors: initialize network weights randomly, and generate random inputs from a chosen distribution.

Reproducibility. Call torch.manual_seed() before each random tensor creation to get identical values every run.

Other distributions exist too (e.g. multinomial, exponential).

_like functions create a tensor that inherits device, size, dtype and layout from a reference tensor.

BaseLikeFills with
torch.empty()empty_like()Uninitialized
torch.zeros()zeros_like()0
torch.ones()ones_like()1
torch.rand()rand_like()Uniform random
torch.randint()randint_like()Random integers
torch.full()full_like()A given value
