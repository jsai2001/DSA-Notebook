Advanced RAG › 4. Embeddings: Model Choice, What to Embed, Distance Metrics › Picking a model

FactorMeaning
Embedding sizeDimensionality (384, 768, 1536). Larger = more compute to compare. Only same-size embeddings are comparable.
Model sizeSmaller = cheaper; larger = more fine-grained
Training dataLanguage (a Chinese model won't work for Arabic), structure (chat vs essays), data size

Algorithmic (non-neural) models produce sparse/binary embeddings: TF-IDF (Term Frequency–Inverse Document Frequency), SPLADE (Sparse Lexical and Expansion Models), BM25 (Best Matching 25).
