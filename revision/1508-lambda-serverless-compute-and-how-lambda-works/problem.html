AWS Lambda › 1. What Lambda is › Serverless compute and how Lambda works

AWS Lambda is a serverless, event-driven compute service that runs code without you provisioning or managing servers. Serverless means pay-as-you-go, no infrastructure management (AWS handles servers, scaling, patching and availability) and automatic scaling up and down with traffic.

How it works:

  1. Upload code in a supported language (JavaScript, Python, Java, C#, Go and more).
  2. Configure triggers: state changes, HTTP requests or AWS service events (for example an S3 bucket event).
  3. Execution: Lambda runs the code when triggered. The code can run business logic, call other AWS services or call external APIs.
