3.5 Retrieving RAG with LlamaIndex

RAG with LlamaIndex › 3. LlamaIndex Fundamentals › 3.5 Retrieving

A retriever is the interface an index exposes to fetch relevant nodes. The query is embedded with the same model used at indexing, a similarity search runs, and the top-k nodes come back with scores. Retriever types include vector, fusion, and recursive (hierarchical via node relationships).

The lesson notes pass similarity_cutoff=0.75 to as_retriever; the notebook uses similarity_threshold=0.75. For a reliable cutoff use a SimilarityPostprocessor(similarity_cutoff=...) on a query engine (sections 3.6 and 7.1).

Retrieval returns raw nodes and scores. A query engine is needed for a synthesized answer.
