Challenge: reusable S3 bucket template AWS CloudFormation

AWS CloudFormation › 5. First Templates (YAML) › Challenge: reusable S3 bucket template

Build one template that creates multiple S3 buckets.

  1. Parameterize the bucket name (user enters it).
  2. Parameterize versioning as a dropdown with a default (check the docs for allowed values).
  3. Output the bucket URL and ARN.
  4. Bonus: an environment name parameter that tags the bucket.
