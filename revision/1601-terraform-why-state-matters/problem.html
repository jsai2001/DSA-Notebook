Terraform › 5. State Management › Why state matters

Q. Why is the state file key, and what if it is corrupted? It tracks infrastructure. Corruption causes duplicates and errors. Restore from backup.

Q. How do you recover a lost state file? Restore a backup or rebuild it with terraform import.

Q. What is state drift, and how do you fix it? Drift is a mismatch between real infrastructure and state. Detect it with plan. Fix it with apply or by updating the config.
