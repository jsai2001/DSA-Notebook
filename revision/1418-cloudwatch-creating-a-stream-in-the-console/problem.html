Creating a stream in the console AWS CloudWatch

AWS CloudWatch › 5. Metric Streams › Creating a stream in the console

CloudWatch > Metrics > Streams > Create metric stream.

  1. Choose all namespaces or specific ones (for example CloudWatchApiCourse).
  2. Choose destination: Quick S3 setup auto-creates a Firehose, an S3 bucket (for example metrics-streams-streamdemo) and IAM roles; or an existing Firehose; or a custom Firehose with source Direct PUT (required for CloudWatch to send metrics).
  3. Name the stream (for example streamdemo) and create it.
