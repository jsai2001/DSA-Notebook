Google Cloud (GCP) › 7. Cloud Tasks and the Fan-Out Pattern › Concepts

  • Create tasks and run them in the background. Two target types: App Engine tasks (endpoints in an App Engine app) and HTTP target tasks (any public URL).
  • A task has a name (auto-generated if omitted), target POST URL, payload, optional schedule time (otherwise ASAP) and a queue.
