AWS Lambda › 10. Infrastructure as Code and AWS SAM › Why Infrastructure as Code

Building serverless apps in the console is error-prone, tedious, hard to maintain and impossible to replicate across test, dev and production accounts. Infrastructure as Code (IaC) defines infrastructure in YAML or JSON and treats it like application code (testing, code review, version control).

Advantages:

  • Programmatic management: no manual console clicks, fewer human errors.
  • Replicability: reuse the same scripts across environments.
  • Version control: Git records who changed what and why.
  • Scalability: one engineer can manage large infrastructure, with reusable components.
  • Quality and security: code review and automated tests apply to infrastructure.
  • Speed: reuse existing templates.
