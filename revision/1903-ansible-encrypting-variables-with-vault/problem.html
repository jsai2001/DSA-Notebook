Encrypting variables with Vault Ansible

Ansible › 7. Variables, Facts and Vault › Encrypting variables with Vault

Q. What is Ansible Vault? It encrypts secrets (passwords, API keys) in files so they can be stored safely, even in version control.

Q. Encrypt variables with Vault?

ansible-vault create prompts for a vault password and opens an editor. The saved file is AES256-encrypted on disk (it starts with $ANSIBLE_VAULT;1.1;AES256).
