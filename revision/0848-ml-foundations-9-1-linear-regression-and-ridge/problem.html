9.1 Linear regression and Ridge ML Foundations

ML Foundations › 9. Model Tuning › 9.1 Linear regression and Ridge

Linear regression has almost nothing to tune (fit_intercept, copy_X, n_jobs). It can't be made more complex, only simplified. Ridge adds alpha for regularization (penalizes over-reliance on any one feature): alpha=0 equals plain linear regression, default 1, higher means a simpler model.

Scores go from about 0.802 (alpha=0) to about 0.807, a negligible gain. The plot looks dramatic only because of the y-axis scale, so always check axis ranges. If the gain is marginal, try different data splits to confirm it's consistent.
