GCP for Machine Learning › 8. Vector Search (Embeddings, ANN, RAG)

Vector search retrieves by semantic similarity instead of keywords.

ConceptDescription
EmbeddingsText/images/audio turned into low-dimensional numeric vectors that capture meaning (like fingerprints)
Similarity metricsDistance between vectors; closer means more similar
Approximate Nearest Neighbor (ANN)Algorithm that finds a query vector's nearest neighbors quickly

It is critical for RAG: embeddings plus vector search ground LLM responses in real data.
