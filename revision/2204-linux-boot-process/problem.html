Boot process Linux

Linux › 1. Linux Basics › Boot process

Q. What is the Linux boot process? BIOS/UEFI, then GRUB loads the kernel and initramfs, then the kernel initializes hardware and mounts root, then systemd starts services, then the login prompt appears.

Q. How do you troubleshoot a boot failure? Check GRUB (press e to edit, boot to single-user mode), read logs with journalctl -b, or use a live CD to run fsck.
