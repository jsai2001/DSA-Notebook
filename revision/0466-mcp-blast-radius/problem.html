Model Context Protocol › 9. Security › Blast radius

Blast radius is the potential scope of damage or unintended consequences when AI agents execute actions on your computer. "The blast radius of AI agents and MCPs is unlimited until we limit it." Even if you read a server's code you may not know what is really happening on it.

RiskExample
Unintended actionsDeleting files instead of reading them
Hidden operationsCode runs behind the scenes, data manipulated without awareness
Excessive accessFull file system access when only read is needed
LLM extensionsThe model uses the server in unexpected ways
