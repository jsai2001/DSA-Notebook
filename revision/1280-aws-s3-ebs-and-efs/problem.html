Q. S3 vs. EBS vs. EFS?

  • S3: object storage for backups and web content.
  • EBS: block storage for EC2, for example databases.
  • EFS: shared file system for multi-instance apps.

Q. What is Amazon EBS and how does it integrate with EC2? Block storage that mounts to EC2 as a root or data volume. Snapshots provide backup.

Q. SSD vs. HDD in EBS?

  • SSD (gp3, io2): fast and IOPS-heavy. Good for databases.
  • HDD (st1, sc1): cheap and throughput-focused. Good for big data and cold storage.

Q. What is Amazon EFS and when do you choose it over S3? A shared file system that mounts to multiple EC2 instances. Use it for shared file access, where S3 offers object storage.
