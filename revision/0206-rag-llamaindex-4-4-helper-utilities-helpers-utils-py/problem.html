RAG with LlamaIndex › 4. Introduction to RAG: Pipelines, Prompts, Data Prep › 4.4 Helper utilities (helpers/utils.py)

Thin wrappers used by all later notebooks. Knowing what they do makes the later code readable.

HelperWhat it does
setup_llm(provider, model, api_key)Sets Settings.llm for cohere / openai / mistral
setup_embed_model(provider, **kw)Sets Settings.embed_model: cohere (embed-english-v3.0), openai (text-embedding-3-large unless overridden), fastembed (BAAI/bge-base-en-v1.5)
setup_vector_store(url, key, collection, enable_hybrid=False)Builds QdrantVectorStore with both sync and async Qdrant clients
get_documents_from_docstore(persist_dir)Loads a persisted SimpleDocumentStore and returns its documents
create_index(from_where, **kw)"vector_store" → VectorStoreIndex.from_vector_store; "docs" → from_documents
ingest(transformations, documents, **kw)Runs an IngestionPipeline (pipeline.run(nodes=documents))
create_query_pipeline(chain, verbose=True)QueryPipeline(chain=chain)
create_query_engine(index, mode, **kw)"chat" → as_chat_engine, "query" → as_query_engine, "retrieve" → as_retriever
display_prompt_dict(prompts)Pretty-prints prompt templates in a notebook
group_documents_by_author, sample_documents, run_generations_on_eval_setEvaluation helpers (section 5)
