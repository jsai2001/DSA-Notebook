RESTful API › 4. Database with SQLAlchemy: Models and Seeding

  • APIs do CRUD against a database. SQLite is file-based, needs no server and ships with Python.
  • An ORM (SQLAlchemy) generates SQL behind the scenes and represents rows as Python objects. Benefits: no raw SQL, easy database switching (SQLite to MySQL), schema defined in code (version-controlled), support for several databases when shipping on-premises.
  • Install Flask-SQLAlchemy (with the dash; FlaskSQLAlchemy is a different package). It installs SQLAlchemy too.
