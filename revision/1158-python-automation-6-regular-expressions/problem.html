6. Regular Expressions Python Automation

Python Automation › 6. Regular Expressions

Use regex to extract structured data (phone numbers, emails) from text.

  • re.compile() builds the pattern. \d matches one digit. The pattern matches XXX-XXX-XXXX.
  • .search() returns the first match or None, so test it before calling .group(). .group() returns the matched text.
