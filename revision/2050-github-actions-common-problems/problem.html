GitHub Actions › 9. Debugging, local testing and limits › Common problems

  • No runner available: wrong runs-on label or offline self-hosted runner.
  • Network failures: external services down or unstable.
  • Permission errors: missing GITHUB_TOKEN scopes.
  • Concurrency conflicts: multiple runs triggered at once.
  • Skipped workflows: [skip ci] in the commit message or a conditional if.

Practices: enable ACTIONS_STEP_DEBUG=true, retry flaky steps, use continue-on-error for non-critical steps, and rotate exposed secrets immediately.
