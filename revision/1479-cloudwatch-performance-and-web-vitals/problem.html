Performance and web vitals AWS CloudWatch

AWS CloudWatch › 14. CloudWatch RUM › Performance and web vitals

Default time range is 1 week. The Performance tab shows page load times, errors and average load time by time of day. Web vitals (similar to Lighthouse): Largest Contentful Paint (LCP), First Input Delay (FID), Cumulative Layout Shift (CLS), and page load steps over time. Red metrics indicate problems. Better vitals improve the experience and SEO ranking.
