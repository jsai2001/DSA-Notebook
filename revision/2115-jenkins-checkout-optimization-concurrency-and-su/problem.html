Jenkins › 5. Triggers and SCM Integration › Checkout optimization, concurrency and submodules

Q. What is Git sparse checkout, and how do you speed up large checkouts? Sparse checkout fetches only specified paths instead of the whole repo, which helps monorepos. Other options: shallow clone (depth), skipping tags, reference repos, and disabling unneeded submodules.

Q. How do you handle Git submodules during checkout? Enable the SubmoduleOption extension (recursive, with parent credentials) so submodules are initialized and updated.

Q. How do you stop concurrent builds of the same branch? Add disableConcurrentBuilds: a new build of the same job or branch queues until the current one finishes, avoiding races on shared resources and deploys. abortPrevious: true cancels the older run instead.

Q. What is the Quiet Period? A configurable delay between a trigger firing and the build starting. It batches a burst of rapid commits into one build and avoids redundant runs.
