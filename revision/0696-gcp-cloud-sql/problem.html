Google Cloud (GCP) › 5. Cloud SQL and Service Accounts › Cloud SQL

  • Fully managed MySQL, Postgres and SQL Server. Google handles uptime, replication, backups and scaling.
  • Create instance form: Instance ID, root password (manual, generated, or none), region and zone, database version.
  • Region is permanent, the zone can be changed. Keep the DB in the same location as the services using it.
