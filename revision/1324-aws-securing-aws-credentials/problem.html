Q. How do you keep AWS credentials secure in Python scripts?

  • IAM roles: assign roles to EC2 instances or Lambda functions so no credentials are hardcoded.
  • AWS Secrets Manager: store credentials there and retrieve them with boto3.
  • Environment variables or CLI profiles: AWS_ACCESS_KEY_ID and AWS_SECRET_ACCESS_KEY in the environment, or named profiles in ~/.aws/credentials.
  • No hardcoding: never embed credentials in source code.
  • Least privilege: give roles and users minimal permissions.
