Setup for these notebooks: sample 10 documents per author, chunk with SentenceSplitter(chunk_size=256, chunk_overlap=16), ingest into an in-memory Qdrant collection (QDRANT_URL = ":memory:"), create_index(from_where="vector_store", ...). Same code as sections 4 and 6.

Order of operations in a LlamaIndex query: ingestion → indexing → retrieval → reranking → post-processing → response generation. Reranking reorders nodes (most relevant first); post-processing transforms or filters nodes (drop low scores, replace text, compress). Both run on retrieved nodes before the LLM.
