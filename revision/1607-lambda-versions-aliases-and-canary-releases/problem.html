Q93. How do versions and aliases support blue/green or canary deployments? Publishing a version creates an immutable snapshot ($LATEST is mutable, numbered versions are frozen). An alias is a named reference (for example PROD) to a version and can split traffic between two versions by weight. That enables blue/green (flip the alias) and canary (shift a small percentage first) without changing callers.

Q94. How does CodeDeploy manage weighted alias traffic shifting? CodeDeploy automates alias shifting with deployment configs such as Canary (for example 10% for 5 minutes, then 100%) or Linear (for example +10% every minute). It watches CloudWatch alarms during the shift and rolls back automatically to the previous version if alarms trip. SAM wires this up with DeploymentPreference.
