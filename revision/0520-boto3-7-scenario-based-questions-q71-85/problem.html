Q78. EKS cluster not scaling as expected. Diagnose:

  • Check node group config (desired, min, max) with boto3.
  • Check that the Cluster Autoscaler is deployed and configured.
  • Review CloudWatch logs.
  • Validate IAM permissions for scaling.
  • Fix by updating the node group scaling config.

Q79. Automate cleanup of unused S3 buckets. List buckets, delete those matching a tag or age, schedule in GitHub Actions, and add safeguards (dry run, confirmation). (Gotchas: delete_bucket fails on non-empty buckets, and get_bucket_tagging raises an error for buckets with no tags.)

Q80. IAM role lacks DynamoDB permissions. Inspect the AccessDenied error, describe the role's policies with boto3, attach a policy allowing the needed dynamodb:* actions (scope it tighter in practice), rerun.
