Q41. API Gateway Proxy Integration vs Custom Integration?

  • Proxy (Lambda proxy) integration: API Gateway passes the entire raw request (path, headers, query, body) to Lambda as the standard event, and Lambda must return a {statusCode, headers, body} shape. Simple, flexible, minimal mapping config.
  • Custom (non-proxy) integration: you use mapping templates (VTL) to transform the request and response between client and Lambda. More control and decoupling, more configuration.

Q42. How do you trigger a function on a schedule? Use Amazon EventBridge (Scheduler or a rule) with a rate() or cron() expression. EventBridge invokes the function asynchronously.
