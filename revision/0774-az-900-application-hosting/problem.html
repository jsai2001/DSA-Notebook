Application hosting (1/2) AZ-900

AZ-900 › 6. Compute and networking › Application hosting

App Service (PaaS): web apps in the cloud.

  • Apps run on VMs in an App Service Plan, the unit of scaling. All apps in the plan share the same VMs.
  • Lower plan tiers cost less with fewer features. Higher tiers add power and features.
  • App names must be globally unique (<app-name>.azurewebsites.net).
  • Scaling applies to the whole plan: scale up (bigger VM), scale out (more instances) or autoscale by metric (CPU, traffic).
  • Turnkey authentication: add Microsoft, Apple, Facebook, GitHub or Google sign-in with no auth code.
