Terminology changes that appear in the material:

  • Azure Active Directory (Azure AD) is now Microsoft Entra ID. Azure AD Domain Services is now Microsoft Entra Domain Services. Microsoft Entra is the product family; Entra ID is one product in it. These notes keep "Azure AD" where the course does. The commands are unchanged.
  • Serverless was added to the cloud-concepts domain (July 2023): the provider provisions, scales and manages the infrastructure, and you only write code.
  • Infrastructure as Code (IaC) was added to the managing-and-deploying domain (July 2023).
  • Other updates were wording only (capitalization, "MFA" spelled out, "defense-in-depth" hyphenated, "external identities, including B2B and B2C").
