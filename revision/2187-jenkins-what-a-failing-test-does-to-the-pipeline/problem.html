What a failing test does to the pipeline Jenkins

Jenkins › 10. Artifacts, Fingerprints and Test Reports › What a failing test does to the pipeline

With a deliberately failing test in the Test stage (publishing with junit in post), the Test stage fails, the Build and Deploy stages are skipped, and the build is marked unstable (yellow). The Test Results link shows the failed test with its error message and stack trace.
