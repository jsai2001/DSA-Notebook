Database with Python › 1. Databases and the Python Database API › Why Python apps use a database

Databases keep data between user sessions and give an organized structure for storing, accessing and managing large datasets. A database needs a query language (such as SQL) to add, remove or read data. The course builds databases in SQLite, MySQL and Postgres, talks to them through modules that follow the Python Database API, and then uses SQLAlchemy, an object-relational mapper (ORM).
