4.2 The three outputs of PCA (1/2) ML Algorithms

ML Algorithms › 4. PCA and Other Dimensionality Reduction › 4.2 The three outputs of PCA

  1. Principal components: the transformed data, with the same rows but PCs as columns.
  2. Explained variance ratio: information per PC, in descending order.
  3. Feature weights (components_): how much each original feature contributes to each PC.

Scree plot (variance per PC):

Cumulative sum shows the cutoff. To keep 95% of the information, take the first 2 PCs and drop the rest. Fewer columns make many ML algorithms much faster.

Feature weights. Large magnitude means the feature strongly affects the PC; near 0 means it barely matters. If features share a scale, the weights act as feature importance; otherwise standardize first. The PCs are mutually orthogonal.

Iris example (here X is the 4-feature frame, so use X_all.columns):

sepal lengthsepal widthpetal lengthpetal width
PC10.36-0.080.860.36
PC20.660.73-0.17-0.08

PC1 is mostly petal length; PC2 is mostly sepal width and sepal length.

How a PC is computed: centre each feature, multiply by its weight, sum.
