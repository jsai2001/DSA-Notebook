Q. How do you run Docker-in-Docker or Kaniko in Kubernetes agents to build images? DinD runs a Docker daemon in a sidecar and needs privileged mode, which is a security concern. Kaniko builds images in userspace without a Docker daemon or privileged access, so it is preferred in Kubernetes. It pushes straight to a registry using mounted credentials.
