CrewAI › 8. Tasks › Async execution

async_execution=True runs a task in the background without blocking the main sequence. Good for long-running work (scraping, summarizing millions of records) and non-critical work (logging, notifications, emailing). If a downstream task lists the async task in context, it waits for it to finish.

ScenarioBehavior
Async task, nothing depends on itRuns in background, blocks nothing
Async task + downstream contextDownstream task waits for it
Non-async tasksSequential as normal
