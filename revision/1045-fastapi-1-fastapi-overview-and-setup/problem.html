FastAPI › 1. FastAPI Overview and Setup

FastAPI is fast in two ways: fast to develop (little code to a working server) and fast at runtime (serves many requests efficiently).

  • Prerequisites: Python, HTTP/JSON/REST basics, command line.
  • FastAPI does not implement a web server itself. It speaks ASGI, and Uvicorn serves HTTP.
  • Pydantic handles validation and serialization; OpenAPI docs are generated at /docs.
