Object lifecycle management Google Cloud (GCP)

Google Cloud (GCP) › 6. Cloud Storage (GCS) › Object lifecycle management

  • Rules apply to all objects in a bucket. Age counts from when the object was added. Set under bucket, Lifecycle tab, Add a Rule (action, then conditions).
  • If an object matches several rules, the least-costly-to-keep action wins: Delete beats downgrade to the lowest class, which beats downgrade to a higher class.
ActionsConditions
Set storage class (e.g. Standard to Archive), DeleteAge (days since upload), creation date, storage class, newer versions + live state (versioning)

Example (file download service): rule 1 sets class to Archive at age 30 days and class Standard. Rule 2 deletes at age 365 days, so links expire after a year.
