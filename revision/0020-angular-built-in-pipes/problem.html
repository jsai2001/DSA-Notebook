Built-in pipes Angular

Angular › 7. Pipes › Built-in pipes

  • slice : start : end works like JavaScript slice. Array form is slice : 0 : 5 (first 5 items).
  • percent : 'minInt.minFrac-maxFrac' formats with the browser locale. '1.1-1' means min 1 integer digit, min 1 and max 1 fraction digit.
  • number adds locale thousands separators. Others: uppercase, lowercase, titlecase, json, currency, date.
  • async subscribes to a Promise/Observable and unsubscribes automatically (section 14).
