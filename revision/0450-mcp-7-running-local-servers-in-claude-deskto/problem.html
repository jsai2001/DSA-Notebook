Model Context Protocol › 7. Running Local Servers in Claude Desktop

Published servers (npm/PyPI) need simple args such as the package name. Local servers (on your disk) need complex args because Claude Desktop must create a virtual environment and install dependencies itself. Claude Desktop is a good test bed before publishing.

The args array is this terminal command:

PartPurpose
command (absolute path to uv)Find with which uv / where uv
uv runStart uv
--with mcp[cli]Add the MCP CLI to a temporary environment
mcp runRun the server via the MCP CLI
last argAbsolute path to server.py (get it with pwd in the project)

What happens: Claude reads the config, runs the command, uv creates a temporary venv, installs mcp[cli], runs the server, and the server is ready. The LLM app is running software inside itself.

Mix local and published servers freely in one config (local weather with uv run ..., plus fetch via uvx, as in section 4).
