Q. What is strategy? The task execution mode:

  • linear (default): waits for all hosts to finish a task before the next one.
  • free: each host proceeds independently, so faster hosts do not wait.
  • debug: interactive, for troubleshooting.

Setting strategy: free or strategy: debug on a play works the same way. With linear, everyone waits for the 5-second hosts; with free, host1 and host2 move to Task 2 after 2 seconds.
