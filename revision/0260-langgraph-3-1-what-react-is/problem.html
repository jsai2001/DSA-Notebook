3.1 What ReAct is LangGraph

LangGraph › 3. ReAct Agent (prebuilt and from scratch) › 3.1 What ReAct is

ReAct = Reason + Act. From a research paper; the LLM drives an iterative loop, which also makes agent actions explainable.

User input → Thought → Action → Observation → repeat until done → Final answer

  1. Thought: the LLM analyzes the input and decides the next step.
  2. Action: the agent runs a tool or computation.
  3. Observation: the LLM checks the result and decides whether more steps are needed.

Course example: a math agent with tools find_sum and find_product. "What is the sum of 2 and 3?" calls find_sum(2, 3) and returns 5.
