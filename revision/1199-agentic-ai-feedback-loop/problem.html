Agentic AI Fundamentals › 3. Perception, Feedback and Agent Communication › Feedback loop

The system learns from its mistakes and refines future responses.

StepDescription
Action takenAgent makes an initial assessment (a person is stealing)
Outcome sensedThe result is observed and reassessed
Feedback receivedA user or the system corrects it (it is a delivery)
LearningThe agent will not repeat the wrong assumption

Examples: a doorbell camera learns a delivery person is not a thief. A phone fraud detector learns a known friend is not a fraud threat.
