1. Big picture LangChain Chatbot

LangChain Chatbot › 1. Big picture

Goal: a chatbot that answers from your own data (hotel PDF + website) using OpenAI and LangChain, wrapped in a Flask web app. No model training; the data is injected through the prompt.

Pipeline: extract text -> save to a text file -> prompt template with that text + persona -> prompt | llm chain -> Flask route -> HTML/JS front end.

Stack: Python, OpenAI API, LangChain, PyMuPDF, requests + BeautifulSoup, Flask, HTML/CSS/JS.

Two ways to feed your data to the model (key interview distinction):

ApproachHowTrade-off
Prompt stuffing (Sections 5-6)Entire extracted text in the promptSimple; fails when data exceeds the context window; pays tokens for all text every call
RAG (Section 8)Chunk, embed, store in a vector store, retrieve top-k per questionScales to large data, cheaper per call; more moving parts
