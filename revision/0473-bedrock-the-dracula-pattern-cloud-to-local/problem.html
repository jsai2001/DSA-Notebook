Amazon Bedrock › 4. Compare Mode and the Dracula Pattern › The Dracula Pattern (cloud to local)

Same process, but the target is a free local model (Ollama with Qwen 2.5 Coder). Test on Bedrock Claude first, move working prompts to Ollama, refine while monitoring quality loss, iterate until local matches cloud.

Cloud (Bedrock)Local (Ollama)
Cost modelPay per call (variable)Pay per server (fixed hardware and power)
HardwareAWS managedYour own, CPU or NVIDIA GPU
InternetRequiredNot needed after setup
Data privacyData leaves your networkData stays local
UpdatesAutomaticManual

Use local for: lower API cost at high volume, privacy, legal or health compliance, offline use, batch workflows (CPU may be enough; use an NVIDIA GPU for low-latency inference).

PitfallConsequence
Skipping the cloud testing phaseNo baseline to compare against
