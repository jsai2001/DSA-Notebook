Conditional stages with when Jenkins

Jenkins › 4. Parameters, Conditions and Approvals › Conditional stages with when

Q. How do you run a stage conditionally with when? when decides whether a stage runs. If it evaluates to true the stage runs, otherwise it is skipped. Conditions:

  • branch: only for given Git branches (for example main).
  • environment: an environment variable has a given value.
  • expression: a Groovy expression using parameters or variables (for example params.ENV != 'prod').
  • Others include changeRequest and tag.
