Building and testing locally with SAM AWS Lambda

AWS Lambda › 10. Infrastructure as Code and AWS SAM › Building and testing locally with SAM

sam build copies the sources into .aws-sam, installs dependencies, leaves out test code and dev dependencies, and writes a transformed template.yaml (Docker must be running). sam local invoke runs one function with an event file (the first run builds a Docker image, so it is slower). sam local start-api serves the API at http://localhost:3000, so you can test paths without deploying.

Edit the handler (for example add console.log('Hello') and change the message), then rebuild and re-invoke to see the new logs and response.
