Conditionals AWS CloudFormation

AWS CloudFormation › 11. Advanced Features › Conditionals

The if/else of a template. For a disaster-recovery template: if the user supplies a snapshot ID, create the EC2 instance from that snapshot; if not, start fresh. One template then creates either a fresh environment or a restored one. Conditionals also let a template create different resources based on user input.
