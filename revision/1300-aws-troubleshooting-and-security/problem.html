Troubleshooting and security AWS

AWS › 10. Scenario-Based Questions › Troubleshooting and security

Q. How do you troubleshoot an unreachable EC2 instance? Check status, Security Groups, routes, IP and logs. Restart if needed.

Q. How do you fix slow application performance? Use CloudWatch and X-Ray, then scale EC2, add caching and optimize the database.

Q. How do you secure an S3 plus RDS app? IAM, encryption, private subnets and restricted access.

Q. An S3 bucket was made public. What do you do? Remove public access, turn on the block-public-access settings and audit with CloudTrail.
