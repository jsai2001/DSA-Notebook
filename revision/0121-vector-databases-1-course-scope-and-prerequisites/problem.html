1. Course scope and prerequisites Vector Databases

Vector Databases › 1. Course scope and prerequisites

  • Instructor: Kumaran Ponnambalam. Goal: what a vector DB is, what it offers, how it helps LLM apps.
  • Flow: vector concepts, Milvus setup (Docker), CRUD + search from Python notebooks, then two use cases: LLM caching and RAG.
  • Prerequisites: ML/NLP basics, transformers and LLMs (prompt in, response out), text embeddings, Python and Jupyter, Docker, LangChain (helpful). Needs an OpenAI API key (free tier hits rate limits).
