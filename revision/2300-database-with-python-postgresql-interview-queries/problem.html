Q. PostgreSQL vs MySQL talking points? JSONB, window functions and extensibility. Also be ready to explain MVCC (Multiversion Concurrency Control), handle NULLs, and optimize slow queries. For DBA roles stress replication, vacuuming and configuration tuning. For developer roles stress complex queries and JSONB. Practise 20 to 30 SQL problems on LeetCode or HackerRank, and test commands on a local instance (Docker works).
