AWS Lambda › 12. Scenario-based questions › Image thumbnails without timing out

Q96. An image uploaded to S3 must become 3 thumbnails. How do you design this with Lambda without timeouts? S3 ObjectCreated triggers Lambda asynchronously. Generate the three sizes in one invocation if it is quick. If it is heavy, fan out: one Lambda publishes 3 messages (SNS, SQS or EventBridge) and a worker Lambda resizes each in parallel. Right-size memory (more memory means more CPU and faster image work), stream to /tmp, and configure a DLQ or destination for failures. Fan-out keeps each invocation far below the timeout and parallelizes the work.
