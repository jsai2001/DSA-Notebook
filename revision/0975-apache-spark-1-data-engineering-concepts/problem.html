Apache Spark › 1. Data Engineering Concepts

Data engineering is designing and building systems that collect, move, process and store data at scale and low latency, so analytics and ML can use it. It is a prerequisite for ML (training data must be cleansed and transformed; inference also needs pre/post-processing). Roles: Data Engineer, Big Data Architect.
