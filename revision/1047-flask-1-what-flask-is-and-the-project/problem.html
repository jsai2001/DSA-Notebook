1. What Flask Is and the Project Flask

Flask › 1. What Flask Is and the Project

Flask is a micro web framework for Python: small core, extensions added only when needed, full control over structure. Created by Armin Ronacher in 2010 (started as an April Fools' joke). Typical uses: blogs, REST APIs, microservices, dashboards, data-visualization apps (popular in data science).

Prerequisites: basic Python, conceptual HTML/CSS, HTTP client-server basics, Git/Bash, Python + editor + GitHub account.
