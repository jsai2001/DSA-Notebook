Function not invoked by its event source AWS Lambda

AWS Lambda › 13. On-call troubleshooting › Function not invoked by its event source

Symptom: Lambda function not invoked by an event source. Check the event source mapping, permissions and CloudWatch Logs.

Console steps: Lambda > Functions > select the function > Triggers (verify the source, for example SQS) > Permissions (check the execution role) > Monitor > Logs.
