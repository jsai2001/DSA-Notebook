Azure AI Services › 9. Azure AI Foundry (AI Studio) and Azure OpenAI › Demo: chat with your PDF (Azure OpenAI + AI Search)

  1. Azure OpenAI resource (paid; delete when done).
  2. Deploy gpt-35-turbo from base models with default settings.
  3. Supporting resources: Blob Storage account (LRS, standard; enable CORS) for the PDF, and Azure AI Search (cannot be Free tier here, the most expensive part; delete afterward).
  4. Add data source: upload the PDF, pick the storage and search resources, name the index, set chunk size and API-key auth, save, wait for ingestion.
  5. Chat Playground: answers come with references to where in the PDF they were found. View Code shows the Python behind it, and the app can be deployed into your own apps.
