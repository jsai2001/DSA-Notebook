4. Natural Language Generation Hugging Face Transformers

Hugging Face Transformers › 4. Natural Language Generation

NLG produces text that is meant to be indistinguishable from human writing, from a phrase to several paragraphs. It uses the transformer decoder stack (GPT, BART, T5). Use cases: content creation, chatbots and voice bots, translation, personalized emails, text reports from structured data, product descriptions. Three tasks below: content generation, conversation, translation.
