Installing SAM and creating a project AWS Lambda

AWS Lambda › 10. Infrastructure as Code and AWS SAM › Installing SAM and creating a project

Prerequisites: an AWS account with an IAM admin user (access key and secret), the AWS CLI configured with aws configure, and Docker (SAM Local needs it running). Install the SAM CLI per operating system (MSI or package manager on Windows, Homebrew on macOS, package manager on Linux).

Create a project with sam init: pick AWS Quick Start Templates, the Hello World Example, a runtime (Node.js 18 or Python), package type Zip, language or dependency manager (pip for Python), X-Ray tracing No, Application Insights No, and a project name (sam-first-project). Key files: README.md (setup, testing and deployment), template.yaml (resources), the function folder (hello-world/app.js, or hello_world/app.py plus requirements.txt for Python).
