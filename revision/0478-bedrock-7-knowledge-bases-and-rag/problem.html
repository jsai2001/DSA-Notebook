Amazon Bedrock › 7. Knowledge Bases and RAG

A knowledge base is a vector store that grounds responses on your own corpus, restricting the model to your information (eliminating hallucination from outside data).

Workflow:

StepWhat happens
1. Source dataRaw text (for example transcripts made with Whisper CPP)
2. Upload to S3Store raw text in a bucket
3. Sync to vector storeBedrock creates embeddings automatically
4. RAG queryRelevant chunks are retrieved for the question
5. Synthesized responseLLM answers grounded in retrieved data

Re-sync whenever new data lands in S3 to keep the store current.

Create it: Builder Tools > Knowledge Bases > Create, choose data source (S3), Bedrock builds the vector store and embeddings, select a query model (for example Claude 3 Sonnet), test in the built-in interface.

Query modeReturnsUse
Search only (Generate responses OFF)Raw matching chunksVerify data, debug retrieval
Generate responses (ON)Synthesized answerProduction, user-facing (full RAG)

Configuration options: data manipulation, guardrails, query modification, prompt editing, model selection (Sonnet, Haiku, and so on).
