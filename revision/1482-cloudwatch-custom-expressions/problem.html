Custom expressions AWS CloudWatch

AWS CloudWatch › 9. Metric Math › Custom expressions

Choose Add math > Start with an empty expression, with M1 = Errors, M2 = Invocations, M3 = Duration for the Lambda function.

  • M3 / M2 is average duration per invocation in milliseconds.
  • (M1 / M2) * 100 is the error rate percentage (33% for one failure in three, 100% when every request fails). Name it "Error Rate" (ID E1).
  • IF(E1 >= 25, E1, 0) shows only error rates of 25% or more and sets the rest to 0. IF must be upper case. Raise the threshold (for example to 75) for a stricter filter.

Untick the other metrics to see only the expression result.
