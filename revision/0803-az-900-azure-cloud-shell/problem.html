Azure Cloud Shell AZ-900

AZ-900 › 11. Managing and deploying resources › Azure Cloud Shell

Browser-based PowerShell and Bash with no install. Reach it from the portal, Azure docs ("Try It") and the Azure Mobile App, on any browser, Android, iOS or tablet. It switches between PowerShell and Bash, includes a built-in editor, supports file upload/download, and uses a storage account to persist sessions (installed modules and extensions follow you across devices). It is already authenticated.
