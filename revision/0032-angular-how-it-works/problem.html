Angular › 11. Dependency Injection › How it works

  • Angular keeps an injector: a collection of key-value pairs, each key a unique token.
  • For constructor(private api: ApiService), the type annotation is the token. Angular looks it up in the injector and injects the instance.
  • What can be injected: services (most common), strings, booleans, object literals, anything with a provider.
