Terraform › 8. Advanced Terraform › Scale, policy and integration

Q. How do you handle large-scale infrastructure? Modules, split state, parallel runs and -target.

Q. What is Terraform Sentinel? Policy-as-code for Terraform Cloud that blocks non-compliant applies.

Q. How do you integrate Terraform with Ansible or Chef? Terraform provisions and Ansible configures. Pass outputs such as IPs between them.

Q. How do Terraform and Ansible differ when managing AWS resources through Python? Terraform is declarative (desired state) and Ansible is procedural (steps). Terraform provisions (for example EC2 instances) and Ansible configures (installing software). Terraform keeps a state file and Ansible is stateless. Python drives Terraform through python-terraform or subprocess, and Ansible through its Python API or custom modules.
