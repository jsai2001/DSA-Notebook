Agentic AI Fundamentals › 3. Perception, Feedback and Agent Communication › Agent coordination

Coordination is the set of strategies and processes that manage interactions between many agents. Doorbell camera example: Agent 1 monitors the video feed, Agent 2 spots objects that need identification, Agent 3 decides what object is seen.

Agentic AI architecture has two components: internal processing (inside each agent) and communication and coordination (how agents talk and work together).
