IAM role for the agent AWS CloudWatch

AWS CloudWatch › 8. CloudWatch Agent › IAM role for the agent

Create a role (for example AgentDemo) and attach it to the instance (EC2 > Instances > Actions > Security > Modify IAM role):

  • CloudWatchFullAccess to send data.
  • EC2FullAccess (or AmazonEC2FullAccess) to read instance metadata for EC2 dimensions.
  • AmazonSSMFullAccess to store the configuration in SSM Parameter Store.

In production use fine-grained permissions instead of full access (CloudWatchAgentServerPolicy is the scoped option).
