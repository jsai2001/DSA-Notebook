Outputs AWS CloudFormation

AWS CloudFormation › 4. Parameters, Outputs and Intrinsic Functions › Outputs

Some values, such as an IP address or ARN, are only known once the resource is built. The Outputs section surfaces them in the console, and a stack can have several. A classic output is a load balancer's domain name, so users can go straight to the new website.

After the stack completes, the Outputs tab shows them.
