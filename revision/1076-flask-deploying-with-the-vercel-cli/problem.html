Deploying with the Vercel CLI Flask

Flask › 8. Deployment to Vercel › Deploying with the Vercel CLI

Prompts: set up and deploy: Yes; scope: your account; link to existing project: No; project name: flask-health-tracker-project.

  1. The app shows a server error until storage is connected.
  2. Vercel dashboard -> project -> Storage -> Create Database -> Postgres (first database is free) -> Connect it to the project. Connecting auto-populates POSTGRES_URL and related variables.
  3. Settings -> Environment Variables: POSTGRES_URL is auto-populated; add SECRET_KEY manually with your own unique value.
  4. Run vercel again so the variables take effect, then test the preview URL (submit the form, check the dashboard). The Postgres DB starts empty; no local SQLite data carries over.
  5. Promote once the preview works:

Flow: vercel login -> vercel (preview) -> create and connect Postgres -> add SECRET_KEY -> vercel (redeploy) -> test -> vercel --prod.
