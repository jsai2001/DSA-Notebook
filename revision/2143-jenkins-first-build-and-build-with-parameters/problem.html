Jenkins › 4. Parameters, Conditions and Approvals › First build and Build with Parameters

Parameters change the Jenkins interface only after one build registers them. The first build uses Build Now and may fail if defaults are invalid or blank. Refresh the job page and Build with Parameters then appears. Any later change to the parameters also needs one build to take effect. If parameters do not show up, run the pipeline once and refresh.

Q. How do you configure parameterised builds (String, Choice, Boolean, Git Parameter)? Declare a parameters block; values are supplied at build time and read via params.NAME. The Git Parameter plugin adds a gitParameter type for choosing branches or tags.
