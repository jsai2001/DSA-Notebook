Custom domain Google Cloud (GCP)

Google Cloud (GCP) › 3. App Engine: Hello World, Domains, HTTPS › Custom domain

  • Default URL is a subdomain of appspot.com. Set up under App Engine, Settings, Custom Domains: link an existing domain or register a new one.
  • Verify an existing domain: pick the registrar, copy the TXT record into the domain's DNS, then Verify. DNS propagation can take minutes, and the TXT value does not change, so retrying is safe.
  • Then select the verified domain, map the domain and www subdomain, save, and add the DNS records Google lists.
  • Google then provisions a managed, auto-renewing SSL certificate automatically (about 15 minutes), so HTTPS works with no extra setup.
