AWS CloudWatch › 9. Metric Math › What it is

Metric Math runs calculations across multiple metrics in real time and produces new time series. Path: Metrics > All metrics > select metrics > Graph metrics tab > Add math. Each metric has an ID (M1, M2) and each expression has an ID (E1) that other expressions can reference. If no data shows, widen the timeframe (for example 4 weeks).
