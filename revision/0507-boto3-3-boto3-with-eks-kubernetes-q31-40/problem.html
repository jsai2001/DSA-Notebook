Boto3 › 3. boto3 with EKS / Kubernetes (Q31-40)

Q37. Retrieve EKS logs from CloudWatch. Use the logs client against the log group /aws/eks/<cluster>/cluster; times are epoch milliseconds.

Q38. Configure autoscaling for EKS. Same update_nodegroup_config call as Q33, with minSize/maxSize set to the autoscaling bounds and desiredSize set to the minimum: configure_eks_autoscaling(cluster, nodegroup, 2, 5). The autoscaling client can also tune the underlying Auto Scaling group. This call only sets bounds; actual scale-out needs the Cluster Autoscaler (see Q78).

Q39. Delete an EKS cluster and its resources. Delete node groups first, wait, then delete the cluster.

Q40. Manage EKS add-ons (VPC-CNI, CoreDNS). create_addon, describe_addon, delete_addon.
