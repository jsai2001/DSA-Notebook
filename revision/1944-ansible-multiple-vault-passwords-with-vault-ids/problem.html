Q. Manage multiple vault passwords?

  • --vault-id dev@prompt: dev is a user-defined label and prompt means the password is typed in.
  • --vault-id dev@dev_pass.txt: Ansible reads the password for the dev label from dev_pass.txt.

Different environments can use different IDs (dev@prompt, prod@prod_pass.txt), and several --vault-id flags can be passed in one run. A password file holds the plaintext password, so restrict it (chmod 600 dev_pass.txt) or use a secrets manager.
