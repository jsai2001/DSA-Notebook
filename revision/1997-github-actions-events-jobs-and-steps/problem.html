Events, jobs and steps GitHub Actions

GitHub Actions › 1. CI/CD and GitHub Actions basics › Events, jobs and steps

Q. What is an event, and what are common examples? An event triggers a workflow. Common ones: push (code push), pull_request (PR activity), schedule (cron-based) and workflow_dispatch (manual).

Q. What is the difference between a job and a step? A job is a group of steps that run on one runner. A step is an individual task (checkout, run a script) inside a job. Jobs can run in parallel by default; steps run sequentially.
