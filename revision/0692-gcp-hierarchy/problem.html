Google Cloud (GCP) › 4. App Engine Components, Versions, Traffic Splitting › Hierarchy

  • A Google Cloud project can have only one App Engine application.
  • App Engine application, then Services (multiple), then Versions (multiple per service), then Instances (multiple per version).
ComponentPurpose
ServiceActs like a microservice (user API, batch processing, admin panel)
VersionA deployment of a service (v1 main, v2 bug fixes, v3/v4 A/B tests)
InstanceUnit of capacity; scales up/down automatically or manually
