Monitoring and troubleshooting Jenkins

Jenkins › 11. Administration, Monitoring and JCasC › Monitoring and troubleshooting

Q. How do you monitor controller health, CPU, memory and thread dumps? Use the Monitoring (JavaMelody) plugin for CPU, heap and threads, the built-in System Information and Load Statistics, and take thread dumps at /threadDump (or via the CLI) to diagnose hangs. Watch JVM heap, GC, executor queue length and disk.

Q. How do you integrate Jenkins metrics with Prometheus and Grafana? Install the Prometheus metrics plugin, which exposes /prometheus for scraping. Grafana dashboards then show queue length, build durations, executor utilization, node health and JVM stats. Add alerts for queue backlog or controller memory.

Q. How do you troubleshoot a hung or deadlocked Jenkins, or heavy GC pauses? Capture thread dumps (/threadDump) to find blocked or deadlocked threads and heavy operations; capture a heap dump and enable GC logging to spot memory pressure. Common fixes: raise heap (-Xmx), tune GC (for example G1), reduce plugins and executors, move builds off the controller, add build discarders and split load across agents.
