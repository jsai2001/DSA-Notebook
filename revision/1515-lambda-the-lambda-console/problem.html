AWS Lambda › 2. Console, programming model and triggers › The Lambda console

Sign in with an IAM admin user (not root). Lambda is region-specific: functions are isolated by region and account, so check the region first when a function seems missing. The account default concurrency limit is 1,000 concurrent executions (can be raised), and account-level metrics sit on the dashboard.

A function page shows:

  • Layers: manage dependencies.
  • Triggers: events that invoke the function (for example API Gateway).
  • ARN: the unique identifier, for example arn:aws:lambda:eu-west-1:123456789012:function:helloWorld.
  • Code tab: source code (the helloWorld function returns status 200 and "Hello from Lambda!" to an API Gateway trigger).
  • Configuration tab: memory (affects performance and cost), triggers, permissions. The default role only allows CloudWatch Logs access.
  • Monitoring tab: metrics, logs and traces.
  • Test tab: run the function directly with a test event.

Functions start with minimal permissions, so add only what is needed.
