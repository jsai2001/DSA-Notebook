VPC, subnets and route tables AWS

AWS › 4. Networking › VPC, subnets and route tables

Q. What is a VPC and how do you set one up? A private cloud network. Set a CIDR (for example 10.0.0.0/16), subnets, an Internet Gateway and route tables.

Q. Public vs. private subnet?

  • Public: routes to the Internet Gateway. Web-facing.
  • Private: no direct internet. Backend.

Q. What is a route table in a VPC? It directs traffic. For example, 0.0.0.0/0 to the Internet Gateway for public subnets.
