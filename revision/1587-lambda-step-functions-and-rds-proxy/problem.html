Step Functions and RDS Proxy AWS Lambda

AWS Lambda › 8. Storage, state and integrations › Step Functions and RDS Proxy

Q74. How does Step Functions orchestrate stateful workflows with Lambda? Step Functions is a managed state machine that coordinates several Lambdas (and other services) with sequencing, branching (Choice), parallelism (Map/Parallel), retries, error handling and wait states. The workflow state is external, so each Lambda stays stateless and short. It suits long-running, multi-step processes.

Q75. What is the max payload Step Functions passes between Lambda tasks? 256 KB per state transition. For larger data pass a reference (for example an S3 key) and have the Lambdas read and write the real payload in S3.

Q76. How do you manage DB connection pooling with RDS Proxy and Lambda? Lambda's rapid scaling can exhaust database connections. RDS Proxy sits between Lambda and RDS or Aurora, keeps a warm pool and multiplexes many Lambda connections onto fewer DB connections. Lambda connects to the proxy endpoint (IAM auth supported), which smooths spikes and improves failover. Pair it with reserved concurrency.
