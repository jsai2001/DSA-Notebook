Preloading strategies Angular

Angular › 13. Routing and Navigation › Preloading strategies

Preloading loads lazy modules in the background after the initial page load, giving fast startup and low navigation lag. Set it through preloadingStrategy:

  • NoPreloading (default): everything lazy on demand.
  • PreloadAllModules: loads everything on launch. Fine for small apps, slow launch with many modules.
  • Custom class implementing PreloadingStrategy with a public preload(route, fn) method returning an Observable. Call fn() to preload, return of(null) to skip.

Bracket access route.data['preload'] is required by Angular's type definition. Mark routes with data: { preload: true } as in the route table above.

Network result with that setup: first load fetches main.js and the current page module (players), and preloads messages in the background. leaderboards has no flag, so it is fetched only when visited. Navigating to messages causes no request.
