Q. What is Terraform, and how does it differ from Ansible or CloudFormation? Terraform is a declarative IaC tool that provisions infrastructure across clouds. Ansible is procedural and excels at configuration management. CloudFormation is AWS-only and uses JSON/YAML, which is less readable than Terraform's HCL.

Q. What is Infrastructure as Code (IaC), and why is it important? IaC is managing and provisioning infrastructure through machine-readable definition files instead of manual processes. It gives consistency, scalability, automation and version control. Terraform is declarative, uses HCL, supports many cloud providers and keeps a state file so operations are idempotent. Ansible is procedural, uses YAML playbooks, is agentless (SSH) and excels at configuration management and application deployment. Terraform focuses on provisioning, Ansible on configuration.

Q. What are the key components of Terraform?

  • Providers: bridges to cloud APIs.
  • Resources: the infrastructure pieces.
  • Modules: reusable configs.
  • State: tracks reality.
  • Variables: inputs.
  • Outputs: results.
