Command summary and typical workflow AWS CloudWatch

AWS CloudWatch › 6. Logs Insights › Command summary and typical workflow

  • fields @message selects fields; filter @message like /keyword/ filters; stats count(*) as error_count aggregates; by bin(5m) groups by time.
  • Other aggregations to explore: sum, avg, max, min.
  • Scenario: a bug throws a validation exception because an ID parameter is missing. Filter on exception, read the stack trace for the source, then aggregate by bin(5m) to see frequency.
