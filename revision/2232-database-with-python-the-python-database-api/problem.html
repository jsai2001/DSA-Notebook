Database with Python › 1. Databases and the Python Database API › The Python Database API

A common specification that database modules follow, so code is portable between database systems and easy to learn across modules. Two objects matter:

  • Connection object: returned by the module's connect function. It closes the connection, commits pending transactions and rolls back to the start of the pending transaction (if supported). A transaction is a set of all-or-nothing changes.
  • Cursor object: obtained from the connection. It executes commands and fetches data with fetchone() (one row), fetchmany() (several rows) and fetchall() (all rows).
  • Modules also provide constructors for special values so types are detected and bound correctly when passed to cursor methods.
