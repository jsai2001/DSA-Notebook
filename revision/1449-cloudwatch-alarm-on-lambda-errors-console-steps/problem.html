Alarm on Lambda errors: console steps AWS CloudWatch

AWS CloudWatch › 11. Alarms › Alarm on Lambda errors: console steps

  1. Generate baseline requests (for example 100, one failure in three, about 33 failures a minute).
  2. CloudWatch > Alarms > All alarms > Create alarm.
  3. Select metric: Lambda > By Function Name > the function (for example putitemFunction) > Errors.
  4. Change the statistic from Average to Sum, and the period to 1 minute for faster triggering.
  5. Choose a Static threshold (over Anomaly Detection): errors greater than 20 in 1 minute. The API sends about one request a second, so roughly 20 failures a minute is the failure rate.
  6. Notification: create an SNS topic (for example apiadmins) with comma-separated email addresses, for both Alarm and OK states.
  7. Name and create the alarm. It starts at Insufficient Data.
  8. Test by ticking "Fail all requests". The state moves Insufficient Data to OK to Alarm and each change sends a notification. When the issue is fixed it returns to OK.
