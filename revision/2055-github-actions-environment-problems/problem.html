GitHub Actions › 10. Scenario questions › Environment problems

Q. A workflow fails because a tool version is missing. How do you handle it? Install the tool, use a custom container or use a self-hosted runner.

Q. Test results are inconsistent across runners. How do you fix it? Pin versions, use the same runner and control test randomness.

Q. A legacy app needs a custom build environment. How do you address it? Use a custom Docker image or a self-hosted runner.
