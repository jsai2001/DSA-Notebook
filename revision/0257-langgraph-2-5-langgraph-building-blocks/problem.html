LangGraph (LangChain ecosystem) is a workflow orchestration engine for stateful multi-agent apps: it manages agent interactions and state, integrates LLMs, tools and third-party apps, and streams intermediate results.

  • Nodes: LLM node (analyzes prompt, creates actions), tool node (runs function tools), action node (invokes other agents), logic node (custom code).
  • Edges: basic (sequential) and conditional (routes on a check). Start and End blocks mark entry and exit.
  • Agent state: shared structure nodes read and write. Data moves through state, not through edges.
