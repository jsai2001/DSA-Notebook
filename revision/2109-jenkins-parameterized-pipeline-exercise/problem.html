Jenkins › 4. Parameters, Conditions and Approvals › Parameterized pipeline exercise

Requirements: parameters ENVIRONMENT (choice: development, staging, production), API_KEY (password, default 123ABC) and CHANGELOG (text); stages Test, Deploy and Report; Deploy runs only for production; Report writes the changelog to a file named after the environment and archives it. Use the Declarative Directive Generator for the parameter snippets. The choices must be separate strings in a list (['development', 'staging', 'production']), not one string.

Testing: with development, Deploy is skipped and development.txt holds the changelog; with production, Deploy runs and production.txt holds it. The API key shows as dots in the UI.
