AWS CloudWatch › 14. CloudWatch RUM › Wiring RUM into a Vue app

The demo app is Vue.js with TypeScript (CloudwatchRum).

Paste the SDK code from the app monitor into registerRum.ts:

Open http://localhost:8080. The demo sends a configurable number of requests (for example 100) to a public JSON placeholder API and every third one fails and throws. Data appears on the app monitor Overview after about 5 minutes. If it does not, open the browser Network console, check the requests to the app monitor, and read the Preview tab for errors. Uncaught runtime errors in the Vue dev server are normal and do not stop RUM collection.
