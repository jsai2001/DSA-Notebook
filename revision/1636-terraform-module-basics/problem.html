Terraform › 4. Modules › Module basics

Q. What is a Terraform module? A reusable bundle of configuration that simplifies and standardizes infrastructure.

Q. How do you create a reusable module? Make a directory with main.tf, variables.tf and outputs.tf, and parameterize it.

Q. What is the difference between a root and a child module? The root module is the main directory where commands run. A child module is a called submodule that can be reused.
