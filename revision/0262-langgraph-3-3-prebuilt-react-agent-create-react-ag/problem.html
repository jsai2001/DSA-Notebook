agent_graph is a compiled LangGraph graph. Input is a dict with a messages list; the last message is the answer, and printing all messages gives the trace.

Trace: HumanMessage → AIMessage (tool choice and arguments) → ToolMessage (result) → AIMessage (final answer). A compound question ("What is 3 multipled by 2 and 5 + 1 ?") triggers find_product(3, 2) and find_sum(5, 1).

Debugging: debug=True prints graph state per step, message IDs, LLM decisions, token usage and tool inputs/outputs.
