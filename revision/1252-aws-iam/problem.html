AWS › 6. Security and Identity › IAM

Q. What is AWS IAM and how do permissions work? It controls access. Users, roles and policies define the allowed actions.

Q. IAM policies, roles and users?

  • Policies: JSON rules.
  • Users: individual identities.
  • Roles: temporary access for services.

Q. How do you apply least privilege? Limit permissions to the essentials with specific policies, and review them with Access Analyzer.

Q. How does MFA work in AWS? It adds a second factor. Enable it in IAM and scan the QR code in an authenticator app.
