3.7 Agents RAG with LlamaIndex

RAG with LlamaIndex › 3. LlamaIndex Fundamentals › 3.7 Agents

An agent is an LLM-powered entity that decomposes complex queries, selects tools and parameters, plans, and executes. Agentic behavior is essentially a sophisticated prompting strategy plus tool access. ReAct (Reasoning + Acting) reasons step by step and decides when to call tools.

Tool docstrings matter: the agent reads them (and the type signature) to decide when and how to call the tool.

Different LLMs differ in tool use. In the demo Command-R beat Command-R+ here, so test multiple models.
