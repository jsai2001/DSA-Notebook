The full lesson script repeats this on a page with Enable/Disable, Remove/Add buttons and a checkbox, using find_element for static elements, wait.until for elements that reappear after loading, and sleep(3) between steps to watch the result. wait.until(...) proceeds as soon as the condition is true, so it can finish well before the timeout. sleep(10) always costs 10 seconds.

Syntax: wait.until(condition((locator_strategy, 'locator_value'))). Note the locator is a tuple.
