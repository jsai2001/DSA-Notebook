Reading traces AWS CloudWatch

AWS CloudWatch › 13. X-Ray Tracing › Reading traces

Traces tab: filter by trace ID, by node (service id name: "Scorekeep", type: client), or click a node in the service map > View traces. Adjust the time range (for example last 15 minutes). Open a trace (for example a POST):

  • the trace map shows the flow, such as Client to ECS container to DynamoDB game and session tables,
  • the timeline shows how long each step took and where requests slow down or fail.
