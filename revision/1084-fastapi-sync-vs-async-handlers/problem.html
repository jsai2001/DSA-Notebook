FastAPI › 3. Handlers, Running the Server, Sync vs Async › Sync vs async handlers

FastAPI uses asyncio for I/O-bound concurrency. asyncio runs on a single thread, so a blocking call inside an async handler blocks every request.

Handler (10 concurrent requests)Total timeWhy
sync + sleep~1 sthread pool
async + sleep (bad)~10 sevent loop blocked, serialized
async + asyncio.sleep~1 snon-blocking

Recommendation: start with sync handlers; move to async only for performance reasons. A third-party library deep in the call chain may block without you knowing.
