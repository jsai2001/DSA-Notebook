Q. How do you authenticate a Python script to a Kubernetes cluster's API?

  • Kubeconfig file: config.load_kube_config() reads ~/.kube/config.
  • In-cluster config: inside a Pod, use config.load_incluster_config() with a service account token.
  • Manual token: provide a bearer token and cluster URL explicitly.
  • Certificates: use client certificates.
