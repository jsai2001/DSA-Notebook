Jenkins › 10. Artifacts, Fingerprints and Test Reports › Python pipeline with tests and coverage

A five-stage Python pipeline: Setup (install dependencies), Lint (syntax), Test (JUnit report plus Cobertura coverage), Build and Deploy. The server needs Python 3 and python3-venv (Ubuntu), Git, and the JUnit and Code Coverage API plugins. Verify with python3 --version and python3 -m venv test && . test/bin/activate.

On Windows install Python and Git manually and fix the Python and pip paths in the Jenkinsfile. Set the branch specifier to main and the script path to the Jenkinsfile location when using the exercise repo.

Viewing reports: test results appear as a trend graph on the project page, and the Test Results link shows passes, failures and skips with package drill-down. Coverage shows a trend graph, a Coverage Report overview and package details, and a File Coverage tab with line-by-line source.
