Deleting a stack AWS CloudFormation

AWS CloudFormation › 6. Creating, Updating and Deleting Stacks › Deleting a stack

Stacks, select the stack, Delete, confirm. Status moves from DELETE_IN_PROGRESS to DELETE_COMPLETE. This tears down all the resources the template created, in dependency order. The web server template deletes the EC2 instance first and the security group after it. Deleted stacks disappear from the console and their data is no longer accessible. Together with create and update this completes the lifecycle.
