1. What GraphQL Is and Why GraphQL

GraphQL › 1. What GraphQL Is and Why

  • GraphQL is a query language for APIs. It is not a database, and it is not a client. It acts as a server-side layer that sits in front of data sources.
  • Created at Meta (Facebook) because REST could not handle deep queries (4-5 levels deep in a friend network). GraphQL handles any depth across multiple databases.
  • Ecosystem: Facebook's reference implementation, Apollo, Relay.
BenefitMeaning
Precise fetchingClient asks for exactly the fields it wants, so there is no over-fetching
Type checkingThe schema describes and enforces types (like TypeScript)
Multiple data sourcesOne request can pull from several databases
Single entry pointAll input is validated by the schema before it reaches the database

Type safety example: sending a Boolean for a String field (name: true) is rejected by GraphQL, and the database is never reached.

Tooling: VS Code with a GraphQL extension (general GraphQL, Apollo GraphQL, or Relay variants); WebStorm has built-in support.
