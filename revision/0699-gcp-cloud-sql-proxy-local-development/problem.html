Google Cloud (GCP) › 5. Cloud SQL and Service Accounts › Cloud SQL Proxy (local development)

  • Locally, the App Engine service account does not apply. The Cloud SQL Proxy authenticates with a valid account and exposes the DB on localhost:3306.
  • Prerequisites: Cloud SQL instance, an account with permissions above Cloud SQL Viewer, a MySQL client, Cloud SQL Admin API enabled, and the right account active in gcloud (gcloud auth list, see Section 2).
  • Best practice: use different databases for production and development.

Final app.js. When DB_HOST is set (local, via proxy) it uses TCP, otherwise the Unix socket (deployed). The earlier socket-only version is the same file without createTcpPool/createPool, calling createUnixSocketPool directly.
