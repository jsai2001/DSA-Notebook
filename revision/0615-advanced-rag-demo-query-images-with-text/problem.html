Advanced RAG › 10. Multimodal RAG › Demo: query images with text

Query an image DB with text. Helpers resize base64 images for the OpenAI call and split retrieved docs into images vs text.

Multimodal chain:

How it works: (1) CLIP's text encoder embeds the query; (2) FAISS finds the nearest image embeddings (same space); (3) images are resized and base64-formatted; (4) GPT-4o mini describes them; (5) RunnableLambda replaces RunnablePassthrough because a function (splitting images/text) must run, not just pass a string through.
