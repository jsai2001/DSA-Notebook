Q. Fetch files with fetch? fetch pulls files from the remote host to the control node, the opposite of copy.

  • src is the file on the remote host.
  • dest is the path on the control node; {{ inventory_hostname }} keeps files from different hosts from overwriting each other (/local/logs/dev-web1.log, /local/logs/prod-web1.log).
  • flat: yes saves directly to dest. Without it, the remote path is mirrored (for example /local/logs/dev-web1/var/log/app.log).

Typical uses are collecting logs for debugging or auditing, backing up configuration files, and centralizing files from many hosts.
