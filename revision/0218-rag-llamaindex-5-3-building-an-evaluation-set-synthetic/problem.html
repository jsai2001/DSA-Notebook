The hard part of RAG evaluation is a high-quality evaluation dataset, not the metrics. Pipeline: sample documents per author → chunk → LLM writes a question per chunk → LLM answers from the chunk → critic LLM scores question groundedness → filter → publish.

OpenAI is used here because Cohere's free tier is rate-limited (the dataset is published, so rerunning is optional).

The helpers behind that (helpers/utils.py): group_documents_by_author builds a defaultdict(list) keyed by doc.metadata['author'] (warns and skips docs with no author). sample_documents keeps only docs longer than 500 characters, then random.samples num_samples per author (warns if an author has too few).

Prompts (helpers/prompts.py): the question prompt asks for a short, first-person, search-engine-style question answerable from the context; the answer prompt answers in second person using only the context.
