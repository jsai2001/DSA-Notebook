Network configuration and ports Linux

Linux › 4. Networking and Security › Network configuration and ports

Q. How do you check network config? ip addr (modern, shows IPs) or ifconfig (older, IPs and MAC).

Q. What are netstat and ss for? netstat -tuln lists ports and connections. ss -tuln is the faster, modern alternative.

Q. How do you set a static IP? Edit /etc/netplan on Ubuntu (addresses: [192.168.1.100/24]) or /etc/sysconfig/network-scripts on CentOS, then apply with netplan apply.
