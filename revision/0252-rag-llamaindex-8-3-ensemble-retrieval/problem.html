8.3 Ensemble retrieval RAG with LlamaIndex

RAG with LlamaIndex › 8. Modular RAG › 8.3 Ensemble retrieval

Try several retrieval strategies at once (here: four chunk sizes), merge their results, and rerank. Steps: build a vector index per strategy → wrap each retriever in an IndexNode → put the index nodes in a SummaryIndex (simple list-based structure) → a RecursiveRetriever fans the query out to every retriever → rerank the combined nodes.

(The index node text still says "Llama 2 paper" because the notebook is adapted from the LlamaIndex docs; the wording is only a label.)

Reranking also tells you which strategy matters: compute the reciprocal rank of the first node from each chunk size in the final ranking. Higher MRR means that chunk size tends to rank earlier, i.e., more relevant. In the demo, chunk size 128 ranked highest.
