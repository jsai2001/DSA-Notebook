Deploying a SAM project AWS Lambda

AWS Lambda › 10. Infrastructure as Code and AWS SAM › Deploying a SAM project

Run sam build, then sam deploy --guided for a new project. Answers used: stack name sam-first-project, region eu-west-1, confirm changes before deploy No, allow SAM to create IAM roles Yes, disable rollback No, and accept open APIs (learning only). The settings are saved in samconfig.toml, so later deploys are just sam deploy. SAM creates an S3 bucket for function code, transforms the template to CloudFormation and deploys through CloudFormation, so you can watch events, resources and outputs in the CloudFormation console.

Production APIs should add authentication (Cognito or Lambda authorizers). Test the deployed endpoint in the Lambda console (the API Gateway trigger shows the URL) or in Postman; repeated GETs return random rolls such as {"message": 4}.
