Q. How is template different from copy? template renders a Jinja2 file with variables, loops and conditionals; copy transfers a static file as-is.

Aspectcopytemplate
File contentStatic, copied as-isDynamic, processed as Jinja2
Use caseScripts, binaries, static configConfigs that vary by host or environment
Source fileAny fileJinja2 template (.j2 by convention)
FlexibilityNo dynamic contentVariable substitution, loops, conditionals

Variables can be used in the src and dest paths of both modules, but only template processes variables inside the file content.
