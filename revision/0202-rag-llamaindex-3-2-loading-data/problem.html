3.2 Loading Data RAG with LlamaIndex

RAG with LlamaIndex › 3. LlamaIndex Fundamentals › 3.2 Loading Data

Ingestion has three stages: Load (Reader → Documents) → Transform (Documents → Nodes: chunking, metadata, embeddings) → Index & store (vector DB). It resembles ETL / ML data cleaning.

A Reader (data connector) formats data into Document objects (text + metadata + id + embedding slot). SimpleDirectoryReader reads markdown, PDF, Word, PowerPoint, images, audio, video; one Document per page for PDFs.

Nodes are chunks of documents and the first-class citizen in LlamaIndex (Document is a subclass of Node). A node holds text, metadata, relationships to other nodes, and a link to its source document. Node parsers turn documents into nodes.

Node relationships link chunks sequentially (NEXT/PREVIOUS) or hierarchically (PARENT/CHILD). Useful for books with chapters, legal docs with clauses.
