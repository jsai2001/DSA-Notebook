LangChain Level Up › 1. Overview, Prerequisites & Setup

Why RAG? LLMs generate text and answer questions but often lack current and specific knowledge, which gives inaccurate outputs. RAG (Retrieval-Augmented Generation) connects the LLM to external data sources. Course arc: LangChain basics → similarity search/RAG → Streamlit UI → multi-source Q&A agent → MongoDB Atlas Vector Search → NoSQL (MongoDB) interaction → LangServe REST API → cloud deployment.

Prerequisites: Python 3.10+ (syntax, control flow), CLI/venv/pip, 1–2 years of web development, VS Code, an OpenAI account with credits.

PackagePurpose

OpenAI API key: platform.openai.com → Project API Keys → Create new secret key (copy immediately; it is shown once). Put it in a .env file at the project root.

OpenAI() / ChatOpenAI() read OPENAI_API_KEY from the environment automatically once load_dotenv() has run.
