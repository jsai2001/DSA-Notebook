Initialized tensors

torch.empty returns whatever was in memory (garbage values), not zeros.

Random tensors (all accept dtype and device):

FunctionDistributionValues

torch.randn()NormalFloat, mean 0, std 1

Tensor with another tensor's properties:

Attributes (accessed without parentheses):

A 2-D tensor such as torch.tensor([[1, 2, 3], [4, 5, 6]]) gives shape = torch.Size([2, 3]), ndim = 2 (same attributes, same defaults).

AttributeMeaning
.deviceWhere the tensor lives (cpu/cuda)
.dtypeElement type
.shapeSize of each dimension (torch.Size)
.ndimRank: scalar 0, vector 1, matrix 2
.requires_gradWhether autograd tracks it

Data types

Casting (two ways: named function like .float(), .int(), .double(), or .to(dtype=...)):

Automatic casting: when operands have different dtypes, PyTorch casts to the larger type. Larger types use more memory and give more precision; smaller types use less memory and lose precision. This trade-off matters in DL.
