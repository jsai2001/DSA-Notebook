Update a planet (PUT, JWT-protected) RESTful API

RESTful API › 6. CRUD Endpoints › Update a planet (PUT, JWT-protected)

Read planet_id from the form, find the row, assign new attribute values, commit. No add() is needed because the object is already tracked by the session. Success returns 202, a missing planet returns 404.

  • PUT is the standard update verb, but some teams use POST. Supporting both is an option.
  • A typo in a form key (home_start vs home_star) causes an error.
  • An expired token returns Token has expired. Log in again via /login.
