Model Context Protocol › 4. Using MCP Servers in Claude Desktop › Multiple servers, mixed languages, env vars

Each server is a uniquely named object inside mcpServers, separated by commas.

  • command is the executable: uvx (Python package runner), npx (Node package runner), or any executable.
  • args: for npx, -y auto-confirms, then the package name, then (for filesystem) the allowed directories.
  • env passes environment variables such as API keys. Generic form: "env": {"API_KEY": "...", "BASE_URL": "..."}.
  • The same JSON structure works across languages, clients, and operating systems, so configs are portable between clients.

Official reference servers: fetch (Python), filesystem, github, slack, google-maps, postgres (TypeScript). Repo: github.com/modelcontextprotocol/servers.
