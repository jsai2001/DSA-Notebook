Nginx on EC2 with CentOS 7 Terraform

Terraform › 16. Hands-On: Complete Stacks › Nginx on EC2 with CentOS 7

The network resources are identical to the Ubuntu stack. Only the AMI and user data change.

  • AMI: ami-0b2c7a2f6f2d513d4 is CentOS 7 in us-east-1. Update it for other regions.
  • User data: installs epel-release first because the EPEL repository provides Nginx. On CentOS use yum install -y nginx instead of apt-get.
