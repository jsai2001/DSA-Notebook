An index is a data structure for fast retrieval of relevant context for a query. Indexes build Retrievers, Query Engines, and Chat Engines. Flow: raw text → Document → Nodes → embeddings → vector DB.

An embedding is a fixed-length numeric vector representing the meaning of a text. The length depends on the model, never on the input length.
