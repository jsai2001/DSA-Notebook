Both exercises ran in CoderPad with a MockTensor class standing in for PyTorch (so from mock_tensor import MockTensor as torch). On a real install use import torch. The challenge pages also had show_expected_result / show_hints flags to switch on for help.

Exercise 1: build four tensors. Tasks: tensor from a list, tensor from a NumPy array, 3×4 ones, 4×5 filled with 5. Test inputs and solution (the starter was the same four functions with return 0):

  • torch.tensor() works for lists and NumPy arrays and keeps the input dtype.
  • torch.ones(shape) and torch.full(shape, value) take the shape as a tuple.

Exercise 2: split tensors with chunk and split. Test inputs, then solution:
