Spark SQL and ML Apache Spark

Apache Spark › 2. Spark Capabilities for ETL › Spark SQL and ML

  • Spark SQL: standard-SQL syntax that is translated to distributed operations. Works on batch and streaming. Can sit in the same pipeline, cascade (one output feeds the next), and persist to databases or streams.
  • Spark ML: pre-processing (feature extraction, transformation, dimensionality reduction), popular algorithms, and ML pipelines that chain extraction, pre-processing, training and inference inside the same Spark pipeline.
  • Spark is one integrated platform for data engineering, analytics and ML.
