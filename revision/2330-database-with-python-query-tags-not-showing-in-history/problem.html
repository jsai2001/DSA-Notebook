Q. Query tags set for cost tracking do not appear in query history. How do you debug it? Set the tag with ALTER SESSION SET QUERY_TAG, run the query, check the tag in INFORMATION_SCHEMA.QUERY_HISTORY(), and review session parameters (SHOW PARAMETERS LIKE 'QUERY_TAG'), tag visibility and permissions.
