Architecture Vector Databases

Vector Databases › 4. Milvus: deployment, architecture and setup › Architecture

  • Access layer: gRPC API, port 19530.
  • Coordinator: cluster management.
  • etcd: metadata (schemas, users, indexes).
  • Message queue (RocksMQ default; Kafka/Pulsar): DML.
  • Worker nodes: data processing, index loading, search.
  • MinIO: object store for vector data and logs.

Request flows:

  • DDL (create DB/collection/user/index): client -> access layer -> coordinator -> etcd.
  • DML (insert/update/delete): client -> access layer -> message queue -> worker node -> MinIO.
  • Query/search: client -> access layer -> coordinator (metadata check) -> worker node (load index, search, return).
