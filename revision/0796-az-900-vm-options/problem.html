VM options AZ-900

AZ-900 › 6. Compute and networking › VM options

  • Each VM is a guest on a host server in an Azure data center.
  • Stopping (deallocating) a VM stops billing, and starting it resumes billing.

Availability sets give high availability inside a data center (not the same as availability zones):

ComponentPurpose
Fault domainsA logical physical server rack. Protects against rack failures
Update domainsAzure reboots one update domain at a time and waits for VMs to return before the next

VM Scale Sets (VMSS): automatically scale a group of identical VMs using autoscale, deployed with availability sets for fault tolerance (see Section 3 for the VMSS commands).

Azure Virtual Desktop: desktop virtualization in the cloud. Run apps without local installation. Clients exist for Windows, macOS, iOS, iPadOS, Android and web browsers. Each user gets their own profile.
