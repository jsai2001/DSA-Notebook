Create the GitHub webhook Jenkins

Jenkins › 6. Connecting Jenkins to GitHub › Create the GitHub webhook

  1. Copy the Jenkins server URL (right-click the Jenkins icon, Copy Link Address).
  2. In the repo go to Settings, Webhooks, Add webhook.
  3. Payload URL: the Jenkins URL plus /github-webhook/ (for example http://your-jenkins-server/github-webhook/).
  4. Content type: application/json. Events: Just the push event. Click Add webhook.
  5. GitHub pings Jenkins. A green checkmark means the connection works; if not, edit or recreate the webhook.

To test, edit README.md and commit to main. A new build should start by itself, and its log shows the commit.

Troubleshooting: the Jenkins server must be publicly reachable, the URL must end with /github-webhook/, the first Jenkins build must have succeeded, and the repo URL, branch specifier and webhook settings should be rechecked when nothing triggers.
