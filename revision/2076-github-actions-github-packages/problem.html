GitHub Packages GitHub Actions

GitHub Actions › 8. Integrations: Packages, Pages, Terraform, CodeQL, Dependabot › GitHub Packages

GitHub Packages is a registry for npm, Docker and Maven packages that works with Actions. It authenticates with GITHUB_TOKEN. The registry-url must match the package type (https://npm.pkg.github.com for npm). Use scoped names (@owner/package-name), and note that public packages need a public repo.
