RAG with LlamaIndex › 9. Wrap-up › LlamaIndex evaluation module

Beyond the course's hand-built evaluation set, LlamaIndex has a built-in evaluation module (docs → Advanced Topics → Evaluation) with component-wise evaluation (the query engine without retrieval) and end-to-end evaluation (the whole system, multiple metrics). Metrics are mostly implemented as LLM-as-a-Judge calls.
