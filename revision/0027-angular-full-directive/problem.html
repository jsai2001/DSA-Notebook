Angular › 9. Directives › Full directive

  • @Input receives a value from the parent through binding. Simplest pattern: the property name equals the selector name. Alias form: @Input('customName') public appOnlineStatus: boolean;.
  • ElementRef<T>.nativeElement is the underlying DOM element, injected via the constructor.
  • AfterContentInit guarantees Angular has initialized content before the code runs, so DOM edits are safe.
  • Angular creates one directive instance per element, each with its own ElementRef. Online players get the lightning icon, offline ones do not.
