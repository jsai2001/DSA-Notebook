JUnit reports and code coverage Jenkins

Jenkins › 10. Artifacts, Fingerprints and Test Reports › JUnit reports and code coverage

Testing is central to CI. Many tools emit common formats: JUnit XML for test results (originally Java, now used by most languages) and JaCoCo or Cobertura for code coverage (lines of code executed by tests; higher coverage makes bugs more likely to be found).

  • The JUnit plugin collects reports, publishes graphs and tracks trends.
  • The Code Coverage API plugin collects and publishes JaCoCo, Cobertura and other formats.

Q. How do you publish JUnit results and coverage to the UI? Use junit for test results (trends, and the build goes UNSTABLE on failures) and the coverage plugin (recordCoverage, or publishHTML for HTML reports).
