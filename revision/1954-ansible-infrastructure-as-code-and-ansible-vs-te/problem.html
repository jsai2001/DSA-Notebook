Ansible › 14. Ansible with Python › Infrastructure as Code and Ansible vs Terraform

Q. What is Infrastructure as Code (IaC), and how do Terraform and Ansible support it? IaC manages and provisions infrastructure through machine-readable definition files instead of manual processes, giving automation, consistency and version control.

  • Terraform: a declarative tool using HCL; supports many cloud providers and tracks resources in a state file.
  • Ansible: a procedural tool using YAML playbooks; agentless over SSH, strong at configuration management and application deployment.

Terraform focuses on provisioning and Ansible on configuration.

Q. Key differences between Ansible and Terraform when managing AWS resources?

  • Approach: Terraform is declarative (desired state); Ansible is procedural (steps to reach a state).
  • Focus: Terraform provisions infrastructure (creating EC2 instances); Ansible configures it (installing software on instances).
  • State: Terraform keeps a state file; Ansible is stateless.
  • Python integration: Terraform uses python-terraform or subprocess; Ansible uses the ansible Python API, ansible-runner or custom modules.
