Automate, monitor and govern ML systems serverlessly (managed Kubernetes underneath).

FeatureDescription
ServerlessNo infrastructure to manage
FrameworksKubeflow Pipelines (KFP) or TensorFlow Extended (TFX)
DAG visualizationDirected Acyclic Graph of steps
Template GalleryPre-built templates for common workflows
Custom templatesUpload your own

Pipelines tie together: Feature Store (features for training), Training, Model Registry, Endpoints, Evaluation.

Template Gallery (Vertex AI → Pipelines → Template Gallery): filter by type (e.g., "Pipelines and Vertex AI" is the easiest to run), view the DAG with node inputs/outputs, create a run from the UI or download to customize. Example: LLM Text Generation Evaluation (summarization, Q&A, text generation).
