Common errors seen in the course:

  • creatProduct typo: the resolver name must match the schema name or the mutation does not resolve.
  • Forgetting to add a new resolver to the schema's Mutation/Query type, so GraphQL does not recognize it.
  • Adding a field to type but not to input (or to the model/constructor).
  • Using Widgets.remove() (deprecated) instead of deleteOne.
  • Forgetting { new: true } in findOneAndUpdate, which returns the pre-update document.
  • Not restarting the server or refreshing GraphiQL after schema changes.
  • SQLite sqlite::memory: data and the in-memory productDatabase object are lost on restart.
