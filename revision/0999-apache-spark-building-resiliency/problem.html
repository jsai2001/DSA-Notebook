Building resiliency Apache Spark

Apache Spark › 6. Best Practices › Building resiliency

  • Spark handles failures at task, stage and executor level out of the box.
  • Monitor jobs and clusters and set up alerting for unhandled failures.
  • Use checkpoints on persistent stores (HDFS, S3) for streaming jobs so they resume after a restart.
  • Make input/output stores redundant and persistent, and deploy Spark on a cluster so one node failure does not stop the pipeline. The whole solution must be resilient, not only Spark.
