Q. What is Docker vs a VM?

  • Docker: lightweight containers that share the host OS kernel. Fast.
  • VM: full OS emulation. Heavy and slower.

Q. What are the advantages of Docker over virtualization? Lightweight, fast, efficient, portable, scalable.

Q. What is containerization, Docker's take? The app and its dependencies packaged in one unit. Docker uses namespaces, cgroups and a union file system.

Q. What problem does Docker solve? Consistency across dev, test and prod. No "works on my machine" issues.
