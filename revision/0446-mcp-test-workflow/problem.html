Model Context Protocol › 6. Testing with MCP Inspector and Troubleshooting › Test workflow

  1. Open the URL and click Connect.
  2. Tools tab, List Tools, select a tool (for example get_forecast).
  3. Enter arguments (Latitude 63.4463991, Longitude 10.8127596) and Run Tool.
  4. The History/Tool Result shows the request (tool and arguments) and the response (data from the API). Expected data means success. Ctrl+C exits.

Recommended test order: Inspector, then dynamic invocation, then Claude Desktop, then other clients such as Cursor, with logs monitored throughout.
