Key techniques:

  • Parallel JDBC read via partitionColumn, lowerBound, upperBound, numPartitions, with the filter query wrapped as a subquery in dbtable.
  • The same Kafka topic is written by a batch job (write) and read by a streaming job (readStream).
  • zincrby on a Redis sorted set increments counts atomically.
  • startingOffsets: earliest consumes the topic from the beginning. Section 5 used latest.
