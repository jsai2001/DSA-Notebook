5.7 Assumptions ML Algorithms

ML Algorithms › 5. Linear Regression › 5.7 Assumptions

Linear regression is often used as a baseline, then replaced by something like XGBoost if needed.

AssumptionMeaningIf violated
Linear relationshipStraight-line relation between features and targetLine fits curved data (Anscombe y2); may still be good enough
No multicollinearityFeatures aren't correlatedCorrelated features split weight and ruin interpretation
HomoscedasticityConstant error variance across target valuesMay need better features or another model
No outliersNo extreme pointsOutliers pull the line (Anscombe y3)

Even with violations, the model may be good enough for the business. Judge by whether it saves or makes money.
