Creating and testing a first function AWS Lambda

AWS Lambda › 2. Console, programming model and triggers › Creating and testing a first function

  1. In the Lambda console choose Create function > Author from scratch (other options: blueprint, container image).
  2. Set a name (my-lambda-function), runtime (Node.js 18.x; Python, Java and custom runtimes also work) and architecture (Intel x86_64 or Graviton).
  3. On the Code tab edit the handler and click Deploy to make the change live.
  4. On the Test tab create a test event and run it. No trigger is needed to test.

The result shows the response, the logged event and a REPORT line with duration, billed duration and memory used. Use that data later to tune the function.
