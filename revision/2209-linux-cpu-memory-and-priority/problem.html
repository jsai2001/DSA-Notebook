CPU, memory and priority Linux

Linux › 3. Processes and Resource Management › CPU, memory and priority

Q. How do you check CPU and memory usage? top (live CPU and memory), free -h (memory snapshot), vmstat 1 (detailed stats).

Q. What are nice and renice for? nice -n 10 cmd sets priority at launch (-20 high to 19 low). renice 15 -p PID adjusts a running process.

Q. How does Linux manage memory? Virtual memory maps addresses and paging swaps to disk. free -h shows swap.
