Q. What is CI/CD, and how does it benefit software teams? CI/CD automates code integration, testing and deployment. Benefits: faster feedback, fewer bugs, better collaboration, quicker releases.

Q. What is the difference between Continuous Integration, Continuous Delivery and Continuous Deployment?

  • Continuous Integration: frequent code merges with automated tests.
  • Continuous Delivery: CI plus an automated release, with a manual deploy step.
  • Continuous Deployment: CI plus automated deployment to production.

Q. What are the key components of a CI/CD pipeline? Source control, build, test, deploy, monitoring.

Q. How does GitHub Actions fit into the CI/CD ecosystem? It automates CI/CD workflows inside GitHub using YAML, integrating with repos and tools such as Docker and AWS.

Q. What are some common use cases for GitHub Actions beyond CI/CD? Automation (issue labeling), code review (linting), notifications and scheduled tasks.
