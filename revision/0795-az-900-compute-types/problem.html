  • VMs: Windows or Linux, many sizes. Azure installs the OS and you configure everything else.
  • ACI: runs containers without VMs, with container groups for several containers in one instance. For heavy or long-running workloads use AKS.
  • Azure Functions: microservices that take an input, do an operation and return a result. Event-driven (file upload, HTTP request, timer). Consumption billing, no VM costs.
