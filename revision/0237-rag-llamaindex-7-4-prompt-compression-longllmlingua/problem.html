7.4 Prompt compression (LongLLMLingua) RAG with LlamaIndex

RAG with LlamaIndex › 7. Advanced RAG: Post-Retrieval & Other Techniques › 7.4 Prompt compression (LongLLMLingua)

Shorten the prompt while keeping the relevant information: faster, cheaper, and counters "lost in the middle". Reported gain: up to 21.4 points at 4x compression in RAG settings. Components:

  1. Question-aware coarse-grained compression: relevance of each context to the question based on perplexity.
  2. Question-aware fine-grained compression: contrastive perplexity to keep key tokens (not implemented in LlamaIndex).
  3. Adaptive granular control: different compression ratios per document, driven by the coarse-grained ranking.
  4. Subsequence recovery: maps response subsequences back to the original prompt content.

Requires a GPU: model_name defaults to NousResearch/Llama-2-7b-hf, device_map defaults to "cuda". Other arguments: model_config, open_api_config, metadata_mode.
