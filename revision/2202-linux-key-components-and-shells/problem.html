Key components and shells Linux

Linux › 1. Linux Basics › Key components and shells

Q. What are the key Linux components? Kernel, shell (Bash), file system (ext4), user tools (ls, grep), libraries (glibc), daemons (sshd) and bootloader (GRUB).

Q. What is the role of the shell? The shell (Bash) interprets user commands, talks to the kernel and supports scripting for automation.

Q. What are the common Linux shells? Bash (default, script-friendly), Zsh (advanced completion), Fish (user-friendly), Sh (lightweight), Tcsh (C-like).
