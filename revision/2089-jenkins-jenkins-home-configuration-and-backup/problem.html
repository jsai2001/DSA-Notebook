JENKINS_HOME, configuration and backup Jenkins

Jenkins › 1. Jenkins Fundamentals and Architecture › JENKINS_HOME, configuration and backup

Q. What is JENKINS_HOME, and what lives in it? The root data directory holding all Jenkins state:

  • config.xml: global config
  • jobs/: per-job config and build history
  • plugins/: installed plugins
  • secrets/: encryption keys and credential material
  • users/, nodes/, workspace/, fingerprints/, updates/

Backing it up backs up the whole instance.

Q. How does Jenkins store configuration, and why XML? Config is persisted as XML files on disk (config.xml, per-job config.xml, node and user configs). Jenkins serializes its Java object model with XStream, so the files are human-readable, diffable and directly editable. That is also why config can be version-controlled and reloaded.
