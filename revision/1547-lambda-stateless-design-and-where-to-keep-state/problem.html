Q71. Why is Lambda stateless, and where should application state live? Each execution environment is ephemeral and any invocation may land on a fresh one, so nothing in memory or /tmp is guaranteed to persist. Store state externally: DynamoDB (key/value, sessions, counters, idempotency), S3 (objects and files), RDS/Aurora (relational) and ElastiCache (fast shared cache). Warm-environment caching is a performance optimization, not a correctness guarantee.
