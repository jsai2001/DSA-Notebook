CodeQL code scanning GitHub Actions

GitHub Actions › 8. Integrations: Packages, Pages, Terraform, CodeQL, Dependabot › CodeQL code scanning

CodeQL scans for vulnerabilities and hard-coded secrets (for example SQL injection) in languages such as JavaScript, Python and Java, and reports into the GitHub Security tab. Set language per project, run on push and pull request, and review false positives manually.
