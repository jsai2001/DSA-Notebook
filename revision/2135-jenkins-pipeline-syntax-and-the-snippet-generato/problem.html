Jenkins › 3. Declarative Pipeline Basics › Pipeline syntax and the snippet generator

The snippet generator writes step code for you. Common basic steps: echo, git (check out a repo), sh (run shell commands) and archiveArtifacts (store job artifacts). The full list is in the Jenkins docs under Basic Steps Reference and Pipeline Steps Reference (which includes plugin steps).

  1. In a pipeline job click the Pipeline Syntax link under the script field.
  2. Pick a step from the Sample Step dropdown (for example archiveArtifacts) and set its parameters (for example *.txt).
  3. Expand Advanced for options such as allow empty archive, only if successful, fingerprint.
  4. Click Generate Pipeline Script, copy the snippet into the pipeline, use Apply to check syntax, then save and build.

The Declarative Directive Generator does the same for directives such as parameters and tools.

A blue icon next to the build shows the archive succeeded, and report.txt is downloadable from the job page.
