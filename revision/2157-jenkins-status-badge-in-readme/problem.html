Status badge in README Jenkins

Jenkins › 6. Connecting Jenkins to GitHub › Status badge in README

A status badge is a dynamic image showing whether a Jenkins job's build is passing or failing, usually placed in a repo README.md.

  1. Install the Embeddable Build Status plugin (Manage Jenkins, Manage Plugins, Available, search embed), choosing Download now and install after restart, and restart Jenkins.
  2. Open the job, select Embeddable Build Status, choose the Markdown option and the Unprotected link, and copy the snippet.
  3. Edit README.md in GitHub, paste the snippet near the top and commit to main.

If the badge does not show, check the plugin is installed and Jenkins restarted, the snippet is correct, the Jenkins URL is reachable, and the job has run so the status is accurate.
