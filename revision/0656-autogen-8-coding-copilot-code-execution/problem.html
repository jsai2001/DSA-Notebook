AutoGen › 8. Coding Copilot (Code Execution)

Two-agent pattern: a code writer (LLM, writes code, does not execute) and a code executor (no LLM, runs code, returns output/errors). Errors go back to the writer, which fixes the code until it succeeds (automatic iterative debugging).
