SQuAD metric Hugging Face Transformers

Hugging Face Transformers › 2. Question Answering › SQuAD metric

Regular accuracy often does not fit NLP outputs. The SQuAD metric (Stanford Question Answering Dataset) scores predicted answers against correct ones and reports Exact Match and F1, per answer and for a whole dataset. It comes from Hugging Face's evaluate package.

Workflow: build an evaluation set (context, questions, correct answers), run it through the model, compare predictions with the correct answers using the metric.

  • Exact match gives F1 = 100, no overlap gives 0, partial overlap reflects token overlap.
  • Cumulative keys: exact (percent exact matches, 1 of 3 = 33.33), f1 (average F1), total (answers evaluated), HasAns_exact / HasAns_f1 (only questions that have answers).
