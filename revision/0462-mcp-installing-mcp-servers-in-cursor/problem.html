Model Context Protocol › 10. Using MCP in Cursor and the Documenter Workflow › Installing MCP servers in Cursor

Cursor reads mcp.json; the format matches Claude Desktop's. Project-level config is .cursor/mcp.json in the project; global config is ~/.cursor/mcp.json.

Steps: open Cursor Settings, MCP section, add a server (project or global), edit mcp.json, save (it appears immediately), and refresh after code changes.

Using it: open the Agent panel, add context (files/folders), enter "Document this project". Cursor detects the MCP, asks for approval, and runs the tools sequentially. Cursor supports tools only (see section 2). Custom rules control how the agent uses MCPs:
