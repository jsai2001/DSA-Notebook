Stateful stream processing Apache Spark

Apache Spark › 2. Spark Capabilities for ETL › Stateful stream processing

  • Checkpointing: saves pipeline state to persistent storage (HDFS, S3) so a failed job resumes where it left off. Saves metadata (configuration, progress), Kafka offsets, key-based state, and RDDs for operations spanning batches (windowing).
  • Watermarks: for event-time windowing (time the event was created at the source, not when it arrived). A window must wait for all its events. The watermark is the delay to wait before processing a window. Spark tracks events until the watermark passes.
  • State tracking by key (UpdateStateByKey): tracks entity state by key (e.g., browser session ID). New events change state, and updated states are published as a DStream to downstream transformations.
