7.1 Atlas setup LangChain Level Up

LangChain Level Up › 7. Semantic Search with MongoDB Atlas Vector Search + OpenAI › 7.1 Atlas setup

  • Sign up at mongodb.com/atlas, deploy a Free (512 MB) cluster (name e.g. ClusterLangChain, pick AWS/GCP/Azure and nearest region).
  • Browse Collections → Create database elearning, collection mongodb-training.
  • Connect → Drivers → Python → copy connection string.
  • Security → Database Access: add/edit a database user with password auth and the Atlas Admin built-in role (required to create the vector search index). Without valid credentials the connection fails with an authentication error.
