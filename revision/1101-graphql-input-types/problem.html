Input types GraphQL

GraphQL › 4. Types: Scalars, Objects, Lists, Enums, Input › Input types

Mutation arguments that are objects must be declared with the input keyword, not type. type = output shapes, input = argument shapes. Every type field you want to send via a mutation must exist in the matching input, and lists need a matching input type ([Store]! becomes [StoreInput]!).
