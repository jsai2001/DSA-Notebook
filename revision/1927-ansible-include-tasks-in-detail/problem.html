include_tasks in detail Ansible

Ansible › 5. Includes, Imports and Tags › include_tasks in detail

include_tasks processes the file while the playbook runs, so the path or tasks can depend on variables resolved at runtime. It suits conditional inclusion or looping over a set of tasks. The limitation is that it is harder to debug, because tasks are not resolved until execution. Plain include is legacy after Ansible 2.4; include_tasks is used instead.

If env is dev, dev_setup.yml is included at runtime.
