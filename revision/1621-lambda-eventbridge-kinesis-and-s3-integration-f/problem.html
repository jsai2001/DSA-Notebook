EventBridge, Kinesis and S3 integration failures AWS Lambda

AWS Lambda › 13. On-call troubleshooting › EventBridge, Kinesis and S3 integration failures

Symptom: Lambda not receiving EventBridge events. Verify the rule targets the function, the function policy allows events.amazonaws.com, and logs for invocation errors.

Symptom: Lambda failing to write to Kinesis. Verify the role has kinesis:PutRecord and kinesis:PutRecords, the stream name and the code. Test with a sample event.

Symptom: Lambda not processing S3 events. Verify the bucket event notification (S3 > bucket > Properties > Event notifications > add the Lambda trigger), the function policy allowing s3.amazonaws.com, and logs.
