Gateways AWS

AWS › 4. Networking › Gateways

Q. What is a NAT Gateway? It gives outbound internet access to private subnets. It sits in a public subnet with an Elastic IP.

Q. Internet Gateway vs. NAT Gateway?

  • Internet Gateway: two-way public access.
  • NAT: one-way outbound for private subnets.

Q. What is AWS Direct Connect? A private link to AWS for high-speed, secure hybrid transfers.
