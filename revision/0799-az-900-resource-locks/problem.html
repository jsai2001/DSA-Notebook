Resource locks AZ-900

AZ-900 › 10. Governance and compliance › Resource locks

Prevent changes or deletion, and apply to all users (unlike RBAC). Available on every resource (Settings → Locks). A user with a restricted role (for example Website Contributor) cannot remove locks.
