What X-Ray gives you AWS CloudWatch

AWS CloudWatch › 13. X-Ray Tracing › What X-Ray gives you

X-Ray provides end-to-end visibility by tracing requests across distributed systems.

  • Distributed tracing follows the entire request lifecycle, including AWS services and external resources.
  • Dynamic service map draws components and their interactions, showing dependencies and architecture.
  • Performance metrics: request latency, request rate, errors and fault rates.
  • Root cause analysis: correlates traces and logs to show which service failed and why.
  • Integrations: Lambda, EC2, ECS, API Gateway and others, across service boundaries.
