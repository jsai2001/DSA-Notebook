Q35. Create a node group. create_nodegroup takes instance types, scaling config, subnets and the node IAM role.

Q36. Combine boto3 with the kubernetes client. boto3 fetches the cluster endpoint and CA data; those configure the Kubernetes API client. (Gotcha: the source passes the caller ARN as the API key. Real EKS auth needs a signed STS token, for example from aws eks get-token.)
