LangChain Level Up › 10. Deploying Chains as a REST API with LangServe

LangServe deploys runnables and chains as a REST API; it builds on FastAPI (server) and Pydantic (validation) and auto-generates JSON Schema + Swagger docs, so endpoints can be tested in the browser.

uvicorn is the ASGI server that runs the FastAPI app. Project: server.py (FastAPI + routes), .env, requirements.txt, README.
