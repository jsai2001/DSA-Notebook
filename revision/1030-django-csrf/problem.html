CSRF Django

Django › 7. Forms, CSRF and Validation › CSRF

Without {% csrf_token %} a POST returns 403 Forbidden. CSRF = Cross-Site Request Forgery.

  1. Django sends a unique token to the browser with the form page.
  2. The token is submitted back with the data.
  3. Django verifies it, so only the browser that got the form can submit it. A third party has no token and is rejected.

Put {% csrf_token %} inside every <form method="POST">.
