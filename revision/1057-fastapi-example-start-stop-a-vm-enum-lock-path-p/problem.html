Example: start/stop a VM (Enum, Lock, path params) FastAPI

FastAPI › 4. Accepting Data › Example: start/stop a VM (Enum, Lock, path params)

Spec: POST /vm/start with cpu_count (1-64), mem_size_gb (8-1024), image (one of three); returns an id. POST /vm/{id}/stop returns the id and spec, or 404.

  • Enum field: Pydantic rejects values outside the allowed set.
  • Lock protects shared state because sync handlers run in multiple threads.
  • vms.pop(id, None) removes and returns the VM, or None.
