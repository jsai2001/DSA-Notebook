Database with Python › 3. SQLAlchemy Core and ORM › Engine, connection and running a query

The engine (create_engine) is the starting point and manages database connections. It is not the same as a Python DB-API connection. engine.connect() returns a connection that proxies the real DB-API connection. echo=True logs what SQLAlchemy does (for example BEGIN and ROLLBACK). With no commit, a read-only block ends in an implicit ROLLBACK.

Run it inside the activated virtual environment (source bin/activate, then python database.py). In SQLAlchemy 1.4 and later a plain string must be wrapped in sqlalchemy.text().
