Utility functions and preference modeling Agentic AI Fundamentals

Agentic AI Fundamentals › 7. Utility-Based Frameworks and Reinforcement Learning › Utility functions and preference modeling

A utility function maps outcomes to numbers so the agent picks the best action mathematically. Security camera example: a person carrying an object is detected, and the utility function ranks it from 1 (least likely a weapon) to 10 (most likely a weapon). The agent evaluates the threat level and decides whether further observation is needed.

Preference modeling sets user preferences and feeds them into the utility function to find the most optimal solution. For example, preferences define how a camera image is optimized for analysis before the agent decides.
