AutoGen › 6. Nested Chats (Reflection pattern) › Review chat queue and registration

  • chat_queue: list of nested chat configs, run in sequence.
  • trigger: agent whose messages activate the nested chats (here, whenever writer sends a message).
  • Execution: Reviewer → Writer (task) → Writer drafts → nested chats (SEO, Grammar, Ethics, Meta) → Reviewer sends consolidated feedback → Writer improves.
  • Use max_turns: 1 for a single focused specialist review, about 3 for back-and-forth.
  • Pass content via the reflection function rather than hard-coding text.
  • Same pattern fits code review (security/performance/style reviewers + lead) and paper review (methodology/statistics/ethics + editor).
