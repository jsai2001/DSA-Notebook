Q. A long query times out on Snowflake and on a generic SQL database. What do you do? Look at query complexity, raise the timeout (QUERY_TIMEOUT session parameter for Snowflake, connect_timeout for MySQL), add indexes on frequently queried columns in MySQL, and break big queries into pages with LIMIT/OFFSET. Standard Snowflake tables have no user-created indexes, so rely on warehouse size and clustering instead.
