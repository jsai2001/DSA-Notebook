Why ML is harder than software engineering MLOps

MLOps › 2. MLOps Foundations › Why ML is harder than software engineering

  • Software has 2 artifact types: code and records (requirements, design, test plans/results).
  • ML has 4: code, records, data (training, production, labeled) and models (trained artifacts).
  • Artifacts depend on each other: requirements guide data prep, data plus requirements build the model, the model is integrated into code, and code execution produces new training data.
ChallengeDetail
Independent life cyclesEach artifact has its own life cycle but depends on the others
CoordinationDependencies need careful coordination
CollaborationData engineers, ML engineers, product owners must work together
Extra toolingTools and workflows to manage and govern every artifact type
Different skill setsEach artifact needs specialized skills
Integrated workflowNeeds an end-to-end workflow across all life cycles
