AWS Lambda › 8. Storage, state and integrations › Layers

Q91. What are Lambda Layers, and how do they manage shared code? A Layer is a .zip archive of libraries, custom runtimes or shared code that you attach to functions. It is extracted into /opt at runtime. Layers let several functions share dependencies without bundling them into each package: smaller deployment packages, faster deploys and central versioning.

Q92. What are the limits on Layers? Up to 5 layers per function. The combined unzipped size of function code and all layers must be at most 250 MB. Layers count toward the same limit, so they save package size but not the total footprint.
