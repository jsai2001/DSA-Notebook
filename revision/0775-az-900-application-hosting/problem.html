AZ-900 › 6. Compute and networking › Application hosting

AKS: managed container orchestration, good at scaling containers and keeping them available. A Kubernetes cluster has a control plane (manages scaling in/out) and nodes (run containers). You pay only for the compute in the cluster.

Virtual Machines: most flexible and the most responsibility (install, configure, secure everything).
