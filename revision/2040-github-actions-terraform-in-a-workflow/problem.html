hashicorp/setup-terraform installs Terraform. The workflow runs terraform init, plan and apply, with AWS credentials from secrets. Use a remote backend (such as an encrypted S3 bucket) for state, use -auto-approve only for non-production, and run terraform fmt and terraform validate in CI.
