Ansible › 5. Includes, Imports and Tags › import_tasks in detail

import_tasks loads the tasks when the playbook is parsed, before execution. All tasks are known and fixed up front, which is predictable and efficient. The limitation is that you cannot choose the file from runtime conditions: import_tasks: "{{ env }}_setup.yml" fails if env is not defined at parse-time.

Use include_tasks for dynamic behavior and import_tasks for static, predictable inclusion.
