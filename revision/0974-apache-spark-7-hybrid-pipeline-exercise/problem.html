7. Hybrid Pipeline Exercise Apache Spark

Apache Spark › 7. Hybrid Pipeline Exercise

Problem: Using the visit_stats table from Section 5, build a downstream pipeline for significant actions. Requirements:

  1. A daily job extracts last-action records with duration > 15 (within a 5-second window).
  2. Stream them to Kafka topic spark.exercise.lastaction.long (created in setup).
  3. In real time, keep a running counter of significant last actions by action name.

Design: MariaDB visit_stats -> Job 1 (batch extraction, filter duration > 15, publish to Kafka) -> Kafka topic -> Job 2 (streaming scorecard) -> Redis sorted set of running counts. Batch plus real-time makes it a hybrid pipeline.
