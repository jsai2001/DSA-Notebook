Canonical HTTP service Angular

Angular › 8. Services › Canonical HTTP service

  • Class name ends in Service. Constructor injects dependencies; private is recommended (easy to spot dead code), public if the template needs it, protected for subclasses.
  • Module-based apps import HttpClientModule in AppModule.imports.
  • $ suffix marks observable-returning methods or properties (convention, not required).
  • http.get<Type>(url, options?): URL is local or remote, the generic gives type safety and autocomplete.
  • .pipe(...) composes operators. delay simulates network lag, map transforms the data.
  • Return observables from services and let components (or the async pipe) subscribe.
