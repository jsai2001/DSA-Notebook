Amazon API Gateway as a trigger AWS Lambda

AWS Lambda › 2. Console, programming model and triggers › Amazon API Gateway as a trigger

API Gateway is a fully managed service for creating, publishing, maintaining, monitoring and securing APIs at scale. It acts as the front door to backends (Lambda, EC2, DynamoDB, Kinesis or public endpoints), handles up to 200,000 concurrent API calls, and manages traffic, authorization, access control, monitoring and API versions. Pricing is pay-per-use (API calls and data out), with no minimums. Clients send HTTP or WebSocket requests to its endpoints.

Uses:

  • Route HTTP requests to a function by path and method.
  • WebSockets for serverless real-time chat (with Lambda and DynamoDB for sessions).
  • Direct DynamoDB CRUD through Velocity Template Language (VTL) mapping, with no Lambda in between.
  • Authentication through Amazon Cognito or Lambda authorizers.
