Q99. How do you implement idempotent processing for duplicate events? Derive an idempotency key (message id or a hash of the payload) and record it in a store (DynamoDB with a conditional write such as attribute_not_exists, with TTL for cleanup). On each event try to claim the key. If it already exists, skip (return the prior result). The AWS Lambda Powertools Idempotency utility does this for you.
