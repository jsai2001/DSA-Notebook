Q71. GitHub Actions workflow cannot authenticate with AWS. Troubleshooting checklist:

  • Verify AWS_ACCESS_KEY_ID and AWS_SECRET_ACCESS_KEY in GitHub Secrets.
  • Check the IAM user/role has the needed permissions.
  • Check the aws-actions/configure-aws-credentials step config.
  • Check the region.
  • Enable debug logging with ACTIONS_STEP_DEBUG: true.
  • Switch to OIDC with an IAM role.

Q72. Timeout listing thousands of S3 objects. Use a paginator and process in batches to limit memory; add retries for transient errors. (Gotcha: MaxItems caps the total results returned, so it truncates rather than speeds up. Use PageSize to tune per-request size.)

Q73. Create an EKS cluster with boto3, then configure it with Ansible.

  1. boto3 creates the cluster and node group and waits for ACTIVE.
  2. boto3 reads the cluster details and generates a kubeconfig.
  3. Ansible uses the kubeconfig and the k8s module to deploy resources.
  4. Run both in a GitHub Actions workflow.

Q74. "Rate Exceeded" when creating many EC2 instances. Exponential backoff with retries, limit concurrent calls, use batch operations (for example MinCount/MaxCount instead of looping).
