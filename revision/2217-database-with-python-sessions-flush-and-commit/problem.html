Sessions: flush and commit Database with Python

Database with Python › 4. MySQL with Python › Sessions: flush and commit

A Session manages a transaction (all-or-nothing) using the unit-of-work pattern. Changes accumulate and are only sent on flush.

  • session.add() queues a new object.
  • session.flush() emits the SQL and fills in auto-assigned keys such as project_id.
  • session.commit() makes the transaction permanent. session.rollback() undoes it. session.close() ends the session.
  • Flush after adding the project, otherwise project_id is missing when the tasks are saved and the foreign key fails.
  • bulk_save_objects is efficient for many objects but skips some ORM features (event listeners). Use session.add() for a single task.
  • with Session(engine) as session: closes the session automatically. Do not leave transactions open, because that holds database locks.
