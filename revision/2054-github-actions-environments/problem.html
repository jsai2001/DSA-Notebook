GitHub Actions › 4. Secrets, tokens, permissions and security › Environments

Q. What are GitHub Actions environments, and how are they used in deployments? Environments represent deployment targets (dev, staging, production) with protection rules (such as approvals), secrets and variables.

Q. How do you deploy to dev, staging and prod with different configs? Use environments, environment-specific secrets, conditional jobs and approvals.
