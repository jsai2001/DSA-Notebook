Q. What is the script block, and when should you use it? script { } embeds arbitrary Scripted (Groovy) code inside a declarative stage, for loops, complex conditionals or variable manipulation that declarative syntax cannot express. Use it sparingly; prefer shared-library steps for anything reusable.
