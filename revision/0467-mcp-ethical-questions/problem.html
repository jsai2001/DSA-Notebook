Model Context Protocol › 11. Conclusion: Mindset and Responsibility › Ethical questions

  • Data access: What data does it access, is that necessary, how is it protected, who can see it, how long is it kept?
  • User impact: Are users informed, can they control it, what happens if it fails?
  • Broader: Could it be misused, what are unintended consequences, is it transparent, does it respect autonomy?
