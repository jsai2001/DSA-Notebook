Q. What are the key Docker architecture components?

  • Daemon: manages Docker objects.
  • Client: the CLI.
  • Images: templates.
  • Containers: running instances.
  • Registry: image store.

Q. Container vs image?

  • Container: a running instance.
  • Image: a static blueprint.

Q. Image layer vs container layer?

  • Image: a read-only stack of layers.
  • Container: a writable top layer.

Q. What is the default storage driver and why does it matter? overlay2 (the Linux default). It affects performance, storage and compatibility.
