Script security, CSRF and hardening Jenkins

Jenkins › 7. Security, Credentials and Access Control › Script security, CSRF and hardening

Q. What is Script Security, and why do some Groovy scripts need admin approval? The Script Security plugin gates Groovy that runs on the controller. Sandboxed pipeline code is limited to safe APIs; anything outside the sandbox (or @NonCPS code using sensitive methods) goes to In-process Script Approval, where an admin must approve it. This stops arbitrary code from compromising the controller.

Q. How do you restrict script capabilities with the Groovy Sandbox? Run pipeline Groovy in the sandbox (the default for a Jenkinsfile from SCM). Only allowlisted, safe methods are allowed; anything else is blocked or needs admin approval, so pipeline code cannot call dangerous controller APIs or the filesystem directly.
