Q. Difference between ansible and ansible-playbook?

  • ansible: ad-hoc, single tasks (ansible all -m ping).
  • ansible-playbook: runs full YAML playbooks for structured automation.

Q. What is idempotency and why is it key? Tasks only change a system if needed, for example skipping an install when the package is already present. That keeps results consistent, avoids redundant actions, and makes runs reliable.
