Multi-container Pods and restarts Kubernetes

Kubernetes › 3. Pods and Workloads › Multi-container Pods and restarts

Q. What is a multi-container Pod, and when would you use one? Multiple containers in one Pod, used for sidecars (for example logging) or tightly coupled apps.

Q. How do you restart a Pod without deleting it?

  • For a Deployment: kubectl rollout restart deployment <name>
  • Direct: edit the spec (for example add a label) or let probes fail.
