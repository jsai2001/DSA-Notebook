AWS CloudWatch › 13. X-Ray Tracing › Demo app with CloudFormation

In the CloudWatch console go to X-Ray Traces > Service Map > Set up demo app > Create sample application with CloudFormation. Stack name X-Ray-demo-app, accept defaults, acknowledge resource creation. When the stack finishes, open the URL in its Outputs tab to reach Scorekeep: set a username, create a session, create a game (for example demo, tic-tac-toe) and play to generate backend requests.
