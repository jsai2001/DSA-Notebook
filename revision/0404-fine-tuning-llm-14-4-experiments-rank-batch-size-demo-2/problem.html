Findings (lecture):

SettingEffect
Higher rankMore stable training and better loss reduction, more parameters
Higher batch sizeFewer steps, faster wall-clock, more memory
Low rank + small batch~2,500 steps, ~325 s, unstable training
High rank + large batch~157 steps, ~200 s, stable training

Layer targeting: dense layers first, attention for more capacity; final layers (lm_head) are often most impactful. Batch 8–16 is low-memory but unstable, 64–128 stable but memory-hungry. Deployment: save only the LoRA adapters, combine with the base model at inference, swap adapters per task.
