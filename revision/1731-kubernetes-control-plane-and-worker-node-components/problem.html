Control plane and worker node components Kubernetes

Kubernetes › 2. Architecture › Control plane and worker node components

Q. What are the key components of Kubernetes architecture?

  • Control Plane: kube-apiserver, etcd, kube-scheduler, kube-controller-manager.
  • Worker Nodes: kubelet, kube-proxy, container runtime (for example Docker).

Q. What is a control plane, and what does it consist of? The brain of the cluster. It manages state and scheduling and includes kube-apiserver, etcd, kube-scheduler, and kube-controller-manager.

Q. Explain the difference between master nodes and worker nodes.

  • Master: runs the control plane (manages the cluster).
  • Worker: runs Pods (executes workloads).
