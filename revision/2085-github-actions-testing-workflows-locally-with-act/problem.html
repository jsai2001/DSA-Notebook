Testing workflows locally with act GitHub Actions

GitHub Actions › 9. Debugging, local testing and limits › Testing workflows locally with act

act reads the workflow YAML and runs it in Docker containers that mimic GitHub's runners. It shortens the feedback loop and saves CI minutes. Docker must be installed. Secrets are not available locally, so mock them with environment variables or a .env file (--secret-file). Custom or complex actions may not behave identically. Use -P to choose a runner image for compatibility.
