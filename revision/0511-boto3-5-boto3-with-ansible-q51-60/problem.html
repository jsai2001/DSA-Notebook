Boto3 › 5. boto3 with Ansible (Q51-60)

boto3 handles what Ansible's AWS modules do not cover: pre-provisioning, inventories, readiness checks and remediation. Data is handed to Ansible through JSON files, tags or environment variables. Ansible's AWS modules themselves require boto3 installed on the host.

Q51. Complement Ansible playbooks. Create or query resources before or after playbooks run.

Q52. Generate an inventory for Ansible. Query running instances and write them in an inventory-compatible structure.

Q53. Validate resource state before a playbook. Check instance state or tags so prerequisites are met.

Q54. Create resources Ansible will configure. Provision EC2 or S3 with boto3, then pass IDs/ARNs to Ansible. Code is the same as Q51 (run_instances, return instance_id), with a region parameter.
