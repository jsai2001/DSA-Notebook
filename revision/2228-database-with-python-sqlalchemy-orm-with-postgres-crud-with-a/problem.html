The ORM uses classes instead of tables. Define the schema by hand (clear structure) or autoload it with automap_base: Base.prepare(engine, reflect=True) and read the model from Base.classes.sales. Objects bound to a session are tracked, so changing attributes and committing updates the row. Always commit to persist, and close sessions.
