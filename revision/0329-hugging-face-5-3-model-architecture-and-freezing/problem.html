5.3 Model architecture and freezing Hugging Face Transformers

Hugging Face Transformers › 5. Transfer Learning (Sentiment Model) › 5.3 Model architecture and freezing

Loading a base checkpoint copies its architecture, hyperparameters, and weights, so nothing is built from scratch. num_labels sets the size of the new classification head.

Freezing a layer means its weights are not updated in backpropagation, which keeps what the base model already learned.

Layer 0 is the DistilBERT encoder (most parameters), then pre_classifier and classifier (Dense). Layers can also be added, inserted, or removed through the layers object.
