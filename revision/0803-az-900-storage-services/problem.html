Blob types:

TypeUse

Append blobsAppend-only data such as logs
Page blobsVHDs used by VMs

Azure Disks: Azure auto-creates the OS disk with a VM. For persistent data, add a separate data disk.

Azure Files: SMB shares mapped like a network drive. It can be slow over the internet, so Azure File Sync syncs files to an on-prem server for local speed while the data stays in Azure.
