Azure AI Services › 5. Search › AI enrichment

Raw data (PDF with images, video) must be "cracked open" first. Pipeline: data -> crack documents -> apply AI skill -> enriched document -> index -> search. Example: translation skill lets a search for "hund" match "dog".

  • Built-in skills: word meanings, OCR, entity recognition, translation, image analysis.
  • Custom skills: call any web API (e.g., OpenAI models) or Azure Machine Learning skills.
  • The free tier does not support cognitive skills.
