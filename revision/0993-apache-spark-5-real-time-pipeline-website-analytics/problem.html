5. Real-Time Pipeline: Website Analytics Apache Spark

Apache Spark › 5. Real-Time Pipeline: Website Analytics

Use case: An e-commerce site tracks visits (date, country, duration, last action before exit: Catalog, FAQ, ShoppingCart, Order). Required in real time:

  1. 5-second summaries of duration by last action -> MariaDB website_stats.visit_stats.
  2. Running total of visit duration by country -> Redis sorted set.
  3. Visits ending in ShoppingCart -> Kafka topic spark.streaming.carts.abandoned.

Architecture: E-commerce app -> Kafka spark.streaming.website.visits -> one Spark job fanning out to MariaDB, Redis and the abandoned-carts Kafka topic. Kafka scales the source, Spark scales across executors, Redis sorted set scales horizontally, each executor writes to MariaDB in parallel.
