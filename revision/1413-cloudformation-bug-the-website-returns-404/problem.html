Bug: the website returns 404 AWS CloudFormation

AWS CloudFormation › 8. S3 Static Website Template (JSON) › Bug: the website returns 404

Opening WebsiteURL from Outputs gives a 404. The template names index.html as the index document, but no files have been uploaded. Fix it by uploading these files to the bucket in S3.

The first file is index.html and the second is error.html. After the upload, refreshing the site gives a 403, a permissions problem caused by the missing bucket policy.
