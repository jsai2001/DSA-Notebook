Database with Python › 1. Databases and the Python Database API › Non-relational (NoSQL) databases

Built for big data and unstructured data that does not fit rows and columns. "NoSQL" means "not only SQL". Storage formats are JSON documents, key-value pairs and graphs.

  • Document database: stores JSON-like or XML-like documents with varying attributes per document. Examples: MongoDB, DynamoDB.
  • Columnar database: organized by column instead of row, and rows can have different columns. Example: Cassandra (a hybrid of key-value and columnar).
  • Graph database: nodes (data) and edges (relationships), good for interconnected data. Example: Neo4j.
