Q55. Tag instances for Ansible dynamic inventory. create_tags; Ansible groups hosts by tag.

Q56. Ensure prerequisites (boto3 installed) for Ansible's AWS modules. Run a shell command on the instance through SSM send_command.

Q57. Retrieve resource details for Ansible's ec2_instance module. Query with boto3 and save to a JSON file or environment variables. (Gotcha: the source code uses json.dump without import json.)

Q58. Create an SNS topic for Ansible notifications. create_topic and return the ARN; same call as Q21, with a region parameter and a return topic_arn.

Q59. Handle resource failures dynamically. Monitor health (for example via CloudWatch) and remediate, either by restarting directly or by triggering an Ansible playbook.
