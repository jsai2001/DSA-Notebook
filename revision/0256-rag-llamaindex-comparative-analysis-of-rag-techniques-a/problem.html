ARAGOG: Advanced RAG Output Grading compared techniques with LlamaIndex abstractions.

AspectDetail
Data423 arXiv papers on AI/LLMs; 107 QA pairs (GPT-4 generated, human validated); detailed analysis on 13 papers plus noisy extras
Runs10 per technique for statistical reliability (ANOVA, then Tukey HSD for pairwise comparisons)
MetricsRetrieval precision (0-1, relevance of retrieved context); answer similarity (0-5, match to reference answer)
TechniquesSentence window retrieval, document summary index, HyDE, multi-query, MMR, Cohere reranker, LLM reranker
ResultFinding
Best retrieval precision and answer similarityHyDE + LLM reranking
Strong, but inconsistent answer similaritySentence window retrieval
ModerateDocument summary index, multi-query
LowerMMR, Cohere reranker

Takeaways: prioritize retrieval precision (it drives faithfulness); answer similarity also depends on the LLM and prompting, not only retrieval. Reasonable baseline: HyDE + LLM reranking; sentence window retrieval for precision-critical use; combine hybrid search + reranking + query transformation; evaluate with repeated runs and significance tests. Faithfulness needs the LLM to understand retrieved meaning, not just match keywords.
