5.2 Metrics RAG with LlamaIndex

RAG with LlamaIndex › 5. RAG Evaluation › 5.2 Metrics

MetricMeaning
FaithfulnessAnswer stays true to the context; key for catching hallucinations
Answer relevanceAnswer addresses the question and stays on topic
Context relevanceRetrieved context is accurate and targeted, without irrelevant text that wastes LLM capacity
MRR (Mean Reciprocal Rank)Reciprocal of the rank of the first correct result, averaged across queries

Faithfulness, context relevance, and answer relevance use the LLM-as-a-Judge paradigm: a strong LLM scores other LLM outputs to approximate human judgment. Benefits: scalable, cheap, fast iteration. Limits: position bias, verbosity bias (prefers longer outputs), weak reasoning on topics like math. GPT-4 reaches over 80% agreement with human preferences.

Further reading: ARAGOG (advanced RAG output grading, recommended), ARES, "Evaluation of Retrieval-Augmented Generation: A Survey", and the Hugging Face cookbooks on RAG evaluation and LLM-as-a-judge.
