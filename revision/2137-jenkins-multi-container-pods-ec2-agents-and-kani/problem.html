Multi-container pods, EC2 agents and Kaniko Jenkins

Jenkins › 8. Agents and Distributed Builds › Multi-container pods, EC2 agents and Kaniko

Q. How do you run several containers (Maven, AWS CLI) in one pod? Declare multiple containers in the pod YAML and target each with container('name'); they share the workspace volume.

Q. How do you provision EC2 instances as agents with the AWS EC2 plugin? Configure an EC2 cloud with an AMI, instance type, IAM role, subnet and security group, and labels. When jobs need capacity Jenkins launches EC2 instances as agents (over SSH) and terminates idle ones per the retention strategy.

Q. How does workspace persistence work in Kubernetes pods? By default an ephemeral pod's workspace vanishes with the pod. Mount a PVC (or use workspaceVolume: dynamicPVC(...)) so the workspace persists across steps, containers or reruns, which helps caches such as .m2 and node_modules. Trade-offs: PVC lifecycle and cleanup, and RWX access constraints.
