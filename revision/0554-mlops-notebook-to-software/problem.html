Notebook to software MLOps

MLOps › 7. Continuous Integration › Notebook to software

Convert notebook code into a deployable, executable model that faithfully reproduces notebook processing and performance.

Deployment forms

ModeForms
Embedded in non-ML executablesFunction in a program, SDK, Python package, pipeline Lambda function, bundled in a product
Service, batchBatch ML job (reads from DB, writes predictions back)
Service, batch/streamingREST API (request in, prediction out)
Service, streamingStream processing job (queue in, queue out)

What to convert

StepDetail
Pre-processingTokenization, encoding, input scaling
Model fileFrom the registry; packaged or read from an external repo at runtime
InferenceCode the prediction step
Post-processingDecoding, reverse scaling, conversion to business outcomes
InterfacesFunction calls, REST APIs or DB queries for input/output
Build/test/deploy infraCI/CD like any other software module

Regression test after conversion: use the model's benchmark results as the baseline and the same benchmark input data, and verify the same performance as the notebook. If not, fix and retest. Pay special attention to pre- and post-processing. Some tools convert notebooks to services automatically, so try those first.
