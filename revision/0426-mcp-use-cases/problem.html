Model Context Protocol › 3. Examples, Use Cases and Finding Servers › Use cases

  • Development: codebase context in Cursor, run builds/tests/linters, query docs.
  • Data analysis: query databases in natural language, analyze CSV/Excel, generate reports.
  • Business: CRM data, inventory, order status, invoices.
  • Personal: organize files, schedule tasks, email, calendars.
  • Servers can be personal (local only), public (published), or company-specific (expose only approved data).
