5. Search Azure AI Services

Azure AI Services › 5. Search

Azure AI Search is an enterprise-class search engine over your data, with AI added.

OfferingSearchesUse case
Microsoft SearchM365 / SharePoint contentAuthenticated users, internal content
Bing SearchOpen internet (or a slice)Internet-facing sites
Database searchAzure SQL, Cosmos DB (full-text or vector)Data already in a DBMS
Azure AI SearchCustom, security-protected sourcesEnterprise search over your own content

Choose it for: relevance tuning, heterogeneous sources, heavy indexing/query workloads, offloading search from the DBMS, or content that is neither on the internet nor in SharePoint.

How it works: content from multiple sources -> provision the service (size, queries, indexes) -> full index, then refresh crawls (changes only) -> optional AI enrichment -> query engine serves apps (portal, APIs, clients).
