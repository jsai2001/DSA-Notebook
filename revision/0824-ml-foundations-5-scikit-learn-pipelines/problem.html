ML Foundations › 5. Scikit-Learn Pipelines

A pipeline looks like overhead at first but rescues you as complexity grows. It chains steps into one reproducible object with the same API everywhere: fit, transform, fit_transform. A transformer transforms data; a Pipeline is a sequence of transformers; a ColumnTransformer applies different transformers to different columns.

ClassPurpose
PipelineSequence of steps
ColumnTransformerDifferent steps for different columns
StandardScalerMean 0, std 1 per column
OneHotEncoderCategorical to one numeric column per category
SimpleImputerFill missing values
FunctionTransformerWrap a plain function as a step
BaseEstimator + TransformerMixinBase classes for custom transformers

To list numeric columns: print(tweak_housing(raw).select(cs.numeric()).columns)
