Open-source deep learning framework from Meta. Four pillars: Tensors, Autograd, API, Libraries.

StrengthDetail
Dynamic computation graphGraph is built as operations run, so debugging is plain Python
PythonicFits the Python ecosystem
GPU accelerationFast training and inference
Prototyping to productionTorchServe for serving, TorchScript for optimization

Hybrid API design: Python user API (torch, torch.nn, torch.optim, torch.utils.data) on top; C++ core (ATen: tensor library, serialization) below; CUDA kernels for NVIDIA GPUs. Python ease plus C++/CUDA speed.

Tensor = multidimensional array with GPU support and autograd tracking. Interop with NumPy via .numpy() / torch.from_numpy(). Cast dtype with .to(dtype=...), move device with .to('cuda').

Autograd = automatic differentiation engine. Goal: minimize loss by adjusting weights; gradients say which direction to change each weight.
