Execution plan (lazy evaluation) Apache Spark

Apache Spark › 2. Spark Capabilities for ETL › Execution plan (lazy evaluation)

  • Spark runs code only when an action (reduce, collect) is called. It then analyzes all prior steps and builds an optimized physical plan.
  • The optimizer reduces I/O, shuffling and memory use, reads in parallel from executors (not the driver) where the source allows, and applies predicate pushdown.
  • Print and analyze execution plans to find optimizations.
