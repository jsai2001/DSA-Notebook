AWS Lambda › 9. Monitoring, logging and testing › CloudWatch metrics and logs for Lambda

CloudWatch collects logs, metrics and events from AWS services, and Lambda sends metrics automatically with no code change. In the function's Monitoring tab (choose a time range):

  • Invocations: how many times the function was triggered. Shows usage patterns and traffic.
  • Duration: minimum, average and maximum time per request. Shows variation and where to optimize.
  • Error count and success rate: a 100% success rate with no errors means a healthy function.

Alarms on high error rate or long duration can be configured, and duration data guides memory tuning.

Lambda sends anything written with console.log (or the language equivalent) to CloudWatch Logs automatically. Structure: a log group per function (/aws/lambda/my-lambda-function), log streams inside it (created on deploy, over time, or when a stream fills), and log events as entries. Logs can be viewed in the Monitoring tab (filter by time, auto-refresh) or opened in the CloudWatch console. Lambda writes START, END and REPORT lines itself. REPORT shows duration, billed duration, memory size, max memory used and init duration.

CloudWatch Logs are stored indefinitely by default, so set a retention policy to control cost. Log sparingly and log JSON (JSON.stringify(event)) for complex data.
