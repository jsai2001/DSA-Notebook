Boto3 › 1. Core Concepts (Q1-15)

  • Needs knowledge of both AWS APIs and Python.
  • API rate limits (throttling).
  • Some services have limited resource support, so you fall back to client.
  • Needs robust exception handling.
  • Steep learning curve versus the Console.

Q14. Serverless (Lambda). boto3 runs inside Lambda functions to call S3, DynamoDB, SNS and so on. The function's IAM role supplies the credentials. Typical use is event-driven work such as processing S3 uploads or sending notifications.

Q15. What is botocore? The low-level library under boto3. It handles HTTP requests, authentication and response parsing. boto3 adds the friendly interface on top.
