Common modules and command vs shell Ansible

Ansible › 6. Modules › Common modules and command vs shell

Q. Commonly used modules? command, shell, file, copy, yum/apt, service, template, user, setup.

Q. Use the command module? Limitations? It has no shell features (pipes, redirects); use shell for those.

Q. shell vs command?

  • command: direct, no shell (for example uptime).
  • shell: runs through a shell, supports pipes (for example ls > file).
