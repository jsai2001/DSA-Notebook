Network types and the default bridge Docker

Docker › 4. Docker Networking › Network types and the default bridge

Q. What are the types of Docker networks? Bridge (default), Host (no isolation), Overlay (multi-host), None, Macvlan.

Q. What is the default bridge network? It uses private IPs and NAT to the host, so port mapping is needed.

Q. Host vs bridge network?

  • Host: uses the host's network stack, no isolation.
  • Bridge: isolated and NAT'd.

Q. When do you use an overlay network? For multi-host communication in Swarm, for example distributed apps.
