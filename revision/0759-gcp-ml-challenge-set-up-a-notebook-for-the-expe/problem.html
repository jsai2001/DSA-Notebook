GCP for Machine Learning › 7. Notebook Types and GPU Scaling › Challenge: set up a notebook for the expert MNIST example

  • Best choice: Instance (SSH like user-managed, dynamic sizing/GPU like managed).
  • Get the notebook in: open the expert MNIST notebook from tensorflow.org in public Colab → download .ipynb → upload into the instance.
  • Pick a machine type with a GPU, set the TensorFlow runtime, watch the resource meter.
  • Observation: training (5 epochs) used about 50% of one GPU, so one GPU is enough; more would waste money.
  • At recording, 5 GPU types were available and not all are compatible with every base image. Test before scaling.
