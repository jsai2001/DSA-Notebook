AWS CloudWatch › 14. CloudWatch RUM › Other RUM tabs

  • HTTP requests: only failed requests (for example a PUT returning 404 Not Found) to find API or network issues.
  • Sessions: each app instance creates a session; open a session ID for page views and events.
  • Events: HTTP events, JavaScript error events and other telemetries, chosen by telemetries: ['performance', 'errors', 'http'] in registerRum.ts.
  • Browsers and devices: spot issues tied to a device or browser once live.
  • User journeys: navigation across pages. Empty in the single-page demo; multi-page tracking needs extra configuration.
