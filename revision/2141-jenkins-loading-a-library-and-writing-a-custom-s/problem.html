Q. How do you load a library implicitly vs explicitly?

  • Implicit: a Global Shared Library configured with "Load implicitly" is available in every pipeline.
  • Explicit: @Library('my-lib@main') _ at the top of the Jenkinsfile, pinning a branch, tag or commit.

Q. How do you write a custom step in vars/ with an argument map? Define a call method taking a Map of named arguments with defaults; the file name becomes the step name.

Q. What is the difference between vars/*.groovy globals and src/ classes? vars files expose a step-like global (with call() making it invocable as name(args)), good for the pipeline-facing DSL. src classes are regular Groovy or OOP for structured, reusable and unit-testable logic. Use vars for the API surface and src for the implementation.

Q. What is the difference between Global and Folder-level Shared Libraries?

  • Global: configured in Manage Jenkins, available instance-wide, can be trusted (runs outside the sandbox) and loaded implicitly.
  • Folder-level: configured on a folder, scoped to jobs in it, always sandboxed and untrusted. Use for team-specific libraries and to limit the blast radius.
