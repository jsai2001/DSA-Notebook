Hugging Face Transformers › 2. Question Answering

Extractive QA: given a context and a question, the model returns the span of the context that best answers it. Flow: the corpus is tokenized and vectorized, the question goes through the same steps, the model compares them, scores candidate answers, and returns the best one.

Open Domain (ODQA)Closed Domain (CDQA)
ScopeAny topic (Google Search)Specific domain (pharma, product FAQs)
CorpusVery large (all of Wikipedia)Limited, domain-specific
Model sizeLargeSmaller
AccuracyLowerHigher
CostHigher training and inferenceLower
Use casePublic searchEnterprise self-service, product Q&A
