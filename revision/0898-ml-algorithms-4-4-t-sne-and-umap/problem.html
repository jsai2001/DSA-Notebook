Autoencoders are also named as an option; the course gives no code for them.

Practical workflow: cluster the high-dimensional data, run PCA on the original data, colour the PCA scatter by cluster label, then inspect the PCA weights to see which features drive the clusters. Unsupervised methods show what is in the data without encoding your bias.
