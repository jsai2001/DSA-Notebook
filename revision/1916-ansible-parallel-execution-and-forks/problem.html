Parallel execution and forks Ansible

Ansible › 9. Advanced Features and Scaling › Parallel execution and forks

Q. How does parallel execution work? Forks (default 5) run tasks across hosts concurrently, while tasks on each single host run sequentially. With 10 hosts and the default, Ansible does 5 hosts, then the next 5.

Q. What are forks? The number of parallel processes. Higher forks (for example 20) speed up large runs but strain the control node (CPU, memory, SSH connections). Set it with -f or in ansible.cfg.
