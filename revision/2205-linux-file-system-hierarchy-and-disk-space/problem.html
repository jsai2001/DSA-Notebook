File system hierarchy and disk space Linux

Linux › 2. File System and Commands › File system hierarchy and disk space

Q. What is the Linux file system hierarchy? Root (/) holds /etc (configs), /var (logs), /home (users), /bin (binaries), /usr (programs), /tmp (temp) and /proc (kernel info).

Q. How do you check disk space? df -h shows file system usage. du -sh /dir shows directory size.

Q. What does lsblk do? It lists block devices (disks and partitions) with names, mount points and sizes (sda1 at /).

Q. What is /proc? A virtual file system for kernel and process info (/proc/cpuinfo, /proc/[PID]).
