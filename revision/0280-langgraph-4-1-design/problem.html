LangGraph › 4. Product Q&A Chatbot (function tool + retriever tool + memory) › 4.1 Design

Self-service laptop chatbot ("What are the features and pricing for X?").

  • Function tool get_laptop_price: DataFrame lookup (stands in for an RDBMS) from data/Laptop pricing.csv (Name, Price, ShippingDays).
  • Retriever tool get_product_features: PDF chunked and embedded into Chroma.
  • Agent: a ReAct agent choosing between the two tools. Chatbot: agent plus conversation memory.
