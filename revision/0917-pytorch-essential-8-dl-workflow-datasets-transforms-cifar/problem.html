Pipeline:

StageSteps
Data preparationLoad data → convert to tensors → apply transforms → batch
Model developmentDesign → train (training data) → validate (validation data)
DeploymentSave model to file → deploy to cloud server or edge device

Learning types: supervised (labeled), unsupervised (no labels, finds patterns), semi-supervised (mix).

Dataset splits

SplitPurpose
TrainingFit model parameters
ValidationMeasure performance on unseen data and tune hyperparameters
TestingFinal evaluation

Overfitting: the model is excellent on training data but fails on unseen examples. The validation set exposes this.

CIFAR-10: 60,000 colour images (50,000 train, 10,000 test), 32×32 RGB, 10 classes (0 airplane, 1 automobile, 2 bird, 3 cat, 4 deer, 5 dog, 6 frog, 7 horse, 8 ship, 9 truck).

PyTorch data conventions: a Dataset stores samples and labels; a DataLoader feeds them into the network.

Transforms (torchvision.transforms) adjust data before it enters the model. Compose chains them; Resize((H, W)) rescales; ToTensor() converts to a tensor; Normalize(mean, std) normalizes per channel. Training and test transforms may differ (here only training is resized).
