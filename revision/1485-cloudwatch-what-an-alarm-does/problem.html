What an alarm does AWS CloudWatch

AWS CloudWatch › 11. Alarms › What an alarm does

An alarm watches a metric against a threshold and triggers actions or notifications, so nobody has to check the console by hand. It can be set on any metric. Beyond notifications it can act: shut down unused resources, or scale an EC2 Auto Scaling group (add instances above a CPU threshold, remove them below). This keeps performance and cost balanced.
