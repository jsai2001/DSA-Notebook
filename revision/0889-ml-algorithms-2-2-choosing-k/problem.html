ML Algorithms › 2. Clustering: K-Means, Choosing K, Interpreting Clusters › 2.2 Choosing K

Choosing K is judgment, not a formula. For Iris the elbow suggests 3-4 clusters and the silhouette suggests 2. When several values score about the same, choose the simpler model (fewer clusters). You must be able to explain and justify the K you chose, using domain context as well as the metrics.

Notebook variant on the Australian electricity data: the same elbow loop runs on X = elec.drop(columns=['class']), and the silhouette loop uses silhouette_visualizer(km, X.sample(1_000, random_state=42), ...). Sampling matters because the full run takes about 2 min 20 s. The elbow suggested about 5 clusters. Silhouette favoured 4 but 5 was close, so 5 was chosen.
