A tensor is PyTorch's core data structure: a multi-dimensional array whose elements share a single data type. It holds inputs, intermediate representations and outputs. Real-world data (e.g. images) is encoded into tensors; each intermediate representation is a set of floats produced by multiplying the input with the previous layer's weights.
