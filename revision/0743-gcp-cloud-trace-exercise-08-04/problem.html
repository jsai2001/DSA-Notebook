Cloud Trace (Exercise 08_04) Google Cloud (GCP)

Google Cloud (GCP) › 9. Operations Tools: Logging, Debugger, Trace › Cloud Trace (Exercise 08_04)

  • Traces requests to find bottlenecks. It samples a subset of requests. Works out of the box on App Engine and can be set up elsewhere, even outside GCP.
  • Overview page: Insights (improvement tips), Recent Traces, Most Frequent URIs (keep latency low on these), Most Frequent RPCs, Chargeable Trace Spans (free tier: first 2.5 million spans), Daily Analysis Reports (latency vs previous week).
  • Trace list: filter by time range, minimum latency, status, version. Each trace shows spans, which show which part of the code took longest, and links to the full log entry in the Logging Viewer.
  • Daily analysis reports are automatic. Custom reports are made with Create a Report.
