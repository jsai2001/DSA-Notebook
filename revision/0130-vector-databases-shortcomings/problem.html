  • Compute-heavy: CPU-intensive similarity math; may need GPUs (GPU_IVF_FLAT).
  • Memory rule of thumb: 1M vectors x 768 dims x 4 bytes ~ 3 GB, plus 30-50% index overhead (~4.5 GB).
  • Not suited for financial transactions, inventory, critical state updates.
