Database with Python › 2. SQLite with Python › Filter with a parameterized query

Pass the filter value as a tuple with a ? placeholder. A tuple is used so the driver binds the value safely, which prevents SQL injection. Building the query with string concatenation ("... WHERE year = " + str(year)) is a security risk.

The same placeholder technique applies to UPDATE, DELETE and executemany. Wrap frequent queries in functions with error handling, or use an ORM to avoid hard-coded SQL strings.
