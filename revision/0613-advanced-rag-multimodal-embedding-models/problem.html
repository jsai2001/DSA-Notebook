Advanced RAG › 10. Multimodal RAG › Multimodal embedding models

They embed several data types using internal per-type functions (different preprocessing, different model parts trained on different data). Usually trained on pairs (image + text most common).

ModelSourceDescription
CLIPOpenAITwo encoders (image + text), open source

CLIP = Contrastive Language-Image Pretraining (most popular; free, open source, on Hugging Face):

  • Contrastive: trained on pairs; both encoders pull matching pairs close and push unpaired combinations far apart.
  • Language-Image: separate text and image encoders, but vectors land in the same embedding space with the same dimensionality.
  • Pretraining: 400 million internet image-text pairs.
