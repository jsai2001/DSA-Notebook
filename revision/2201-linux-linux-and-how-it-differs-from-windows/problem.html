Linux › 1. Linux Basics › Linux and how it differs from Windows

Q. What is Linux, and how does it differ from Windows? Linux is an open-source, Unix-like OS that is customizable and free. Windows is proprietary. Linux has open code, no license cost, a hierarchical file system (ext4 vs. NTFS) and a CLI focus (Bash vs. PowerShell).

Q. Linux kernel vs. distribution? The kernel is the core OS that manages hardware and processes. A distribution is the kernel plus tools and software (Ubuntu, Fedora). Distros differ in packages and package managers.

Q. Monolithic vs. microkernel? Monolithic (Linux): everything runs in the kernel, which is fast. Microkernel (QNX): minimal kernel, modular, slower.
