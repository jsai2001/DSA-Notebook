1. Big Picture Azure AI Services

Azure AI Services › 1. Big Picture

  • Azure AI Services = pre-built AI APIs. No AI background needed; you only call an API (REST or SDK for .NET, Node.js, Python). Course code is Node.js.
  • Services: Vision, Speech, Language, Search, Content Safety, Translator, Document Intelligence, plus Azure AI Foundry for building with models.
  • Common pattern for every service demo:
    1. Create the resource in Azure Portal (Free tier is fine for dev).
    2. Resource Management -> Keys and Endpoint: copy a key and the endpoint (or region). Two keys exist so you can rotate one without downtime.
    3. Put key/endpoint in .env, load with dotenv, call the SDK client.
