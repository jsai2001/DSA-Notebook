Hugging Face Transformers › 4. Natural Language Generation › Machine translation

Translates with attention to context, not word-for-word. Typical architectures: GPT-3 and T5. Challenges: many languages and variants, and large models (smaller custom models can be built for narrow cases). Applications: real-time speech translation, enterprise documents, multilingual customer service, multilingual text analytics.

Here an explicit tokenizer and model are used instead of the translation pipeline, which helps when a tokenizer/model combination is not supported by the pipeline. Model: t5-base. T5 is text-to-text: one model does summarization, QA, and translation, chosen by a task prefix on the input.

  • return_tensors="pt": PyTorch tensors. input_ids: IDs into the embedding matrix. max_length: output token limit. skip_special_tokens=True: strips <pad>, </s> from the output.
