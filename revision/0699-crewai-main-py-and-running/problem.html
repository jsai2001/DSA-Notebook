main.py and running CrewAI

CrewAI › 11. Project: Technical Writing Crew › main.py and running

main.py has four functions, each runnable through the CLI:

CLIFunctionPurpose
crewai runrun()Run the full workflow
crewai traintrain()Train with feedback to improve outputs
crewai replayreplay()Jump to a specific task and replay from there
crewai testtest()Run N iterations with performance metrics

TechnicalWritingCrew() creates the class, .crew() returns the Crew, .kickoff(inputs=) starts the workflow.

Flow: researcher (web search, notes) > strategist (outline) > writer (full draft, the longest step) > editor (review) > editor (format) > technical_article.md.
