Django › 3. Models, Migrations and ORM › Adding a field to an existing model (likes)

Field choice: IntegerField (about ±2 billion) is oversized and allows negatives. PositiveSmallIntegerField (0 to 32,767) fits a likes counter and needs no negative-value validation.

default=0 gives existing rows a value. Then run makemigrations (creates 0002_notes_likes.py, depends on 0001) and migrate.
