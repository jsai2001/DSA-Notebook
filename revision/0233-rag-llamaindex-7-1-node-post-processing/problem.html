RAG with LlamaIndex › 7. Advanced RAG: Post-Retrieval & Other Techniques › 7.1 Node post-processing

A node postprocessor takes the retrieved nodes, transforms or filters them, and returns them, after retrieval and before response synthesis. All subclass BaseNodePostProcessor, so they share one usage pattern. They plug into a query engine, not into as_retriever().
