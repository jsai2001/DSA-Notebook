Stack: FLAN-T5 (Google's instruction-tuned T5), Hugging Face transformers/datasets, TensorFlow/Keras, LoRA/PEFT, Flask, Google Colab (free GPU, allocation varies).

Pipeline: pre-trained model → load dataset → tokenize → freeze layers (or add LoRA) → train with validation → evaluate (ROUGE/BLEU) → deploy.

Version gotchas (not in the lectures): datasets.load_metric is removed in newer datasets (use evaluate); tokenizer.as_target_tokenizer() is deprecated for text_target=; the notebooks import tf_keras for the optimizer because of the Keras 3 split.
