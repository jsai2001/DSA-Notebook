6. Content Safety Azure AI Services

Azure AI Services › 6. Content Safety

Detects and flags harmful content.

CapabilityDescription
Prompt ShieldsScans user input to LLMs to block crafted inputs (jailbreaks) that coax harmful output
Protected Material DetectionText and code; for code, detects if it was lifted from existing GitHub repos
Analyze TextSeverity scores for Hate, Self-Harm, Sexual, Violence
Analyze ImageSame four categories for images
Groundedness DetectionChecks LLM responses are grounded in the supplied sources; domains (medical, generic), tasks (Q&A, summarization); detailed explanations of ungrounded parts cost speed
Custom CategoriesDefine categories, label data, train; a rapid version answers quickly without full retraining

Text is scored on all four categories at once, so it can be both sexual and violent.
