RecursiveRetriever is not created via index.as_retriever(): it is a standalone class that takes a root id plus dicts of retrievers/query engines/nodes, follows links, deduplicates nodes, and returns them. RetrieverQueryEngine wraps a retriever, applies postprocessing, and synthesizes the answer.
