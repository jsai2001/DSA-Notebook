!Ref vs !GetAtt AWS CloudFormation

AWS CloudFormation › 4. Parameters, Outputs and Intrinsic Functions › !Ref vs !GetAtt

FunctionSyntaxReturns
!Ref!Ref ResourceNameUsually the ID of the resource (instance ID, bucket name); a parameter's value for parameters
!GetAtt!GetAtt Resource.PropertyAny attribute of the resource (bucket ARN, VPC CidrBlock, public IP)

Sometimes the logical ID can only be obtained with !Ref. Use !GetAtt for a specific property, and check the AWS docs for the attributes each resource type offers.
