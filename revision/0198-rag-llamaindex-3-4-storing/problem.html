3.4 Storing RAG with LlamaIndex

RAG with LlamaIndex › 3. LlamaIndex Fundamentals › 3.4 Storing

By default an index lives in memory. Re-indexing costs time and money, so persist it. The simplest option is index.persist() to disk; the course uses a vector database (Qdrant).

Steps: initialize Qdrant client → create a vector store bound to a collection → assign it to a StorageContext → build the index from that context.

StorageContext tells LlamaIndex where to put each kind of data: vector_store (embeddings), docstore (nodes/documents), index_store (index metadata), graph_store (knowledge graphs). The Qdrant dashboard shows the collection, vector dimension (1536 here), a visualization tab, and "Find Similar".
