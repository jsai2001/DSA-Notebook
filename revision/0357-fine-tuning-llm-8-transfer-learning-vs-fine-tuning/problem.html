Transfer learningFine-tuning
AnalogyChef adapting existing skills to a new kitchenChef learning an entirely new cuisine
TechnicalPre-trained model + new task-specific head; base mostly frozenUpdate all weights and biases on the new dataset
ApproachKeep structure intact, train only new componentsFurther train the whole model
Use whenSimilar tasks, little data/compute, quick adaptation, prototypingDifferent task/domain shift, large dataset, maximum accuracy, specialised domain

Decision rule from the lecture (high task similarity + small data → frozen transfer; medium similarity + high compute → progressive fine-tuning; low similarity + large data → full fine-tuning; otherwise partial transfer):

Success factors: model pre-trained on a similar domain; freeze according to task similarity; lower learning rate when fine-tuning; start frozen, then unfreeze gradually; quality labelled data; compare against a baseline.
