Adding an SSH agent Jenkins

Jenkins › 8. Agents and Distributed Builds › Adding an SSH agent

Prerequisites: a server reachable by SSH from Jenkins, and a user and key (for example an EC2 instance).

  1. Manage Jenkins, Manage Nodes and Clouds, New Node. Name it (for example Linux) and choose Permanent Agent.
  2. Set the remote root directory (for example /home/ec2-user) and a label such as linux.
  3. Usage: "Only build jobs with label expressions matching this node".
  4. Launch method: Launch agents via SSH; Host: DNS name or IP.
  5. Credentials: Add, Jenkins, "SSH Username with Private Key", ID linux, username ec2-user, paste the full private key (no passphrase in the example).
  6. Host Key Verification Strategy: Non verifying (used in the course). Availability: keep the agent online as much as possible. Save to connect.
  7. Check the agent's Log for errors and confirm it is online.

Build Now, then check Console Output for the message showing the job ran on the linux agent and its workspace path. Private repositories need Jenkins credentials; the public exercise repo does not.
