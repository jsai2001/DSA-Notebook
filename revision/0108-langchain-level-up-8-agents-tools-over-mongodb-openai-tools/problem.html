LangChain Level Up › 8. Agents & Tools over MongoDB (OpenAI Tools Agent)

Agents use an LLM with function calling to choose among tools (Python functions) and call them. Here: Tool 1 = MongoDB Atlas vector search over PDF docs; Tool 2 = web search over an HTML page (WebBaseLoader). The agent picks the tool from the query and tool descriptions, and can fall back to the web when the vector index lacks the answer.
