AWS CloudWatch › 8. CloudWatch Agent › Linux setup: configuration wizard

Wizard answers used in the course:

  • OS Linux, running on EC2, default user.
  • StatsD: yes, default port, collect interval 10 or 60 seconds.
  • CollectD: yes (needs its own install).
  • Host and CPU metrics: yes. EC2 dimensions: yes, aggregate by instance ID.
  • Resolution: normal 60 seconds (high resolution costs more). Default metric configuration.
  • Monitor log files: no (when the app writes no local logs).
  • Store config in SSM Parameter Store: yes, name AmazonCloudWatch-linux, confirm region (for example us-east-1), use the SDK option.
