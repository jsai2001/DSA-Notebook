Memory and exit codes Docker

Docker › 12. On-Call: Container Failures › Memory and exit codes

Q. Container exits with code 137? It is an out-of-memory (OOM) kill.

Check host memory (free -m), application leaks, or adjust --memory-swap.

Q. Container fails: "cannot allocate memory"?

Check for memory leaks, make sure the host has memory, and adjust swap settings.
