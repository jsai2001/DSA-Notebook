6. Logistic Regression ML Algorithms

ML Algorithms › 6. Logistic Regression

Despite the name, this is a classification algorithm. It fits a sigmoid (S-shaped) curve and outputs a probability: above 0.5 predicts class 1, below predicts class 0.

$$y = \frac{1}{1 + e^{-z}}$$

z is the linear combination of features (as in linear regression) and y is the probability.
