RESTful API › 1. Course Overview and the Planetary API

  • Flask is a Python microframework for web apps and APIs. It gives essential features without forcing infrastructure choices, and has a large plugin ecosystem.
  • The course covers authentication, database access, ORM, routing, Flask plugins, testing, and deployment to a cloud server.
  • An API receives requests and returns JSON. JSON is preferred over XML or custom formats because it needs no parsing and is supported natively by Python and most languages.
  • Prerequisites: basic Python 3, and how web apps work (form posts, request/response).
  • Tools: PyCharm (Professional has Flask tooling; Community works with manual venv/pip), Postman (tests all HTTP verbs), DB Browser for SQLite (inspect the DB file).
  • Database: SQLite. It is file-based and needs no server, which avoids PostgreSQL/MySQL setup.
