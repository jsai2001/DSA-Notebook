Azure AI Services › 9. Azure AI Foundry (AI Studio) and Azure OpenAI › Key features

  • Model catalog: OpenAI (GPT), Microsoft (Phi), Meta (Llama), Google (Gemma), and more.
  • Model benchmarks: select several models and compare on GPT similarity, cost, accuracy, etc.
  • Prompt catalog: templates such as Defect Detector (finds defects against a reference image), Natural Language to SQL, Summarization.
  • AI Services integration: e.g., use Content Safety to keep competitor information out of LLM answers, Translator to accept any input language, Vision/Speech/Language alongside LLMs.
