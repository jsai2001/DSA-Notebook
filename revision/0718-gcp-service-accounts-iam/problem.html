Service accounts (IAM) Google Cloud (GCP)

Google Cloud (GCP) › 5. Cloud SQL and Service Accounts › Service accounts (IAM)

  • A service account is a user-like identity for applications. Two kinds: user-created and Google-managed (no functional difference).
  • App Engine's default account is <project-id>@appspot.gserviceaccount.com. To let the app use another service (e.g. Cloud SQL), add a role to this account via IAM & Admin, IAM, Edit, Add Another Role (e.g. Cloud SQL Client; Cloud SQL Editor or Admin also work).
  • Create a new one under Service Accounts: name, ID, description, then roles, optionally grant users access.
  • Keys: Add Key, Create New Key, JSON. The file downloads once, so treat it as a secret.
  • Disable is temporary and reversible. Delete is permanent.
