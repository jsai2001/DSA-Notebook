Flask CLI commands: create, drop, seed RESTful API

RESTful API › 4. Database with SQLAlchemy: Models and Seeding › Flask CLI commands: create, drop, seed

The Flask CLI (1.0+) runs custom commands registered with @app.cli.command. db.create_all() builds tables from the models. db.drop_all() removes them.

  • db.session.add() stages a record and db.session.commit() persists it. Without commit, nothing is saved (the lesson hit this bug).
  • DB Browser for SQLite: Open Database, pick planets.db, check the users and planets tables with Browse Data. It does not auto-refresh. After db_drop the file can remain with no tables.
