For simple actions with no input or validation, a function-based view can be simpler.

  • get_object_or_404 returns the object or raises 404. reverse('name', args=(pk,)) resolves a named URL in Python. HttpResponseRedirect redirects.
  • Only POST may change data; GET must never modify state. So the button is a POST form (not an <a> link), with {% csrf_token %}.
