Advanced RAG › 8. Image Embeddings and Vision Models › Two types of image vectors

TypeCapturesCreated byUsed in RAG?
Semantic embeddingsThe meaning of the imageDeep learning model's second-to-last layer✅ Yes
Visual / pixel embeddingsWhat the image literally looks likeCompressed image input vector (e.g. PyTorch model input)❌ Not typically

Semantic: image → input layer → hidden layers → output (prediction); the second-to-last layer holds the learned meaning, and that is the embedding. Pixel embeddings are also long number lists but encode raw pixels, not meaning. RAG uses semantic embeddings.
