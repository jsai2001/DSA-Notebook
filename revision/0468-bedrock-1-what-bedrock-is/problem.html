1. What Bedrock Is Amazon Bedrock

Amazon Bedrock › 1. What Bedrock Is

Amazon Bedrock is a fully managed AWS service with a unified API to many foundation models (FMs) from different providers (Anthropic Claude, Amazon Titan, Mistral and others). No infrastructure to manage. You can pick model variants, fine-tune, and use everything through one API.

The console is the fastest way to learn new features: experiment there first, code later.

Cost optimization is a recurring theme: move an expensive prompt from a high-cost model to a cheaper one with equivalent results (see section 4).
