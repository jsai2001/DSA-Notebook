Load balancing, DNS and filtering AWS

AWS › 4. Networking › Load balancing, DNS and filtering

Q. What is an Elastic Load Balancer and what are its types? It distributes traffic: ALB (HTTP), NLB (TCP/UDP), CLB (legacy).

Q. What is Amazon Route 53? A DNS service that resolves domains and offers failover and latency routing.

Q. Security Group vs. Network ACL?

  • Security Group: stateful, instance-level.
  • NACL: stateless, subnet-level.

Q. How do you troubleshoot VPC connectivity? Check routes, Security Groups, NACLs, Flow Logs and IP assignment.
