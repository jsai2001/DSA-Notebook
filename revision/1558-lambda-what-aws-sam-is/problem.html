What AWS SAM is AWS Lambda

AWS Lambda › 10. Infrastructure as Code and AWS SAM › What AWS SAM is

AWS SAM (Serverless Application Model) is an open-source framework for building serverless applications, built on CloudFormation. Q95. How does SAM extend CloudFormation? It offers a shorthand syntax: Transform: AWS::Serverless-2016-10-31 expands concise resources such as AWS::Serverless::Function, Api and Table into full CloudFormation at deploy time. The SAM CLI adds build, local testing (local invoke, start-api), guided deploy and logs. You can still drop to raw CloudFormation for anything SAM does not cover.

Components:

  1. SAM transform templates: YAML with simplified syntax for Lambda, API Gateway and DynamoDB.
  2. SAM CLI: deploys templates, tests locally, integrates with CI/CD.

Features:

  • SAM Local: test and debug locally, emulating Lambda and API Gateway.
  • SAM Accelerate: faster development with sam sync, parallel updates without full redeploys and aggregated logs.
  • CI/CD integration: CodeBuild, CodeDeploy and CodePipeline, with sam pipeline init.
