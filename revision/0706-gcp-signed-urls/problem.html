Signed URLs Google Cloud (GCP)

Google Cloud (GCP) › 6. Cloud Storage (GCS) › Signed URLs

  • A signed URL gives temporary access to a private object. Flow: user asks the app, the app signs a URL using a service account, user fetches the object directly from GCS.
  • V4 URL parts: object path, signing algorithm, credentials, start date (can be in the future), expiry (seconds from start, up to 7 days), signed headers, signature.
  • Needs a service account with at least Storage Object Viewer (storage.objects.get) and its downloaded private key.
  • Locally you must pass the key file. On GCP the default service account is used automatically.
  • Signed upload URLs: same code with action: 'write'.
