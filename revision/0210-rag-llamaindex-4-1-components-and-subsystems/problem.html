4.1 Components and subsystems RAG with LlamaIndex

RAG with LlamaIndex › 4. Introduction to RAG: Pipelines, Prompts, Data Prep › 4.1 Components and subsystems

RAG = retrieve context from external data → add it to the prompt → generate with the LLM.

ComponentRole
LLMGenerates the answer from the augmented prompt
Prompt / user inputThe query that starts the pipeline; template that combines query + context
Document loaderReads raw data into Documents
Chunker (node parser)Splits documents into manageable chunks
Embedding modelTurns chunks and queries into vectors
Vector storeStores and indexes embeddings
RetrieverFetches relevant chunks by vector similarity
SubsystemSteps
IndexingLoad → chunk → embed → store embeddings
RetrievalEmbed the query (same embedding model) → vector search → relevant chunks
Augment & generateBuild prompt (query + context) → LLM → response
