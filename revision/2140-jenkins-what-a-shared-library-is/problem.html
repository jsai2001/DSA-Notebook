Jenkins › 9. Shared Libraries and Groovy › What a Shared Library is

Q. What is a Shared Library, and why use it in enterprises? A versioned Git repo of reusable pipeline code (steps, helpers, classes) that many Jenkinsfiles import. It enforces DRY, standardizes CI/CD across teams (one place to fix or upgrade), hides complexity behind simple custom steps and keeps each Jenkinsfile tiny.

Q. What is the structure of a Shared Library?

  • vars/: global custom steps and variables; each foo.groovy becomes a callable step foo(...).
  • src/: Groovy classes in package folders for OOP-style helper logic.
  • resources/: non-Groovy files (templates, JSON, scripts) loaded with libraryResource.
