Q1. What is boto3 and how does it talk to AWS? The official AWS SDK for Python. It gives a Pythonic interface to AWS APIs (EC2, S3, Lambda and more). It sends HTTP requests signed with your credentials, and botocore does the low-level work.

Q2. boto3.client vs boto3.resource

clientresource
LevelLow-level, maps 1:1 to the API; returns raw dicts/JSONHigher-level, object-oriented (buckets, instances as Python objects)
CoverageAll API operationsSimpler, but not every service or operation
Use whenYou need precise control or the resource abstraction is missingCommon tasks, readable code

Q3. How does boto3 authenticate? Credential sources, in resolution order:

  1. Environment variables (AWS_ACCESS_KEY_ID, AWS_SECRET_ACCESS_KEY, AWS_SESSION_TOKEN).
  2. Credentials file (~/.aws/credentials).
  3. IAM roles for EC2 instances or ECS tasks.
  4. AWS CLI SSO or temporary credentials from STS.

You can also pass credentials explicitly in code or select a named profile (Q19).

Q4. Which services can boto3 manage? Most of them:

  • Compute: EC2, Lambda, ECS, EKS
  • Storage: S3, EBS, Glacier
  • Database: DynamoDB, RDS, Redshift
  • Networking: VPC, Route 53, ELB
  • Messaging: SNS, SQS, SES
  • Monitoring: CloudWatch, CloudTrail
  • Management: IAM, CloudFormation, SSM

Q5. Pagination. Use paginators. They follow NextToken (or the equivalent marker) automatically.
