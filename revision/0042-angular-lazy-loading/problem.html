Lazy loading Angular

Angular › 13. Routing and Navigation › Lazy loading

Loading modules or components only when a route is first visited is Angular's default for routes (loadChildren / loadComponent). It uses a dynamic import:

The arrow function returns a Promise, import() loads an ES module asynchronously, and .then extracts the exported class.

  • Upside: faster first load, smaller initial bundle.
  • Downside: network lag on first navigation to a page, noticeable on slow connections.
