Resources, resource groups, management groups AZ-900

AZ-900 › 5. Core architecture: regions, zones, resources › Resources, resource groups, management groups

  • Resource: any entity you create (VM, web app, database, storage).
  • Resource group (RG): a logical container. Every resource is in exactly one RG.
    • Benefits: per-group cost view, delete the group to delete everything, tag the group and filter invoices by tag, export as an ARM template to redeploy elsewhere.
  • Management group: organizes subscriptions. It can contain subscriptions and other (nested) management groups, but not resource groups or resources.

Hierarchy: Management groups → Subscriptions → Resource groups → Resources. Organize by department, project or environment as you like.
