12.1 PEFT in one view Fine-Tuning LLMs

Fine-Tuning LLMs › 12. PEFT & LoRA Concepts › 12.1 PEFT in one view

Parameter-Efficient Fine-Tuning (PEFT) modifies a small subset of parameters (or adds small modules) instead of retraining the whole model, getting strong task performance with limited data and compute.

Analogy: full fine-tuning = reworking the recipe; transfer learning = adding a sauce (new head); PEFT = specialised tools (adapters) that enhance the dish without altering the recipe.

Traditional fine-tuningTransfer learningPEFT
Parameters updatedAllNew layers + some base layersSmall adapter modules only
Data neededLargeMediumSmall
Compute / training timeHigh / longMedium / mediumLow / fast
Storage per taskFull model copyModified model per taskBase model + small adapters

Advantages: works with limited data, lower cost, faster training, one shared base model with swappable per-task adapters. Lecture rules of thumb: ~0.1–1% of parameters trained, ~10x faster, ~5x less memory, 95–99% of full fine-tuning quality. Use PEFT when compute or data is limited, you serve many tasks from one model, or you are prototyping.
