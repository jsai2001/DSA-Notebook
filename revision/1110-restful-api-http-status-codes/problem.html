HTTP status codes RESTful API

RESTful API › 3. Returning JSON, Status Codes, URL Parameters and Variables › HTTP status codes

  • Status codes are response metadata saying whether the request worked. Clients (web, mobile, desktop) branch on them.
  • 200 OK, 401 Unauthorized, 404 Not Found. 400-499 are client errors, 500-599 are server errors.
  • Flask defaults to 200. Return a tuple to change it: return jsonify(...), 404. Setting 200 explicitly is optional but clearer.
