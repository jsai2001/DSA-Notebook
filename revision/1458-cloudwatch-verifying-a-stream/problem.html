Verifying a stream AWS CloudWatch

AWS CloudWatch › 5. Metric Streams › Verifying a stream

Generate traffic (for example 100 requests). Check the stream status and destination, then the Firehose metrics (Incoming Bytes, Put Requests, Incoming Records, Data Sent to S3), then the S3 bucket. Data is batched, so it can take 1-2 minutes to appear, and the Firehose may need about 5 minutes to become fully active. Make sure the app is running and the IAM roles for Firehose and S3 are correct.
