Jenkins › 10. Artifacts, Fingerprints and Test Reports › Fingerprinting

Fingerprinting tracks which jobs created or used an artifact. Jenkins computes an MD5 checksum for each artifact and stores it with the job details in an internal database. fingerprint: true on archiveArtifacts records creation, and fingerprintArtifacts: true on copyArtifacts records each use. In the UI open a build, choose See Fingerprints, and click the artifact (for example report.txt) to see the MD5 value and the jobs that used it.
