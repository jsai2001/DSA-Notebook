Azure Resource Manager (ARM) and ARM templates (1/2) AZ-900

AZ-900 › 11. Managing and deploying resources › Azure Resource Manager (ARM) and ARM templates

ARM is the layer that creates and manages all Azure resources. It is declarative (you say what, not how), and every tool (Portal, PowerShell, CLI, Visual Studio) goes through it, so results are consistent.

ARM templates are JSON files declaring what ARM should do, for repeatable and predictable deployments. Sections: $schema (template language version), contentVersion, parameters (values at deploy time), variables (reusable values), resources, outputs (values returned).
