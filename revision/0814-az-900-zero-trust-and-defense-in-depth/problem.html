Zero Trust and defense in depth AZ-900

AZ-900 › 8. Identity, access and security › Zero Trust and defense in depth

Zero Trust assumes every access is a breach. It covers endpoints, data, apps, infrastructure and network. Apps must be designed for the lowest access necessary.

PrincipleImplementation
Verify explicitlyMFA for every user
Least-privilege accessGrant the minimum needed
Assume breachConditional Access to secure the environment

Defense in depth is layered protection, so a breach of one layer is still caught by others (castle doctrine). Outer → inner:

LayerAzure equivalentCastle
PhysicalData center securityStone walls
Identity and accessAzure AD, MFA, Conditional AccessGate with guards
PerimeterDDoS protection, firewallsMoat
NetworkNSGs, VNet segmentation, private endpointsHigh walls
ComputeVM security, patching, endpoint protectionArchers
ApplicationSecure coding, vulnerability scanningInner defenses
DataEncryption at rest and in transit, access controlsSoldiers guarding the vault
