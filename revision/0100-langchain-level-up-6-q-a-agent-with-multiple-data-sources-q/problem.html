LangChain Level Up › 6. Q&A Agent with Multiple Data Sources & Query Analysis

Query analysis is an intermediate step that inspects the user's question, decides which data source (retriever) to use, and produces a structured output feeding retrieval/generation. It relies on function calling (the LLM makes decisions and returns schema-conformant output) and Pydantic (defines the schema).
