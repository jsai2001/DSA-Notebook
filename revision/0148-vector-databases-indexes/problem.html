Vector Databases › 6. Partitions and indexes › Indexes

  • Speed up retrieval. One index per field; no composite indexes. Scalar indexes (RDBMS-like) and vector indexes (ANN).
  • A vector index must exist and the collection must be loaded before vector search.

nlist / nprobe trade-off

SettingEffect
Higher nlistfaster search, lower recall (use for large datasets: 4096+)
Lower nlistslower, higher recall (small datasets: 128-512); 1024-2048 general
Higher nprobebetter recall, slower (5 = fast, 10 = balanced, 20 = higher recall)

Same metric_type must be used for the index and the search.
