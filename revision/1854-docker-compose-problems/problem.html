Docker › 17. On-Call: Compose and Swarm Problems › Compose problems

Q. Docker Compose "service not found" error? Check docker-compose.yml for the service definition, validate syntax (docker-compose config), and restart (docker-compose up -d). Verify service names, file paths and the Compose version.

Q. Compose service communication failure? Verify the network (docker network inspect <network>), test connectivity (docker exec <container> ping <service>), and ensure service names resolve. Check DNS, firewall and network configuration.

Q. Compose ignores environment variables? Verify docker-compose.yml (env_file or environment), check the container (docker inspect <container> | grep Env), and restart (docker-compose up -d). Validate variable syntax and avoid overrides.

Q. Compose crashes due to resource limits? Check limits (docker inspect <container>), adjust docker-compose.yml (mem_limit: 512m, cpus: 0.5), and restart (docker-compose up -d). Monitor resource usage and balance limits.

Q. Compose file startup errors? Validate syntax (docker-compose config), check logs (docker-compose logs), fix errors, and restart (docker-compose up -d). Verify service dependencies and image availability.
