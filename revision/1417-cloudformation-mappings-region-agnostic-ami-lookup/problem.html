Mappings: region-agnostic AMI lookup AWS CloudFormation

AWS CloudFormation › 9. Web Server Template with Mappings (JSON) › Mappings: region-agnostic AMI lookup

Two lookup tables find the right AMI ID.

  1. AWSInstanceType2Arch maps instance type to architecture (for example m3.medium to HVM64).
  2. AWSRegionArch2AMI maps region plus architecture to an AMI ID.

The user picks an InstanceType, mapping 1 gives the architecture, and mapping 2 combined with the region gives the AMI ID. The region comes from the pseudo-parameter AWS::Region, so the template works in any region.
