User cannot view metrics AWS CloudWatch

AWS CloudWatch › 19. Troubleshooting Permissions and Configuration › User cannot view metrics

Q. A user cannot view CloudWatch metrics. What is missing? IAM permissions such as cloudwatch:GetMetricData and cloudwatch:ListMetrics.

Add the permission under IAM > Users > user-name > Permissions, then test in CloudWatch > Metrics.
