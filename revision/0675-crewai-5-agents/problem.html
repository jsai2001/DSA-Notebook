CrewAI › 5. Agents

An agent is a single autonomous unit built for one specific problem. Design principle: one agent = one focused responsibility (e.g. Tax Auditor vs Tax Filer; Deal Finder vs Inventory vs Delivery agent).

Capabilities: perform a specific task, make decisions guided by role and goal, use tools, collaborate with other agents, use memory of past communications.

Agent role in a crew: the action takers and the only autonomous component, powered by an LLM. Each agent can be given a different LLM.
