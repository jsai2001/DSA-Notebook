Environment variables and web server setup Linux

Linux › 5. Advanced Linux Topics › Environment variables and web server setup

Q. What are environment variables and how do you set them? Key-value pairs such as PATH. Set with export VAR=value. Make permanent in ~/.bashrc.

Q. How do you configure Linux as a web server? Install Apache (apt install apache2), start it (systemctl start), set /var/www/html and allow port 80 (ufw).
