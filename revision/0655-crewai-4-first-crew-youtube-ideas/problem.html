CrewAI › 4. First Crew: YouTube Ideas

Two agents (idea generator, idea filter), two tasks, sequential process. Task 1 output feeds Task 2. Default LLM is OpenAI GPT-4, so set the key first.

  • The four core imports: Agent, Task, Crew, Process.
  • {topic} is a dynamic variable. kickoff(inputs={...}) fills it, which makes tasks reusable.
  • verbose=True shows each agent's reasoning.
  • Output: 3-5 filtered ideas, each with reasoning.
