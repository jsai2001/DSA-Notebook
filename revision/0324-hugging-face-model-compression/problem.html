Model compression Hugging Face Transformers

Hugging Face Transformers › 6. Deploying Models in Production › Model compression

Goal: smaller trained model for production. Two routes: fewer layers, nodes, and parameters; or smaller storage types (FLOAT32 to integers). Both cut math operations, memory, and compute.

TechniqueDescription
QuantizationConverts floats to smaller types such as integers. Supported out of the box by most frameworks
PruningRemoves selected nodes and connections
Low Rank ApproximationReduces data dimensions by dropping unneeded information
Knowledge DistillationAdvanced. Shrinks the model while retaining learned knowledge (DistilBERT, DistilBART)
Neural Architecture SearchFinds the best architecture for a problem (compute intensive)

After compression, retest on the original test/validation data. Start with quantization and pruning before the advanced options, which need more time and expertise.
