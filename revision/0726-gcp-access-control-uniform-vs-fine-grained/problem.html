Access control: Uniform vs Fine-grained Google Cloud (GCP)

Google Cloud (GCP) › 6. Cloud Storage (GCS) › Access control: Uniform vs Fine-grained

ModeDescriptionNotes
UniformBucket-level permissions, all objects inheritRecommended, tends to cost less
Fine-grainedPer-object permissions (ACLs), one object public while another is privateRiskier, needs extra attention
  • Switch under the bucket's Permissions tab. Warning: switching back to fine-grained restores previously set object ACLs, which may grant wider access than the bucket IAM policy.
  • Uniform, make all objects public: Add allUsers with role Storage Object Viewer, then Allow public access. Remove that permission to make them private again. Per-object "Edit permissions" disappears under uniform.
