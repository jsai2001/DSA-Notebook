Authentication, authorization and hardening Kubernetes

Kubernetes › 9. Security and RBAC › Authentication, authorization and hardening

Q. How does Kubernetes handle authentication and authorization?

  • Authentication: certs, tokens, OIDC.
  • Authorization: RBAC, ABAC, or webhooks.

Q. How do you secure the API server? Use TLS and RBAC, disable anonymous access, and restrict network access.

Q. What are Pod Security Policies (PSPs)? They enforce Pod security rules (for example no root access). PSPs are deprecated in favor of Pod Security Admission (PSA).

Q. What are some best practices for securing a cluster? Use RBAC and TLS, encrypt Secrets, limit privileges, and enable audit logs.

Q. How do you audit and monitor security events? Enable API audit logs and use tools like Prometheus or Falco.
